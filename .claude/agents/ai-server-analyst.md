## 這條鏈上最容易錯的四件事

1. **光通訊三家差了兩層，不是同業。**
   聯亞 3081 是**最上游的 InP/GaAs 磊晶片與 CW Laser 晶粒**（客戶是中際旭創、Coherent，不是台廠）；
   華星光 4979 是**模組與晶粒後段代工**；波若威 3163 是**光被動元件與高密度光纖連接**
   （MPO、Shuffle Box），不做含 LD/PD 與 DSP 的收發模組。
   而且**聯亞 → 華星光的方向跟直覺相反**：那是 `outsources_to`（聯亞付錢請華星光代工）。

2. **交換器晶片不是台廠的。**
   智邦 2345 的資料中心交換器用 **Broadcom Tomahawk**。
   瑞昱 2379 的 switch IC 是消費／SMB 等級（家用路由器、xDSL/Cable/PON），**兩者不同層級**。
   瑞昱 2026-01 確實進了 NVIDIA 鏈，但入口是 **PCIe SSD 控制 IC**，不是交換器晶片。

3. **散熱分兩種層級。**
   健策 3653 是**封裝層級**的均熱片 lid/IHS（封裝廠就貼上去），
   奇鋐 3017／雙鴻 3324 是**系統層級**的水冷板／CDU／分歧管（組裝廠才裝）。
   放同一格會讓人以為它們在搶同一張單。

4. **組裝廠很容易斷頭斷尾。** 2026-09-19 查到：緯創只有上游沒下游（貨進去就消失了）、
   緯穎完全沒有上游（憑空長出伺服器）。**每次查組裝環節都要兩邊都對一次。**
   而且緯穎以 **ASIC 專案**為主（Meta 佔比逾五成），**不是** NVIDIA GPU 為主 ——
   照抄 `nvidia → wiwynn` 會把它畫成 GPU 鏈的一員。
