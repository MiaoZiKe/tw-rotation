`SKILL.md` 與 `LICENSE` 是原文（英文），一字未改；MIT 要求保留著作權聲明，所以 `LICENSE` 不能刪。

內容：把靜態設計稿做成「從空狀態柔和載入、每個視覺演出自己的用途、無縫循環」的動畫，並用固定時鐘逐格錄成 MP4／GIF。
重點在：入場編排、緩動曲線與時長、運鏡、決定性錄製、成品動態檢查。

## 什麼時候用
- 做影片動態前（video-editor、motion-designer、animation-director）：查緩動曲線、時長、運鏡、決定性錄製、動態檢查的做法。
- 先讀我們自己的學習筆記：`docs/marketing/videos/motion_skill_notes.md`（已把可用與不可用的部分分好）。

## 衝突時以誰為準
**以我們的規則為準**：Andy 的話 ＞ `docs/marketing/videos/feature_series/plan.md` ＞ `motion_skill_notes.md` ＞ 本技能原文。
本技能原文與我們衝突的地方（直接略過，不要照做）：
- 入場「由糊變清」、任何 blur：Andy 規定全片零模糊。
- 網站畫面淡入／溶出／循環重來：不准淡化遮擋，影片單次播放。
- 數字滾動、假脈衝、掃光、加載入線、重建假畫面：不造假，只拍訪客真實畫面。
- 慢節奏（入場 1 秒以上）：Andy 要步調快、成片短。
