## 用什麼方法做（ASSET_MODE=raster_first）
全部像素只來自 `default_idle_1011.webp`（Default 原圖），沒有用圓形／橢圓堆角色、也沒有重畫輪廓。

1. **去背＋分層**（2048 工作尺寸＝原圖 ×4）：身體毛球（含波浪毛邊、粗描邊、兩側深色毛斑）、左右耳、腳、
   兩隻眼睛、嘴（含舌頭）、兩顆腮紅。五官挖掉的地方用周圍奶油色 inpaint。
   耳朵、腳拿掉後身體在那幾處缺描邊，用「閉運算＋同尺寸毛邊小圓弧＋同粗細描邊（原圖約 13px／512）」補回。
2. **假 3D 轉身**：毛球近似球，繞垂直軸轉時外輪廓不變 → 身體外框每個姿勢都是原圖那一圈。
   只有貼在球面上的東西會動：
   - 五官：依經度位移（臉轉的角度＝身體的 0.5 倍，側面時臉在前半邊、不會擠到最邊），透視壓縮只取一半，
     大小與正面幾乎一樣；遠側眼睛超過 62° 隱藏、腮紅超過 76° 隱藏。眼距、嘴、腮紅本身不縮放。
   - 耳朵：在頭頂偏後方（經度 ±117°）沿頭頂輪廓滑動、隨輪廓法線轉角度；遠側耳朵往頭裡多收，只露一點。
   - 腳：四隻腳放在身體下方的地面圓上（前腳 ±50°、後腳 ±130°），遠側往上收 7px。
     **四隻腳用同一張腳掌圖**（右腳原圖，左腳＝鏡射），每一格、每一隻都一樣大。
   - 側面時朝前那塊深色毛斑淡出（不然會黏在嘴邊）。
3. **壓縮／拉伸／趴／躺**：身體用「極座標位移變形」，內部等比縮放、外圈只平移不縮放 →
   描邊粗細不變、毛邊不被拉扁、下巴與底部保持圓弧；sx×sy＝1（體積守恆）。五官／耳朵／腳不縮放，只換位置。
4. 2048 合成 → LANCZOS（預乘 alpha）縮成 512 透明 PNG。左版＝右版整張水平鏡像。

## 座標系統（所有姿勢共用，不重新置中）
- 畫布 512×512，透明背景。
- **地面基準線（腳底）y＝485**（接觸表上的紅線），身體水平中心 x≈254。
- 站在地上的姿勢腳底都貼 y＝485；空中姿勢（front_jump 離地 70、side_apex_r 離地 78）整隻往上平移，不改大小。
- 比例尺全部相同：身體面積相對「正面重組版」差 0%（正面、側面、奔跑、起跳、落地）、−0.9%（趴、嗅地）、
  −1.9%（躺）、−2.9%（坐，前高後低的透視）。

## 奔跑步態
對角步態：右前＋左後一組、左前＋右後一組，相位差半拍；步幅 ±14px、抬腳 8px、身體起伏 3px、前傾 2°±1.2°。
身體只做 sx×sy＝1 的 ±1.8% 微擠壓，**身體面積 12 格最大差 0.004%，含耳朵的上半身輪廓最大差 0.02%**。
