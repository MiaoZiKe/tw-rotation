# 比比・wake_once（10-12 四腳天竺鼠版，10 格）

- 依據：Andy 10-12「比比是天竺鼠，他是 4 隻腳的……不可以因為配合互動就改變身體原有設定」。
- 做法：`scripts/anim/bibi_quad.py`（原版 Default 像素本體＋四隻獨立小腳，不畫手）＋`scripts/anim/bibi_quad_moves.py` 關鍵格（ease 補間）。
- 規格：512×512 透明、全身入鏡；成品 160px 動態 WebP（anim.webp）；第 1 格就是動作、最後一格回 Default。
- 播放：播一次（loop=1）；播一次（睡覺時被點）；第 1 格就是嚇一跳彈起（被子往上飛走），伸懶腰是前腳往前、後腳往後伸；最後一格＝Default。
- 合計 1630 ms。
- 四腳自檢（每格：四隻腳都在、腳在身體下半部、著地格≥2 腳貼地、無手掌）：全部通過。
- 重疊檢查（特效／道具 vs 眼嘴、特效彼此）：程式 10 格 0 筆。

| 格 | 動作／表情 | 停留 ms | 四腳自檢 |
|---|---|---|---|
| 01 | 被叫醒嚇一跳：整隻彈起來、毛炸開 | 70 | OK |
| 02 | 往下掉（被子飛走） | 70 | OK |
| 03 | 落地壓扁（四腳著地） | 80 | OK |
| 04 | 睜開眼（還有點呆） | 160 | OK |
| 05 | 眨眼 | 80 | OK |
| 06 | 伸懶腰：前腳往前、後腳往後伸、打哈欠 | 260 | OK |
| 07 | 伸到底（身體拉最長、哈欠張最大） | 300 | OK |
| 08 | 收回來、彈一下 | 90 | OK |
| 09 | 轉正、抖抖毛 | 120 | OK |
| 10 | 回 Default | 400 | OK |
