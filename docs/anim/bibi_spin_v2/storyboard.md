# 比比・spin_v2（v2 骨架重做，12 格）

- 退件原因（Andy 10-11）：舊版是原 GIF 第 0 張變形＋貼東西，沒有真的肢體動作。
- 做法：`scripts/anim/bibi_rig.py` 原版 Default 骨架（本體、耳朵、肉掌、腳、尾巴、眼、嘴、腮紅獨立擺位）＋`scripts/anim/bibi_moves_v2.py` 關鍵格（ease 補間，不是 crossfade）。
- 規格：512×512 透明、全身入鏡、場景座標中心 x=248、腳底 y=482；成品 160px 動態 WebP（anim.webp）。
- 播放：播一次（loop=1）；播一次；第 7～11 格收在暈眩臉（漩渦眼＋歪波浪嘴＋星星繞頭）；第 11 格＝bibi_dizzy 第 1 格（要接暈眩循環就在第 11 格切過去），第 12 格＝Default。
