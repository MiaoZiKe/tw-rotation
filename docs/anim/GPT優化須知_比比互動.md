## 2. 比比的鐵則（Andy 最高原則，10-12）
- **比比是四隻腳的天竺鼠**：不站立、**沒有手**、不舉手、不用手拿東西、不擊掌、不擁抱。
  - 打招呼／擊掌＝往前伸頭用鼻子碰一下；抱抱＝蹭過來貼貼；道具一律放在地上、懸空，或畫在素材裡由身體碰觸。
  - 他貼的一般製作規則若提到「抬手、擁抱前傾、擊掌預備、拿道具姿勢」，**以四腳原則為準，那些有手的姿勢不要做**。
- 12 種要避免的錯誤（Andy 點名）：腳掌每格大小不同、身體輪廓每格差太多、忽胖忽瘦、五官位置飄、耳朵亂跑、壓縮時頸部／下巴生硬、外輪廓變幾何、毛茸茸感消失、只靠簡單幾何圖形畫、補間不足、首尾循環不順、互動接觸瞬間不自然。
- 角色固定規格：奶油白蓬鬆毛球、**波浪狀毛邊、粗深咖啡描邊**、粉橘色耳朵、黑色圓點眼睛、小嘴＋粉色小舌頭、桃粉色圓形腮紅、粉橘色短圓腳掌（左右一樣大）。所有格必須是同一隻。

## 3. 技術規格（交出去的圖要符合）
- **同一個座標系統**：512×512 透明背景，**所有動畫同一個比例尺**：身體縮 0.75、中心 x≈248、**腳底 y≈482**（地面基準線，見 `docs/anim/bibi_library/index.md`）。不要每張重新置中——網站用同一個裁切框（28,52,468,492）切 160px，比比換動作時大小與腳底位置才不會跳。
- 角色完整不裁切；道具超出框外會被切掉一點，可接受，但**重要部位（臉、腳）不能靠邊**。
- **透明背景**：網站亮／暗兩種主題都會用，邊緣要乾淨，不能有綠邊、白邊、方塊底、半透明髒邊。GPT 圖片 API 的 `gpt-image-2` 不支援直接透明，請用純色背景（例如 #00FF00）產出再去背，並檢查邊緣；三種底色（奶油白、淺藍、深色）各看一次。
- **檔案大小**：網站用 160px 動態 WebP，單檔原則 ≤60KB（吃草等細節多的可放寬到 100KB，需講明）。`scripts/anim/bibi_site.py` 會把 512 素材縮成 160px WebP；你交 512 的 PNG 影格與動態 WebP 即可，轉檔由 Claude 做。
- 正式動畫預設 24 格（12 關鍵幀＋12 補間幀），簡單動作 16 格；循環款要首尾接得順，一次款（once）最後一格要回到待機（Default）造型。
- 動作節奏：預備 → 啟動 → **接觸瞬間** → 擠壓／回彈 → 情緒反應 → 收尾；體積守恆（壓扁變寬、拉高變窄）；壓縮時下巴圓滑。
