# Claude 天竺鼠 GIF Prompt 套件

## 最快使用方式
1. 在 Claude 專案（Project Instructions）貼入 `01_Claude_總控Prompt.md` 全文。
2. 上傳你提供的天竺鼠原圖或分鏡圖，優先使用高解析、完整圖片。
3. 每次只需要貼 `02_每次只需修改的參數.txt` 中的參數並修改 `TARGET_ACTION` 等欄位。
4. 若你已有完整 24 格分鏡，請把 `INPUT_TYPE=storyboard_24`，這樣 Claude 只需裁切合成，不必重畫。
5. 若手上只有一張角色圖，請設 `INPUT_TYPE=single_character`。Claude 需有圖像生成／繪圖環境才有能力畫出新的不同姿勢；普通 Pillow 並不會自行從一張圖產生高品質新動作。

## 重要限制
- **無法保證與原圖像素級一模一樣**：最保真方式是保留原像素、圖層變形，必要時再手繪補畫；SVG 自動重建只能接近。
- 24 格 x 50 ms = 1.2 秒／循環；24格 x 100ms = 2.4 秒／循環。
- 要流暢必須保持關鍵姿勢的前後連續性與首尾銜接；僅把12格複製兩遍不是補幀。
- GIF 本身只支援有限色彩及單階透明，若對色彩細節要求高，可另輸出 APNG 或 Animated WebP。

## 套件檔案
- `01_Claude_總控Prompt.md`：主指令，設定一次。
- `02_每次只需修改的參數.txt`：每次的配置。
- `03_快捷指令範例.txt`：3種素材輸入的直接範例。
- `04_情境篇前3項_動作關鍵節點.md`：吃東西／喝飲料／看新聞的12個關鍵姿勢。
