# 情境篇前三項：12 張關鍵幀的動作節點參考

每個動作先產生 K01...K12，再插入 I01...I12，其中 I12 接回 K01。補間幀應產生新的中間姿勢，不能直接複製或交叉淡化。

## 吃東西（12 K）
K01 看碗待機；K02 身體微前傾；K03 筷子伸進碗；K04 夾起食物；K05 食物向嘴移動；K06 食物抵嘴；K07 咬下；K08 咀嚼（鼓頰）；K09 咀嚼收尾；K10 吞下滿足；K11 筷子下移回碗旁；K12 回到初始姿勢。

## 喝飲料（12 K）
K01 看飲料待機；K02 眼神轉向杯子；K03 手伸向杯子；K04 握住杯子；K05 杯子抬高；K06 吸管靠近嘴；K07 接觸吸管；K08 吸吮（臉頰變化）；K09 喝完一口；K10 杯子向下；K11 杯子回原位手鬆開；K12 回待機。

## 看新聞（12 K）
K01 正常閱讀；K02 眼睛掃左欄；K03 視線掃右欄；K04 專注前傾；K05 看到重點；K06 驚訝；K07 報紙下移露臉；K08 開始理解；K09 表情收斂；K10 報紙回正；K11 重新掃視；K12 回初始閱讀姿勢。
