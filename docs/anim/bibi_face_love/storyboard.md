# 比比・表情・愛心眼（飄小愛心）（12 格）

- 需求：Andy 2026-10-10「幫我在影片中新增多點 GIF 圖，表情越豐富越好，情境越多越好，可以多點物件，動作可以跟影片有更多互動，讓觀眾有是比比在介紹的感覺」。
- 用途：影片情緒點綴／貼圖（12 格，待機→表情→回待機，可循環）。
- 製作：`BIBI_SIGN_FONT=<jf-openhuninn-2.1.ttf> python scripts/anim/bibi_faces_c.py --out <scratchpad>/bibi --repo-out docs/anim --only face_love`。
- 身體：原圖 `site/brand/src/support_anim_1009.gif` 第 0 張像素的網格變形（raster_first）；場景座標同 A／B 批（身體縮 0.75、中心 x=248、腳底 y=482）；512×512、透明。
- 五官：在原圖座標上先用周圍毛色補掉原本的眼睛／嘴巴（腮紅保留），再用 SVG 三次 Bézier 畫新五官，跟身體一起變形，所以歪頭、壓扁時五官跟著臉走。臉外物件在場景座標畫、錨點跟著身體。
- 依 Andy 退件教訓：不畫從身體伸出的長手臂，只露小肉掌。
- 合計 1520ms，無限循環；相鄰格皆有實際差異。
