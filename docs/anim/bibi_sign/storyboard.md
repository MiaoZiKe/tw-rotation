# 比比・許願牌懸空 12 格（v2）

- 2026-10-10 Andy 退件第一版（兩手舉牌）：「許願的手太奇怪了，改成用懸空的方式呈現」→ 拿掉兩隻手臂與抓牌的肉掌。
- 需求：`docs/marketing/video_1010/storyboard.md` 第 4 節鏡 31；規格照 `docs/anim/prompt_kit/01_總控Prompt.md`（raster_first）。
- 製作：`BIBI_SIGN_FONT=<jf-openhuninn-2.1.ttf 路徑> python scripts/anim/bibi_actions.py --out <scratchpad>/bibi --repo-out docs/anim --only sign,sign_text`。
- 身體：原圖 `site/brand/src/support_anim_1009.gif` 的像素網格變形。站姿用第 0 張；抬頭看牌子＝頭頂慣性 lag +0.10～0.16，把五官往上推；開心彈一下的「蹲」和「落地」兩格直接用原圖第 2 張（瞇眼笑）。
- 牌子：白色圓角牌，四邊是微彎的三次 Bézier、底部一條米色陰影，懸空在頭頂上方。站著的格牌底離頭頂毛 23～29px（蹲下兩格更遠），碰不到耳朵。上下輕飄 ±6px（身體彈到最高的第 5 格，牌子也在最高點），左右擺 ±4°（跟上下錯開 1/4 拍）。
- 浮著的記號：牌底下 3 顆小黃閃光＋2 道淡弧線，大小、透明度每格固定（不閃爍、不脈動），只跟著牌子移動。
- 字：`anim_text.webp`／`sheet_12_text.png` 用 jf open 粉圓 2.1（justfont，SIL OFL 1.1）寫「許願」，字級 86px；字型檔不進 repo，用環境變數 `BIBI_SIGN_FONT` 指定，沒指定就退回文泉驛正黑。`anim.webp`／`sheet_12.png` 牌面留白給剪輯放字。
- 牌子每格的中心、尺寸、傾角在 scratchpad `bibi/index.json` 的 `sign_box_per_frame`，剪輯疊字照這個跟。
- 場景座標跟其他 4 組相同：身體縮 0.75、中心 x=248、腳底 y=482；512×512、透明。獨立 PNG 在 scratchpad `bibi/sign*/frames/`（不進版控）。
