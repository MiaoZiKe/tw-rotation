# 比比・hop_reach（10-12 四腳天竺鼠版，6 格）

- 依據：Andy 10-12「比比是天竺鼠，他是 4 隻腳的……不可以因為配合互動就改變身體原有設定」。
- 做法：`scripts/anim/bibi_quad.py`（原版 Default 像素本體＋四隻獨立小腳，不畫手）＋`scripts/anim/bibi_quad_moves.py` 關鍵格（ease 補間）。
- 規格：512×512 透明、全身入鏡；成品 160px 動態 WebP（anim.webp）；第 1 格就是動作、最後一格回 Default。
- 播放：播一次（loop=1）；吹泡泡／落葉／花瓣：網頁讓 bubble_prop（或 leaf_prop、petal_prop）飄到比比頭頂上方約 (x 256, y 60)，第 3 格鼻子頂到 → 網頁在那個位置播 pop_burst.webp（3 格，60/70/90ms）；最後一格＝Default。
- 合計 810 ms。
- 四腳自檢（每格：四隻腳都在、腳在身體下半部、著地格≥2 腳貼地、無手掌）：全部通過。
- 重疊檢查（特效／道具 vs 眼嘴、特效彼此）：程式 6 格 0 筆。

| 格 | 動作／表情 | 停留 ms | 四腳自檢 |
|---|---|---|---|
| 01 | 抬頭盯著泡泡、蹲低 | 90 | OK |
| 02 | 往上撲（四腳離地） | 70 | OK |
| 03 | 最高點、鼻子碰到泡泡（網頁在這格播 pop_burst） | 100 | OK |
| 04 | 往下掉 | 70 | OK |
| 05 | 落地壓扁 | 80 | OK |
| 06 | 回 Default | 400 | OK |
