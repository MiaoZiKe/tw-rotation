# 比比・look_up（10-12 四腳天竺鼠版，4 格）

- 依據：Andy 10-12「比比是天竺鼠，他是 4 隻腳的……不可以因為配合互動就改變身體原有設定」。
- 做法：`scripts/anim/bibi_quad.py`（原版 Default 像素本體＋四隻獨立小腳，不畫手）＋`scripts/anim/bibi_quad_moves.py` 關鍵格（ease 補間）。
- 規格：512×512 透明、全身入鏡；成品 160px 動態 WebP（anim.webp）；第 1 格就是動作、最後一格回 Default。
- 播放：循環；紙飛機：plane_prop 在頭頂飛時循環這 4 格（眼睛左上→上→右上→上）；飛機落地後 run_r 跑過去 → sniff_eat 前兩格（或 receive）聞一聞。落葉／花瓣（leaf_prop、petal_prop 也放在這個資料夾）沿用 hop_reach／sniff_eat。
- 合計 640 ms。
- 四腳自檢（每格：四隻腳都在、腳在身體下半部、著地格≥2 腳貼地、無手掌）：全部通過。
- 重疊檢查（特效／道具 vs 眼嘴、特效彼此）：程式 4 格 0 筆。

| 格 | 動作／表情 | 停留 ms | 四腳自檢 |
|---|---|---|---|
| 01 | 抬頭、眼睛跟著飛機轉・看左上 | 160 | OK |
| 02 | 抬頭、眼睛跟著飛機轉・看正上方 | 160 | OK |
| 03 | 抬頭、眼睛跟著飛機轉・看右上 | 160 | OK |
| 04 | 抬頭、眼睛跟著飛機轉・看正上方（接回第 1 格） | 160 | OK |
