# 比比・run_stop_r（10-12 四腳天竺鼠版，6 格）

- 依據：Andy 10-12「比比是天竺鼠，他是 4 隻腳的……不可以因為配合互動就改變身體原有設定」。
- 做法：`scripts/anim/bibi_quad.py`（原版 Default 像素本體＋四隻獨立小腳，不畫手）＋`scripts/anim/bibi_quad_moves.py` 關鍵格（ease 補間）。
- 規格：512×512 透明、全身入鏡；成品 160px 動態 WebP（anim.webp）；第 1 格就是動作、最後一格回 Default。
- 播放：播一次（loop=1）；播一次；第 1 格＝跑步中（run_r 第 3 格），最後一格＝Default。
- 合計 850 ms。
- 四腳自檢（每格：四隻腳都在、腳在身體下半部、著地格≥2 腳貼地、無手掌）：全部通過。
- 重疊檢查（特效／道具 vs 眼嘴、特效彼此）：程式 6 格 0 筆。

| 格 | 動作／表情 | 停留 ms | 四腳自檢 |
|---|---|---|---|
| 01 | 跑步中（＝run 第 3 格） | 70 | OK |
| 02 | 煞車：前腳往前撐、身體往後坐、毛往前甩 | 80 | OK |
| 03 | 往前一晃（跟隨） | 80 | OK |
| 04 | 站穩（側面） | 110 | OK |
| 05 | 轉回來 | 110 | OK |
| 06 | 回 Default | 400 | OK |
