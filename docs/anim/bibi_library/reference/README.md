## 1. 身材
- 一顆**圓滾滾的毛球**，寬略大於高（約 1.15：1），外緣是一圈不規則的毛（短弧形鋸齒，不是尖刺）。
- 毛色奶油白（約 `#FEF8E8`），身體下半與側邊有淡蜜桃色陰影；**粗的深棕黑描邊**（約 `#2A1410`，粗細約身寬的 2.5%）。
- 腳底下有一片淡灰色橢圓影子（做透明素材時不保留影子）。

## 2. 四肢：短短、圓圓，貼在身體邊緣
- **沒有手臂、沒有腿**。手和腳都只是一小團肉掌，直接貼在身體輪廓上（或身前），從輪廓冒出來的長度不超過肉掌本身的一半。
- **手掌**（`hand_l`／`hand_r`／`hand_side`／`hand_pad`）：手套形的小圓團，大小約身寬的 13%×17%；
  蜜桃粉（約 `#FFB4A0`），貼身體那一端深一點（約 `#F58C78`），C 形粗描邊**在根部留缺口**，指尖兩道短趾線；
  肉球面是一大三小的肉球輪廓。
- **腳**（`foot_l`／`foot_r`）：兩顆扁扁的小圓（蜜桃粉、粗描邊、前緣兩道趾線），從身體底部露出一半。
- 揮手、拍手、比讚、摀臉、托腮：**只動這一小團肉掌**（舉到身體上緣側邊／身前／臉前），加弧形動作線表示在動。參考總表最下兩排。

## 3. 耳朵
- 兩片半圓小耳（`ear_l`／`ear_r`），在頭頂兩側略往外，外圈蜜桃粉、內耳深一點的粉＋一道弧線，粗描邊在下緣開口（插進毛裡）。

## 5. 正面／側面／背面（第 5 排，`pose_*`）
- 正面：雙眼＋ω 嘴在中線、腮紅在眼睛外下方、兩耳在頭頂兩側、兩腳露在底部。
- 斜前方：五官往一側偏、遠側耳朵只露一點。
- 側面：只看到一隻眼、一邊腮紅、一隻耳朵在頭頂後方。
- 背面：沒有五官；一隻耳朵露在頭頂，背面中下方有**一小團圓尾巴毛**（`pose_back_tail`）。

第三排：各種揮手、拍手、肉掌舉起——**全部都是貼在身體邊緣的小肉掌＋弧形動作線**。

- [ ] 四肢只有小肉掌，沒有手臂／長腿

- [ ] 五官比例、腮紅位置跟 `pose_front` 一致
