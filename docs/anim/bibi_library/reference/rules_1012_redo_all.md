## 一、要避免的錯誤（Andy 點名）
1. 腳掌大小每格不同　2. 身體輪廓每格差異太大　3. 身形忽胖忽瘦、忽高忽低　4. 五官位置不穩　5. 耳朵位置亂跑
6. 壓縮時頸部／下巴生硬，不夠圓滑　7. 外輪廓被畫成幾何圖形感　8. 毛茸茸感消失
9. 只靠簡單 code 幾何圖形畫角色，很假　10. 補間不足、停頓感明顯　11. 首尾循環不順　12. 互動接觸瞬間不自然
（另外 Andy 看到：側面與跑步姿勢不像原本的比比。）

## 二、角色固定規格
奶油白、圓滾滾、毛茸茸的 Q 版天竺鼠；深色手繪感粗描邊；粉橘色耳朵；黑色圓點眼睛；小嘴＋粉色舌頭；桃粉色圓形腮紅；粉橘色小腳掌；
身體輪廓是毛茸茸、波浪狀、圓潤的。**所有幀必須是同一隻**，不得變成別的造型。

## 三、技術規則（依序選擇）
- A. **原圖擷取＋分層＋補繪**（首選，ASSET_MODE=raster_first）
- B. SVG Bézier 曲線描繪　　C. 高解析（≥2048×2048）程式繪製後縮小
- **不可以只用 ellipse／circle／rectangle 幾何圖形堆角色。**程式繪圖還原不出原圖風格時，直接切回 A，不要硬畫。
- 線條 round linecap／round linejoin；高品質抗鋸齒；縮圖用 LANCZOS；最終輸出 512×512，再轉網頁用的 160px 動態 WebP。

## 四、動畫製作規則
- 正式動畫預設 **24 格＝12 關鍵幀＋12 補間幀**（簡單動作可 16 格）。
- 每格：512×512、透明背景、角色完整不裁切、**同一座標系統**（不要每張重新置中，否則位移消失）。
- 預設參數：FRAME_DURATION_MS=50、LOOP=0（循環款）、ASSET_MODE=raster_first。
- **體積守恆**：壓扁變寬、拉高變窄。
- 壓縮：身體下緣貼地、腳掌略展開、**頸部／下巴過渡圓滑（小圓弧），不可有尖角、折線、內凹怪形**。
- 彈跳：上升略拉長、落地略壓縮、有小回彈。
- 腳掌：短小圓潤粉橘色、**左右一樣大**、不可某格超長或消失。
- 毛邊：保持毛茸茸波浪邊，不可簡化成光滑圓球。
- 五官：眼距固定、嘴位置固定、腮紅大小固定、耳朵與頭的相對位置固定。

## 五、工作流程（不准跳步）
1. 分析錯誤示範（reject_*、線上版截圖）→ 列錯誤點　2. 分析正確參考（default_idle、jump 分格圖）→ 整理風格規範
3. 建立「基礎角色資產包」（見下）　4. 每個動作先出 12 關鍵幀＋12 補間幀規劃　5. 再正式產出 24 格總覽圖、24 張 PNG、動圖、ZIP

### 基礎姿勢資產包（四腳版；有手的項目不做）
正面站姿／壓縮／拉伸／跳躍／落地壓縮；右前 3/4 站姿；側面站姿；側面奔跑 A、B、C；側面起跳／空中最高點／落地；趴姿；坐姿（四腳）；躺姿；低頭嗅地姿勢。
**側面、3/4 必須是原圖那隻比比轉過去的樣子（毛球輪廓、耳朵、腮紅、腳的相對位置不變），不是另外畫一隻。**
