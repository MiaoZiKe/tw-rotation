# 比比動畫單位：唯一交付索引

更新：2026-10-16。CEO 統籌長期團隊；本頁記錄實際產物與證據。規格完成、素材完成、實機驗收及正式上線是不同狀態，不能混寫。角色定義不表示背景有常駐程序。

## 組織與交接

| 角色 | 長期責任 | 交付條件 |
|---|---|---|
| CEO | 拆解原話、排程、跨職能取捨、統整驗收與發布 | 維護本索引、處理退件、核對真實部署結果 |
| 企劃 | 分鏡、行為來源、接觸及情緒差異、逐條需求對照 | [互動規格](interaction_spec.md)，先供動畫與工程共用 |
| 動畫師 | 連續姿勢、重量、步態、接觸關鍵幀與補間 | 同座標逐幀素材、總覽、動圖、時長與錨點表；三種接觸不可共用吃東西動作 |
| 插圖 | 母版、口眼、短圓掌、道具及造型一致性 | 與母版並排比較；耳下全奶白、不加尾巴金錢、不拼拆身體 |
| 互動工程 | 載入、取消、狀態、根軸位移、接觸錨點與網站整合 | 觸發即停待機、固定速度起跑、跑圈接地；取消清除延後工作 |
| 品質審核 | 獨立逐幀及實機審片、核對使用者原話 | 環境、時間點、截圖或錄影及通過／未通過紀錄；沒測不得宣稱通過 |
| Token 效率管理 | 防重複讀大檔、重做素材、多人改同檔、重跑相同測試 | 派工列負責檔／輸入／交付；定向搜尋及短摘要；只重驗受影響範圍，品質失敗不可省略 |

一個檔案同時一位負責人，跨職能需求由 CEO 派送。工程與動畫使用同一份錨點表，新需求先入本索引。其他互動未被本輪指名者不擴大重做。

## 排程與發布

| 順序 | 工作 | 啟動／完成條件 |
|---|---|---|
| 1 | 企劃定三種接觸差異、插圖鎖母版 | 本規格先交；動畫與工程依同一錨點定義並行 |
| 2 | 工程修即停待機、速度及根軸；動畫製作三種口眼反應 | 各自改所屬檔，可驗部分先交 |
| 3 | 整合毛線完整情節 | 纏全身、側跌及逐環鬆脫都要有，不能拿一般吃東西素材代替 |
| 4 | 獨立品質審核 | 三種接觸、毛線、冷載入、取消、地面步態逐項驗；退回受影響段落 |
| 5 | CEO 驗收後直接正式上線 | 使用者最新已授權驗收後直接正式上線，不另設預覽等待確認；實際部署成功且正式頁可見才記已上線 |

這是相依順序，不是耗時承諾；實際起訖與估時由 CEO 依進度補記。新授權覆蓋舊的「只推預覽／等確認」限制，但不省略驗收。回報只列完成、製作中與卡點，不重貼全規格。
