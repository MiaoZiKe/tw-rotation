# 比比接觸反應與地面移動規格

更新：2026-10-15。供動畫、插圖、工程及品質共用；本頁是規格，未宣稱素材或網站通過。固定動作段時長：落葉 1200ms、泡泡 1000ms、紙飛機 1200ms、毛線 2600ms。下表由該段開始計時，接近跑程及回家另計；整合不得在段尾插入額外等待改長。素材未載好不啟動段時計。最新授權為驗收後直接正式上線，由 CEO 核對部署成功後回報。

## 1. 母版與自然行為界線

- 既有奶白阿比天竺鼠，厚咖啡描邊、毛茸茸輪廓、短圓腳掌；耳下全奶白，不添尾巴或金錢。眼距、耳位、掌大小及身形跨幀一致；縮頭、側跌保持完整連續身體，不拆拼頭肚。
- 四腳地面步態用於追逐、起跑及跑圈。指定第一版待機跳躍保留於正式待機，觸發互動即停止，不把跳躍當跑圈。
- 自然行為來源只支持概括：爆米花跳可有短促跳躍與扭動，不能把所有跳動一律解讀為快樂；不支持本頁道具劇情及精確運動參數。
- 落葉咬合、泡泡受驚及紙飛機試探為角色演出設計；咬合節奏不假稱生理嚼速。毛線纏全身→側跌→鬆脫明確屬卡通情節，不宣稱是真實自然行為。泡泡不是食物，紙及毛線不吞食。本文件是角色動畫規格，不延伸現實動物照護建議。

來源（2026-10-15 已開頁查證）：[Toronto Humane Society，爆米花跳](https://www.torontohumanesociety.com/why-does-my-guinea-pig-popcorn/)（2026-06-05，短促向上跳及可能扭動）；[Vet Help Direct，為何跳躍](https://vethelpdirect.com/vetblog/2021/06/01/why-does-my-guinea-pig-jump-what-is-popcorning/)（2021-06-01，獸醫 Ashley Clayton，快速跳躍及不同情緒脈絡）。未查證牙齒運動方向，不寫特定磨牙方向或頻率為動物學事實。

## 2. 共用錨點與狀態

| 名稱 | 定義 |
|---|---|
| 地面根軸 G | 四腳站立支撐的地面；移動、陰影、回家共用，不以鼻尖為旋轉中心 |
| 鼻尖 N | 當幀可見鼻尖中心；泡泡、紙飛機碰觸使用 |
| 口緣 M | 當幀嘴唇前緣；落葉葉邊夾在此處，不碰額頭冒充咬 |
| 肩 S、腹 B、臀 H | 線環在完整角色輪廓的附著位置，隨側跌一起轉 |
| 來源座標 | 以最終素材實際尺寸逐幀量測；縮放、鏡像、根軸位移用同一矩陣轉至網頁 |

鏡像時 x 隨來源寬度轉換，口眼及道具同時翻轉，不沿用舊鼻尖。最終 160px 輸出接觸點至 N／M 距離 ≤2px（含描邊），正常速度看不見穿入。鼻尖／嘴唇預定接觸可相交；其他道具不可穿眼、耳、腹。毛線用前後遮擋分層，不能全蓋在身體前方。

觸發當幀取消待機跳圖與上下位移，進入準備／載入，顯示完整地面站姿。等待素材期間不能繼續跳。載好才開始動作時鐘。準備→接近→接觸→反應→收尾→回家／待機屬同一可取消工作；停止、Esc、換頁及既有點空白取消，均清掉圖、線、道具、位移、計時與延後回呼，舊工作不可稍後重播。

## 3. 落葉：固定 1200ms，嘴部咬合

角色先用地面跑步到葉前，段開始時葉已在嘴前可接觸範圍。

| 階段／段內時間 | 姿勢與口眼 | 錨點／道具 | 驗收 |
|---|---|---|---|
| 預備 0～200ms | 降頭、眼看葉尖，嘴由閉到小開，掌貼地 | 葉緣靠向 M，接觸前留間隙 | 有嘴預備，不只晃頭 |
| 咬住 200～350ms | 下顎小幅閉合夾葉，眼專注 | 葉緣固定跟 M，遠端下垂 | 張→碰→合三種可辨輪廓，葉不瞬間消失 |
| 咬合 350～850ms | 2～3 次小開合，下顎或頰微動，頭大致穩定 | 葉隨口緣輕動，不穿臉 | 不以全身縮放冒充嘴動，不是嗅聞 |
| 放開 850～1050ms | 嘴鬆、頭微抬、眨眼 | 葉離 M 掉回地面 | 可見放開及落下，不吞葉道具 |
| 收尾 1050～1200ms | 四腳站定、放鬆 | 葉留地後淡出 | 完成咬合才離開；尾幀可接地面返回 |

## 4. 泡泡：固定 1000ms，鼻碰後受驚

| 階段／段內時間 | 姿勢與口眼 | 錨點／道具 | 驗收 |
|---|---|---|---|
| 接近 0～200ms | 四腳站穩、頭微伸、眼追泡泡、嘴閉 | 泡泡表面靠 N，不是中心穿鼻 | 不播放吃東西 |
| 碰破 200～280ms | 鼻受觸、眼先睜大 | 破裂中心在 N，原泡泡同步撤掉 | 破裂與接觸對時，不遠處先破 |
| 縮頭 280～460ms | 頭後縮、耳輕收，嘴短暫小驚訝 | N 離開破點、身體連續 | 明確驚嚇，不跳起咬泡泡 |
| 小退 460～700ms | 交替踏步小退，眼看破點 | G 沿地面退 | 不四腳懸空、不彈飛 |
| 觀察／收尾 700～1000ms | 停拍、眨眼、放鬆站姿 | 碎光消失 | 無咀嚼、吞泡泡或食物屑 |

## 5. 紙飛機：固定 1200ms，碰鼻→縮頭→嗅聞

飛行可抬頭追視，鼻前降低飛機速度，避免尖端高速撞臉。

| 階段／段內時間 | 姿勢與口眼 | 錨點／道具 | 驗收 |
|---|---|---|---|
| 輕碰 0～100ms | 眼看飛機、嘴閉、頭剛伸到前 | 飛機鼻端只觸 N | 有可辨輕碰幀，不穿臉 |
| 縮頭 100～300ms | 頭頸連續後縮、眼稍睜、腳不移 | 飛機停止前進，落鼻前地面 | 不是整隻後滑，不咬紙 |
| 停頓 300～450ms | 縮頭一拍、眨眼 | 飛機地面可見 | 停頓與再靠近分開 |
| 再探／嗅聞 450～900ms | 緩伸鼻，兩次小探動，嘴持續閉 | N 停紙表面前小間隙 | 先躲再好奇，無咬合或紙片減少 |
| 收尾 900～1200ms | 抬頭放鬆、四腳站定 | 飛機留地再淡出 | 不吞紙，不沿用落葉嘴動段 |

## 6. 毛線：固定 2600ms，纏全身→側跌→鬆脫

卡通情節，嘴全程不咬線。球與線都可見，不能用壓球一格直接跳到纏住。

| 階段／段內時間 | 姿勢與口眼 | 錨點／道具 | 驗收 |
|---|---|---|---|
| 追碰 0～350ms | 地面追近，鼻低、眼看球 | 球在鼻／掌前，線拖在後 | 有追與碰，不搬移跳躍圖 |
| 纏繞 350～850ms | 腳逐漸踏不開、眼困惑、嘴閉 | 線環逐步跨 S、B、H，前後遮擋合理 | 肩腹臀三區皆有纏繞，非單線掛腹前 |
| 卡住 850～1050ms | 掌想踏出又縮回、重心側移、眼睜 | 線隨完整軀幹固定 | 先停再失衡，不瞬移躺下 |
| 側跌 1050～1350ms | 完整身體繞側面支撐傾到側躺、掌收、嘴驚訝 | S／B／H 及線同步轉，側腹落地 | 站→傾→躺可見，不拆身、不倒栽飛起 |
| 側躺小動 1350～1700ms | 眼清醒追線，掌兩次小動、身體輕扭 | 仍纏身，第一環開始鬆 | 不劇烈抽搐或高速全身抖 |
| 鬆脫 1700～2250ms | 輕扭、掌逐步伸出、表情放鬆 | 線依 S→B→H 鬆開滑落地，球在外側 | 至少兩個鬆脫中間狀態，不瞬間清線 |
| 翻正／收尾 2250～2600ms | 完整身體翻回四腳、站穩眨眼 | G 回站立，線留地才退場 | 解纏後才起跑／待機，無線穿頭吞線 |

## 7. 起跑、跑圈與量測

- 固定速度起跑：開始位移即採設定平面速度 v，距離 d 的時間為 d/v。不緩入、不先滑行、不原地跑數拍才移動；步態與根軸同幀開始。彎道依弧長均速，不能等分橢圓角度造成忽快忽慢。
- 跑圈 G 沿地面路線移動，每一幀至少一隻可辨支撐掌接近 G；身體只容許小幅步態起伏，禁止跳躍曲線、整體懸浮或旋轉成平躺飛行。支撐掌不得明顯打滑，不能只靠陰影貼地宣稱接地。
- 速度驗收記每個渲染影格時間、G 位置及狀態；直線或彎道弧長速度為設定值 ±5%，第一有效位移區間也要量；掉幀用實際時間差，不排除起步掩蓋緩入。
- 最終 160px 尺寸支撐掌距 G 垂直差 ≤2px，跑圈逐幀至少一掌符合；另看正常及慢速錄影確認無漂浮、打滑、截掌。側跌是獨立情節，以側腹支撐量測，不套跑圈掌規則。

## 8. 品質交件

1. 每段交影格與時長清單、接觸幀、逐幀 N／M 或 S／B／H、透明總覽及正常速度動圖。固定時長逐檔驗，不以總覽存在代替動畫完成。
2. 三種反應並排靜音仍辨「咬合／受驚小退／縮頭再嗅」，不能共用吃東西。口眼變化來自素材，不能靠文字宣稱演出了。
3. 毛線抽查全身纏繞、傾斜中間姿勢、側躺、逐環鬆脫、翻正，驗前後遮擋及完整身體。
4. 桌機及手機實驗觸發即停待機、首次載入等待、重複觸發、接觸、回家與各取消方式；取消後等超過原總長，舊道具與特效不能重現，再觸發可正常播。
5. 跑步跑圈交速度紀錄、逐幀接地檢查及錄影，禁止用爆米花跳替代跑。未取證記待驗，不寫通過。
6. 列刻意接觸與毛線纏身允許區；其餘道具、文字、角色、選單依既有版面規則檢查。報告記實測幀數、人工抽格及問題數，未查不能填零。通過後依已授權流程正式發布，正式頁實際可見且部署成功才記已上線。
