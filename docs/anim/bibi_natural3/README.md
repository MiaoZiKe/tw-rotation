紙飛機先前原圖1254×1254，等分格線會切第一排腳與第五格右緣，成功以全張共同偏移(14,20)修正；沒有逐格重新對齊腳底。恢復原圖後須重新確認是否同張。非4整除的來源只在較小格透明補1px，不獨立縮放。

錨點設定在各動作 `export_settings.json`：`anchors` 每筆有 `frame`、`name`（mouth或nose）、`source_cell_xy`、`measurement`。座標必須以共同偏移後的分格左上為原點。原始等分格點須先減 `source_grid_offset`。嘴鼻要放大人工定位，允許以嘴鼻深咖啡連通區邊界輔助，禁止由角色總外框猜嘴；未量到的點在軌跡標null。`body_source`每格為 `[cx,cy,rx,ry,angle]`，是人工近似身體橢圓，不含耳腳，不能宣稱線圈已附著通過。

`durations_ms`配合`sequence`控制逐格停留，保留來源16格，可重複咀嚼格；`events_ms`寫實際側跌與鬆脫時間；`visual_review`記錄實際審查與限制。口鼻座標輸出512與160版本，engine_tracks逐播放格含開始時間、mouth_160、nose_160、body160。

機器檢查：主體不得碰格邊，只去極小碎片；全格共用聯集裁切、縮放與置中，保留側跌高度與位移；動畫讀回逐格驗四角透明、時長、尺寸與檔案大小。三底逐格及網站動態仍須人工審片，不可用機器通過冒充自然流暢。
