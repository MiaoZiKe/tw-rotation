## 四、結算日換月時點的敏感度（假設性上限，不進冠軍資格）

做法：連『結算日當天』的報酬也換成現貨報酬（假設下個月合約在結算日的表現等於現貨），等於提早一天換到下個月合約、避開結算日收斂。連續序列裡看不到下個月合約，所以這個好處**只能靠假設**；結算日當天『期貨 - 現貨』平均 -18 bp（約 -2.2%／年）的來源也沒有拆解（可能是結算價與收盤價的差、也可能是殺尾盤）。
