## 八、結論、優化空間與限制

- 內部保留期：優化版 8.3%／-20.2%，預設版 7.5%／-18.4%，優化版＋外資期貨 7.5%／-20.4%；0050 18.3%／-28.2%。沒有冠軍。已被看過的 2021 起僅供參考：優化版 17.1%、0050 27.6%。
- 美股面：9 個進場濾網與 2 個出場規則中，只有 U_DXY 通過過半門檻；S&P、Nasdaq、SOX 的前一晚漲跌、VIX、ADR 溢價在『隔日開盤才進場』的框架下**沒有**讓指標變好——原因推測：美股前一晚資訊已大幅反映在隔日開盤跳空（相關 0.6），而本策略以隔日開盤價成交，等於已經吃到這個跳空；濾網只是少做了一些單。
- 外資期貨（2018-06 起）：搜尋期沒有資料，只在內部保留期驗一次（2018-06～2020-12，約 2.6 年），樣本太短，不能當結論。
- 補測結果：NHI 沒有進前段班；JA 與 BC 一起被採用（BC 8/8 基底變好，是目前最一致的濾網，但它只是『逆價差時才進場』，也讓交易數減少）。
- 優化空間（由逐筆檢討彙整）：見第七節最慘五筆；趨勢轉折偵測落後、跳空越過停損是主要來源。與前兩輪一致：這類 1 倍多頭擇時的價值是回撤小，不是超額報酬。
- 限制：搜尋期 2008～2016 只有 9 年且含 2008 單一大空頭，0050 在該期年化只有約 4%，容易『贏』；保留期 2017～2020 是 0050 大漲期；DGS10、P/C 比、事件日歷史缺；2021 起已被看過。
