## 一、策略白話（照著做會做出一樣的單）

**哲學**：只看 K 棒與均線；順勢、不接刀；沒有目標價，用均線移動停利；停損放在『技術位』（長紅棒低點）而不是固定點數；只在收棒時決策。

**主結果＝規格書原則全開（試單、停損反手、加減碼、多空都做；B 版），A 版＝同樣原則但只做多（對照）。**

**怎麼執行（日K 版；60 分 K 原版把『日』換成『60 分鐘』即可）**

1. 每天收盤後（原策略是每小時收棒後）檢查一次，**隔天開盤**下單，不用當天收盤價。
2. **長紅棒**＝收紅、實體 >= 1.5 倍過去 15 根平均實體（推論值）。記下它的最低點 L 與最高點 H。
3. **模組 A 做多**：近 8 根內有長紅棒；今天最低點回到 L 附近（距離 <= 0.3 ATR）**且**同時回到『上揚的 10MA 或 20MA』附近（均線比 3 根前高），今天收盤仍在 L 與該均線之上 -> 收盤後確認，隔天開盤進多 1 口。
4. **停損**：停損價＝L 與該均線兩者中離現價較近（較高）的那個；**收盤**跌破停損價，隔天開盤出場（不是盤中觸價）。停損距離超過 3 ATR 的訊號直接放棄（老吳：停損距離要自己能接受才進場）。
5. **移動停利**：價格收盤站上 5MA 之後，只要收盤跌破 5MA，隔天開盤出場（60/5）。**沒有目標價**。
6. **停損後**：同方向 5 根內不再進場；B 版若當天同時符合反方向訊號，隔天開盤直接反手。
7. **趨勢濾網（5a）**：只在均線多排（5>10>20>60 且 20、60 均線上揚）做多；空排才放空。
8. **加減碼（5c）**：基礎部位 0.5 倍；收盤突破長紅高點 H 加到 1 倍；收盤跌破 5MA 先減半、跌破 10MA 全出。
9. **模組 B**：均線糾結（5/10/20MA 的距離 < 0.5 ATR）連續兩根後，長紅棒收盤站上全部短均線 -> 進多，停損＝該長紅低點。**模組 C**：空排之後創低但收盤站回 5MA -> 試單進多。**模組 E**：平台（20 根區間 < 4 ATR、低點被測試 >= 2 次）低點附近試單 0.5 倍，突破平台高點補到 1 倍。**模組 D**（5 分 K 碰 20T 反壓放空）需要 5 分 K，資料湖沒有，**未實作**。

**部位**：主結果固定 1 倍名目曝險（一口對應帳戶權益）；附表另有『每筆風險 1.5%』口數版（口數＝權益 x 1.5% /（停損距離 x 200），名義曝險上限 3 倍）。

## 十、優化建議（由逐筆檢討彙整）

事後檢討最常出現的類型：可要求拉回棒縮量／下一根…（68 次）；移動停利啟動後回落到 5…（55 次）；逆勢單（週K 多頭進場做…（47 次）；收盤確認停損吃到跳空：實…（42 次）；順勢賺到，沿 5MA 持…（38 次）；平台試單…（35 次）。

- 保留期表現最好的是『A只多 優化參數』：年化 2.2%、回撤 -10.4%，仍輸 0050（27.6%／-33.9%）25.4 點。日K 版主結果（B 多空、規格書原則全開）持倉日只占約 27～32%，其餘空手只賺現金利息，保留期是 0050 年化 27.6% 的大多頭，無法跟上。
- **出場有價值、進場沒有**：固定 87 點的進場測試勝率約 4 成、盈虧比 < 1（進場點本身沒優勢）；換成 60/5 移動停利後盈虧比升到 2.5 以上，這與老吳『沒有目標價、沿 5T 走』的說法一致——賺的是讓獲利奔跑，不是進場點神準。
- **想貼近原策略就必須有 60 分 K**：日K 的 5MA 等於一週，停利太慢也太鈍；請 Andy 決定是否申購期交所『臺股期貨百分秒成交簡檔』（2015～2020）或接券商 API 1 分 K，才能用原週期正式驗證（資料與費用由 Andy 決定，我不代購）。
- 若不補資料，可行的低成本方向：把日K 版當『0050 的避險腳』（空頭或空排時才做空單），而不是取代 0050；或等 2027-08 真期貨 60 分 K 滿一年。
- 『停損後反手』在日K 版很少觸發：B 版原則全開時，搜尋期 5 次、保留期 2 次；單獨加進六步表（步驟 5b）時因為已有多排／空排濾網，結果完全沒變。『加減碼』提高盈虧比但最大單筆虧損變大（基礎部位減半抵銷不了跳空）。

## 十一、已知限制與缺陷

- 主結果是日K 版，**週期與原策略不同**：原策略靠 60 分 K 的高頻率機會與 5MA 緊貼停利，日K 版 6 年只有 15～60 筆交易，統計力很低；日K 版的失敗**不代表**原 60 分 K 策略失敗。
- 規格書的『紅棒明顯』『均線附近』都是主觀判讀，我量化成 m 倍平均實體與 δ 倍 ATR；結果不好時規格書建議優先調這兩項，本輪已在網格內（m、δ）。
- 『移動停利須先站上過 5MA 才啟動』『加減碼的 5MA 減半、10MA 全出』是我的推論，不是老吳原話。
- 模組 D（5 分 K）未實作；模組 C 與 E 是逆勢／試單，規格書說小資金應關閉；依 Andy 指示『指定的策略照原則跑』，主結果全開（試單、停損反手、加碼、多空都做），六步表（第三節）列出各原則的邊際效果。
- 保留期（2021 起）不是真正沒看過的資料：前兩輪研究已看過 2013～2026 台指期整體走勢；本輪沒有用它調整設計。
- 成本：每口單邊手續費 50 元、期交稅十萬分之二、滑價 2 點，沿用前幾輪口徑；0050 為含息、扣手續費、ETF 稅與滑價。
