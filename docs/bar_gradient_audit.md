# 長條漸層盤點（2026-10-07）

Andy 原話：「部分長條圖沒有 Follow 圖二那樣的一點漸層風格，改成漸層但對應顏色不變」。

## 規格（量值）
| 類型 | 方向 | 色標 |
|---|---|---|
| 直條（正值） | 上到下 | 實色 → 45% 透明 |
| 直條（負值） | 上到下 | 45% → 實色（遠端實色） |
| 橫條（正值） | 左到右 | 55% → 實色（D 款） |
| 橫條（負值） | 左到右 | 實色 → 55% |
| 堆疊／分段 | 每段各自同色漸層 | 同上，段間仍以相鄰的實色端分辨 |

## 盤點表
| 位置 | 原本 | 做法 |
|---|---|---|
| 全站 ECharts bar（總覽漲跌分佈、資金流向排行、市場漲跌分佈、個股資券／法人／營收／EPS／股利、ETF 報酬、產業地圖族群條、季節性、財經日曆等） | 多為實色；少數已青藍漸層 | `app.js` 圖表包裝處呼叫 `BAR.apply`：字串色、逐筆色、函式色、調色盤色一律轉同色漸層，負值反向 |
| K 線下的成交量柱（ECharts） | 實色 | 同上（只換漸層，不動粗細圓角） |
| 個股籌碼快照：法人 20 日、集保分布、信用與借券（`.mixbar`） | 實色 | CSS 左淡右實；賣超斜紋維持（斜紋是語意） |
| 當沖率、量比、毛利率（`.meter>i`） | 實色 | CSS 左淡右實 |
| 總覽摘要卡分段條（`.osc-bar i`，漲平跌／輪動／資金去向） | 實色 | `ovsSeg` 改給 `--c`，CSS 漸層 |
| 均線格進度條（`.magrid .ma .bar i`） | 實色 | 改給 `--c`，CSS 漸層 |
| 管理區：頁面堆疊條、每日直條（含最高日、開啟分色）、`.mdays` | 部分實色 | `--c` 或 CSS 直條漸層 |
| 手機排行底條（`.mrank .bar`）、手機機構條（`.minst`） | 半透明單色／實色 | 同色漸層 |
| ETF 成分股權重小條（`.wbar`）、訂閱管理選取日 | 單色 | 同色漸層 |
| 已是漸層：管理區流量橫條、客服分類條、`.lgbar` | 漸層 | 不動 |
| 例外：lightweight-charts 成交量（canvas 不支援漸層）、賣超斜紋 | 實色／斜紋 | 維持；已記錄 |
