## 5. 不一致❗ 清單（一句話版）

1. 市場明細四頁的鎖頭：手機頁內分頁看得到，網頁 10-10 改側欄後看不到。
2. 方案名稱：網頁帳號選單寫「免費會員」，手機與方案範本寫「註冊會員」。
3. 手機體驗橫幅把「活動辦法」字藏掉、位置隨分段跳動、兩行截斷可能吃掉「免綁卡、不扣款」。
4. 手機法人四象限、本益比河流圖在觸控畫面寫「滾輪放大」。
5. 站上均線分段名：網頁「其他產業別／傳產與內需／基礎建設與能源」，手機「法定產業別／傳產／基礎建設」。
6. 手機個股頁首漲跌點數用四捨五入的百分比反推（▼34.90），實際是 -35.00。
7. 拿掉休閒風格後，手機帳號選單「版面風格」還是三欄，右邊空一格。
8. 複利試算表改付費（10-10 已上 main）：網頁頁內分頁鈕反灰＋小字，手機頁首「複利試算」那格沒標。
