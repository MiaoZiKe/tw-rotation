## 使用規則（法遵 7-3，六條全成立才可上貼文圖）

### 公司 LOGO
1. 緊貼公司名稱作標示，**不當主視覺**；**封面一律不放公司 LOGO**（封面左上固定放頻道自己的開口圈，見第三節「第 1 張封面規格」）（輪播第一張、單圖貼文本身、Reels 封面都算封面，不論 LOGO 多小），不當大頭貼、不放 IG 精選封面。
2. 原色原比例、不裁切標誌本身、不加效果（本庫只做白底置中、等比例縮放、裁掉標誌外的空白邊，不改色、不變形），**不與開口圈 LOGO 組合**。低解析版貼文上顯示高度不超過約 128px（原圖內容高的 2 倍），要更大就改純文字。範例 A、B、C 三個系列的頁首一律用純文字「科技透明圈」，不放開口圈圖示（統一決策，見 review_art.md）。
3. 高度不超過公司名字高的 1.5 倍；多家並列時一樣大（範例 A1：LOGO 高 80px、公司名 120px，約 0.67 倍）。
4. **負面內容（工時長、加班、抱怨、繁忙）只寫公司名、不放 LOGO，而且以整篇貼文為單位**：同一篇任何一頁有這類欄位，整篇每一頁都不放 LOGO。所以「公司行情」（A 系列，有加班時數、繁忙程度欄位）**固定用純文字版**。
5. 不寫「與○○合作」「○○推薦」。**放了 LOGO 的貼文**，圖內頁底與貼文文字最後一行都要用完整固定句：「文中公司標誌僅用於標示公司，本帳號與各公司無合作或授權關係。」純文字版可用短句「與各公司無合作或授權關係」（範例 A 三張的頁底）。
6. 收到檢舉、來函或 GitHub 通知：**先下架**，換純文字版再發，不爭論。
7. 技術商標（CoWoS、SoIC、3DFabric 等是台積電的商標）：講台積電那項技術才用原名，第一次出現補白話（例「CoWoS（台積電的一種 2.5D 先進封裝）」）；泛指這類技術改寫「2.5D 先進封裝」；有用到的貼文頁底加「CoWoS 為台積電之商標。」不仿原廠字標、不寫「○○概念股」。

法遵複審：2026-11-03 legal-compliance 已審，結論與出處見 `review_legal.md`（有條件通過：公司行情一律用純文字版）。

### 架構圖
- 一律標「示意圖，非實物比例」（每張底部已印）。
- **不畫公司 LOGO、不標客戶對應**：截圖時程式把卡片裡的台股膠囊、股票代號、含公司名的說明文字整個拿掉（程式掃描結果：可見文字 0 個公司名、0 個四位數代號）。圖內「CoWoS」是技術名稱（台積電商標），不是客戶對應；用法照上面第 7 條。
- 取自 `site/diagrams.js`／`site/dg/*.js`／`site/themes3d.js` 的現有圖，淺色主題、2 倍解析度，已去掉網站導覽列與客服／吉祥物浮層。
