## 每張圖的固定驗收（寫進各自的 `_uitest.py` 段落）
1. 兩種模式各切一次 → 底色、卡片、引線真的變
2. 收合 ≤ 700px、章節列打得開收得回、全開文字變多（沒刪內容）
3. 點零件只亮不篩、點背景恢復、小卡「誰做的」正確
4. 12px 下限（閱讀 13px）；對比度正文 ≥ 4.5、次要 ≥ 3
5. 800／390 不溢出
