# 比比主持與異常圖像驗收

依據：Andy 2026-10-17 明確要求，比比是品牌代言與每頁主持人，隨內容、情境及互動呈現豐富動作與表情；不是固定貼角落的吉祥物。使用者圈選的 ASML 範例異常只作退件案例，不裁切重用、不上傳原圖。

## 每頁先寫主持意圖

逐頁製作單必填：本頁結論、比比正在介紹什麼、台詞、表情、視線落點、動作、道具、與圖表／場景的互動、為何需要這個姿勢、素材 ID。必要時配物件；不為了變化硬加道具。

|內容任務|表情與動作示例|視線／物件互動|
|---|---|---|
|封面提問|歪頭、探頭、短掌靠近問題牌|看讀者或主題物件，邀讀者往下看|
|介紹名詞|認真解說、短掌指向模型|看被介紹的零件，泡泡只說一個白話定義|
|結構拆解|湊近觀察、使用放大鏡|鏡片對準零件，不遮接點與標籤|
|比較差異|思考、左右觀察|對應兩個比較物，不能用模糊手勢暗示未證實優劣|
|解讀數據|驚喜或專注、短掌指示重點|看正確的數字或圖表；不能擋軸、單位或財測標籤|
|風險限制|擔心、皺眉、停下檢查|對應警示物或限制條件，避免誇張驚嚇|
|供應鏈|帶路、依節點轉移視線|引導理解流程，不以接觸道具暗示公司訂單|
|結論討論|點頭、朝讀者、整理筆記|回到本頁結論或提問|

以上是選項而非固定姿勢表；依題材選擇。連續兩頁在表情、視線、動作、道具中至少換兩項，並檢查整篇是否重複同一笑臉／貼圖。角色維持奶白毛球、黑點眼白高光、小耳短掌短腳、無尾巴；粉色限耳掌腳，不用金錢圖示。

## 必做的三種視圖

1. **整頁 100%**：確認主持位置、閱讀動線、泡泡方向、圖表正確、物件互動與文字留白。
2. **角色及接觸處放大 200～400%**：檢查耳、眼、嘴、毛邊、掌、腳、輪廓與道具接觸；原始素材解析度不足須換素材或重製，不能用模糊縮圖掩蓋問題。
3. **約 360 px 寬手機縮圖＋整篇縮圖總覽**：看標題重點是否可讀、主持是否明確、連續頁角色是否有內容相關變化。

## 異常圖像退件條件

- 多出或缺少不合理的耳、眼、嘴、掌、腳；多頭、多臉、五官錯位、重影、肢體融合。
- 毛邊外多出無法解釋的小塊、輪廓破碎、殘留碎片、異常凸起、生成的尾巴；不能把這些當正常毛量。
- 前掌拉長、人類手指、與身體斷開、漂浮或穿透道具；物件接觸無支撐、握持方向不合理。
- 臉型、毛量、身體比例或配色偏離官方參考；耳／掌／腳外出現粉色。
- 比比被裁切，泡泡尾指錯人，角色、文字或道具遮住關鍵資料；科技零件重複、熔在一起、結構或箭頭方向不合理。
- 比比只是裝飾，台詞與本頁無關，或用同一姿勢反覆貼上但宣稱已作情境變化。

## 品管紀錄與修正

`qa_report.md` 每頁記「素材 ID／版本、主持功能、放大檢查範圍、缺陷、修正方法、複查結果」。保留檢查用整頁、角色裁切與手機縮圖在本機 `qa/`；裁切只作檢查，不用它掩蓋原素材缺陷。上傳時仍遵守檔案大小與來源登錄要求。

異常先退件，修圖、換合規素材或重製後，重新看完整頁與接觸處。最多三輪仍不過，列出未通過原因，不能標成已完成。沒有實際放大檢查的頁面不得勾選通過。CEO 的風格判斷與 Andy 的風格確認分開記錄。
