## 視覺主軸與構圖

主軸是「奶油系 Q 版毛球 × 科技研究筆記 × 手繪資訊圖表」。科技物件必須是解釋內容的主圖，與比比形成主持互動；裝飾與卡片服務閱讀。

- 封面先看見短問題，再看見一張可辨認的科技主圖，最後讀一句白話承諾。主圖可採晶片分層、機台透視、資料傳輸或產業情境，不用一排清單卡取代主視覺。
- 1080×1350 封面依既有規範起稿：主標區約上方 20～25%，科技主圖與圖表約 45～55%，剩餘空間留給解說、來源與頁碼；依內容調整，這些比例是設計建議而非原圖量測。
- 內頁每頁一個結論：一張主圖或一個圖表，配一到三段短解說。閱讀動線為標題→主圖→標註→比比一句話。
- 留白必須分隔資訊群。外緣保留 64～80 px 安全距離；泡泡、掌、科技物件及頁碼都不可貼邊裁切。
- 先前製作的簡單清單卡封面只屬試做，不代表 Andy 已核可的定版。後續校準應以上述五張參考的科技主圖與角色互動為方向，並保留待確認狀態。

## 手繪線條與科技結構圖

- 外輪廓採深咖啡粗線，略有自然起伏；內部標線較細，保持接點、邊界清楚。線條可以手繪，技術關係不能含糊。
- 科技物件採輕透視或分層剖面，配柔和陰影、紙感色塊與少量高光。避免照片式設備拼貼與過度擬真金屬效果。
- 分層圖先確定上下層、連接與訊號方向，再加標籤。每個箭頭必須能說明傳輸、製程、因果或觀看順序，不能只有裝飾。
- 比較用兩欄表格或對齊長條；流程用編號步驟；供應鏈用節點箭頭；應用用少量場景圖。依經查核的內容選圖，不為套版硬加欄位。
- 數據圖須程式或排版工具繪製，保留資料表及來源編號；座標、單位、期間與財測標籤都須可核對。

## 文字層級與圖文比例

正式繁體中文字、英文標籤、數據、頁碼一律後製排版；生成插畫時保留文字區，不能把模型生成的中文當完稿。

| 層級 | 1080×1350 起始字級 | 使用方式 |
|---|---|---|
| 封面主標 | 88～120 px | 圓潤厚重、深咖啡；問題主標原則 ≤14 字，分兩至三行，重點詞可換色 |
| 內頁頁標 | 56～72 px | 一眼讀到本頁結論，不與主圖搶位置 |
| 本文 | 34～42 px | 清楚繁中字體，保持行距與完整詞彙斷行 |
| 比比泡泡 | 30～36 px | 一句白話，避免重述整段本文 |
| 來源與註解 | 24～28 px | 深色文字，避免淡色小字；來源頁補完整資訊 |

粗手寫感主要用在標題、數字圓章與短標籤；長文使用易讀字體。標題可用奶白細外框強化對比，不能以多層描邊擠滿空間。內頁以圖像承擔解釋，文案超量先刪減或拆頁，不縮字。完稿需另看約 360 px 寬手機縮圖。

## 配色與紙感

以下色碼是從附件視覺歸納的建議色盤，並非對原圖逐像素取樣：

| 用途 | 建議色 |
|---|---|
| 暖白紙底 | `#FFF9EF` |
| 深咖啡文字與輪廓 | `#321A14` |
| 珊瑚重點 | `#F58C83` |
| 蜜桃色塊 | `#FFD4BA` |
| 淡黃提示 | `#FFE5A5` |
| 淺藍資訊 | `#B9DFF0` |
| 薄荷資訊 | `#B9DBCC` |
| 淡紫資訊 | `#DCCEF0` |

每頁以暖白＋深咖啡為底，選一至兩個主重點色；卡片可用淡色底與較深同色邊框。膠囊底、圓章、短底線協助分類。紙紋、星點、短光芒只作少量點綴，不能壓過圖表或造成髒污感。角色的粉色限制獨立適用，不因背景色盤而放寬。

## 比比是主持人

- 造型唯一依據為 `docs/anim/bibi_library/reference/parts_sheet_1011.webp`，可用資產先查 `docs/anim/bibi_library/index.md`。附件只是整體視覺參考，不取代角色造型規範。
- 奶白毛球、深咖啡外輪廓、黑點眼與白高光、小耳、短圓掌、短腳、無尾巴；不能拉長手臂。粉色僅用於耳、掌、腳，不沿用參考圖粉色腮紅或舌頭。不用金錢圖示。
- 每頁賦予主持功能：提問、指向結構、觀察、比較、示範、整理結論。連續兩頁的表情、視線、動作、道具至少改變兩項。
- 掌與道具接觸合理：手持指示棒須握住，趴在晶片上須有承托，放大鏡對準觀察物。角色不能遮住關鍵接點、數據或標籤。
- 泡泡尾巴指向比比，字區與角色分開。比比台詞說明該頁的一個直覺，不提出未證實結論或投資建議。

## 輪播與海報的差異

輪播用逐頁揭露形成節奏：封面提問→名詞→重要性→運作→比較→應用→供應鏈→限制→結論→討論與來源。頁數依內容增減；不為湊十頁填字。每頁同一底色與字體系統，但改變圖表與比比行為。

海報可採大型主圖加三欄或六格知識區，讀者可自行掃讀。轉成輪播時應把每區拆成單頁並重畫布局；不能把整張海報縮小塞入輪播。Threads 配圖沿用主圖、色盤與角色語氣，正文以短段落承接觀點，不複製海報全部小字。

## 製作與驗收

1. 先確認來源與單一結論，寫逐頁製作單及圖表資料。
2. 檢查現有可用素材，決定需重畫或生成的比比與科技物件，登錄來源及權利狀態。
3. 先交第 1 頁風格校準，完成原尺寸與手機縮圖品管；不能把自行品管通過寫成 Andy 已核可。
4. 正式文字與圖表後製，檢查元素不重疊、不裁切、箭頭有用途、泡泡方向正確。
5. 逐頁核對數字與來源、財測與推算標示、角色規格與原創素材來源；最終頁及文案附固定免責。
6. 禁止複製第三方帳號、浮水印、Logo、原圖或直接挖取參考圖素材；不能移除浮水印後重新使用。原作者／權利未知的第三方風格參考原圖不得上傳；既有角色衍生素材須保留 unknown 與使用限制，不宣稱自有原畫。
