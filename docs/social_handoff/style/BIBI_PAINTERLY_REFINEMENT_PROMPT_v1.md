## 1. 風格方向與密度

以「平衡加強版」為基礎：暖白奶油紙底、深咖啡手繪線、珊瑚蜜桃／淺藍／薄荷柔色。保留主題情境、適量物件與留白，不是滿版資訊海報，也不是單色圖示簡報。

## 2. 字體：改掉制式字與硬描邊

請比較參考與成品的字重、字寬、轉角、收筆、字距、行距、基線與描邊比例。不能只說「都是可愛字體」。
主標採厚實圓潤的手寫感字形：寬字面、飽滿筆畫、柔和圓角；筆畫粗細與字的高低有細微自然變化，但仍容易辨識。深咖啡主字搭一個珊瑚關鍵詞，避免細字加厚外框或雙層空心描邊冒充胖字。
內文乾淨清楚，字重比標題輕一階；避免標題與內文同等粗重、每句都膠囊化。中文字不拆詞斷行。
沒有字型檔或字體辨識證據時，只描述可觀察特徵，不亂指定字體名稱。正式文字須逐字驗證，不以「手寫感」容許錯字。

視線看向正在介紹的內容；短掌圍著道具自然彎曲，道具靠近身體；身體與道具接觸處有合理遮擋與柔影。指棒角度和視線朝向同一個重點。

## 4. 物件：增加主題內部細節，不靠加雜物

主題物件要有結構與材質：筆電有鍵盤、鉸鏈、厚度和螢幕框；晶片有層次與接點；伺服器有板件、風扇或插槽；記事本有紙頁、裝訂與手寫痕跡。細節要能解釋主題，不憑空增加未查證功能或製造規格。
主物件之外加一到兩件有用途的輔助道具，例如公告紙、鉛筆、拆解標註或小日曆。使用前後景、遮擋、軟陰影和桌面局部筆觸增加豐富度，避免把大量符號、盆栽和星星塞滿空白。

## 5. 避免僵硬、制式向量感

輪廓略帶粗細與方向變化，邊角圓潤；色塊有輕微筆觸與局部明暗，科技物件有溫柔而清楚的立體感。避免每條線同粗、每個框同尺寸、每件物件完全對齊、角色像貼紙懸浮。

「增加繪畫感」不等於降低字體清晰度、模糊輪廓或畫錯科技結構。
