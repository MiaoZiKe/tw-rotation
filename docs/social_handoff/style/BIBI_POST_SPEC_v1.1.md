# 哩股哩股｜貼文設計與製作規格 v1.1

Andy於2026-10-18指定，優先於舊版版型。預設平衡加強版；角色依Andy提供「跳跳.gif」。

- 預設10頁IG輪播，1080×1350，01.png至10.png；保留非標準原檔不拉伸。
- 必附IG文案、Threads短文、Hashtag、全篇預覽、ZIP；登記來源、日期、版本、素材歸屬；不自動發布。
- 每頁：一清楚標題、一有解釋功能主圖、一隻參與情境比比、兩短重點、一小句操作／解讀／限制。主圖約40–50%，呼吸空間25–30%，不機械切格。
- 暖白#FFF9F0、深咖啡#3C2118、蜜桃#F58C78、淺藍#BBDFF3、薄荷#C7E7D5、少量淡黃#F9DFAC；色票為工作近似值。
- 物件與角色有筆觸、局部明暗、柔和陰影、自然輪廓；不是整齊向量加紙紋。避免等粗線、等大框、過度幾何對稱、塑膠高光、生硬投影、制式三卡、無關星星盆栽。
- 主標80–110px，厚實圓潤寬字面手寫感；禁止細字厚描框、雙層空心框。內文34–42px，補充28–34px，註24–28px，安全邊距64–80px；先減字，不縮小塞滿，不拆詞斷行。
- 比比扁圓寬奶白毛球、深咖啡粗輪廓不規則柔毛邊、小純黑點眼、小鼻ω嘴、可露橘粉小舌、大淡橘粉腮紅、小圓橘粉耳、兩側橘棕短毛斑、小圓掌短橘粉腳、無尾巴。禁止尖臉、長身、長手臂、多肢。
- 先決定介紹內容再設計主持動作，側身／歪頭／重心轉移／抱物／靠桌／短掌指讀；視線、指棒與重點對應。道具接近身體有合理接觸遮擋與陰影。相鄰頁表情／視線／朝向／動作／道具至少變兩項。
- 主物件結構材質提供豐富度，最多一至兩件有用途輔助道具；示意不冒充精確工程規格。結構圖保持正確層次、接點、承載與連線。
- 每篇頁序依主題，不硬套APP導覽範例。末頁只放收尾台詞、討論／收藏CTA及免責，不放網址／QR。
- IG包含開場、解說、互動、來源、官網、Hashtag；Threads另寫短文，不貼製作稿。官網https://liguligu-puipui.com/#overview，追蹤參數放#前；私人Studio不是對外品牌官網。
- 固定免責「整理公開資訊，非投顧，投資請自行判斷。」
- 數字日期單位功能有來源；介面標「功能示意，非即時行情」；不推薦個股、不保證配息報酬複利、不把未確認關係頻率當事實。
- 文字逐字、整頁、角色放大、手機縮圖、全篇總覽驗收；不多肢、不漂浮、不穿模、不複製第三方帳號浮水印Logo原圖。
- 保存原圖、文案、提示詞與來源，另留版本、不覆蓋歸屬；原作者權利未知保留unknown。本機、網站、GitHub、PR合併、發布分開回報。

- Andy最新：圖卡底部不放資料來源名稱或來源網址，統一列在FB／IG／Threads文案，並留sources.md。此指示取代舊來源頁要求；必要資料日期、期間／單位、公司說法、財測／示意／情境標籤及免責仍保留。

- Andy再更新：最底部任何額外小字備註都取消，包括行情日期、來源、灰字限制與免責，全部移文案；依根目錄 `專屬產貼文.md`。黃色內容補充句仍保留；必要期間、單位、約數與示意／情境辨識融入主圖或正文，不能誤導。

- 去備註後重新配版，不保留原腳註占位或過大下方空洞；重分配主圖／兩點／黃色補充帶尺寸與間距，保留適當安全邊距，整體飽滿協調，不硬塞無關裝飾。
