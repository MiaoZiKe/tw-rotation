## 1. 這張圖要回答什麼問題

**「AI 資料中心的電從哪裡來、為什麼重電廠吃得到這波。」**

使用者看完要能自己講出這三句：

1. **電從電網來，而且中間要換好幾手。** 從電廠出來是 345kV 超高壓，
   到機櫃裡的晶片是幾十伏特的直流 —— 中間每一次「換手」都是一台設備、一張訂單。
2. **降壓的是變壓器，切斷與隔離的是開關設備，兩者是不同的東西。**
   GIS（氣體絕緣開關設備）不降壓；配電盤也不降壓。電壓只在變壓器那幾格往下掉。
3. **台廠吃到的不是「AI」，是「這條路徑上的鐵件」。**
   資料中心用電暴增 → 電網要擴建、廠內要受電 → 電纜、GIS、變壓器、配電盤、
   不斷電系統全部要買 —— 這些東西台廠本來就在做，而且交期長、產能有限。

**這張圖的成敗**：使用者指著圖上任何一格，要能說出
「這一格是**降壓**還是**開關**、電進來幾 kV、出去幾 kV、這一格的台廠是誰」。
說不出來，圖就白畫。

## 3. 層別／流向順序（★ 最常錯，四組全部寫死）

### 3-A 主路徑：由左到右，電壓單調遞減

```
〔段0 分支：發電端〕
    電廠 / 再生能源 + 電網級儲能  ──升壓──▶
段1  超高壓輸電        345 kV         架空線（鐵塔）＋ 地下電纜
      ↓（超高壓變電所 345→161）
段2  變電所 GIS        161 kV         ★ 開關，不降壓
      ↓（主變壓器降壓）
段3  主變壓器          161 kV → 22.8 kV（示意，見 §6-B4）
段4  中壓配電盤        22.8 kV        ★ 開關，不降壓
      ↓（廠內變壓器降壓）
段5  廠內變壓器 → UPS → PDU    380 / 220 V
段6  匯流排槽 → 機櫃 → 電源架 → 直流匯流排（示意，見 §6-B6）
```

**硬規則（違反其一就退回）**：

1. **所有箭頭一律由左（電網）指向右（機櫃）。**
   任何一條線倒著走就是錯 —— 2026-09-19 圖十就是這個錯（目標在左邊的邊整條
   倒著從卡片底下穿過去），這張圖是路徑圖，方向錯了整張圖的意思就反了。
2. **電壓只准降不准升。** 唯一一次升壓在段 0（電廠端），而且要畫在
   **「進入輸電線之前」**，不是之後。
3. **★ GIS 不降壓，配電盤也不降壓。** 電壓階梯帶在段 2 與段 4 **必須是平的**。
   只有變壓器那幾格（段 0 升、段 3 降、段 5 降）才准出現階差。
   **這是這張圖最容易被內行人一眼抓到的錯。**
4. **GIS 在主變壓器之前**（進線側的 161kV 開關），**中壓配電盤在主變壓器之後**。
   兩者對調＝錯。理由：開關設備的工作是在**它所在的那個電壓等級**上切斷與隔離，
   進線側的開關當然在降壓之前。
5. **UPS 在 PDU 之前**，PDU 在機櫃之前。
6. **電池掛在 UPS 的直流側，是一條往下的分支，不是串在 UPS 的輸出上。**
   畫成「市電 → UPS → 電池 → PDU」＝錯。
7. **柴油發電機（如果畫）是分支，不是一站。** 它從側邊併到**段 4 的中壓匯流排**上，
   且併接點要標「示意：實際併接位置依案場設計而異」（§6-B5）。
8. **段 0 的再生能源與電網級儲能也是分支**，接在**電網側**（段 1 之前），
   不是接在資料中心裡。把太陽能板畫在機房屋頂旁邊接進 PDU ＝ 另一件事，不是這張圖。

### 3-B 電壓階梯帶（畫面最上方那一條，由左到右）

| 位置 | 標示 | 依據 |
|---|---|---|
| 段 0 出口 | 升壓 → **345 kV** | §6-A1、A2 |
| 段 1 → 段 2 之間 | 超高壓變電所 **345 → 161 kV** | §6-A2 |
| 段 2 | **161 kV**（平的） | §6-A2、A3 |
| 段 3 | **161 → 22.8 kV**（一次配電變電所路徑） | §6-A2，**惟資料中心受電等級為示意，見 §6-B4** |
| 段 4 | **22.8 kV**（平的） | §6-A1 |
| 段 5 | **22.8 kV → 380 / 220 V** | §6-A1 |
| 段 6 | 低壓交流 → 機櫃直流（**示意**，不標數字，見 §6-B6） | §6-A10 |

**硬規則**：
- 階梯**高度不必與電壓成比例**（345 到 220 差三個數量級，畫不出來）
  → 畫面上必須有一行「電壓階梯為示意，階高與電壓不成比例」。
- 另外畫一條**可選的 69 kV 支線**（一次變電所 161→69，二次變電所 69→22.8/11.4），
  標「另一條常見路徑」，用虛線。**不要**把它畫成主線的一部分 —— 台灣兩條路徑都存在，
  但一張圖只能有一條主線（§6-A2）。

### 3-C 油浸式變壓器外觀（由外到內，只畫外觀不畫繞組）

1. 基礎與滾輪軌道 → 2. 油箱（含加強肋）→ 3. 側面掛散熱器（**垂直薄片**，上下各一集管）
→ 4. 箱蓋上伸出套管（**高壓側左、低壓側右**）→ 5. 油箱上方一側架橫放的儲油櫃
→ 6. 儲油櫃下掛吸濕呼吸器 → 7. 儲油櫃與油箱的連通管上裝瓦斯電驛
→ 8. 油箱側面掛 OLTC 驅動機構箱 → 9. 箱壁上的溫度計與油位計

**硬規則**：
- **高壓側朝左（進線）、低壓側朝右（出線）**，方向不准反。
- **高壓側套管明顯高於低壓側套管**（絕緣距離的必然結果）。兩側等高＝錯。
- **散熱片是垂直的。**
- **儲油櫃是橫放的圓筒。**
- **不畫繞組剖面**（§6-B3：低壓繞組在內、高壓繞組在外這件事，
  本次查不到可引用來源 → 寧可不畫，不要編）。

### 3-D GIS 一個 bay 的內部順序（**可選**，要畫才適用；畫了一律標示意）

線路側 → 避雷器 → 比壓器（VT）→ 隔離開關（DS）→ **接地開關（ES）**
→ 比流器（CT）→ **斷路器（CB）** → 比流器 → 隔離開關（DS）→ 母線

**硬規則（只有這兩條是硬的，其餘排列依案場而異 → 標示意）**：
- **斷路器兩側各要有一組隔離開關**（檢修時兩邊都要隔離得開）。
- **接地開關要緊鄰隔離開關的線路側**（先隔離、後接地，順序不可倒）。

### 3-E 底部流程列（由左到右，6 格，對應段 1～段 6）

1. **發電與升壓** → 2. **超高壓輸電** → 3. **變電所：開關與降壓**

## 4. 一定要有的識別特徵

看到這些才認得出是哪一種設備，而不是「一堆有顏色的方塊」：

### GIS（段 2）

- **★ 水平的圓筒，不是方箱。** 這是 GIS 唯一的決定性特徵，缺了這個整格就報廢。
- **圓筒之間用法蘭接合**：接縫處畫一圈**凸出的環 ＋ 一圈等距小螺栓**。
  每一段之間就是一個氣室分界。
- **斷路器氣室明顯比母線圓筒粗**，而且**下方（或旁邊）掛一個方形操作機構箱**（有觀察窗）。
- **外殼上有 SF6 氣體密度錶**（小圓錶），至少畫 2～3 個，分散在不同氣室上。
- **高壓級畫成三個平行的圓筒**（單相分箱）。畫成一根粗筒是中壓級的畫法，
  跟 161kV 的標註對不起來。
- **一端有電纜終端封匣（垂直向下）或帶傘裙的套管（斜向上接架空線）**。
- **整體接地**：畫一條粗接地線從外殼拉到地面接地符號。
- ✗ **不准畫成開放的瓷瓶＋裸露刀閘**（那是 AIS，是 GIS 的對照組，不是 GIS）。

### 油浸式電力變壓器（段 3）

- **★ 側面一排垂直的散熱薄片，上下各一根集管接回油箱。** 這是一眼認出變壓器的特徵。
- **★ 油箱上方一側橫放一個圓筒（儲油櫃）**，用一根管子接到箱蓋。
- **★ 箱蓋上伸出帶傘裙的套管，而且左邊（高壓側）明顯比右邊（低壓側）高。**
- 吸濕呼吸器：儲油櫃下方一根細管接到一個小玻璃筒。
- 油箱側面一個獨立的方形箱體（OLTC 驅動機構）。
- 底部有軌道式滾輪。
- ✗ 不准畫成一個光滑的大方塊（那是乾式／模鑄變壓器，是段 5 那一台）。

### 乾式／模鑄變壓器（段 5）

- **★ 沒有油箱、沒有散熱片、沒有儲油櫃** —— 這三個「沒有」就是它的識別特徵。
- **看得見三個直立的環氧樹脂圓柱線圈站在底座上**，外面罩一個**帶百葉或網孔的金屬護罩**。
- **要跟段 3 的油浸式並排對照放在同一個視野裡**，不然「為什麼室內用這一台」看不出來。

### 中壓配電盤（段 4）

- **★ 一整排等高、等深的金屬櫃並排**，櫃縫等距 —— 不是一個大方塊。
- **每一櫃正面分三段**：上段是低壓儀表／電驛室（面板上有小方塊電驛、指示燈、電表）、
  中段是斷路器室、下段是電纜室。
- **至少一櫃把抽出式斷路器拉出來一半**，看得到**導軌與一次接觸子** ——
  這是「metal-clad」跟「一個鐵箱」的差別。
- **櫃頂有洩壓通道**（一條掀起的板或格柵）。

### 不斷電系統與電池（段 5）

- UPS 櫃正面有**顯示面板**與**進出風百葉**。
- **★ 電池櫃是一層一層的電池模組抽屜，看得出分層與極柱** —— 不是一顆大方塊。
- **電池是從 UPS 的直流側往下分出去的一條支線**，不是串在輸出上。

### 匯流排槽與機櫃（段 6）

- **★ 機櫃上方懸吊一條矩形金屬槽，每隔一段掛一個插接箱往下拉線到機櫃。**
  不是一堆亂拉的電線。
- **電源架裡並排數個可熱插拔的 PSU 模組**（看得出把手與風扇孔）。
- **機櫃背面一條垂直的銅色匯流排**。

### 輸電段（段 1）

- 架空：**格子狀鋼架鐵塔**，每相吊一**串**絕緣礙子（多片傘裙盤串成一串，不是一顆），
  導線畫成**分裂導線**（同一相多根並行，不標根數，見 §6-B7）。
- 地下：**電纜剖面由內到外**：導體 → 內半導電層 → 交連聚乙烯（XLPE）絕緣
  → 外半導電層 → 金屬遮蔽／被覆 → 外被。這個順序寫死，同心圓要看得出層數。

### 全圖

- **比例小人站在段 3 的變壓器旁邊。** 這張圖的六個物件真實尺寸差很多
  （鐵塔幾十公尺 vs 電源架幾公分），沒有小人就沒有人知道哪個大哪個小。

1. 資料中心是**特高壓等級的大用戶**，不是接一條家用電線就好 ——

   而且是重資產、長交期、要通過台電與業主認證的東西 —— 產能不是想開就開。
4. **本圖不放任何在手訂單、市占率或營收占比數字**（會過期，且屬於

### D. `data-seg` 的限制（★ 這條不照做顏色會說謊）

`supply_chain.yaml` 裡有一個 `power` 環節，但它屬於 **`chain: ai_server`**，
成員是台達電、光寶科這些**伺服器電源**廠 —— **不是電網的重電**。

現行 `T.heavy_electric` 把變壓器／開關／馬達三站都掛了 `seg: 'power'`，
於是它們拿到的是「AI 伺服器電源環節」的顏色。
在題材圖裡 `data-seg` **只影響顏色**（`app.js` 的 `wireThemeDiagram()` 只用
`pick(n.dataset.seg)` 挑色，個股清單走 `data-codes`），所以**這不是資訊錯誤，
嚴重度低於 `mlcc_stack` §6-D**，但仍然是「顏色在說一件不對的事」。

→ **這張圖的所有站點一律只帶 `data-part` 與 `data-codes`，不帶 `data-seg`。**
`pick()` 會自動退回 `PALETTE` 依序配色，六站六個不同顏色，正是這張圖要的。
