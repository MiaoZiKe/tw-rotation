# machine_tool：CNC 工具機 3D 場景 —— 一台立式綜合加工機

> 2D 那張是 `site/dg/machine_tool.js`，規格散在 `motion_control.md`（兩個族群共用分級）與 `docs/diagram_plan_electronics.md`。
> 這一份只管 **3D 場景 `machine_tool`**（`site/three3d.js` 的 `SCENES.machine_tool`，0923-E 新增），
> 2026-09-26 第二批細緻化（D 組）時補寫。共同驗收條件引用 `dg3d_standard.md` §3、§5。

- **id**：`machine_tool`（3D 場景；路由 `#industry/electronics/dg/machine_tool`）
- **型式**：真 3D。理由（0923-E 就寫在場景註解裡）：一台加工機是**三根互相垂直的軸疊起來**的，
  「誰疊在誰上面、誰帶著誰走」在正視圖看不出來，一定要轉才看得到。
- **零件清單、編號、卡片文字、台股對應**：這一輪一個都沒動（17 件，編號 01 床身 … 17 排屑機）。
- **不再自己動**（2026-09-23 Andy 退版）：這一輪也沒有加回任何動畫（`_uitest.py` 的 C6 棘輪要求 `machine_tool` 是空集合）。

## 1. 這張圖要回答什麼問題

「一台綜合加工機的三根軸裡裝的是什麼？哪幾塊是台廠自己做、哪一塊（控制器）是外購的？」
所以結構上最重要的是**三軸疊法**與**傳動件跟單軸模組那張是同一批零件**。

## 2. 層別／順序（收攏狀態，★ 這一輪改對的地方）

以前收攏時：立柱的滑軌**埋在立柱裡面**、主軸頭**插進立柱**、鞍座直接貼在床身上（沒有滑軌可走）。現在：

| 由下往上 | 世界座標 y | 說明 |
|---|---|---|
| 床身 | −12～4 | 頂面兩條 **Y 向滑軌**（沿 z） |
| 鞍座 | 4～24 | 底下四顆 Y 向滑塊包住床身滑軌；頂上兩條 **X 向滑軌**（沿 x） |
| X 軸螺桿 | 軸心 22 | 在兩條 X 滑軌中間 |
| 工作台 | 20～34 | 底下四顆 X 向滑塊＋螺帽座；頂面 T 型槽 |
| 工件＋壓板 | 34～46 | 凹穴在主軸正下方 |

| 由後往前（z） | 說明 |
|---|---|
| 立柱 −36～−6 | 正面兩塊加工座面 |
| Z 向滑軌 −6～−1 | 頂面朝 +z（朝主軸頭）；以前轉錯方向，頂面朝側面 |
| Z 軸螺桿 軸心 −1 | 兩條滑軌中間 |
| 主軸頭 滑塊 −4～3、背板、箱體 5～35 | 主軸中心 z = 22，正對工作台上的工件 |

主軸（58～92）→ 刀柄法蘭（55～58）→ 刀尖（≈ 43，在工件凹穴裡）。刀庫最下面那個倒下的刀套、換刀臂的兩個爪、主軸上的刀柄 V 形槽都在 y ≈ 56，一條線。

## 3. 識別特徵（缺了就不算做到）

| 零件 | 識別特徵 |
|---|---|
| 床身、立柱 | 鑄件：肋、鑄孔（取砂芯留下的窗）、立柱底部三角補強肋 |
| 滑軌／滑塊 | 軌道斷面四道圓弧溝＋沉頭孔；滑塊 ㄇ 字＋端蓋＋刮油片（沿用「工業自動化」那張同一支幾何） |
| 鞍座 | 上下兩組互相垂直的導引（下 Y 上 X） |
| 工作台 | T 字斷面的 T 型槽、集水溝 |
| 主軸 | 鼻端兩顆驅動鍵、暗色錐孔、拉桿與碟形彈簧 |
| 刀柄 | 拉釘 → 7:24 錐柄 → 法蘭（V 形夾持槽＋兩個驅動鍵槽）→ 夾頭 → 銑刀（兩條螺旋刃） |
| 刀庫 | 一圈刀套、每個插一支刀柄；**最下面那個倒下 90°**（換刀位置） |
| 換刀臂 | 兩端 C 形爪、張口方向相反；中間輪轂＋凸輪箱 |
| 控制器櫃 | 操作面板＋下半門拿掉看得到 CNC 控制器、四台驅動器（散熱鰭片）、線槽 |
| 排屑機 | 鏈板＋鉸鏈銷＋擋屑板，平段轉斜段；底下切削液水箱 |
| 冷卻液（沒有自己的零件編號） | 主軸頭的冷卻液環＋兩支節式噴管對準刀尖；排屑機底下水箱的水面 |
| 三顆進給馬達（沒有自己的零件編號） | X 在鞍座 +x 端、Y 在床身正面、Z 在立柱頂上軸朝下 —— 主軸馬達卡片寫「跟三顆進給馬達同一支幾何」，以前場景裡其實沒有這三顆 |

### 仍是示意（副標已寫「示意圖，非實物比例」）

- **整台機器的外罩鈑金沒有畫**：真機的加工區被一整圈防護鈑金包住，畫上去就什麼都看不到了（這張圖的目的就是看裡面）。這是刻意的省略，不是漏掉。
- Z 軸配重（或平衡油壓缸）沒有畫；Y 軸螺桿沒有畫（被伸縮護罩蓋住的位置）。
- 刀庫的刀套數畫 10 個是示意；刀庫裡的刀柄比主軸上那支小一號（0.84 倍）才排得下。
- 換刀臂畫在「抓刀」的那一瞬間位置（靜止圖），實際換刀時主軸頭要先升到換刀高度。
