## 1. 這張圖要回答什麼問題

**「打線跟覆晶差在哪？一顆晶片從晶圓到出貨要測幾次？封測廠與測試服務廠各做哪幾格？」**

使用者看完要能自己講出這四句：

1. **打線是「面朝上、一根一根拉線」，覆晶是「面朝下、凸塊一次全接」。**
   打線的銲墊只能排在晶片四周，所以接腳數受限；覆晶可以在整個面上排陣列，
   接腳多、電性也比較好（§7-A1）。
2. **測兩次，而且是在兩個不同的東西上測。**
   **CP（晶圓針測）在晶圓上、用探針卡，在封裝之前**；
   **FT（成品測試）在封裝好的顆粒上、用測試座**（§7-A2）。
3. **CP 先測是為了省錢。** 先把壞的晶粒標出來，就不會把封裝的錢花在注定報廢的晶片上；
   而且 CP 也用來監控前段製程的良率（§7-A3）。
4. **封測廠（OSAT）做整條產線；測試服務廠只做 CP 與 FT 這兩格、不做封裝。**
   這就是兩個族群為什麼是兩個族群（§7-D2）。

**這張圖的成敗**：Andy 指著流程列任何一格，要能說出
「這一格在做什麼、用什麼工具、**是封測廠還是測試服務廠在做**」。第三句講不出來，圖就白畫。

## 3. 層別／順序（★ 可判定的條目，最常錯的三組全部寫死）

### 3-A 打線 vs 覆晶：兩張剖面的硬規則

**打線（區 A）**
- **W1**　★★ **晶片正面朝上**（有銲墊那一面朝上）。朝下＝那是覆晶。
- **W2**　★ **銲墊只排在晶片上表面的四周**，中間不可以有銲墊。
      這是「打線接腳數受限」的原因本身（§7-A1）。
- **W3**　★★ **銲線從晶片上表面的銲墊拉到載體的指部，畫成弧形。**
      三個子條件：① 起點在晶片**上**表面；② 終點在**晶片之外**的載體上；
      ③ **線不可以穿過晶片本體**。任一條不成立就退回。
- **W4**　俯視小格畫成**四周一圈**、中間空。

**覆晶（區 B）**
- **F1**　★★ **晶片正面朝下**（主動面朝向基板）。朝上＝那是打線。
- **F2**　★ **凸塊在晶片與基板之間**，而且**比銲線粗短很多**（凸塊是一顆一顆的柱／球，不是一條線）。
- **F3**　★★ **底填膠只填在晶片下方、凸塊之間的縫隙裡。**
      畫成蓋在晶片**上面**＝那是模封膠，兩者混掉就把「底填」這個名字弄反了。
- **F4**　俯視小格畫成**滿版陣列**（整個面都有點）。
- **F5**　★★★ **同一張剖面裡不可以同時出現銲線與覆晶凸塊。**
      那是兩種互斥的接合方式；混畫＝直接退回，不進二輪。
- **F6**　**兩張剖面的晶片用同一個顏色、同一個大小** —— 這張圖的命題是「同一顆晶片、兩種接法」。

### 3-B 流程順序（★ 這是這張圖最常錯的一段）

```
晶圓 →【CP】→ 切割 → 黏晶 → 接合 → 模封 → 切單成型 →【FT】→〔預燒〕→ 出貨
```

- **T1**　★★★ **CP 一定在切割之前、FT 一定在模封之後。**
      CP 測的是**還連在一起的晶圓**，FT 測的是**已經封好的顆粒**。
      把兩者畫成同一個階段、或把 FT 畫在封裝之前＝**直接退回，不進二輪**。
- **T2**　★★ **第 2 格底下必須標「做在晶圓上」、第 8 格底下必須標「做在封裝好的顆粒上」。**
      這一條是 T1 的文字版保險 —— 順序對了但沒寫清楚對象，讀者還是會混。
- **T3**　★ **CP 用探針卡、FT 用測試座**，兩者**不可以畫成同一種工具**。
      區 D 的針尖接觸的是**晶圓**，區 E 的座夾住的是**封裝顆粒**（§7-A4）。
- **T4**　**黏晶在切割之後。** 還連在晶圓上就黏到導線架上＝物理上不成立。
- **T5**　**模封在接合之後。** 先包膠再打線＝線拉不進去。
- **T6**　**切單／成型在模封之後。**
- **T7**　預燒（Burn-in）那一格**標成選配**（用虛線框或灰底），不是每顆都做。

### 3-C 標示帶

- **S1**　★ 帶 ① 必須**連續覆蓋第 2～9 格**。
- **S2**　★★ **帶 ② 必須是斷開的：只蓋第 2 格與第 8（含 9）格，第 3～7 格必須露空。**

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **打線**：**晶片面朝上 ＋ 弧形的線 ＋ 銲墊在四周**。
- **覆晶**：**晶片面朝下 ＋ 一排凸塊 ＋ 底填膠只在下方**。
- **CP**：**針尖 ＋ 一整片晶圓**。
- **FT**：**測試座 ＋ 一顆封好的顆粒**。
- **標示帶 ②**：**中間是斷的**。

### 4-B 最常見的畫錯

| # | 畫錯的樣子 | 為什麼是錯的 | 對應審查 |
|---|---|---|---|
| 1 | **CP 與 FT 畫成同一個階段**（或都畫在一顆封好的晶片上） | CP 測晶圓、FT 測顆粒。這是整張圖最核心的區分 | **T1（紅線）** |
| 2 | **同一張剖面同時畫銲線與凸塊** | 兩種接法互斥 | **F5（紅線）** |
| 3 | 覆晶的晶片畫成面朝上 | 「覆」就是翻過來的意思 | **F1（紅線）** |
| 4 | **底填膠蓋在晶片上面** | 那是模封膠。底填是「填在底下」 | **F3（紅線）** |
| 5 | 銲線起點畫在晶片側面或底面 | 銲墊在上表面，線只能從那裡拉 | W3 |
| 6 | 銲線畫成直線且穿過晶片 | 線是弧形的、繞在外面 | W3 |

## 9. 給 `tech-illustrator` 的實作邊界

- **先畫兩張剖面、先確定「面朝上 vs 面朝下」在 800px 下還看得出來**，再補流程列。
  那一組對比是這張圖的靈魂；窄畫面下如果兩張被擠成上下堆疊，**方向對比就沒了** ——
  那時要在每張剖面旁各加一個小的方向圖示（「▲ 主動面朝上」／「▼ 主動面朝下」）。
- 兩張剖面**用同一支函式畫晶片與載體**，只換「晶片翻轉」與「接合方式」兩個參數 ——
  這樣 F6 自動成立，而且 F5（不可混畫）在程式層面就不可能發生。
- 銲線用 `path` 的二次貝茲畫弧，**起點一律取晶片上表面的 y**、
  終點一律取載體上表面的 y，**用變數不要用魔術數字** —— 手填座標是 W3 最常見的失敗原因。
- 底填膠用**只在晶片下方那一段**的 `rect`／`path` 畫，
  **它的 y 範圍上限必須是晶片底面**（程式層面保證 F3）。
- 流程列走既有的 `processBar`，**行距用改過之後的 40／+32**。
  **CP 與 FT 兩格用同一個強調樣式**，並在格子底下多一行「做在晶圓上／做在封裝好的顆粒上」（T2）。
- **標示帶 ② 用兩段 `rect` 畫**（第 2 格一段、第 8～9 格一段），
  **不要用一條長 `rect` 再蓋白色遮罩** —— 遮罩在深淺主題切換時會露餡。
- 顏色一律走 `--dg-*` / `var(--c)`，不准寫死 `#xxxxxx`。這張圖**有兩個 `data-seg`**，
  所以 `var(--c)` 會帶進兩種環節色 —— **兩區的環節色不同是對的，不要硬統一**。
- **`data-part` 一律要寫**。建議命名：
  `ot_lf` / `ot_da` / `ot_die_up` / `ot_pad` / `ot_wire` / `ot_mold` / `ot_lead` / `ot_top_wb` /
  `ot_sub` / `ot_die_down` / `ot_bump` / `ot_uf` / `ot_ball` / `ot_top_fc` /
  `ot_wafer_in` / `ot_cp` / `ot_dice` / `ot_attach` / `ot_bond` / `ot_molding` / `ot_singulate` /
  `ot_ft` / `ot_burnin` / `ot_probecard` / `ot_socket` / `ot_band_osat` / `ot_band_test`。
- 動畫：只做一件事 —— **一顆晶粒沿著流程列由左往右走**，經過 CP 與 FT 時停一下閃一下。
  **不要讓剖面裡的層跑來跑去。** 靜止時流程箭頭仍看得見。
- **SVG 的 `<style>` 裡（含註解）一律不准出現角括號。**
