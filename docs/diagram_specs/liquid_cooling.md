## 0. 要不要 3D —— 判斷與理由（★ 這一段要先被簽掉）

**結論：不做真 3D。`SLOTS` 的 `scene` 留 `null`。**

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 冷板內部的流道（微流道／削切鰭片 skived fin） | 不會。流道被銅殼完全包住，**只存在於剖面**。真 3D 轉到任何角度看到的都是一塊實心銅盒 | 2.5D 切開即可 |
| 均熱板（VC）內部的毛細層與蒸氣腔 | 不會，而且會更糟。毛細層是**多孔材的微觀結構**，3D 網格畫不出多孔，只能靠 2D 局部放大的紋理表達 | 2D 放大剖面 |
| 熱管內部的液／汽逆向流動 | 不會。要表達的是「同一根管子裡液體往左、蒸氣往右」，那是**剖面上的兩個箭頭** | 2D 剖面 |
| VC 是「面」而熱管是「線」 | **不會，而且轉了會混淆**。這是「擴散的維度」不是「物體的維度」—— 用一張俯視熱分佈對照圖（一條長條擴散 vs 一個面擴散）講最快 | 2D 對照小圖 |
| 熱的路徑：晶片 → TIM → 冷板 → 快接頭 → 分歧管 → CDU → 設施側 | 不會。這是**拓樸（誰接誰）**，不是空間座標。並聯或串聯這件事在 2D 管路圖上最清楚，3D 反而會被管子互相遮住 | 2D 迴路圖 |
| 一次側／二次側兩個迴路不相通 | 不會。這是**兩個封閉環**的邏輯關係，2D 畫兩個環、中間夾一個板式熱交換器最清楚 | 2D 迴路圖 |

**唯一一個「3D 可能有用」的候選**是「一整櫃裡冷板、軟管、側分歧管、CDU 的實際三維走管路徑」——
但那件事**既有的 `three3d.js` `ai_server` 機櫃場景已經在做**（`dg3d_standard.md` 的 16 個零件），
再做一個等於做兩次同一件事。

反面成本三條，都是查得到或量得到的：
1. `site/three3d.js` 的 `SCENES` 是「零件排開（explode）」語彙。冷板、VC、熱管**拆開之後看到的是三塊金屬片**，
   而這張圖的全部資訊都在它們**沒被拆開時的內部**。
2. 3D 在手機吃力（AGENTS §11 明列）。
3. 每多一個 3D 場景就多一組 WebGL context 與 rAF 迴圈要管（`dispose3D()` 那條既有的坑）。

**什麼條件下才該回頭加 3D**（寫死，避免下次又變成事後補簽）：
> 只有當這張圖要新增「**冷板／分歧管／CDU 在機櫃裡的實體位置與尺寸關係**」這一類
> **空間座標**資訊，**而且**確認既有的 `ai_server` 3D 機櫃場景無法承擔時，
> 才重開這一段、改規格書、重新簽。
> 「看起來比較立體」「別張圖有 3D 所以這張也要有」**都不算理由**。

## 1. 這張圖要回答什麼問題

畫面上要印出這三個問題（`q` 欄位取第一個）：

1. **「熱從 GPU 晶片走到機房外面，中間經過哪幾關？每一關是誰做的？」**
2. **「均熱板（VC）跟熱管的內部差在哪？為什麼一個是『面』、一個是『線』？」**
3. **「液冷為什麼不是把風扇換成水管那麼簡單？」**

使用者看完要能自己講出這四句：

1. **熱是接力跑的**：晶片 → 導熱介面材料（TIM）→ 蓋板／均熱板 → 冷板 → 冷卻液 →
   快接頭（QD）→ 分歧管 → CDU → 設施側水 → 屋外。**任何一棒掉了，前面做再好都沒用。**
2. **VC 與熱管是同一個物理，差在形狀**：都是「真空腔＋少量工作流體＋毛細結構」，
   靠蒸發—冷凝搬熱。**熱管把熱沿著一條線送走，VC 把點熱源攤平成一個面。**
3. **液冷系統真正的難點不在冷板，在接點與迴路**：快接頭是最容易漏水的地方、
   分歧管要讓幾十個冷板**並聯**而且流量分得均勻、CDU 要把機櫃側（二次側）
   跟機房側（一次側）**用板式熱交換器隔開**，兩邊的水不相通。
4. **台股在這條路上不是只有一家**：冷板、分歧管、CDU、快接頭、均熱板／熱管
   分別是不同公司的主戰場，而且 2026 年開始互相跨線。

**這張圖的成敗**：Andy 指著圖上任何一個零件，要能說出
「這一塊是誰做的、它壞掉會發生什麼事」。講不出這句，圖就白畫。

- **一次側與二次側接成同一條管路** → 這是這張圖**最致命**的錯，見 §3-C。

## 3. 層別／流向順序（★ 最常錯，四組全部寫死）

### 3-A 熱的路徑（由內到外，這是主圖的主軸）

```
 裸晶 die
   │  ← TIM1（極薄）
 均熱片 IHS／lid（實心銅）  或  均熱板 VC（真空腔）      ← 二選一，圖上兩種並排對照
   │  ← TIM2（極薄）
 冷板底板（銅）
   │
 冷板內部流道 ── 冷卻液帶走熱
   │
 出水口 → QD → 回水分歧管 → CDU 二次側
   │
 CDU 內部板式熱交換器（二次側 ↔ 一次側，**液體不相通**）
   │
 一次側設施水 → 屋外（冷卻水塔／乾冷器／冰水主機）
```

**硬規則（違反其一就退回）**：
- **每兩個固體之間都要有 TIM**，而且 **TIM 畫得比它上下的任何金屬層都薄**。
- **冷板一定在蓋板／VC 之上**，不可以畫成冷板在下、晶片在上。
- **進水冷、出水熱**：進出口要用**兩種顏色**分開，且顏色一路延續到分歧管與 CDU。
- 熱的方向**全程單向**（晶片 → 外面），圖上不准出現往回指的熱流箭頭。

### 3-B 兩相元件內部（VC 與熱管，由外到內）

**VC（均熱板）**，由下到上：
1. **下蓋板**（貼熱源那一面）
2. **毛細結構**（燒結銅粉／溝槽／網目）—— 液體在這一層，**往熱源方向回流**
3. **蒸氣腔（真空，只有少量工作流體）**—— 蒸氣在這一層，**往冷端流動**
4. **支撐柱陣列**（撐住上下板，避免真空把腔體壓扁）
5. **上蓋板**

**熱管**，由外到內：
1. **管壁**（銅）
2. **毛細結構**（同上三種其一）
3. **中央蒸氣通道**

**硬規則**：
- **液體與蒸氣的箭頭必須反向**，而且**液體一定在毛細層裡、蒸氣一定在中央空腔裡**。
  畫成同向，或畫成液體在中央、蒸氣在毛細層＝不過。
- **腔體裡不准畫滿液體**。它是真空腔＋少量工作流體，畫滿就變成水管。
- **VC 一定要有支撐柱**；熱管**不准有支撐柱**（圓管靠管壁本身撐）。
- **VC 是兩片板封起來的扁腔**、**熱管是管（圓或壓扁）**。形狀不准互換。
- 毛細結構要**看得出是多孔／溝槽／網目**其中一種，不可以畫成一條實心線。

### 3-C 迴路順序（★ 這一段最容易被畫成同一條管）

**二次側（TCS，機櫃側，封閉環）**：
`CDU 泵 → 供水分歧管 → QD → 冷板進水口 → 冷板流道 → 冷板出水口 → QD → 回水分歧管 → CDU 板式熱交換器 → 回到泵`

**一次側（FWS，設施側，另一個封閉環）**：
`設施冰水進 → CDU 板式熱交換器 → 設施冰水出 → 屋外`

**硬規則**：
- **兩個環只在板式熱交換器處「靠在一起」，絕不相接**。
  畫成一條管貫穿到底＝這張圖最致命的錯，直接退回。
- **泵畫在二次側**（CDU 內部），不是畫在一次側。
- **多個冷板是並聯**：供水分歧管的每一個分支各接一個冷板，各自回到回水分歧管。
  畫成一個冷板的出水接到下一個冷板的進水（串聯）＝不過。
- **每一個「可拆的接點」都要畫 QD**，而且 QD 一定**成對出現**（一進一出）。
- 一次側的管**畫得比二次側粗**，並用**第三種顏色**（不是進水色、也不是出水色）。

### 3-D 底部流程列（由左到右，5 格）

1. **晶片端**：die → TIM1 → 蓋板／VC
2. **冷板**：TIM2 → 冷板 → 流道
3. **接點**：QD → 軟管 → 分歧管
4. **CDU**：泵 → 板式熱交換器 → 過濾／控制
5. **設施端**：一次側水 → 屋外散熱

**硬規則**：格 3（接點）一定在格 4（CDU）**之前**；
格 4 與格 5 之間要畫一條**分界線**，標「**這條線的右邊是機房基礎設施，不在這條產業鏈上**」——
這是整張圖在產業鏈上的意義所在（也是 §7-D1 不掛 `data-seg` 的原因）。

## 4. 一定要有的識別特徵

看到這些才認得出這是液冷系統，而不是隨便幾個方塊加幾條管：

- **冷板的底面是平的**（要貼晶片），而**內部是密排的細鰭／微流道**。
  底面畫成有起伏、或內部畫成空心一個大腔＝認不出是冷板。
- **快接頭是「對插的兩半」，而且端面是平的**（平面式 flat-face，為了少殘液）。
  畫成一般的水管螺牙接頭＝認不出是 QD。
- **分歧管一定是「一根主幹 ＋ 多個等距分支」**，而且分支數要明顯多於 2。
- **CDU 有四個口**（一次側進、一次側出、二次側進、二次側出），內部看得到**一疊波紋板**。
  只畫兩個口＝讀者會以為它是個泵。
- **VC 內部有支撐柱陣列**；**熱管內部沒有**。
- **VC 與 IHS 並排對照**：一個內部是空的、一個是實心。**沒有這一格，名詞陷阱就沒有畫面上的解藥。**
- **熱擴散維度對照格**：左邊熱沿一條線走、右邊熱攤成一個面。
- **液體與蒸氣的反向箭頭**，在 VC 與熱管兩格都要有。
- **一次側／二次側用不同顏色，而且中間有一片隔板**。

### 4-B 最常見的畫錯（逐條對應 §6 的審查條目）

| 常見錯法 | 為什麼是錯的 | 對應審查條目 |
|---|---|---|
| 一次側與二次側畫成同一條管 | 兩個迴路本來就是靠板式熱交換器隔開的；接通等於在說機房的水直接流過 GPU | L4／L5 |
| 冷板直接貼裸晶、沒有 TIM | 兩個固體表面永遠有微觀空隙，沒有 TIM 熱過不去 | H2 |
| 冷板內部畫成一個大空腔 | 冷板靠的是「大表面積 ＋ 細流道」，畫成大空腔就不是冷板 | H4 |
| VC 畫成實心銅板 | 那是 IHS／lid。VC 的全部價值在那個真空腔 | P1／P2 |
| 熱管畫成實心銅棒 | 同上；實心的叫銅柱，導熱靠傳導不是相變 | P1 |
| 液／汽箭頭同向 | 相變循環的定義就是逆向：蒸氣去冷端、液體回熱端 | P3 |
| 腔體裡畫滿液體 | 那是水管不是熱管 | P4 |
| VC 沒畫支撐柱 ／ 熱管畫了支撐柱 | 扁腔要撐、圓管不用 | P5 |
| 分歧管畫成串聯 | 後面的晶片會吃到前面加熱過的水 | L3 |
| QD 只畫一個（沒成對） | 可拆的接點一定是一進一出 | L2 |
| 泵畫在一次側 | 泵是 CDU 二次側的心臟 | L6 |
| 把浸沒式畫進主圖 | 那是另一種做法，不是這條路徑上的一關 | M3 |
| 把風扇畫成主角 | 那是 `air_cooling` 那張的事 | M4 |
| 畫任何廠商的產品外觀 | AGENTS §11 紅線 | M5 |

## 5. 標註文字

一律引線拉到外側文字框，**不壓在零件上**，畫面上真實字級 ≥ 12px。
主標題：`液冷：熱從晶片走到機房外面，中間經過哪幾關`

| 指到哪個零件 | 文字寫什麼（標題／副標） |
|---|---|
| TIM1／TIM2（2、4） | **導熱介面材料（TIM）**／兩個固體貼在一起時中間一定有微觀空隙；TIM 把空隙填掉。它很薄，但整條路上每一層都要過 |
| 均熱片 IHS（3） | **均熱片／蓋板（IHS，實心銅）**／把晶片的點熱源先攤開一點，再交給上面那一關 |
| 均熱板 VC（3b） | **均熱板（VC，vapor chamber）**／跟 IHS 長得像，但**裡面是真空腔**：靠蒸發—冷凝搬熱，不是靠銅傳導。★ 中文兩個名字很像，看內部有沒有腔體就分得出來 |
| 冷板殼體（5） | **冷板（cold plate）**／直接貼在晶片上的液冷主角，所以這套做法叫「直接晶片液冷（DTC）」 |
| 冷板流道（6） | **流道：微流道／削切鰭片／柱狀鰭**／鰭越密，液體接觸到的面積越大、帶走的熱越多；代價是壓力損失變大，泵要更用力 |
| 進出水口（7） | **進水冷、出水熱**／溫差就是被帶走的熱。同樣的熱量，溫差越小代表流量要越大 |
| 快接頭 QD（8） | **快接頭（QD／UQD）**／可以帶壓拔插、拔開不滴液。**這是整套系統最怕漏水的地方**，所以有 OCP 的通用規格讓不同家的可以互換 |
| 盲插型 QDB（8） | **盲插（blind-mate）**／托盤推進去就自動接上，人看不到接點；靠浮動公差對位 |
| 分歧管（9） | **分歧管（manifold）**／把一路水分給機櫃裡幾十個冷板。**是並聯不是串聯**——串聯的話後面的晶片會吃到前面加熱過的水 |
| CDU（11） | **CDU（冷卻液分配單元）**／泵 ＋ 板式熱交換器 ＋ 過濾 ＋ 控制。它是機櫃側與機房側的交界 |
| 板式熱交換器（12） | **兩邊的水不相通**／二次側（機櫃側，TCS）與一次側（設施側，FWS）只交換熱、不交換液體。這樣機房的水髒了也不會流進 GPU |
| 一次側（13） | **這條線的右邊是機房基礎設施**／冷卻水塔、乾冷器、冰水主機不在這條產業鏈上，圖上只畫到 CDU 為止 |
| 熱管剖面（14） | **熱管：把熱沿著一條線送走**／管壁 → 毛細層（液體回流）→ 中央蒸氣通道。一端吸熱蒸發、另一端放熱凝結，液體再靠毛細力爬回來 |
| VC 剖面（15） | **VC：把點熱源攤成一個面**／同樣的物理，形狀換成兩片板封起來的扁腔，加上**支撐柱**撐住真空 |
| 維度對照（16） | **一個是線、一個是面**／熱管擅長「搬到遠處」，VC 擅長「就地攤平」。AI 晶片的熱是**高熱通量的點**，所以要先攤平 |
| 毛細結構（14／15 內） | **毛細結構：燒結銅粉／溝槽／網目**／燒結毛細力強、可以逆重力工作；溝槽流阻小但怕倒著裝。這就是為什麼同一根熱管換個方向裝，能力會不一樣 |
| 單相 vs 兩相（17） | **單相：全程是液體**／靠溫升帶熱。**兩相：在冷板裡沸騰**／靠汽化潛熱帶熱、晶片表面溫度更平穩，代價是流體管理複雜、目前導入少 |
| DTC vs 浸沒式（18） | **DTC：冷板貼在最熱的那幾顆上**／其餘零件仍靠氣流。**浸沒式：整片板泡進不導電的液體**／兩者是不同路線，不是同一條路的兩段 |
| 流程列分界線 | **左邊是這條產業鏈上的東西，右邊是機房基礎設施** |

**三塊固定說明框（這張圖的結論，不可省略）**：

- 左下「**為什麼一定要走到液冷**」：
  1. 晶片功耗一路往上，**同樣的面積要散掉更多的熱**。
  2. 空氣的搬熱能力有上限：要多搬就要更大的風量與風壓，風扇的耗電與噪音等比例上去。
  3. 所以最熱的那幾顆（GPU／CPU）先換成冷板直接貼上去，**其餘零件仍然靠氣流**——
     這就是為什麼液冷機櫃裡**還是有幾百顆風扇**（詳見 `air_cooling` 那張）。
- 右下「**這張圖上誰做哪一塊**」（這是這張圖在這個網站存在的理由）：
  - 冷板 ／ 分歧管 ／ Sidecar ／ CDU → `thermal`（散熱）環節
  - **同一格裡的分工是有差別的**：
    奇鋐 3017、雙鴻 3324 的主體是**系統層級**（水冷板、Sidecar、CDU）；
    健策 3653、一詮 2486 的主體是**封裝層級**（均熱片 lid／IHS、補強框）；
    高力 8996 是**板式熱交換器與 CDU／CDM**；
    富世達 6805 做的是**快接頭 QD**。
    ⚠ 2026 年這幾家互相跨線（見 `supply_chain.yaml` 的 `thermal` note），
    所以畫面上寫「主體是」，不要寫「只做」。
  - ⚠ 一次側（冷卻水塔、冰水主機）**不在這條鏈上**，所以不掛環節、不列台股。
- 中下「**這張圖沒有回答的事**」：
  1. **各家的市占率**：`supply_chain.yaml` 在 2026-09-19 就因為「查不到可查證出處」把

## 6. 結構審查清單（`mechanical-engineer` 逐條驗，每條都要判得出過／不過）

> 寫法規則：每一條都是「A 必須在 B 之前」「A 不可以碰到 B」「A 的數量／厚薄關係必須是 X」
> 這種**看圖就能判定**的句子。**不准出現「要畫得清楚」「要好看」這種驗不動的條目。**

**H 組・熱的路徑**
- H1　由下到上的順序是 `die → TIM1 → 蓋板/VC → TIM2 → 冷板`，**沒有任何一層跳過**。
- H2　**兩個固體之間都畫了 TIM**，而且 TIM **比它上下相鄰的任何金屬層都薄**。
- H3　冷板在蓋板／VC **之上**，不是在它下面。
- H4　冷板內部是**密排細鰭／流道**（至少 8 條），不是一個大空腔。
- H5　進水口與出水口用**兩種不同顏色**，且該顏色一路延續到分歧管與 CDU。
- H6　熱流箭頭**全程單向由內往外**，圖上沒有往回指的熱流。

**P 組・兩相元件（VC 與熱管）**
- P1　VC 與熱管**內部都畫了空腔**，沒有任何一個被畫成實心金屬。
- P2　圖上**同時有 IHS（實心）與 VC（空腔）兩格並排對照**，而且一眼分得開。
- P3　液體箭頭與蒸氣箭頭**方向相反**；液體在**毛細層**、蒸氣在**中央空腔**。畫反＝不過。
- P4　腔體**沒有被畫滿液體**。
- P5　**VC 有支撐柱陣列、熱管沒有**。反過來＝不過。
- P6　毛細層畫得出**多孔／溝槽／網目**其中一種質感，不是一條實心線。
- P7　VC 是**扁腔（兩片板）**、熱管是**管**。形狀互換＝不過。
- P8　有「線 vs 面」的熱擴散對照小圖。

**L 組・迴路**
- L1　二次側自己形成**一個封閉環**（從泵出發回到泵）。
- L2　每一個可拆接點都有 QD，而且 QD **成對出現**（一進一出）。
- L3　多個冷板是**並聯**：每一個冷板各自接到供水分歧管與回水分歧管。串聯＝不過。
- L4　**一次側與二次側沒有任何一處相接**，只在板式熱交換器處相鄰。相接＝**直接退回，不進二輪**。
- L5　板式熱交換器畫成**一疊交錯薄板**，兩側流體用不同顏色且**中間有隔板**。
- L6　泵畫在**二次側（CDU 內）**，不在一次側。
- L7　CDU 有**四個口**。
- L8　一次側的管**比二次側粗**，而且用第三種顏色。

**M 組・辨識與邊界**
- M1　快接頭畫成**對插的兩半、平面端面**，不是螺牙水管接頭。
- M2　分歧管是**一主幹 ＋ ≥3 個等距分支**。
- M3　浸沒式**只出現在對照小圖**，沒有畫進主路徑，且標籤講明它是另一種做法。
- M4　圖上**沒有把風扇畫成主角**（最多只有文字提到混合散熱）。
- M5　圖上**沒有任何廠商 logo、產品外觀、料號或商標**。
- M6　流程列上有一條**分界線**把「這條鏈上的東西」與「機房基礎設施」分開。

**N 組・誠實性（紅線，違反任一條就退回，不進二輪）**
- N1　畫面上**沒有任何良率數字、成本金額、市占率百分比**。一個都不准。
- N2　凡是帶年份的量級數字（滲透率、功率等級），畫面上**都附了「來源＋年份」**。
- N3　畫面上同時有「示意圖，非實物比例」與「冷板數／分歧管分支數為示意」兩行。
- N4　§7-B 裡標為低信心的每一項，畫面上**都沒有寫成確定的單一數值**
      （特別是 VC 相對熱管的性能提升百分比、液冷帶走熱量的佔比）。
- N5　畫面最底下有 §5 那一行「點零件篩到的是環節不是族群」。
- N6　**「均熱片」與「均熱板／VC」在畫面上一律各自標清楚是哪一種**（§7-B1），
      沒有任何一處只寫「均熱片」三個字就指向 VC。
