## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| **平面電晶體：閘極只管到一面** | 不會。那是剖面上「閘極貼在通道上方」的一條線 | 2D 剖面 |
| **FinFET：閘極包三面** | **會一點點** —— 「三面」本身是立體的。但只要畫**垂直於鰭的橫剖面**（看到一個ㄇ字形的閘極騎在一片直立的鰭上），三面包覆就一眼看得出來，而且比透視圖清楚 | **2D 橫剖面 ＋ 一個小的等角輔助圖** |
| **GAA：閘極包四面、金屬要鑽進奈米片之間** | **會一點點**，但關鍵資訊「閘極金屬填在片與片之間的縫裡」**只有橫剖面看得到** —— 進了透視，那幾條縫第一個被擋掉 | **2D 橫剖面**（這是本圖最重要的一格） |
| **製程迴圈（黃光→蝕刻→沉積→CMP）** | 不會。那是一個環狀流程圖 | 2D 環 |
| **一片晶圓切出幾顆晶粒** | 不會。那是一個平面的格線 | 2D 俯視 |
| **節點演進（N5→N3→N2→A16）** | 不會。那是一條時間軸 | 2D 列 |

反面成本四條：
1. 這張圖六個資訊點裡有五個是「剖面／平面上的關係」，3D 只會把它們擋住。
2. 真實尺度差太多：鰭寬是 nm 級、晶圓是 300 mm 級，差七個數量級。2D 可以誇張放大並標「非實物比例」，3D 不行。
3. 3D 在手機吃力（AGENTS §11 明列）。
4. `semiconductor` 這條鏈**已經有一個 3D 場景**（`SCENES.semiconductor`），再開一個就多一組 WebGL context 與 rAF 要管（`dispose3D()` 那條既有的坑）。

**什麼條件下才該回頭加 3D**（寫死）：

> 只有當這張圖要新增「**一整座晶圓廠的機台配置與晶圓傳送動線**」——
> 也就是同時需要平面位置與垂直樓層（次微米級的 clean sub-fab 在潔淨室正下方）的資訊時，
> 才重開這一段、改規格書、由 `mechanical-engineer` 重新簽。
> **而且比較好的做法是把那件事交給 `semi_facility.md`（S13）那張圖，不是把這張改成 3D。**
> 「看起來比較立體」「別張有 3D 這張也要有」都不算理由。

## 1. 這張圖要回答什麼問題

**「一顆電晶體從平面變成 FinFET 再變成 GAA，到底改了什麼？為什麼一片晶圓要繞同一個迴圈幾百次？N3 跟 N2 差在哪？」**

使用者看完要能自己講出這四句（畫面上會把這四句印在右側說明欄的抬頭）：

1. **三代電晶體改的都是同一件事：閘極能管到通道的幾個面。**
   平面管 1 面 → FinFET 管 3 面（頂＋兩側）→ GAA 管 4 面（金屬鑽進片與片之間）。
   管得越多面，漏電越關得住，同樣速度下越省電（§7-A1、A2）。
2. **晶圓廠不是「一次做完」，是同一個迴圈繞好幾十次。**
   每一層圖案都要走一次「清洗 → 沉積 → 塗光阻 → 曝光 → 顯影 → 蝕刻 → 去光阻 → CMP → 量測」，
   一顆先進邏輯晶片有 80～120 層這樣的層、大約 90 道光罩、整片晶圓在廠裡待三到四個月（§7-A5）。
3. **N3 是最後一代 FinFET，N2 是第一代 GAA。**
   N2 相對 N3E：同功耗下速度高 10～15%，或同速度下省電 25～30%，密度增加逾 15%；
   N2 在 2025 年底進入量產（§7-A3）。
4. **背面供電不是 N2 的事，是 A16 的事。**
   A16 的 Super Power Rail 把供電網搬到晶圓背面，2026 下半年製程就緒、放量看 2027（§7-A4）。
   **把背面供電畫在 N2 上就是錯的**（§3-D N4）。

**這張圖的成敗**：Andy 指著迴圈上任何一步，要能說出
「這一步在做什麼、它吃什麼材料、**台股有沒有人在這一步**」。講不出第三句，圖就白畫。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A 三格電晶體：閘極包覆面數必須是 1 → 3 → 4

```
① 平面      閘極只在通道上方          → 1 面
② FinFET    閘極罩住鰭的 頂 ＋ 左 ＋ 右 → 3 面（鰭底沒包到）
③ GAA       閘極包住每一片的 上下左右   → 4 面（金屬在片與片之間）
```

**硬規則**：
- **F1**　**三格必須用同一個放大倍率、同一套材質色、同一個剖面方向**，只有結構不同。
  用不同畫法＝讀者無法比較，這張圖的命題就沒了。
- **F2**　**平面那格的通道是一條水平薄層，且閘極只從上方蓋下來**。
  閘極包到側面＝那不是平面電晶體。
- **F3**　★★ **FinFET 的鰭高必須 > 鰭寬 × 2。**
  畫得又矮又胖就跟平面分不出來 —— 這是這張圖最容易畫壞的一條。
- **F4**　**FinFET 的閘極是 ㄇ 字形、真的罩到鰭的兩個側面**，而且**鰭的最底部沒有被包到**
  （被 STI 埋住）。三面包覆畫成「貼在鰭頂上的一塊方塊」＝不過。
- **F5**　★★ **GAA 的奈米片必須是 2～4 片、水平、彼此分開，而且片寬 > 片厚 × 3。**
  只畫一片＝那是平面；畫成直立的＝那是 FinFET；畫成正方形斷面＝那是奈米線（nanowire），不是奈米片。
- **F6**　★★★ **GAA 的閘極金屬必須填進每一對相鄰奈米片之間的縫。**
  這是「Gate-All-Around」這個名字的全部意義。
  **只把金屬畫在最上面那片的上方＝畫的是 FinFET，直接退回。**
- **F7**　**GAA 的介電層要繞著每一片走一圈**（每片外圍一個封閉細框），不是只畫在片的上下兩面。
- **F8**　**三格的「閘極控制面數」標記必須分別是 1／3／4**，且數得出來。
- **F9**　**源極與汲極一律在通道的左右兩端**，三格都一樣。GAA 那格的 S／D 磊晶必須**把所有片的端部一起接起來**
  （不是一片接一個 S／D）。

### 3-B 製程迴圈：九站的順序寫死，而且必須閉合

```
清洗 → 沉積 → 塗光阻(BARC 先、光阻後) → 曝光 → 顯影 → 蝕刻 → 去光阻/清洗 → CMP → 量測 ─┐
  ↑                                                                                      │
  └──────────────────────────────────────────────────────────────────────────────────────┘
```

**硬規則**：
- **P1**　★ **必須是閉合的環**（最後一站有一條線回到第一站），不是一條左到右的直線。
- **P2**　**顯影一定在曝光之後。** 反了就是「先洗掉再曝光」，物理上不成立。
- **P3**　**蝕刻一定在顯影之後。** 光阻顯影完才是罩幕；先蝕刻就沒有罩幕可用。
- **P4**　**去光阻一定在蝕刻之後。** 蝕刻之前把光阻拔掉＝整片被刻光。
- **P5**　**塗光阻一定在曝光之前**，而且 **BARC 在光阻底下**（先塗 BARC，再塗光阻）。
      BARC 畫在光阻上面＝上下顛倒（這一條同時是 S3 的對齊點）。
- **P6**　**CMP 在沉積與蝕刻之後、在下一輪的塗光阻之前。**
      CMP 的工作是把這一層磨平，磨平之後下一層才站得住；畫在沉積之前＝在磨一層還不存在的東西。
- **P7**　環的中央必須寫出「繞 80～120 次」這件事。**沒有這句，這張圖的命題就不見了。**
- **P8**　**FEOL 弧必須在 BEOL 弧之前（順時針較早的位置）**，並標「電晶體先做、金屬線後做」。

### 3-C 閘極堆疊放大格：由下到上

```
 ┌ 通道（矽 / 奈米片）
 │ 界面層（interfacial layer，極薄）
 │ high-k 介電層（例：HfO₂）
 │ 功函數金屬（work-function metal）
 └ 填充金屬（fill metal）
```

**硬規則**：
- **G1**　**high-k 在功函數金屬底下**，順序不准對調。
- **G2**　**介電層是全圖最薄的一層之一**，畫得比源汲區厚＝不過。
- **G3**　**不准畫成「二氧化矽 ＋ 複晶矽」**。先進節點早就是 high-k／金屬閘（HKMG），
      畫成 poly gate 等於畫了一個二十年前的結構（§7-A6）。

### 3-D 節點列：兩條分界線的位置寫死

- **N1**　順序必須是 **N5 → N3 → N2 → A16**（由左到右，時間往右）。
- **N2**　**「FinFET ↔ GAA」的分界線畫在 N3 與 N2 之間**，不准畫在 N5/N3 之間或 N2/A16 之間。
- **N3**　**N3 那格標 FinFET、N2 那格標 GAA**。把 N3 標成 GAA＝在公開網站上講錯一個可以查證的事實。
- **N4**　★★ **背面供電（Super Power Rail）只准出現在 A16 那一格。**
      畫在 N2 上＝錯（§7-A4）。若區 A 的 GAA 剖面要畫供電線，**必須畫在正面**，
      或另開一個灰色小圖標「A16 才有的背面供電（示意）」。
- **N5**　N2 的效能敘述**必須寫成「相對 N3E」**，不准寫成「相對 N3」或不寫比較基準（§7-B1）。

### 3-E 三級縮放尺

- **Z1**　順序由大到小：**晶圓 → 晶粒 → 電晶體**，且三級之間有引線或放大框連起來。
- **Z2**　晶圓上的**方格必須規則排列**，且**邊緣那一圈是殘缺的方格**（切不出完整晶粒的邊緣損失）。
      畫成「整片都是完整方格」＝把邊緣損失畫不見了。
- **Z3**　晶圓要有**一個 notch（缺口）**，不是一個完美的圓。
- **Z4**　良率那句話**只寫關係、不寫數字**（§7-C1）。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵（看到這個才認得出是它）

- **平面**：通道是一條**水平薄層**，閘極**只在上方**。
- **FinFET**：一片（或數片）**直立的鰭**，閘極**ㄇ 字形罩下來**，鰭底埋在 STI 裡。
- **GAA**：**2～4 片水平堆疊的奈米片**，**每兩片之間都看得到閘極金屬**。
- **製程迴圈**：**閉合的環**，中央寫著繞幾次。
- **晶圓**：**圓形 ＋ notch ＋ 邊緣殘缺的方格**。
- **節點列**：**兩條分界線**，位置分別在 N3/N2 之間與 N2/A16 之間。

### 4-B 最常見的畫錯（逐條對應 §6 的審查條目）

| # | 畫錯的樣子 | 為什麼是錯的 | 對應審查 |
|---|---|---|---|
| 1 | FinFET 的鰭畫得又矮又胖 | 鰭矮到跟基板上的一塊凸起沒兩樣，讀者分不出它跟平面的差別 —— 而「立起來」正是 FinFET 的全部 | T3 |
| 2 | **GAA 的閘極金屬只畫在最上面那片上方** | 那畫的是 FinFET。片與片之間的金屬才是 Gate-All-Around 的定義 | **T7（紅線）** |
| 3 | 奈米片畫成正方形斷面或一條線 | 那是 nanowire。片寬 > 片厚 ×3 才是 nanosheet | T6 |
| 4 | 製程畫成一條左到右的直線 | 命題是「同一個迴圈繞幾百次」；畫成直線＝讀者以為做完一輪就結束 | P1、P5 |
| 5 | 蝕刻畫在顯影之前 | 沒有罩幕就蝕刻，整片刻光。這是流程圖最常見的順序錯 | P2 |
| 6 | CMP 畫在沉積之前 | 磨一層還沒長出來的東西 | P4 |
| 7 | BARC 畫在光阻上面 | BARC 是「底部」抗反射層，在光阻下面。畫反了會讓 S3 那張圖跟著錯 | P3 |
| 8 | 背面供電畫在 N2 上 | N2 是正面供電，背面供電是 A16 的 Super Power Rail。這是可以查證的事實錯誤 | **N4（紅線）** |
| 9 | 閘極畫成「氧化矽＋複晶矽」 | 先進節點是 high-k／金屬閘。畫 poly gate 等於畫 2005 年的結構 | G3 |
| 10 | 晶圓畫成整片完整方格、沒有 notch | 邊緣損失是「晶圓越大越划算」的一半理由；notch 是晶圓的識別特徵 | Z2、Z3 |
| 11 | 把 CoWoS／HBM 畫進來 | 越界到封裝那張圖，而且會讓讀者以為代工廠做的就是封裝 | M1 |
| 12 | 三格用不同的放大倍率或不同顏色 | 三格的意義就在「可以互相比較」 | T1 |
