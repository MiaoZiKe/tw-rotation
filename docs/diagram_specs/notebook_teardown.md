## 0. 開畫之前要先簽掉的四件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 四件殼各在哪一面 | **會一點點**，但用一張**側視剖面 ＋ 一張爆炸小圖**就講完了，而且爆炸圖不會互相遮 | 2D 側視 ＋ 2D 爆炸 |
| 轉軸接的是哪兩塊 | **不會**。那是側視上「上總成與下總成交會於一點」的關係 | 2D 側視 |
| 熱管一端在晶片上、另一端在鰭片上，風穿過鰭片出去 | **不會**。風向與鰭片方向的關係在**俯視**上最清楚；3D 會被上蓋擋住 | 2D 俯視 |
| 主機板與電池在底座裡**前後並排** | **不會**。那是俯視的位置關係 | 2D 俯視 |
| SMT 八站 | 不會。那是流程列 | 2D 列 |

反面成本：五個資訊點全在側視、俯視與流程列上；3D 在手機吃力；`electronics` 鏈目前沒有 3D 場景。

**什麼條件下才該回頭加 3D**（寫死）：
> 只有當這張圖要新增「**轉軸的多連桿動作**」（360 度翻轉或折疊機構，只有動起來才看得懂）時，
> 才重開這一段、改規格書、重新簽。

### 0-B　★★ 第一條紅線：**不准畫成任何一台真實筆電**

`AGENTS.md` 的紅線是「不畫任何真實公司的產品外觀、logo、包裝、商標」。
筆電的辨識特徵在**比例與細節**：轉軸造型、鍵盤配列、觸控板位置與比例、出風口造型、

## 1. 這張圖要回答什麼問題

**「一台筆電拆開有哪幾件？熱管跟鰭片怎麼接？台股在這台機器上分成幾群人？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句**）：

1. **殼是四件，不是一個殼。** 上蓋、螢幕邊框、鍵盤面、底殼，四件的工法與厚度都不同，
   而且分屬不同的採購項目 —— 「機構件」這門生意就是在做這四件與轉軸。
2. **轉軸接的是「顯示總成」與「底座總成」**，不是接兩片殼。
   它同時要撐重量、走線、承受幾萬次開合。
3. **熱是「橫著」走出去的。** 熱管一端壓在晶片上、另一端接到鰭片，
   **鰭片的片縫方向必須對著出風口**，風扇在鰭片旁邊把風推過縫隙 ——
   鰭片轉 90 度就把風擋住了。
4. **台股在這台機器上分成三群人**：做殼與機構件的、打件與組裝的、掛品牌與做板卡的。

**這張圖的成敗**：指著任何一件，要能說出「這是什麼、台股是誰在做這一件」。

## 2. 零件清單

### 2-A 區 A 側視（打開 90 度）

**上總成（由外到內，外＝背向使用者）**

| 零件 | 相對厚度 | 材質觀感 | 備註 |
|---|---|---|---|
| 上蓋（業界慣稱 A 件） | 薄板 | 金屬或複合材 | 最外面那一片 |
| 顯示模組 | 中等 | 一塊板 | **不准剖開畫層**（§0-C） |
| 螢幕邊框（業界慣稱 B 件） | 薄框 | 塑膠或金屬 | **朝向使用者**，框住顯示模組 |

**轉軸**

| 零件 | 備註 |
|---|---|
| 轉軸（鉸鏈） | ★ 連接**上總成**與**下總成**；旋轉中心在兩者交會處；旁邊畫一束走線 |

**下總成（由上到下）**

| 零件 | 相對厚度 | 材質觀感 | 備註 |
|---|---|---|---|
| 鍵盤面／掌托（業界慣稱 C 件） | 薄板 | 金屬或塑膠 | 上面開鍵盤孔與觸控板孔 |
| 鍵盤 | 薄 | 均勻網格 | **不畫鍵帽字元**（§0-B） |
| **主機板 ＋ 電池（同一層前後並排）** | 這一層最厚 | 板：深色＋元件；電池：厚塊 | ★ 見 §3-C |
| 散熱模組（熱管＋鰭片＋風扇） | 薄，橫向延伸 | 銅管 ＋ 鋁鰭 ＋ 離心扇 | ★ 見 §3-D |
| 底殼（業界慣稱 D 件） | 薄板 | 金屬或複合材 | 最下面那一片 |

### 2-B 區 B 四件殼爆炸圖

四片分開擺，**每片都用功能名標註**，字母代號放在括號裡並標「業界慣稱」。
每片旁邊寫工法（沖壓／壓鑄／CNC／射出），**工法是示意**（§7-B2）。

### 2-C 區 C 底座俯視 —— 最少 6 個元素

主機板（靠轉軸側）、電池（靠使用者側）、SoC 位置、熱管、鰭片、離心風扇、出風口。

### 2-D 章節列 `nb_smt`：8 站

`錫膏印刷 → 錫膏檢測 SPI → 打件 → 爐前 AOI → 迴焊 → 爐後 AOI → ICT／功能測試 → 返修`
後面再接三格整機段：`組裝 → 燒機與功能測試 → 包裝出貨`。

### 2-E 不要出現的東西（畫了就是別張圖，或是紅線）

- **任何一台真實筆電的外觀**（轉軸造型、鍵盤配列與鍵帽字元、觸控板比例、出風口造型、配色）——§0-B。
- **任何 logo、商標、機身文字。**
- **顯示模組的內部疊層**（`panel_stack.md`）、**主機板的層間剖面**（`pcb_stackup.md`）。
- **機櫃、風扇牆、導風罩**（`air_cooling.md`）。
- **任何尺寸（mm）、瓦數（W）、容量（Wh）、市占率、營收、出貨量數字。**
- **「全球第幾大」「龍頭」「唯一」**這類法人用語（CLAUDE.md 紅線）。

## 3. 層別／順序（★ 可判定的條目，最常錯的五組全部寫死）

### 3-A 上總成，**由外到內**

`上蓋 → 顯示模組 → 螢幕邊框`

**N1**　★ **螢幕邊框朝向使用者、上蓋在背面**。兩者順序反了，等於把螢幕裝在背面。
**N2**　邊框**框住**顯示模組的四邊（畫成一個ㄇ形或框形剖面），不是貼在顯示模組背面。

### 3-B 轉軸（★ 第一條結構紅線）

**N3**　★★ **轉軸連接「上總成」與「下總成」**，旋轉中心在兩個總成的交會處。
不准畫成「連接螢幕邊框與鍵盤面」或「連接上蓋與底殼」——
那會讓人以為殼件之間可以互相轉動。**紅線。**
**N4**　轉軸旁邊要畫一束**走線**（訊號與天線線材從這裡穿過去）。

### 3-C 下總成的層序與並排（★ 第二條結構紅線）

由上到下：`鍵盤面 → 鍵盤 → 主機板＋電池（同一層）→ 散熱模組 → 底殼`

**N5**　★★★ **主機板與電池在同一層**，在**俯視**上**前後並排、互不重疊**
（主機板靠轉軸側、電池靠使用者側）。
畫成主機板疊在電池上面＝把「筆電厚度在爭什麼」講反了。**紅線，不過就退回、不進二輪。**
**N6**　鍵盤面在鍵盤**上方**（鍵盤從它開的孔露出來），不是在鍵盤下面。
**N7**　底殼在最下，且**散熱模組在主機板與底殼之間**。

### 3-D 散熱模組（★ 第三條結構紅線，這一組最常畫錯）

**N8**　★★★ **熱管的一端必須壓在 SoC 上、另一端必須接到鰭片組**。
兩端都要看得到接觸面（畫一塊導熱介面），中間**不准斷開**。**紅線。**
**N9**　★★★ **鰭片的片縫方向必須平行於氣流方向**（風從縫隙之間穿過去，直達出風口）。
鰭片轉 90 度＝片面正對著風，把風擋住 —— 那是這一類圖最經典的錯。
**紅線，不過就退回、不進二輪。**
**N10**　★ **離心風扇在鰭片的旁邊、出風口對著鰭片**（風扇 → 鰭片 → 機殼出風口，
三者在**同一條直線上**）。風扇畫在鰭片後面（先鰭片再風扇）＝風向反了。
**N11**　出風口在機殼**側邊或後緣**（靠轉軸那一側），不在鍵盤面上。
**N12**　熱管是**扁的**（壓扁過的圓管），畫成正圓剖面也可以，但**寬度必須小於鰭片組的寬度**
（熱管不會比鰭片組粗，AGENTS.md 開頭就在講這種相對尺寸錯誤）。

### 3-E 四件殼的位置與命名

| 功能名 | 位置 | 業界慣稱 |
|---|---|---|
| 上蓋 | 上總成**外側** | A 件 |
| 螢幕邊框 | 上總成**內側**（朝使用者） | B 件 |
| 鍵盤面／掌托 | 下總成**上面** | C 件 |
| 底殼 | 下總成**下面** | D 件 |

**N13**　★★ **畫面上一律用功能名**；字母代號只准放在括號裡，並標「業界慣稱」。
> ⚠ 這一條有具體原因：本次查證時第一份搜尋摘要把 A／B／C／D 的定義**講錯了**
> （而且同一段摘要自己前後矛盾），換關鍵字用第二個獨立來源才更正過來
> （登記在 `docs/diagram_plan_electronics.md` §5）。**用功能名就不會被這種錯誤帶著走。**
**N14**　四件在爆炸圖上的相對位置**必須與區 A 側視一致**（上蓋在最上、底殼在最下）。

### 3-F 章節列 `nb_smt` 的順序

**N15**　★ 順序寫死：`錫膏印刷 → SPI → 打件 → 爐前 AOI → 迴焊 → 爐後 AOI → ICT／功能測試 → 返修`。
**N16**　★ **SPI 必須在錫膏印刷之後、打件之前**（它檢的是錫膏，元件還沒放上去）。
**N17**　★ **爐後 AOI 必須在迴焊之後**；爐前 AOI（可省）必須在迴焊**之前**。
**N18**　整機三格接在 SMT 之後，順序 `組裝 → 燒機與功能測試 → 包裝出貨`。
**N19**　流程列是**單向由左到右**，**不是迴圈**（只有「返修」有一條回到檢測站的支線，
  而且那條支線要標「返修」兩個字）。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **F1 轉軸**：上總成與下總成在一點交會 ＋ 一束穿過去的線。
- **F2 底座俯視**：主機板與電池**前後並排**。
- **F3 散熱模組**：熱管兩端各有一塊接觸面；**鰭片的縫對著出風口**；風扇在鰭片旁。
- **F4 四件殼**：四片分開、各有功能名。
- **F5 鍵盤**：均勻網格，**沒有任何字元**。
- **F6 SMT 列**：八格 ＋ 一條標著「返修」的回頭支線。

### 4-B 最常見的畫錯（逐條對應 §6）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |
|---|---|---|
| **鰭片轉 90 度、片面正對著風** | 風被擋住，散熱路徑不成立 —— 這是這一類圖最經典的錯 | T2（紅線） |
| 熱管沒接到鰭片（或沒壓在晶片上） | 熱走不出去 | T1（紅線） |
| 風扇畫在鰭片之後 | 風向反了 | T3 |
| 主機板疊在電池上面 | 兩者共用同一層厚度預算 | B1（紅線） |
| 轉軸畫成連接邊框與鍵盤面 | 會被讀成殼件之間可以互轉 | H1（紅線） |
| 螢幕邊框畫在上蓋外面 | 螢幕就裝到背面去了 | A1 |
| 用 A／B／C／D 當畫面主標 | 這次查證第一份摘要把定義講錯過，用功能名才安全 | X6（紅線） |
| SPI 排在打件之後 | 它檢的是錫膏，元件放上去就檢不到了 | P2 |
| 爐後 AOI 排在迴焊之前 | 那就檢不到焊錫結果 | P3 |
| 鍵盤畫上字元、觸控板照某機種比例 | 那是機種辨識特徵 | X1（紅線） |

## 9. 給 `tech-illustrator` 的實作邊界

- **先畫區 C 的散熱路徑、先把 T2（鰭片方向）在 390px 下看一遍**，再補其他區。

  **兩條連桿分別掛在上總成與下總成的 `<g>` 裡** —— H1 在結構上就成立。
- 四件殼的爆炸圖**用區 A 側視的同一組 y 順序排**（X2），並且
