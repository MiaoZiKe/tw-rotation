## 0. 開畫之前要先簽掉的兩件事

### 0-A　要不要 3D —— 結論：不做真 3D

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| core ＋ 上下對稱增層的疊法 | 不會。這件事只存在於**剖面**，轉到正面是一塊不透明的板子 | 2.5D 剖面 |
| 微孔是錐形、而且上下兩側都朝 core 收窄 | 不會。錐度是剖面上的形狀 | 2.5D 剖面 |
| 三種節距（微凸塊／C4／BGA 錫球）差一個量級 | 不會，而且會更糟。節距是**並排比大小**，透視一斜就比錯了 | 2D 放大格 |
| 線寬細一個量級（SAP 細線 vs PCB 走線） | 不會。同上，這是並排比較 | 2D 放大格 |
| 上面接晶片、下面接 PCB | 不會。上下關係在剖面上最清楚 | 2.5D 剖面 |

**唯一一個「3D 真的有話要說」的候選是翹曲（warpage）** —— 載板變大之後在迴焊高溫下翹成
「洋芋片」，那確實是一個三維的形狀。但：

1. 洋芋片翹曲的資訊量只有「四個角翹起來」一句，**2D 誇張側視 ＋ 一張等高線小圖就講完了**；
2. 要在 3D 裡表達它得做變形（morph）或另寫 shader，是這張圖裡成本最高、資訊最少的一塊；
3. `site/three3d.js` 的 `SCENES` 是「零件排開（explode）」語彙，對**層層相疊、每層只有數十 µm**
   的東西表達力比 2.5D 差 —— 排開之後看到的是十幾片一樣的薄板；
4. 3D 在手機吃力（AGENTS §11 明列），每多一個場景就多一組 WebGL context 與 rAF 要管。

**什麼條件下才該回頭加 3D（寫死，避免下次又變成事後補簽）**：

> 只有當這張圖要新增**「同一塊載板上不同位置的翹曲量差異」**（也就是翹曲從一句結論
> 變成這張圖的主題、需要看到整片板子的起伏分布），
> 或是要表達**「一顆封裝裡多顆晶粒在載板平面上的排列」**（多晶粒的平面配置）時，
> 才重開這一段、改規格書、重新簽。
> **單純為了「看起來比較立體」不算理由；「別張圖有 3D 所以這張也要」更不算。**
> 附帶一條界線：多晶粒平面配置本來就是**半導體鏈那張 CoWoS 圖**的主題（見 §0-B），
> 真的要畫也該畫在那裡，不是在這裡加 3D。

### 0-B　跟既有兩張圖的分工（★ 這一段是這份規格書存在的理由）

這張圖有**兩個**可能撞車的鄰居，不是一個。

#### （一）跟 `pcb_stackup.md`（第 2 張，多層 PCB 剖面）

一句話判準：
**PCB 那張的下游是「把零件焊上去」，這張的下游是「把晶片黏上去」。**
PCB 那張整張圖沒有任何一個零件是用來接晶片的；這張圖的存在理由就是那一側。

| 主題 | `pcb_stackup`（已寫完） | `abf_substrate`（這一張） |
|---|---|---|
| 介電層怎麼來 | core ＋ **prepreg 膠片**交替**壓合**，都含**織造玻纖** | core 之外是 **ABF 增層膜**逐層貼合，**不含織造玻纖** |
| 線寬量級 | 一般高階 50/50 µm 已算高階 | **細一個量級**，走**半加成（SAP／mSAP）** |
| 孔 | 四種並排對照（PTH／背鑽／盲孔／埋孔） | **只講微孔**：錐形、朝 core 收窄、電鍍填實才能疊孔 |
| 上面接什麼 | 焊墊 → 焊錫 → 被動元件／連接器 | **bump pad → C4 凸塊 → 晶片** |
| 下面接什麼 | 沒有「下面」的概念（板子就是最底層） | **BGA 錫球 → 主機板**（也就是 PCB 那張的板子） |
| 材料的錢流向誰 | CCL 廠（台光電／台燿／聯茂）→ PCB 廠 | **ABF 膜與 BT 樹脂：味之素、三菱瓦斯（全是外商）** → 載板廠 |
| 高速損耗 | 銅箔稜面三格放大鏡、玻纖織效應 | **不重畫**（見下方硬規則） |

**這張圖不准出現的重複內容（違反就退回）**：

- **不畫銅箔稜面三格放大鏡**（HTE／RTF／HVLP）—— 那是 PCB 那張的 §2-14。
- **不畫玻纖織紋放大圖** —— ABF 本來就沒有織造玻纖，畫了是結構錯誤。
  core 那一層**可以**看得出織紋（core 是玻纖補強樹脂），但**不另開放大格**。
- **不畫四種孔的對照**（PTH／背鑽／埋孔）。這張圖只有微孔與 core 的貫孔兩種。
- **不畫走線頂視小圖**（差動對／蛇行等長／45°）—— 那是 PCB 那張的 §3-C。
- **不列表比較表面處理**（ENIG／ENEPIG／OSP／浸銀）—— PCB 那張已經比過。
  這張只畫載板實際的那一層，標「表面處理的種類比較見『PCB 硬板』那張」。

反過來，`pcb_stackup` 右下角那個「IC 載板對照小格」是**縮圖級**的，只負責講一句
「載板跟 PCB 不是同一種東西」。它不解釋 core／增層、不解釋微孔、不解釋凸塊、
不解釋誰供應 ABF 膜 —— **那五件事就是這張圖**。兩張並存不重複。

#### （二）跟 `site/diagrams.js` 既有的 `semiconductor()`（半導體鏈：CoWoS 2.5D 封裝剖面）

那張圖的 `q` 是「一顆 AI 晶片是怎麼被封在一起的？從晶圓、中介層到載板，每一層是誰在做」——
**載板在那張圖裡是最底下那一條**，一層而已。

- 那張講的是**晶片這一側**：晶粒、微凸塊、中介層（interposer）、CoWoS 的貼合。
- 這張講的是**載板這一側**：載板內部怎麼疊出來、材料是誰的、細線與微孔卡在哪。

**分界寫死**：**中介層（interposer）以上的東西，這張圖一律只畫輪廓、不標細節、不掛 `data-seg`。**
晶粒畫成一個灰色剪影並標「這一段是半導體鏈『CoWoS 封裝剖面』那張的主題」，
**不准**在這張圖上解釋微凸塊、TSV、CoWoS-L 的 LSI 或 RDL。
（判準跟 §0-B（一）同源：一張圖只講一個主體，重疊處用一句話把讀者導過去。）

## 1. 這張圖要回答什麼問題

**「AI 晶片底下那塊板子為什麼比主機板貴一個量級，而且為什麼卡住的是材料不是製程。」**

使用者看完要能自己講出這四句：

1. **載板是「以 core 為中心、上下對稱長出來」的**，不是像 PCB 那樣一片一片壓合。
   中間那片 core 負責撐住不變形，上下各長出同樣多層的 ABF 增層。
2. **細線與微孔都靠「沒有玻纖」**。ABF 是熱固性樹脂膜、不含織造玻纖，
   所以雷射打得下更小的孔、銅也能做出比 PCB 細一個量級的線（半加成 SAP）。
   BT 載板的 core 有玻纖補強，所以它走的是另一條路、另一批應用。
3. **一顆封裝裡有三種節距，差一個量級**：晶片到中介層的微凸塊最小、
   中介層／晶片到載板的 C4 凸塊居中、載板到主機板的 BGA 錫球最大。
   **載板的工作就是把最細的那一端轉接到最粗的那一端。**
4. **AI 把載板推大、推厚，於是翹曲變成主要敵人**：樹脂的熱膨脹係數比矽大很多，
   板子越大、迴焊時翹得越兇。無核心（coreless）與玻璃核心就是為了這件事被提出來的。

**這張圖的成敗**：Andy 指著圖上任何一層，要能說出
「這一塊是誰做的（載板廠／ABF 膜廠／BT 樹脂廠）、它變好會讓什麼變好」。
講不出這句，圖就白畫。

## 3. 層別／順序（可判定的條目，這一段最常錯）

### 3-A 疊構方向（由中間往外，這是跟 PCB 最不一樣的一句話）

```
        晶粒（灰色剪影，不是本圖主題）
        ── 微凸塊（最小）
        中介層（灰色剪影）
        ── C4 凸塊（中）
 ┌ 防焊 ＋ SR 開窗 ＋ bump pad ＋ 表面處理      ← 上表面（接晶片）
 │ 增層 U3（ABF 膜 ＋ 細線 ＋ 微孔）
 │ 增層 U2
 │ 增層 U1
 ├━━━━ core（玻纖補強，最厚）＋ 貫孔 ━━━━┤    ← 中心
 │ 增層 L1
 │ 增層 L2
 │ 增層 L3
 └ 防焊 ＋ 開窗 ＋ 球墊                        ← 下表面（接主機板）
        ── BGA 錫球（最大）
        主機板（只畫一小段）
```

**硬規則（違反其一就退回）**：

- **core 只有一片，而且在正中間。** 畫成「兩片 core 夾 prepreg」＝畫成 PCB 了。
- **上下增層的層數必須相等**（圖上各 3 層），**對應層的厚度也要相等**。
  不對稱＝翹曲，而翹曲正是這張圖右側在講的事，自己先畫不對稱就自相矛盾。
- **core 一定明顯厚於任一層增層**，而且**只有 core 那一層看得出織紋**。
- **增層裡不准出現織紋。**
- **上表面才有 bump pad，下表面才有 BGA 球墊**，兩者不准對調、不准兩面都畫成 bump pad。

### 3-B 孔的規則（跟 PCB 那張最容易混起來的一段）

| 孔 | 從哪到哪 | 硬規則 |
|---|---|---|
| core 貫孔 | core 上表面 → core 下表面 | **只穿 core**，不准穿進任何一層增層；孔內畫成**填塞物 ＋ 兩端蓋銅**，不是空心 |
| 雷射微孔 | 某一層增層的上表面 → 它下面那一層的銅 | **只穿一層增層**；形狀**上寬下窄**；**窄的那一端朝向 core** |
| 疊孔 | U1 的微孔正上方再一個 U2 的微孔 | 兩個孔**必須軸心對齊**，中間要看得到一段被電鍍填平的銅；沒有填平就不准疊 |

- ⚠ **錐度方向是這張圖最容易錯的一條**：上半部的微孔**朝下**收窄、下半部的微孔**朝上**收窄
  —— 兩邊都是「從外面往 core 打」。畫成上下同方向＝下半部全錯。
- **微孔不准畫成直筒**（直筒是機械鑽孔），**不准畫成空心**（空心就疊不上去）。
- 圖上**不准出現**背鑽、埋孔、貫穿全板的 PTH 這三種 —— 那是 PCB 那張的內容，
  而且載板的 core 貫孔跟 PCB 的 PTH 不是同一件事（前者只穿 core）。

### 3-C 製程順序（底部流程列，5 格，由左到右）

1. **材料**：core 板材（BT／玻璃環氧）與 **ABF 增層膜**進廠 ← **這一格是外商**
2. **core 加工**：鑽孔 → 鍍銅 → 填塞 → 兩面線路
3. **增層循環**（上下同時、重複 N 次）：貼 ABF 膜 → 雷射開微孔 → **除膠渣（desmear）** →
   化學鍍薄銅 → 圖案電鍍（SAP／mSAP）→ 蝕刻
4. **表面**：防焊 → SR 開窗 → 表面處理
5. **成品**：切割 → 檢測 → 出貨給封裝廠

**硬規則**：

- **第 3 格一定在第 4 格之前**（增層做完才上防焊）。
- **雷射開孔之後、鍍銅之前一定有除膠渣那一步**（§7-A3）。流程列上漏掉它＝不過。
- **第 1 格與第 2 格之間要有一條分界線**，標「左邊是材料商（外商）／右邊是載板廠（台股三家）」。
  這是整張圖在產業鏈上的意義所在，跟 PCB 那張的「CCL 廠 ↔ PCB 廠」分界線同一個作用。
- 「上下同時做」要在第 3 格上標出來 —— 那正是 3-A 對稱規則的製程原因。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

看到這些才認得出這是一塊 **IC 載板**，而不是 PCB、不是中介層、不是隨便一疊方塊：

- **正中間一片厚 core、上下各長出同樣多層的薄增層**，而且**只有 core 有織紋**。
  這是這張圖**唯一的決定性特徵** —— 缺了它，整張圖就只是另一塊 PCB。
- **上表面有 bump pad（接晶片），下表面有 BGA 球墊（接板子）**，兩側的墊子大小明顯不同。
- **微孔是錐形，而且上下兩側各自朝 core 收窄**。
- **三種節距並排**：微凸塊 → C4 → BGA 錫球，由細到粗一眼看得出差一個量級。
- **線比 PCB 那張細一個量級**（同一張圖裡放一小段 PCB 走線當對照尺，不標數字）。
- **材料那一格標明是外商**：ABF 膜與 BT 樹脂那一格在色標上要對得到
  「台股沒有直接對應，看外商」。
- 右下角**三格路線圖**：有核心 → 無核心 → 玻璃核心，**只有 core 那一層在變**。

### 4-B 最常見的畫錯（逐條對應 §6 的審查條目）

| 常見錯法 | 為什麼是錯的 | 對應審查條目 |
|---|---|---|
| 畫成「core ＋ prepreg 交替」 | 那是 PCB。載板的增層是膜，一層一層貼上去 | S1 |
| 上下增層層數不一樣 | 不對稱就翹曲，跟圖上自己在講的事矛盾 | S3 |
| 增層裡畫出玻纖織紋 | ABF 不含織造玻纖，那正是它能做細線的原因 | S4 |
| core 貫孔穿進增層 | 貫孔只穿 core；穿進增層就變成 PCB 的 PTH 了 | V1 |
| 微孔畫成直筒 | 雷射鑽出來是上寬下窄的錐形 | V2 |
| 下半部的微孔也朝下收窄 | 兩側都是從外往 core 打，下半部必須朝上收窄 | V3 |
| 微孔畫成空心 | 沒填實就疊不上去，疊孔那一格會自相矛盾 | V4 |
| 兩面都畫 bump pad | 上面接晶片、下面接板子，兩側的墊子不一樣 | S5 |
| 線寬跟 PCB 那張畫得一樣粗 | 「細一個量級」是這張圖的賣點之一 | M1 |
| 三種節距畫得差不多大 | 差一個量級才是重點；畫得一樣大等於沒畫 | M2 |
| 把 ABF 膜或 BT 樹脂標成台廠做的 | 這兩樣的供應商是外商，台股在這一格是空的 | M4 |
| 在這張圖上解釋 CoWoS／TSV／微凸塊結構 | 那是半導體鏈那張的主題 | M5 |
| 畫銅箔稜面、玻纖織紋放大格、四種孔、走線小圖 | 那是 `pcb_stackup` 的內容，重複 | M6 |
| 流程列漏掉除膠渣 | 雷射打完一定要除殘渣，否則銅附著不上 | P2 |

## 5. 標註文字

一律引線拉到外側文字框，**不壓在零件上**，最小 12px。
主標題：`IC 載板：晶片底下那塊板子，跟主機板不是同一種東西`

| 指到哪個零件 | 文字寫什麼（標題／副標） |
|---|---|
| core（1） | **核心層 core**／玻纖布補強的樹脂板（BT 環氧或玻璃環氧）。它的工作是撐住不變形，**全板最厚的一層** |
| core 貫孔（2） | **core 的貫孔**／鑽穿 core、鍍銅、填塞、兩端蓋銅。**只穿 core**，跟主機板那種貫穿全板的孔不是同一件事 |
| ABF 增層膜（3） | **ABF 增層膜（味之素增層膜）**／熱固性樹脂膜，**不含織造玻纖** —— 這就是它能打出更小的孔、做出更細的線的原因。**幾乎是單一供應商**（市占約 95%，來源：今周刊 2026-05） |
| 細線路（4） | **半加成細線（SAP／mSAP）**／先鍍一層很薄的銅，再把線「長」出來。一般高階 PCB 的線寬到 50 µm 已算高階，**載板要細一個量級** |
| 雷射微孔（5） | **雷射微孔**／上寬下窄，**窄的那一端朝向 core**。打完要先除膠渣，銅才附得上去 |
| 疊孔（6） | **疊孔**／微孔要先用電鍍銅填實，正上方才能再疊一個孔。層數越多、疊得越高，越吃電鍍能力 |
| 防焊開窗（7） | **防焊開窗（SR opening）**／防焊蓋住整面，只在要接晶片的墊子上開窗 |
| bump pad（8） | **凸塊墊 ＋ 表面處理**／晶片的凸塊就焊在這裡。表面處理的種類比較見「PCB 硬板」那張 |
| 三種節距（14） | **一顆封裝裡有三種節距，差一個量級**／微凸塊（晶片↔中介層）最小 · C4（↔載板）居中 · BGA 錫球（載板↔主機板）最大。**載板的工作就是把最細的那一端轉接到最粗的那一端**（量級來源：產業技術媒體與學術論文，2026） |
| ABF vs BT（15） | **ABF 與 BT 是兩種載板，不是等級高低**／ABF 無織造玻纖、走高效能運算與 AI；BT 有玻纖補強、走記憶體與射頻等應用。景碩同時做兩種 |
| 翹曲（16） | **板子越大越翹**／樹脂的熱膨脹係數比矽大很多，迴焊高溫下大尺寸載板會翹成洋芋片，翹了就焊不好 |
| 路線圖（17） | **三條路，差別只在中間那一層**／有核心（現在的主流）→ 無核心（拿掉 core，路徑短但更會翹，要靠補強環）→ 玻璃核心（更硬、熱膨脹更接近矽，所以更平；代價是整套設備與製程要重來） |
| 主機板（13） | **這一條才是「PCB」**／它自己的剖面在「PCB 硬板：多層板剖面與走線」那張 |
| 晶粒剪影（12） | **晶片這一側不是這張圖的主題**／晶粒、微凸塊、中介層請看半導體鏈的「CoWoS 2.5D 封裝剖面」 |
| 流程列（3-C） | **五步，第一步是外商**／材料 → core 加工 → 增層循環（貼膜·雷射·除膠渣·電鍍）→ 防焊與表面處理 → 切割檢測 |

**兩塊固定說明框（這張圖的結論，不可省略）**：

- 左下「**為什麼載板比主機板貴**」：
  1. **線細一個量級**，要走半加成製程，一層一層長出來；
  2. **層數是「循環」出來的** —— 每多一層增層，就多一次貼膜、雷射、除膠渣、電鍍、蝕刻，
     而良率是每一層的連乘；
  3. **關鍵材料幾乎只有一家**（ABF 增層膜），材料漲價直接進成本；
  4. **越做越大就越難** —— 尺寸一大，翹曲、平坦度、電鍍均勻度同時變嚴。
- 右下「**AI 為什麼把載板推到極限**」：
  1. 晶片變大、要接的線變多 → 載板跟著變大、層數變多；
  2. 大板子在迴焊高溫下翹得更兇（樹脂與矽的熱膨脹差太多）；
  3. 所以才有人提**無核心**（路徑短）與**玻璃核心**（更硬、更接近矽）；
  4. 這兩條路都還要換設備與重新認證，**不是換個材料就好**。

**畫面上一定要有的三行**（左下角，跟 `semiconductor()` 同一個位置）：

- `示意圖，非實物比例｜層數與各層厚度均為示意`
- `圖上畫 core ＋ 上下各 3 層增層，實際為十幾至二十幾層`
- `點零件篩到的是「環節」不是整個族群：「IC 載板（ABF / BT）」這一格目前收錄三家`

## 6. 結構審查清單（`mechanical-engineer` 逐條驗）

> 寫法規則：每一條都是「A 必須在 B 之前」「A 不可以碰到 B」「A 的數量／厚薄關係必須是 X」
> 這種**看圖就能判定**的句子。**不准出現「要畫得清楚」「要好看」這種驗不動的條目。**

**S 組・疊構**

- S1　全圖**只有一片 core**，而且在正中間；**沒有任何一片 prepreg**。
- S2　core **明顯厚於**任何一層增層。
- S3　core 上方與下方的增層**層數相等**，且對應層的**厚度相等**。
- S4　**只有 core 那一層有織紋**；任何一層增層裡都沒有織紋。
- S5　**上表面是 bump pad、下表面是 BGA 球墊**，兩側墊子大小不同，沒有對調、沒有兩面相同。
- S6　防焊出現在**兩個外表面**，且**在墊子處開窗**（至少一處看得到開窗）。
- S7　表面處理**只出現在開窗露出來的銅上**，沒有畫在防焊之上、也沒有畫成整片。

**V 組・孔**

- V1　core 貫孔**只穿 core**，兩端都停在 core 的表面，沒有穿進任何一層增層；
  孔內是**填塞物 ＋ 兩端蓋銅**，不是空心。
- V2　每一個雷射微孔**只穿一層增層**，形狀**上寬下窄**，不是直筒。
- V3　**上半部的微孔朝下收窄、下半部的微孔朝上收窄**（兩側都朝 core）。兩側同方向＝不過。
- V4　微孔**內部畫成填實**；疊孔的兩個孔**軸心對齊**，中間看得到一段填平的銅。
- V5　圖上**沒有**背鑽、埋孔、貫穿全板的 PTH 這三種孔。

**M 組・材料與辨識**

- M1　載板細線**明顯細於**圖上那一小段 PCB 走線對照（相對關係看得出來）。
- M2　三種節距（微凸塊／C4／BGA 錫球）**由細到粗排列且差距一眼看得出**，
  三者不得畫成相近大小。
- M3　ABF vs BT 對照格裡，**BT 那格有織紋、ABF 那格沒有**。
- M4　ABF 膜與 BT 樹脂的標註**明講供應商是外商**，沒有任何一處把它們標成台廠產品。
- M5　晶粒與中介層是**灰色剪影**，沒有標任何內部細節（TSV／微凸塊結構／RDL／LSI），
  而且旁邊有一句把讀者導去半導體鏈那張圖。
- M6　圖上**沒有**銅箔稜面放大格、玻纖織紋放大格、四種孔對照、走線頂視小圖、
  表面處理比較表（這五樣都是 `pcb_stackup` 的內容）。
- M7　圖上**沒有**散熱蓋、均熱片、風扇、連接器。
- M8　圖上**沒有**任何廠商 logo、料號絲印或商標。

**P 組・流程列**

- P1　增層（第 3 格）在防焊與表面處理（第 4 格）**之前**。
- P2　第 3 格裡**出現除膠渣**這一步，且在雷射開孔之後、鍍銅之前。
- P3　流程列上有一條**分界線**把「材料商（外商）」與「載板廠（台股）」分開。
- P4　第 3 格標明**上下同時進行**。

**N 組・誠實性（紅線，違反任一條就退回，不進二輪）**

- N1　畫面上**沒有任何良率數字、成本金額、市占率百分比**——
  **唯一例外**是 ABF 膜市占那一句，而且它**必須**同時標來源與年份（§7-A16）。
  其餘一個百分比都不准。
- N2　凡是帶年份／規格等級的量級數字（節距、線寬、層數），畫面上**都附了
  「來源：⋯，年份」或等價的時效標示**。
- N3　畫面上同時有 §5 那三行（非實物比例／層數為示意／環節不等於族群）。
- N4　§7-B 裡標為低信心的每一項，畫面上**都沒有寫成確定的單一數值**
  （尤其是封裝尺寸 mm 數、CTE 的 ppm 值、玻璃核心的剛性與翹曲量）。
- N5　供需缺口、長約漲幅、各家營收占比**一個都沒有出現在 SVG 裡**（§7-B5）。

### D. `data-seg` 的掛法與四個限制

**D1　這張圖用的 seg 有兩個不在 `ai_server` 鏈的本籍，但這一次是成立的。**

`abf_pcb`（IC 載板 ABF / BT）與 `substrate_material`（載板材料 ABF / BT）在
`supply_chain.yaml` 裡的 `chain` 都是 **`semiconductor`**，而這張圖掛在 `ai_server` 鏈。
`site/industry.js` 的 `CHAIN_EXTRA` 明確把這兩格拉進 `ai_server`：

```js
ai_server: ['ic_design', 'foundry', 'adv_pkg', 'hbm', 'abf_pcb',
            'substrate_material', 'osat_test', 'test_interface'],
```

所以 `chainSegments(sc, 'ai_server')` **會**回傳這兩格，環節色標那一排**會**有對應的 chip，
點零件時色標會亮、下方成分股也會被篩。

> ⚠ **順帶抓到的一條既有錯誤（寫給 CEO，不是這張圖的問題）**：
> `pcb_stackup.md` §7-D1 寫「在 `ai_server` 的圖上掛一個屬於 `semiconductor` 鏈的 seg（例如 `abf_pcb`），
> 環節色標那一排**根本不會有對應的 chip**」——
> **這句話與程式碼不符**，`CHAIN_EXTRA['ai_server']` 裡就有 `abf_pcb`。
> 那張圖「ABF 對照格不掛 seg」的**結論**仍然可以維持（一張圖一個主體，對照格本來就不該搶篩選），
> 但**理由要改寫**，否則下一個人會照著那句錯的機制描述去做決定。

這張圖實際要用的三個 seg（全部已逐一比對 `pipeline/groups/supply_chain.yaml` 確認存在）：

|---|---|---|---|---|
| `substrate_material` | 載板材料 ABF / BT | 2 / semiconductor（role: material，`material_of: [abf_pcb]`） | core（1）、ABF 增層膜（3）、ABF vs BT 對照格（15）、路線圖（17） | **只有外商**：味之素 Ajinomoto、三菱瓦斯化學 MGC。**台股掛零** |

**D2　晶片這一側的零件一律不掛 `data-seg`。**
C4 凸塊（9）、微凸塊（10）、BGA 錫球（11）、晶粒與中介層剪影（12）、三種節距放大格（14）
**都不掛**。理由有兩層：

1. **歸屬會誤導**：凸塊到底算封裝廠還是載板廠做的，依製程分工而異，
   這次**查不到可引用的分工說法**（§C）。掛上去等於在網站上宣稱一個沒有證據的分工。
2. **主體只能有一個**：掛了 `adv_pkg` 會讓讀者以為這張圖在講先進封裝，
   而那是半導體鏈那張的主題（§0-B 二）。

**D3　`ic_substrate` 族群與 `abf_pcb` 環節這一次「剛好對得上」，但有一個例外要寫在畫面上。**
`groups.yaml` 的 `ic_substrate` 是 `3037 / 8046 / 3189`，`supply_chain.yaml` 的 `abf_pcb`
也正好是這三家 —— **就目前已寫規格書的幾張圖來說，這是唯一一張族群與環節成分完全一致的**，
不會重演 MLCC（環節少兩家）與 PCB（族群 7 檔、環節 3 家）那種落差。

**例外**：`4958 臻鼎-KY` 的 `tech` 欄裡有「IC 載板 ABF」，但它掛在 `hdi_pcb` 那一格。
所以**點載板零件篩出來的三家，不等於「台股所有做載板的公司」**。
→ 畫面最底下那一行（§5 第三行）要寫清楚「篩到的是環節」，
