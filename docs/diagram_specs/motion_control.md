## 0. 開畫之前要先簽掉的四件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 滾珠螺桿的鋼珠在螺帽裡**繞一圈回來** | **不會**。循環路徑是「螺帽內部的一條通道」，外面看是一個不透明的方塊；**只有剖面看得到** | 2D 剖面 |
| 線性滑軌的滑塊**包住**軌道兩側 | **會一點點**，但「包住」在**垂直於軌道的橫剖面**上一眼就看得出來（一個ㄇ字形罩住一條凸軌），比透視清楚 | 2D 橫剖面 |
| 諧波減速機三件的**徑向套疊**順序 | **不會**。那是同心圓的層序，剖面最清楚；透視會把最裡面的波產生器整個擋掉 | 2D 剖面 |
| RV 減速機是**兩級** | 不會。那是左右兩段的串接關係 | 2D 剖面 |
| 控制鏈（控制器→驅動器→馬達→傳動→回授） | 不會。那是一個閉合的流程環 | 2D 環 |

反面成本三條：
1. 這張圖五個資訊點裡有四個是「剖面上的層序或包覆關係」，3D 只會把它們擋住。
2. 3D 在手機吃力（AGENTS §11 明列），而這張圖的觀眾會在手機上看族群頁。
3. `electronics` 這條鏈**目前沒有 3D 場景**，開一個就多一組 WebGL context 與 rAF 要管。

**什麼條件下才該回頭加 3D**（寫死）：
> 只有當這張圖要新增「**一整條產線的機台配置與物流動線**」（同時需要平面位置與垂直高度，
> 例如 AMHS 天車在潔淨室天花板、底下是機台）時，才重開這一段、改規格書、重新簽。
> 「看起來比較立體」「別張有 3D 這張也要有」都不算理由。

## 1. 這張圖要回答什麼問題

**「工廠裡一次直線移動、一次關節轉動，各自靠哪幾個零件？這幾個零件台股各是誰在做？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句，不准加第五句**）：

1. **滾珠螺桿把「轉」變成「直線走」，線性滑軌只負責「別歪掉」。** 兩個是不同的零件，
   同一根軸上兩個都要有 —— 螺桿出力、滑軌導引與承重。
2. **兩者都是靠鋼珠把滑動摩擦換成滾動摩擦**，所以兩者都必須有**鋼珠回流的路徑**；
   沒有回流路徑的螺桿是鎖緊用的，不是傳動用的。
3. **減速機有兩個家族，不能互換**：諧波小、輕、精度高但剛性低，走協作機器人手腕與小負載關節；
   RV 是兩級、大、重但抗衝擊與壽命好，走工業機器人的基座與腰部。
4. **有編碼器回授才叫伺服。** 控制器 → 驅動器 → 馬達 → 傳動 → 負載，
   再由編碼器繞回控制器，這個環必須是閉的。

**這張圖的成敗**：指著圖上任何一個零件，要能說出「這是什麼、誰做的、那家做的是哪一類」。
講不出第二句，圖就白畫（`diagram_purpose.md` R1）。

## 3. 層別／順序（★ 可判定的條目，最常錯的五組全部寫死）

### 3-A 單軸模組縱剖，**由左到右**

1. 伺服馬達（尾端掛編碼器）
2. **聯軸器**
3. 軸承座（固定端）
4. 螺桿軸 ＋ 螺帽（螺帽騎在軸上）
5. 軸承座（支撐端）

**M1**　馬達與螺桿之間**必須有聯軸器或皮帶輪**。直接畫成一根連續的軸就是錯 ——
那表示馬達軸與螺桿軸完全同心且剛性連接，實務上做不到，也修不了。
**M2**　編碼器**在馬達的尾端**（遠離螺桿那一側），不是在螺桿那一端。

### 3-B 滾珠螺桿內部，**由外到內再回來（這是本圖最重要的一條）**

1. 螺桿軸的**圓弧溝槽**（哥德弧／單圓弧，**不是三角螺紋**）
2. 鋼珠躺在溝槽裡
3. 螺帽內壁的對應溝槽把鋼珠夾住
4. 鋼珠沿溝槽滾到螺帽的一端
5. **進入循環器（回流通道），繞回螺帽的另一端**
6. 重新進入溝槽 —— **這是一個閉合的迴圈**

**M3**　★★ **一定要畫得出 5 → 6 那一段回流**。沒有回流路徑的螺桿是**鎖緊用的梯形螺桿**，
不是傳動用的滾珠螺桿。**這一條不過就退回，不進二輪。**
**M4**　螺紋溝槽的剖面是**圓弧**。畫成 V 形三角就是畫成了一般螺絲。
**M5**　鋼珠**必須同時碰到螺桿溝與螺帽溝**（兩點接觸），不可以浮在中間。

### 3-C 線性滑軌橫剖，**由下到上**

1. 底座（鋁擠型）
2. 軌道（固定在底座上，**凸出來**）
3. 鋼珠（在軌道兩側的圓弧溝裡）
4. 滑塊（**ㄇ 字形，從上方罩下來、包住軌道兩側**）
5. 工作台（鎖在滑塊上）

**M6**　★ 滑塊**必須包住軌道的兩側**。畫成「一個方塊放在軌道上面」就是錯 ——
那樣的東西吃不了側向力也吃不了拉拔力，而滑軌存在的理由就是吃這兩種力。
**M7**　★ 橫剖上必須是 **兩條平行軌道，螺桿在兩軌之間**。
螺桿畫在軌道旁邊或上面都是錯的配置（力矩會把工作台扭起來）。
**M8**　滾珠**在軌道與滑塊之間的溝裡**，不在滑塊外面。

### 3-D 諧波減速機，**由外到內（同心）**

1. **剛輪**（最外，內齒）
2. **柔輪**（中間，薄壁杯形，外齒，被壓成橢圓）
3. **波產生器**（最內，橢圓凸輪＋薄軸承）

**M9**　★★★ 這個順序不准反。把波產生器畫在最外面、或把柔輪畫在剛輪外面，
整個機構就不成立（柔輪要被波產生器從裡面撐開、去咬外面的剛輪）。
**這一條不過就退回，不進二輪。**
**M10**　柔輪必須畫成**橢圓**（長軸兩端咬住剛輪、短軸兩端脫開），不是正圓。
**M11**　柔輪的齒數畫得比剛輪少，畫面上標「柔輪比剛輪少 2 齒」（§7-A2）。
**M12**　輸出從**柔輪**出去（杯底法蘭），不是從剛輪出去。

### 3-E RV 減速機，**由輸入到輸出（左到右）**

1. 前級：正齒輪／**行星齒輪組**（靠馬達端）
2. 曲柄軸（偏心）
3. 後級：**擺線盤 ×2 ＋ 針齒環**
4. 輸出法蘭

**M13**　★ **行星級一定在前（靠馬達）、擺線級一定在後（靠輸出）**。反過來畫就不是 RV。
**M14**　擺線盤畫 **2 片**、相位差 180°（單片會有不平衡力）。
**M15**　擺線盤的外緣是**連續的波浪**，不是尖齒；波浪咬在一圈**圓柱針銷**上。
**M16**　★ 兩格並排時**用同一個比例尺**，而且 **RV 的外徑必須明顯大於諧波**
（在同一輸出扭矩下，大與重就是 RV 的代價 —— 畫成一樣大就把對照的意義畫掉了）。

### 3-F 控制鏈，**閉合**

順序：`控制器 → 驅動器 → 馬達 → 減速機／螺桿 → 負載`；
回授：`編碼器 → 驅動器 → 控制器`。

**M17**　★ 回授線**必須畫出來且接得回去**。只畫單向五格＝畫成了開迴路，那不是伺服。
**M18**　編碼器的回授起點在**馬達**，不是在負載。
**M19**　箭頭方向：主鏈一律向右，回授一律向左，**不准兩條線同方向**。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵（看到這個才認得出是它）

- **F1 滾珠螺桿**：溝槽是圓弧 ＋ 鋼珠成串 ＋ **一條 U 形回流通道**。
- **F2 線性滑軌**：軌道是凸的、滑塊是 ㄇ 形罩下來、兩者之間有兩列滾珠。
- **F3 諧波減速機**：**三個同心圈** ＋ 中間那圈是**橢圓**的薄壁。
- **F4 RV 減速機**：**兩段**（左邊一組小齒輪、右邊兩片大波浪盤）＋ 一圈針銷。
- **F5 伺服馬達**：圓筒 ＋ **尾端一個小圓（編碼器）**。沒有那個小圓就只是感應馬達。
- **F6 聯軸器**：短、中間有一段螺旋溝或膜片。
- **F7 控制鏈**：五格 ＋ **一條繞回去的回授線**。

### 4-B 最常見的畫錯（逐條對應 §6 的審查條目）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |
|---|---|---|
| 螺桿畫成三角螺紋 | 那是鎖緊用的螺絲，不是傳動件；傳動要滾動接觸 | S2 |
| 沒有回流通道 | 鋼珠滾到底就卡住了，機構不成立 | S3（紅線） |
| 滑塊畫成「放在軌道上的方塊」 | 吃不了側向與拉拔力，滑軌的存在理由沒了 | S5（紅線） |
| 螺桿畫在兩軌旁邊 | 推力不在滑座形心上，工作台會被扭起來 | S6 |
| 諧波三件順序畫反 | 機構不成立（柔輪要從裡面被撐開去咬外面） | H1（紅線） |
| 柔輪畫成正圓 | 正圓的話全周都咬住，不會有相對轉動 | H2 |
| RV 畫成一級 | RV 的定義就是兩級（行星＋擺線） | R1 |
| 諧波與 RV 畫成一樣大 | 「小輕 vs 大重」是這格對照唯一要講的事 | R4 |
| 控制鏈畫成一條直線 | 沒有回授就不是伺服，這張圖第四句話沒了 | C1（紅線） |
| 馬達直接接螺桿 | 同心度做不到，而且沒有可更換的犧牲件 | M1 |
| 6603 富強鑫被畫進 CNC 工具機那一格 | 它做的是**射出成型機**，不是切削工具機 | X3（紅線） |
