## 1. 這張圖要回答什麼問題

**「工業電腦跟一般 PC 差在哪？為什麼它沒有風扇卻不會過熱？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句**）：

1. **外殼就是散熱器。** 熱從晶片出來，經過導熱介面 → 金屬塊或熱管 → 鋁擠外殼 → 外側鰭片 → 空氣。
   這條路上**任何一段有空氣間隙，整條就斷了** —— 所以它才會摸起來燙，那是正常的。
2. **沒有風扇是刻意的。** 風扇會吸灰、會壞、會是整台機器裡壽命最短的零件。
   拿掉它，代價就是外殼要變成散熱器、機殼要變厚變重。
3. **接頭是鎖上去的，不是卡上去的。** 現場會震動，卡扣會鬆；
   電源是直流寬壓、走端子台，不是家用的圓孔。
4. **它是模組化的。** 計算模組騎在客製載板上，換一代 CPU 只換模組、載板不動 ——
   這就是「長供貨」賣得出價格的原因。

**這張圖的成敗**：指著導熱路徑上任何一段，要能說出「這一段是什麼、為什麼不能有空氣」。
以及指著任何一格，知道**這 12 家彼此是競爭者，不是上下游**（§7-D）。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A 導熱路徑（★ 這是本圖的命題，第一條紅線）

由內到外：`SoC → 導熱介面（TIM）→ 導熱塊／熱管 → 鋁擠外殼 → 外殼鰭片 → 空氣`

**I1**　★★★ **這條路徑必須是連續的** —— 相鄰兩段之間**不准出現空氣間隙**，
每一個交界都要畫得出**面與面貼合**（或一層 TIM）。
> 中間斷一段，整張圖的第一句話就變成假的。**這一條不過就退回，不進二輪。**
**I2**　★★ **TIM 必須貼在 SoC 上**，而且它是**全圖最薄的一層**（量得出來：厚度 ≤ 導熱塊的 1/8）。
TIM 畫太厚會讓人以為它是主角 —— 它的作用就是**把空氣擠掉**。
**I3**　★ 熱流箭頭**六段、方向一致向外**，**不准有任何一段指向內側**。
**I4**　導熱塊／熱管**同時接觸 TIM 與外殼內壁**（兩端都畫接觸面）。

### 3-B 沒有風扇（★ 第二條紅線）

**I5**　★★★ **整張圖一顆風扇都不准出現**（區 A 一定沒有；區 B 的「一般 PC」那一側可以有，
且**必須標明那是一般 PC 的做法**）。
> 區 A 裡畫了風扇＝畫的不是無風扇工業電腦。**紅線。**
**I6**　★ **鰭片必須在外殼的外側**，不在機殼內部。
**I7**　★ 鰭片的**片縫方向是垂直的**（順著自然對流由下往上），且**上下貫通、沒有被上蓋封住**。
沒有風扇就只剩自然對流，鰭片橫著擺＝熱空氣爬不上去。
**I8**　鰭片是**一排等距直片**，數量 ≥ 8，**片距一致**（§0-B）。

### 3-C 模組化架構

**I9**　★ **計算模組是一片獨立的板，騎在載板上面**，兩者之間有**板對板連接器**
（兩排小柱）。把模組畫成焊死在載板上＝把「換一代只換模組」這件事畫掉了。
**I10**　載板**比模組大**（量得出來：載板寬度 > 模組寬度 × 1.4）。
**I11**　I/O 與電源端子**接在載板上**，不在模組上。

### 3-D 接頭與安裝

**I12**　★ **每一個 I/O 接頭都要看得出鎖固結構**（螺絲耳或鎖環），**不准畫成卡扣**。
**I13**　★ **電源是直流端子台或鎖固接頭**，**不准畫成家用圓孔**。
**I14**　DIN 導軌扣或壁掛耳在**機殼背面**（與 I/O 面相反或相鄰的那一面），不在 I/O 面上。

### 3-E 區 B 對照帶

**I15**　五格**同一個比例尺**，**左工業／右一般 PC** 的左右順序**五格一致**（不准有一格反過來）。
**I16**　★ 「一般 PC」那一側的每一格都要有**明確的標籤**，
不准讓讀者以為那也是工業電腦的做法。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **F1 導熱路徑**：一條**連續**的六段箭頭，每個交界都有接觸面。
- **F2 TIM**：全圖最薄的一層，夾在 SoC 與導熱塊之間。
- **F3 外殼鰭片**：等距直片、**垂直方向**、在外殼外側、**沒有風扇**。
- **F4 模組化**：兩片板 ＋ 中間兩排板對板連接器。
- **F5 接頭**：每個都有螺絲耳或鎖環。
- **F6 安裝**：背面一個 DIN 導軌扣或壁掛耳。

### 4-B 最常見的畫錯（逐條對應 §6）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |
|---|---|---|
| 導熱路徑中間斷一段（留空氣） | 空氣是絕熱的；斷了就不導熱，整張圖的命題垮掉 | H1（紅線） |
| 區 A 裡畫了風扇 | 那就不是無風扇工業電腦了 | H5（紅線） |
| 鰭片畫在機殼內部 | 熱傳不到空氣裡 | H6 |
| 鰭片橫著擺（片縫水平） | 沒有風扇就只剩自然對流，熱空氣爬不上去 | H7 |
| TIM 畫得跟導熱塊一樣厚 | 它的作用是「把空氣擠掉」，不是儲熱 | H2 |
| 計算模組焊死在載板上 | 「換一代只換模組」被畫掉了 | M1 |
| I/O 畫成消費級卡扣 | 現場會震動，卡扣會鬆 —— 這是五個差異之一 | C1 |
| 電源畫成家用圓孔 | 同上 | C2 |
| 對照帶有一格左右反過來 | 讀者會把一般 PC 的做法當成工業電腦的 | B1 |
| 畫成某一家的機器外觀 | 違反「不畫真實公司產品外觀」的紅線 | X1（紅線） |

## 9. 給 `tech-illustrator` 的實作邊界

- **先畫導熱路徑、先把六段接起來**，再補其他零件。
  H1 是這張圖的命題本身，而且「先畫零件再把箭頭塞進去」一定會斷。
  做法：**先用一條 `path` 從 SoC 畫到鰭片外側**，再把每個零件的邊界**對齊到這條 path 上的節點** ——
  這樣 H1 在結構上就成立、改不壞。
- **熱流箭頭用同一條 `path` ＋ `marker`**，六段用 `stroke-dasharray` 分段，
  **不要畫六支獨立的箭頭**（獨立箭頭最容易有一支方向畫反，那是 H3 不過）。
- 鰭片用 `for` 迴圈畫**垂直**線段，**片距用一個常數** —— H7／H8 自動成立。
  **迴圈的方向向量寫死成垂直**，不要給角度參數（給了就有人會調歪）。
- TIM 用一個很薄的矩形，**厚度 ＝ 導熱塊厚度 / 10 算出來**（不要給固定值）——
  H2 自動成立。**最小 1.5px**，不然 390px 下會消失。
- 計算模組與載板畫成兩個 `<rect>`，**中間的板對板連接器用 `for` 畫兩排小柱** ——
  M1 自動成立。**載板寬度 ＝ 模組寬度 × 1.5 算出來**（M2）。
- I/O 接頭用**同一個函式**畫，函式裡固定帶兩個螺絲耳 —— C1 自動成立、改不壞。
- 區 B 五格用一個陣列 ＋ `forEach`，**每格都是 `left(工業)` / `right(一般PC)` 兩個欄位** ——
  B1 自動成立（不會有一格反過來）。
- **整張圖搜尋一次 `fan`／`風扇`**：區 A 的 `<g>` 底下**一個都不准有**（H5）。
- 章節列用既有的 `foldBar()` ＋ `<g class="dgbody" data-fold="…" data-y0 data-y1>`，
  **預設全部收合**，**章節列不准掛 `data-seg`**。
- 顏色一律走 `--dg-*`，不准寫死 `#xxxxxx`（AGENTS §15）。
  ⚠ 這張圖**沒有 `data-seg`**，所以 `var(--c)` 不會被帶進來 —— **主色要自己用 `--dg-*` 指定一個**；
  熱流箭頭用 `--dg-hot`。
