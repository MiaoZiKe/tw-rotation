## 0. 要不要 3D —— 判斷與理由（★ 這一段要先被簽掉）

**結論：不做真 3D。`SLOTS` 的 `scene` 留 `null`。**

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| **SiC MOSFET 是垂直導通**（源極閘極在正面、汲極在背面，電流由上往下穿過整片晶片） | **不會。** 「電流是垂直的」這件事就是剖面上的一個箭頭方向。轉到正面看到的是一片金屬電極，什麼都看不到 | 2D 剖面 |
| **GaN HEMT 是橫向導通**（源、閘、汲三個電極都在同一個上表面） | **不會，而且轉了會更糟。** 這張圖的核心對比就是「垂直 vs 橫向」，兩張剖面並排最清楚；一旦進入透視，兩者的方向感都被削弱 | 2D 剖面 |
| **2DEG 在 AlGaN／GaN 界面的哪一側** | **不會。** 那是一條界線上的一層電子氣，厚度連畫都畫不出來（要誇張放大），只存在於剖面 | 2D 剖面 ＋ 放大格 |
| **平面閘 vs 溝槽閘的差別（JFET 區有沒有）** | **只會多一點點。** 溝槽本身是三維的條狀溝，但「JFET 區被消掉了」這件事是剖面上的一塊面積 | 2D 兩格並排 |
| **漂移層厚度決定耐壓** | **不會。** 這是剖面上的一段厚度對比（SiC 薄 vs Si 厚） | 2D 剖面 |
| **長晶 → 晶碇 → 切片** | **會一點點**（晶碇是圓柱、切片是把圓柱切成圓片，這是有立體感的動作） | **2.5D 等角小圖就夠**，不值得為它開一個 WebGL 場景 |
| **電壓／頻率的分工帶** | **不會。** 這是一張二維的座標帶狀圖 | 2D 帶狀圖 |

**唯一一個「3D 可能有用」的候選**是「功率模組內部：多顆晶粒並聯、打線或銅夾片、DBC 基板、
灌膠」—— 那確實有立體的走線關係。但**那是另一張圖**（功率模組封裝），不是這一張；
而且台股在那一段的成分股跟這一格不同。

反面成本四條：
1. 這張圖的六個資訊點裡有五個是「剖面上的層」，3D 只會把它們擋住。
2. 元件剖面的層厚差好幾個數量級（2DEG 是原子層級、基板是數百 µm），
   3D 渲染時薄層會直接消失在像素裡；2D 可以誇張放大並標「非實物比例」。
3. 3D 在手機吃力（AGENTS §11 明列）。
4. 每多一個 3D 場景就多一組 WebGL context 與 rAF 迴圈要管（`dispose3D()` 那條既有的坑），
   而 `semiconductor` 這條鏈已經有一個 3D 場景（`SCENES.semiconductor`）。

**什麼條件下才該回頭加 3D**（寫死，避免重演 MLCC 的事後補簽）：

> 只有當這張圖要新增「**功率模組內部的立體配置**」——
> 多顆晶粒並聯的平面排列 × 打線／銅夾片的垂直走向 × DBC 基板與散熱底板的堆疊 ——
> 也就是**同時需要平面位置與垂直走向**的資訊時，才重開這一段、改規格書、
> 由 `mechanical-engineer` 重新簽。
> **而且比較好的做法是另開一張「功率模組」圖，不是把這張改成 3D。**
> 「看起來比較立體」「別張有 3D 這張也要有」都不算理由。

## 1. 這張圖要回答什麼問題

**「SiC 跟 GaN 差在哪？為什麼一個守高壓、一個守高頻？台股是在做材料還是做元件？」**

使用者看完要能自己講出這四句（畫面上會把這四句印在右側說明欄的抬頭）：

1. **「寬能隙」換到的東西是「同樣耐壓下，漂移層可以做得更薄」**。
   崩潰電場高 → 承受同樣電壓需要的那層材料就薄 → 電阻低、損耗小、元件可以做小（§7-A1、A2）。
2. **結構決定戰場**：SiC MOSFET 是**垂直**的（電流穿過整片晶片，耐壓靠厚度），
   所以能一路做到 1200V 以上；GaN HEMT 是**橫向**的（電流在表面下的一層電子氣裡跑），
   受限於表面崩潰，主流停在 650V 級，但切換可以快到 MHz 級（§7-A3、A4）。
3. **這條鏈的錢分五段**：長晶（晶碇）→ 切片研磨拋光 → 磊晶 → 元件製造 → 封裝模組。
   **台股目前能指得出名字的，集中在磊晶與元件代工這兩段**（§7-D）。
4. **主戰場是車用與電源**，因為這兩個地方同時要「高壓」與「省下來的每一瓦都算錢」：
   電動車的主驅逆變器與車載充電器、充電樁、光伏逆變器，
   以及 2026 年新冒出來的 AI 資料中心 800V 直流供電（§7-A8、A9）。

**這張圖的成敗**：Andy 指著鏈上任何一段，要能說出
「這一段在做什麼、難在哪、**台股有沒有人在這一段**」。講不出第三句，圖就白畫。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A SiC MOSFET 由下到上（違反其一就退回）

```
 ┌ 汲極金屬（drain）                      ← 背面
 │ n⁺ SiC 基板（厚，導電）
 │ n⁻ 漂移層（磊晶長的；這一層的厚度＝耐壓）
 │ ┌ p-body ─ n⁺ source ─（通道在 p-body 表面）
 │ 閘極氧化層 → 閘極
 └ 源極金屬（source）                     ← 正面
```

**硬規則**：
- **W1**　**汲極在背面、源極與閘極在正面。** 三個電極畫在同一面＝那是 GaN，不是 SiC MOSFET（§7-A5）。
- **W2**　**n⁺ 基板在最下、n⁻ 漂移層在基板之上。** 上下對調＝不過。
- **W3**　**基板畫得比漂移層厚**（基板是機械支撐，漂移層是靠磊晶長出來的薄層）。
- **W4**　**閘極氧化層一定畫在閘極與半導體之間**，且**是整張圖最薄的一層之一**。
      閘極直接碰到半導體＝那是 JFET／HEMT，不是 MOSFET。
- **W5**　**n⁺ 源極區一定被 p-body 包住**，不准直接接觸 n⁻ 漂移層。
- **W6**　**電流箭頭是垂直的**，從正面源極 → 通道 → 漂移層 → 基板 → 背面汲極。
- **W7**　**平面閘那一格必須把 JFET 區標出來**；**溝槽閘那一格不准出現 JFET 區**
      —— 消掉 JFET 區正是溝槽結構存在的理由（§7-A6）。
- **W8**　溝槽閘那一格的**閘極要真的嵌進半導體裡**（是一條往下挖的溝），不是貼在表面上。

### 3-B GaN HEMT 由下到上（第二常錯）

```
 ┌ 基板（Si 或 SiC）                       ← 最下
 │ 緩衝層（AlN / AlGaN）：GaN-on-Si 厚、GaN-on-SiC 薄
 │ GaN 通道層
 │ ─────── 2DEG 在這條界面的「GaN 那一側」───────
 │ AlGaN 阻障層
 └ 源極 ── 閘極（下方可有 p-GaN）── 汲極     ← 三個都在正面
```

**硬規則**：
- **W9**　**2DEG 必須畫在 AlGaN／GaN 界面的 GaN 那一側**，不是畫在 AlGaN 裡面，
      也不是畫在兩層中間的正中央（§7-A3）。
- **W10**　**源、閘、汲三個電極全部在同一個上表面**；**背面不准畫電極**（§7-A4）。
- **W11**　**電流箭頭是橫向的**（源極 → 2DEG → 汲極），
      而且要跟 SiC 那張的垂直箭頭**用同一支箭頭樣式**，方向差 90°。
      這一組對比是整張圖最重要的視覺事實。
- **W12**　**AlGaN 阻障層畫得比 GaN 通道層薄。**
- **W13**　**GaN-on-Si 的緩衝層要明顯比 GaN-on-SiC 厚**（晶格失配差很多，§7-A7）。
      兩者畫成一樣厚＝不過。
- **W14**　畫 p-GaN 閘時，**p-GaN 一定在閘極金屬與 AlGaN 之間**，
      而且標籤要寫「把閘極底下的 2DEG 耗盡 → 零偏壓時不導通（常關）」（§7-A4）。
- **W15**　Cascode 小圖裡，**低壓 Si MOSFET 的閘極才是對外的控制端**，
      GaN HEMT 的閘極接到 Si MOSFET 的源極（§7-A4）。畫反＝不過。

### 3-C 帶狀圖（第三常錯）

- **W16**　三條帶**必須互相重疊**，不可以畫成三個互不相交的方塊。
      650V 那一帶是 GaN 與 SiC **同時存在**的區域，畫成井水不犯河水就是錯的（§7-B1）。
- **W17**　帶狀圖上**不准出現「一定要選 X」這種絕對句**，改寫成有條件的說法（§7-B1）。
- **W18**　軸上的數字**只標量級刻度**（例如 100V／650V／1200V／1700V），
      **不標任何市占或出貨量**。

### 3-D 流程順序（第四常錯）

- **W19**　**長晶（1）→ 切片（2）→ 研磨拋光（3）→ 磊晶（4）→ 元件製造（5）**，順序不准對調。
- **W20**　**磊晶必須在切片與拋光之後。** 磊晶是長在「已經拋好的晶片表面」上的，

- **W21**　流程列上要有一條**標示線**，指出「**台股目前指得出名字的是第 4、5 段**」（§7-D2），
      且第 1～3 段要誠實標「台股在這幾段的角色本圖查不到具名對應，見底部說明」。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **兩張剖面的電流箭頭方向差 90°**：左邊垂直、右邊橫向。這是一眼分辨 SiC MOSFET 與 GaN HEMT 的
  決定性特徵，**缺了這個，整張圖就只是兩疊有顏色的方塊**。
- **SiC 那張背面有電極、GaN 那張背面沒有。**
- **SiC 那張的基板明顯厚、漂移層明顯薄，兩者之間有一條清楚的界線**（磊晶界面）。
- **GaN 那張的 2DEG 是一條發亮的細線，貼在界面下方。**
- **平面閘格有 JFET 區、溝槽閘格沒有**，且溝槽閘的閘極真的是挖下去的一條溝。
- **閘極氧化層是一條細白線**（MOSFET 的定義特徵），GaN HEMT 那張**沒有這條線**。
- **緩衝層的厚薄對照**：GaN-on-Si 厚、GaN-on-SiC 薄。
- **帶狀圖的三條帶是重疊的**，不是三段互不相交的區間。

### 4-B 最常見的畫錯

| 常見錯法 | 為什麼錯 | 對應條目 |
|---|---|---|
| 把 GaN HEMT 也畫成上下電極 | GaN 功率元件主流是**橫向**的，這正是它做不上高壓的原因 | W10 |
| 2DEG 畫在 AlGaN 裡面或兩層正中間 | 2DEG 在 GaN 那一側，這是極化誘發的 | W9 |
| SiC 的漂移層畫得比基板厚 | 漂移層是磊晶長的薄層，基板是機械支撐 | W3 |
| 溝槽閘那格還留著 JFET 區 | 消掉 JFET 區就是溝槽結構的理由 | W7 |
| 閘極直接貼在半導體上、沒有氧化層 | 沒有氧化層就不叫 MOSFET | W4 |
| GaN-on-Si 與 GaN-on-SiC 的緩衝層畫一樣厚 | 晶格失配約 17% vs 約 3.5%，緩衝層需求差很多 | W13 |
| Cascode 畫成 GaN 的閘極對外 | Cascode 的控制端是那顆低壓 Si MOSFET | W15 |
| 帶狀圖畫成「GaN 管 650V 以下、SiC 管 650V 以上」兩個不相交的方塊 | 650V 這一段兩者都在打，而且 1200V GaN 已經在送樣 | W16、§7-B1 |
| 磊晶畫在切片之前 | 磊晶長在拋好的晶片表面上 | W20 |
| 把射頻 GaN 或 LED 畫進來 | 同樣是 GaN，但應用與台股完全不同一批 | §2-F |

## 6. 結構審查清單（`mechanical-engineer` 逐條驗，每條都要判得出過／不過）

**S 組・SiC MOSFET**
- S1　汲極在**背面**、源極與閘極在**正面**（W1）。
- S2　由下到上是 `汲極 → n⁺ 基板 → n⁻ 漂移層 → p-body/n⁺ source → 閘極氧化層 → 閘極 → 源極金屬`（W2）。
- S3　**基板畫得比漂移層厚**（W3）。
- S4　**閘極與半導體之間有一條明顯的氧化層**，且它是全圖最薄的層之一（W4）。
- S5　**n⁺ 源極區被 p-body 完全包住**，沒有直接碰到 n⁻ 漂移層（W5）。
- S6　電流箭頭**垂直**貫穿，方向由正面到背面（W6）。
- S7　**平面閘格有標出 JFET 區；溝槽閘格沒有 JFET 區**（W7）。
- S8　溝槽閘的閘極**真的嵌進半導體裡**（W8）。
- S9　兩格（平面／溝槽）**用同一比例、同一畫法**，只有閘極那一段不同。

**G 組・GaN HEMT**
- G1　**2DEG 畫在 AlGaN/GaN 界面的 GaN 那一側**（W9）。
- G2　**源、閘、汲三個電極全部在上表面，背面沒有電極**（W10）。
- G3　電流箭頭**橫向**，與 SiC 那張同樣式但方向差 90°（W11）。
- G4　**AlGaN 阻障層比 GaN 通道層薄**（W12）。
- G5　**GaN-on-Si 的緩衝層明顯比 GaN-on-SiC 厚**，且兩者並排可比（W13）。
- G6　p-GaN **在閘極金屬與 AlGaN 之間**，標籤講出「耗盡 2DEG → 常關」（W14）。
- G7　Cascode 小圖裡**對外控制端是低壓 Si MOSFET 的閘極**（W15）。
- G8　GaN 那張**沒有閘極氧化層那條細白線**（那是 MOSFET 的特徵，不是 HEMT 的）。

**B 組・帶狀圖**

## §3D-細節（2026-09-26，3D 設計專責）

零件清單、編號、位置、爆炸位移、卡片文字**都沒動**。

| 零件 | 補了什麼 |
|---|---|
| SiC 汲極金屬（背面） | 分成三層：Ti（貼 SiC）→ Ni → Ag（最外、焊接面） |
| SiC p-body／n⁺ | 從「兩塊」改成**三個重複元胞**：每兩個 p-body 夾出 JFET 區、n⁺ 源極貼在 p-body 靠 JFET 側、p⁺ 接觸在 p-body 中央 |
| SiC 閘極氧化層＋閘極 | 每個元胞一條：氧化層 → 多晶矽閘極 → 半透明 ILD 包起來（源極金屬才不會碰到閘極） |
| SiC 源極金屬（正面） | 厚鋁蓋滿正面、接觸窗插到兩條閘極之間；右前角切出**獨立的閘極焊墊**；**焊線從正面打出去**（三條粗的接源極、一條細的接閘極）接到導線架引腳 |
| GaN 緩衝層 | 多層過渡（AlN 成核層＋多層 AlGaN，層數示意） |
| GaN 2DEG | 閘極正下方那一段變暗（p-GaN 在零偏壓下把它耗盡＝常關，跟卡片同一句話） |
| GaN 三電極 | S/D 為兩層歐姆接觸金屬；電極之間 SiN 保護層（半透明）；**源極場板**蓋過閘極伸向汲極；閘極焊墊經穿過保護層的柱子接到閘極；**三條焊線全部從上表面打出去** |

這組焊線就是這張圖要比的那件事的立體版：**SiC 背面沒有焊線（汲極靠整片背面金屬）、GaN 三個電極的焊線全在上面**。
