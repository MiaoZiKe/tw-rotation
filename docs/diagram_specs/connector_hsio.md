## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：不做真 3D

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 為什麼高速要用線纜不走板子 | 不會。這是**損耗對距離**的比較，本質是一條曲線或一把尺 | 2D 對照條 |
| 公母端怎麼接觸（彈片被撐開、產生法向力） | 不會。接觸物理全部在**剖面**，轉到外面只看到一個塑膠殼 | 2D 剖面 |
| 差動對怎麼被接地遮蔽包住 | 不會。遮蔽是**橫剖面**上的同心／包覆關係 | 2D 橫剖面 |
| 金手指為什麼是硬金、為什麼有倒角 | 不會。鍍層是剖面、倒角是側視 | 2D 剖面 |
| 光模組籠是鈑金折出來的盒子、上面有散熱片與 EMI 指片 | **有一點點**，但籠子的重點（通風孔、指片、壓接針腳）用 2.5D 切開就看得完 | 2.5D 切開 |

**最強的 3D 候選是「這四類連接器在機櫃裡各自的位置」** —— 那確實是空間關係。
但這件事**已經有一張 3D 圖在做了**：`site/diagrams.js` 的 `ai_server` 是**鏈層級**的
「AI 伺服器：機櫃與運算托盤」，`scene: 'ai_server'`，本來就在講機櫃裡有什麼、在哪。
**再做一個機櫃 3D 場景就是重複**，而且會多一組 WebGL context 與 rAF 要管。
這張圖要做的是那張圖做不到的事：**把接點切開**。

**什麼條件下才該回頭加 3D（寫死，避免下次又變成事後補簽）**：

> 只有當這張圖要新增「**盲插（blind-mate）時公母端怎麼在三個軸向上自動對正**」
> 這一類**必須看到三個軸向同時位移**的資訊，而且既有的 `ai_server` 3D 場景**確定不打算涵蓋**時，
> 才重開這一段、改規格書、重新簽。
> **單純為了「連接器看起來很立體」不算理由。**

### 0-B　四格怎麼排才不會變成四張圖硬擠

**結論：上方一條訊號路徑帶（四個編號站點）＋ 下方 2×2 四格，格子編號與站點編號一致。**

這張圖跟 `passive_rlc` 那張不一樣的地方在於：**這四樣東西之間真的有順序** ——
訊號從交換器／GPU 晶片出來之後，**必然**會經過其中一條路徑到達外界。
所以上方那條路徑帶不是裝飾，它是四格的索引：

```
┌──────────────────────────────────────────────────────────────┐
│ 訊號路徑帶（2.5D 微斜，一塊板子 ＋ 機櫃後方）                     │
│  ASIC ──① 走板子 → 板邊金手指 ──② → 插槽                       │
│       └─③ 走內部線纜 ─────────────→ 前面板光模組籠 ④          │
│                       └──────────→ 機櫃背板線纜匣 ⑤           │
└──────────────────────────────────────────────────────────────┘
        ┌──────────────┐ ┌──────────────┐
        │ ② 金手指與插槽 │ │ ④ 光模組籠     │     ← 四格等高等寬
        ├──────────────┤ ├──────────────┤
        │ ③ 內部線纜     │ │ ⑤ 背板與盲插   │
        └──────────────┘ └──────────────┘
   底部一條：同一個損耗預算下，走板子 vs 走線纜各能跑多遠（①的答案）
```

**硬規則**：

- **四格等高等寬**（`新-版面等高與多寬度` 那一段驗收本來就在管這件事）。
- **四格的內部結構一致**：剖面 → 一句「它解決什麼」→ 三行標註。
- **上方路徑帶的編號與下方格子的編號必須一致**，而且**兩邊都要看得到編號**
  —— 沒有編號，路徑帶就退化成裝飾。
- **路徑帶高度不得超過整張圖的三分之一。**
- **窄畫面（800px 以下）四格改成一欄四列**，**順序不准變**（②→③→④→⑤）。

## 1. 這張圖要回答什麼問題

**「資料中心的高速訊號，為什麼寧可拉一條線纜，也不願意在板子上多走幾吋。」**

使用者看完要能自己講出這四句：

1. **板子會把訊號吃掉**。同樣一份「允許損耗」的預算，走低損耗線纜能拉的距離
   比走高階板材的走線遠得多。這就是「板上飛越纜線」「線纜背板」出現的原因。
2. **拉線纜省下來的不只是距離**：訊號夠強就不必加中繼器（retimer），
   少一顆中繼器就少一份功耗與成本，板子的層數也能往下壓。
3. **連接器的四個站各解決一件事**：板邊金手指負責「插卡」、內部線纜負責「繞過板子」、
   前面板籠子負責「插光模組並且散熱、擋電磁干擾」、背板匣負責「整櫃盲插」。
4. **接點是機械問題不是電氣問題**：母端的彈片被公端撐開、產生法向力，
   插拔時擦過去把氧化層刮掉；鍍金能用比較小的法向力，鍍錫要大得多。
   **這就是為什麼高速料號幾乎都鍍金。**

**這張圖的成敗**：Andy 指著四格裡任何一個連接器，要能說出
「它接在哪兩段之間、它變好會讓什麼變好」。講不出這句，圖就白畫。

## 3. 層別／順序（可判定的條目）

### 3-A 金手指的鍍層（由內到外）

1. 板子的銅 → 2. **鎳阻障層** → 3. **硬金**

**硬規則**：

- **順序不准對調**：鎳在內、金在外。把鎳畫在金外面是最常見的錯（與 MLCC §3-B、
  `pcb_stackup` S8 同一條規則）。
- **硬金那一層要明顯薄於鎳層**（§7-A2 的厚度量級是金 0.75–1.25 µm、鎳 2.5–5 µm）。
- **金手指前端要有倒角**；沒有倒角＝插的時候會刮壞彈片。
- **金手指是「公端」、插槽是「母端」** —— 標註不准寫反。

### 3-B 接點接觸的順序（格 ② 的放大件 C7）

1. 卡片斜角先碰到彈片 → 2. **彈片被撐開（產生法向力）** →
3. 繼續推入時接點**沿著金手指表面擦過去（擦拭 wipe）** → 4. 到底、鎖定

**硬規則**：

- **彈片一定要畫成「被撐開的變形狀態」**，不是一根沒受力的直片。
- **法向力箭頭必須垂直於接觸面**（那就是「法向」的意思），
  **擦拭行程箭頭必須平行於插入方向**。兩支箭頭畫成同方向＝不過。
- 放大件旁邊要標明**鍍金可以用比較小的法向力、鍍錫要大得多**（§7-A4）。

### 3-C 盲插的接觸順序（格 ⑤）

1. **導引柱／斜面先接觸並把位置對正** → 2. 浮動連接器在間隙內自我修正 →
3. **最後才是訊號接點接觸**

**硬規則**：**導引柱一定比訊號接點先接觸**（圖上導引柱要比接點更靠前）。
畫成「接點先碰到」＝不過，那在工程上就是把接點撞壞。

### 3-D 籠架的組成順序（格 ④，由下到上）

1. 板子 → 2. **籠架以壓接針腳固定在板上** → 3. 籠架開口四周的 **EMI 指片** →
4. 籠架上方的**散熱片與夾持彈簧** → 5. 從前面插入的**光模組**

**硬規則**：

- **散熱片在籠架之上、模組之外** —— 熱是從模組經籠架頂面傳到散熱片的。
  把散熱片畫在籠架裡面或模組裡面＝不過。
- **EMI 指片在開口四周，朝向模組**（模組插進來時被壓住）。
- **籠架要有通風孔**；沒有通風孔就不叫籠。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **格 ②**：一排**等距金色長條 ＋ 前端倒角**（金手指），配上**一排被撐開的彈片**。
  只畫一排金條、沒有畫母端彈片＝這一格就沒有「連接器」，只有一塊板子。
- **格 ③**：**twinax 的橫剖面** —— 兩根等徑導體並排、被同一層接地遮蔽包住。
  這是這一格**唯一的決定性特徵**；畫成單根同軸就變成另一種線了。
- **格 ④**：**鈑金盒 ＋ 通風孔 ＋ EMI 指片 ＋ 壓接針腳 ＋ 散熱片**五件齊全。
  少了 EMI 指片與壓接針腳，籠子就只是一個盒子。
- **格 ⑤**：**導引柱比接點更靠前** ＋ **浮動間隙**。
- **全圖**：**每一格都看得出公端與母端是誰**（標「公」「母」或用形狀區分）。
- **底部對照條**：兩根長度差很多的橫條，旁邊一句「同一份損耗預算」。

### 4-B 最常見的畫錯（逐條對應 §6 的審查條目）

| 常見錯法 | 為什麼是錯的 | 對應審查條目 |
|---|---|---|
| 金手指的金畫在鎳裡面 | 由內到外是銅 → 鎳 → 金 | E1 |
| 金手指沒有倒角 | 沒有倒角插進去會刮壞母端彈片 | E3 |
| 母端彈片畫成沒受力的直片 | 接觸的前提就是彈片被撐開產生法向力 | E4 |
| 法向力與擦拭的箭頭畫成同方向 | 一個垂直於接觸面、一個平行於插入方向 | E5 |
| twinax 畫成單根同軸 | 高速走的是差動對，兩根並排 | B1 |
| twinax 的遮蔽只包一根 | 一對共用一層遮蔽才是 twinax | B2 |
| 籠架沒有 EMI 指片或沒有通風孔 | 那兩樣是籠架的必要結構 | G2／G3 |
| 散熱片畫在籠架裡面或模組裡面 | 熱是從模組經籠架頂面傳出去的 | G4 |
| 光模組畫出內部光學 | 那不是這張圖的主題，而且會跟光通訊那條鏈的圖重複 | G5 |
| 盲插畫成接點先碰到、導引柱後到 | 工程上那就是把接點撞壞 | K1 |
| 四格不等高 | 版面等高是既有驗收項 | X1 |
| 路徑帶沒有編號、或編號跟格子對不起來 | 沒有編號路徑帶就只是裝飾 | X2 |
| 畫出 CPO、PCB 疊構或層數 | 那是 `switch_board` 與 `pcb_stackup` 的主題 | X4 |
| 照著某一家的產品外形描 | AGENTS §11 紅線，而且高速連接器的外形就是品牌識別 | X6 |
| 把這張圖掛在 `connector_ind` 而不處理 §0-C | 那個族群的定義明講「不是資料中心高速料號」 | X7 |

## 5. 標註文字

一律引線拉到外側文字框，**不壓在零件上**，最小 12px。
主標題：`連接器與高速互連：訊號為什麼寧可走線纜，也不走板子`

| 指到哪裡 | 文字寫什麼 |
|---|---|
| 底部對照條（S2） | **同一份損耗預算，能跑多遠**／低損耗雙軸線纜可達約 22 吋，而走高階板材的走線約 4.5 吋（依 IEEE 802.3ck 的損耗上限；**來源：連接器原廠技術頁，2026，單一來源**）。**這就是「線纜取代板子」的全部理由** |
| 對照條第二行 | **省下來的不只是距離**／訊號夠強就不必加中繼器（retimer），少一顆就少一份功耗與成本，板子的層數也能往下壓 |
| 金手指（C2） | **金手指是「公端」**／銅 → 鎳阻障 → **硬金**。硬金是為了耐插拔磨損，不是為了導電 |
| 倒角（C3） | **前端倒角**／沒有倒角，插進去會把母端彈片刮壞 |
| 彈片（C5、C7） | **母端彈片被撐開，才有接觸**／撐開產生**法向力**（垂直於接觸面），插入時接點**擦過**金手指表面把氧化層刮掉。**鍍金能用比較小的法向力（約數十公克級）；鍍錫會氧化，要大得多（原廠慣用值約 100 公克級）** |
| 插槽（C4） | **插槽是母端**／PCIe 這一類卡緣連接器的接點間距是 1.0 mm 等級；新一代改用 PAM4 調變之後，金手指的長度規格也跟著改（來源：連接器原廠與 CEM 規格整理） |
| twinax 剖面（B3） | **一對雙軸線（twinax）**／兩根等徑導體並排、共用一層接地遮蔽。遮蔽擋外來干擾，也讓這一對的阻抗穩定 |
| 線纜連接器（B1、B4） | **內部線纜連接器**／伺服器裡常見兩種：**SlimSAS**（規格 SFF-8654，常見 4 通道與 8 通道）與**MCIO**（規格 SFF-TA-1016，密度更高、支援的通道組合更多）。MCIO 的 38 針對應 4 通道、74 針對應 8 通道 |
| 走板子的對照（B5） | **另一條路：繼續走板子**／同樣兩點之間，走板子要多花掉一大段損耗預算 —— 那就是上面那條尺在比的事 |
| 籠架（G1、G2） | **光模組籠（cage）**／鈑金折出來的盒子，用**壓接針腳**固定在板上（不是焊上去的），盒身要有通風孔 |
| EMI 指片（G3） | **EMI 指片**／圍在開口四周的彈性金屬指，把模組與盒子之間的縫隙壓住，擋住電磁干擾外洩與埠間串擾 |
| 散熱片（G4） | **騎在籠子上的散熱片**／模組的熱經籠架頂面傳到散熱片。現代高速埠幾乎是散熱片、熱介面材料與 EMI 襯墊三件一起上 |
| 雙面安裝（G7） | **背對背（belly-to-belly）**／同一個位置板子上下各一個籠，前面板才塞得下更多埠 |
| 光模組（G5） | **插進去的是光模組**／它自己的內部在光通訊那一條鏈的圖裡。**另一條路是把光引擎搬到晶片旁邊（CPO），見「交換器板卡」那張** |
| 線纜匣（K1） | **機櫃背板：線纜匣**／整櫃的互連改用成束的銅纜裝在匣子裡；托盤推進去時自動對接，不用一條一條手插 |
| 浮動與導引（K2、K4） | **先對正，再接觸**／導引柱比訊號接點更早接觸，把位置對正；連接器本身可在小範圍內浮動，吸收機構公差 |
| 〔選配〕工業／車用對照（A1） | **同樣叫連接器，要求完全不同**／車用要過 USCAR-2 那一套：振動測試分等級，**不密封的連接器不能裝在乘客艙與行李廂以外**，密封件要能通過壓力衰減與真空測試。資料中心料號拚的是速率與熱插拔，車用拚的是十年不鬆脫 |

**一塊固定說明框（這張圖的結論，不可省略）**：

「**連接器賣的是四件事，不是一個接頭**」：

1. **電**：阻抗要連續、差動對要被遮蔽好，不然速率上不去；
2. **機**：法向力、擦拭、插拔次數、盲插對正 —— 全是機械設計；
3. **熱**：高速埠的熱要有路出去，籠架與散熱片是同一套設計；
4. **裝**：壓接、浮動、背對背 —— 決定一台機器塞得下多少埠、好不好維修。

**畫面上一定要有的三行**（左下角）：

- `示意圖，非實物比例｜接點形狀與鍍層厚度均為示意`
- `距離對照為單一原廠技術頁的數字，依板材、頻率與設計規則而異`
- `點零件篩到的是「環節」不是整個族群：「連接器 / 線材」這一格目前只收錄一家`

## 6. 結構審查清單（`mechanical-engineer` 逐條驗）

> 寫法規則：每一條都是「A 必須在 B 之前」「A 不可以碰到 B」「A 的數量／方向必須是 X」
> 這種**看圖就能判定**的句子。**不准出現「要畫得清楚」「要好看」這種驗不動的條目。**

**E 組・金手指與插槽（格 ②）**

- E1　金手指鍍層由內到外是**銅 → 鎳 → 硬金**。金畫在鎳裡面＝不過。
- E2　硬金層**明顯薄於**鎳層。
- E3　金手指前端**有倒角**。
- E4　母端彈片畫成**被撐開的變形狀態**，不是沒受力的直片；**上下各一列夾住卡片**。
- E5　法向力箭頭**垂直於接觸面**，擦拭箭頭**平行於插入方向**；兩支不同方向。
- E6　圖上標明**金手指是公端、插槽是母端**。

**B 組・內部線纜（格 ③）**

- B1　twinax 橫剖面是**兩根等徑導體並排**，不是單根同軸。
- B2　**兩根導體共用同一層接地遮蔽**（遮蔽包住整對，不是各包一根）。
- B3　剖面由內到外的層序是**導體 → 介電 → 遮蔽 → 外被**，沒有對調。
- B4　圖上同時有「走線纜」與「走板子」兩條路，且**走板子那條被標為對照**。

**G 組・光模組籠（格 ④）**

- G1　籠架是**鈑金盒且有通風孔**。
- G2　籠架用**壓接針腳**固定在板上（針腳看得出是壓入不是焊接腳）。
- G3　**EMI 指片圍在開口四周且朝向模組**。
- G4　散熱片在**籠架之上**，不在籠架內、也不在模組內；且有**夾持彈簧**。
- G5　光模組**只有外殼與拉環**，沒有畫任何內部光學元件。
- G6　背對背示意裡，上下兩個籠是**鏡像**且共用同一塊板。

**K 組・背板與盲插（格 ⑤）**

- K1　**導引柱／斜面比訊號接點更靠前**（先接觸）。
- K2　浮動連接器**畫得出浮動間隙**。
- K3　線纜匣裡是**成束的纜線**，不是一塊實心板。

**X 組・版面與分工**

- X1　四格**等高等寬**（誤差 2px 以內），內部結構順序一致。
- X2　上方路徑帶的**編號與下方格子的編號一致**，兩邊都看得到編號。
- X3　路徑帶高度**不超過全圖 1/3**；ASIC 只是一個標名字的方塊，沒有內部細節。
- X4　圖上**沒有** CPO、沒有 PCB 疊構剖面、沒有層數標示、沒有背鑽。
- X5　圖上**沒有**風扇、晶片散熱片、電源模組（籠架自己的散熱片除外）。
- X6　圖上**沒有**任何真實連接器的品牌外形、系列名、料號、logo。
- X7　`SLOTS` 的 key 與 §0-C 拍板的結果一致；若選了「選項三」，
  **格 ⑥（工業／車用對照）必須存在且放大**。

**N 組・誠實性（紅線，違反任一條就退回，不進二輪）**

- N1　畫面上**沒有任何市占率、單價、成長率、營收占比**。一個都不准。
- N2　距離對照那兩個數字（22 吋 / 4.5 吋）**必須同時標明來源與「單一來源」**，
  而且**必須寫出它的前提**（IEEE 802.3ck 損耗上限、高階板材）。
  只寫數字不寫前提＝不過。
- N3　畫面上同時有 §5 那三行（非實物比例／距離對照的限制／環節不等於族群）。
- N4　§7-B 裡標為低信心的每一項，畫面上**都沒有寫成確定的單一數值**。
- N5　畫面上**沒有寫任何一家公司做哪一個料號** —— 公司只透過環節色標出現（§7-D2）。

     **四次篩出來的筆數彼此不同**（這才證明四個 seg 真的分開掛對）；
  3. 在同一格裡依序點三個不同零件（例如籠架、EMI 指片、散熱片），
     **三次的 `.sel-part` 不同**（驗 `data-part`，D4）；
  4. 點上方路徑帶的編號 → **對應的那一格被標示出來**（若實作了這個連動；
     沒實作就驗「編號兩邊一致」這個靜態條件）；
  5. 「動畫：開／關」按了**真的停下來**，靜止時四格的結構仍然看得見；
  6. **800px 窄畫面**下四格改成一欄四列、**順序仍是 ②→③→④→⑤**、沒有文字重疊、
     沒有整頁水平捲軸。
- **效能**：不新增任何函式庫、不新增 CDN；動畫只有一個 rAF，頁面切走要停。
- **不畫**任何真實公司的產品外觀、logo、包裝、商標。

## 9. 給 `tech-illustrator` 的實作邊界（不是規格，是省時間的提醒）

- 版面（980 寬）：上方路徑帶高度上限 ＝ 整張圖的 1/3；下方 2×2，單格約 480×（等高）。
  **四格用同一個 `cell(i)` 函式產生外框**，X1 就自動成立。
- 每格的內容順序用同一個 `panel(no, title, sectionDraw, oneLiner, rows)` 產生，
  **編號 `no` 同時印在路徑帶與格子標題上** —— 那一個參數就是 X2。
- 彈片的「被撐開」用一個小角度的旋轉或貝茲控制點位移表達即可，
  **不要畫成完全直的片再加一支箭頭** —— 形狀本身要看得出受力（E4）。
- twinax 橫剖面用同心層次畫：外被 → 遮蔽（包住整對）→ 兩個介電圓 → 兩個導體圓。
  **遮蔽那一圈是橢圓不是兩個圓**，這一行就是 B2。
- 籠架用 `box` 切開一角即可看到內部與針腳；通風孔用一排小方孔陣列，
  **不要用貼圖或 pattern**（淺色主題下 pattern 常常整片消失）。
- 底部對照條就是兩根長度不同的橫條，**長度比例直接取 22 : 4.5**；
  **兩根旁邊各自標數字，數字旁邊必須帶來源與前提**（N2）。
- 動畫：**最多一個**，建議「一個訊號從 ASIC 出發，沿著路徑帶跑到前面板」跑一次，
  **四格本身不要各自動**。靜止時路徑仍然看得見。
- 800px 窄畫面要先驗（CLAUDE.md「開發過程就要驗窄畫面」）。
- ⚠ **畫連接器外形時刻意畫成通用形狀**，不要照著任何一家的產品照片描（X6）。
