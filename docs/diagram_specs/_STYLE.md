# 剖析圖風格系統（_STYLE）—— 兩種模式、卡片、引線、爆炸拆解、流動

> art-director 2026-09-22 訂。Andy 拍板的方向見 DECISIONS #238；這份是「怎麼落地」。
> 落地的東西只有三個地方：`site/index.html` 的 `--dg-*`（色票與尺寸）、`site/diagrams.js` 的 `STYLE`
> 與共用元件（`labelRow`／`lrow3`／`note`／`processBar`／`pointer`／`explode`／`shadow`）、
> `site/index.html` 的 `.dgv2`／`.dgc`／`.dglead`（HTML 卡片與版面）。
> **畫圖的人不碰顏色、不碰卡片長相**：要新顏色就在 `--dg-*` 加一個名字，不准在 JS 裡寫死 `#xxxxxx`。

## 0. 一句話

**閱讀（read）＝ 教科書插圖：暖白紙底、低飽和粉彩、深灰細引線、白色圓角卡片、深灰字、沒有發光。**
**科技（tech）＝ 精密儀器的 HUD：深藍炭底、材質原色、半透明深色卡片、細引線＋發光小節點；發光只給端點與被選的那一個。**
兩種模式**共用同一套元件與同一組 token 名字**，差別全在值。預設跟著全站主題走（深色→科技、淺色→閱讀），`#dgPal` 可手動切。

### 1-D 環節色的降飽和規則（`--cc`）

零件的環節色 `--c` 是 `industry.js` 用 inline style 寫上去的（inline 贏過任何樣式表），
所以 `diagrams.js` 的 `STYLE` **不直接用 `--c`**，用 `--cc` ＝ 消費端的換算：

| 組合 | `--cc` | 為什麼 |
|---|---|---|
| 深色主題 ＋ 科技 | `--c` 原色 | 預設，跟改動之前逐位元相同 |
| 深色主題 ＋ 閱讀 | `color-mix(--c 58%, #4a463f)` | 螢光組的環節色印在紙底會刺眼 |
| 淺色主題 ＋ 閱讀 | `color-mix(--c 86%, #6b665d)` | 淺色主題本來就是壓深組（#235），只再降一點飽和 |
| 淺色主題 ＋ 科技 | `color-mix(--c 74%, #ffffff)` | 壓深組印在深底會消失，往白混回來 |

`--dg-seg-k`／`--dg-seg-mix` 是這四組的 token（`index.html`）。**一張圖一個主色，其餘灰階**在兩種模式下的落地：
主色永遠是 `--dg-accent-2d`（科技青、閱讀霧青）；環節色只出現在「被選到的那一格」與卡片的色條／圓點，
沒被選到時零件走材質色（灰階族）。

## 2. 字級

| token | 科技 | 閱讀（`.dg.rs`） | 用在哪 |
|---|---|---|---|
| `--dg-fs-ttl` | 16px | 19px | 圖名（一張圖一個；v2 版面搬到 HTML `.dghead`） |
| `--dg-fs-hd` | 13.5px | 15px | 區塊小標、章節列標題 |
| `--dg-fs-lbl` | 12.5px | 14px | 零件名、卡片標題 |
| `--dg-fs-min` | **12px** | **13px** | 說明、註腳、代號、數字 —— **下限** |

⚠ 閱讀的升階**只給已改造成風格系統的圖**（svg 根掛 `.rs`）。實測把 13px 套到全部 18 張：
8 張同一行的字互相撞上（伺服器電源、ABF、AI 伺服器、矽晶圓、HBM、氣冷、液冷、變壓器 GIS）——
那些版面是為 12px 排的，字級要升就得連版面一起改（逐張改造那一波的事）。沒掛 `.rs` 的圖在閱讀模式維持 12px。

**量完再縮**（`D.fitTexts`，`stampParts` 之後自動跑、切模式與開章節都重跑）：右緣超出畫布或超出卡片的 text
設 `textLength`（`spacingAndGlyphs`），只准壓 ≤ 12%，再多就是版面要改。科技模式下 0 行需要壓。

## 3. 卡片（`labelRow`／`lrow3`／`note` → SVG 的 `.lrow` 或 HTML 的 `.dgc`；3D 的 `.lbl3d` 同一組 token）

| 項目 | 科技 | 閱讀 | token |
|---|---|---|---|
| 底 | `rgba(14,20,36,.66)` 半透明深色 HUD | `rgba(255,255,255,.80)` 霧面白 | `--dg-card-f` |
| 磨砂玻璃 | `blur(8px) saturate(1.15)` | `blur(10px)` | `--dg-card-blur`（**只有 HTML 卡片吃得到**：backdrop-filter 對 SVG 元素無效，SVG 卡片退回半透明實色） |
| 邊 | `rgba(120,150,210,.28)` 一條細線，跟元件色混 40% | `rgba(58,53,45,.22)` | `--dg-card-s` |
| 圓角 | 8px | 10px | `--dg-card-r` |
| 落影 | 無 | `drop-shadow(0 1px 2px rgba(40,35,25,.16))`（環境光遮蔽感） | `--dg-card-sh`（SVG）／`--dg-card-box-sh`（HTML） |
| 左側色條 | 3px，元件色 | 同 | `--card-c` |
| 編號圓點 | 實心元件色、深色數字 `#061018` | 粉彩底（元件色 18% 混紙底）＋ 元件色的環 ＋ 深灰數字 | `--dg-no-r` 9.5px、`--dg-no-ink` |
| 選到（`.sel`） | 邊變元件色、底染 12% | 同，但標題**維持深灰**（顏色由色條／圓點／邊扛） | |
| 主角（`.sel-part`） | 底染 26% ＋ 光暈 `--dg-card-glow-r` 6px | 底染 26% ＋ 落影，不發光 | |
| 內距 | 8px 11px（HTML）／底框 40 高、行距 16（SVG） | 同 | |

**卡片與元件同色系串聯（2D／3D 共用介面）**：卡片吃 `--dg-card-c`，畫圖的人用 inline style `--dg-card-c:#xxx`
或 `data-dgcolor="#xxx"` 指定（`stampParts` 會搬成 inline），沒指定就落回環節色 `--cc`／`--c`，再沒有就 `--dg-ink`。
左側色條、編號圓點、邊框、引線端點、引線選到時的顏色全部用它。細節在 `docs/diagram_restyle_plan.md`「卡片介面」。

## 4. 引線與端點（`D.pointer(ax, ay, bx, by, {elbow, drop, node})`）

| 項目 | 科技 | 閱讀 | token |
|---|---|---|---|
| 線 | 1px，元件色 55% 混 `--dg-line-mix` | 0.9px 深灰 `#6b665d` | `--dg-lead-w`、`--dg-lead` |
| 選到 | 1.6px 元件色 | 1.5px 元件色 | `--dg-lead-sel-w` |
| 端點 | 小圓 r 2.8，元件色，帶 3px 光暈 | 實心小圓，不發光 | `--dg-node-r`、`--dg-node-glow` |
| 有編號時 | 端點就是編號圓點（r 9.5）畫在零件上 | 同 | |
| 走法 | 卡片邊緣 → 畫布欄外側 8px 的垂直段 → 水平進到端點 | 同 | |

**引線從卡片邊緣出發，停在端點邊緣**，不進卡片、不穿過端點。v2 版面的引線畫在 `.dglead` 疊層上，
`ResizeObserver` 一動就重算，章節開合、切模式也重算 —— 沒有寫死座標。卡片在畫布下面（單欄）時不畫引線，靠編號對照。

## 5. 版面：垂直爆炸拆解、卡片在兩側、v2 容器版面

- **爆炸間距** `D.explode(n, {y0, h, gap})`（2D）／`D.explodeZ(heights, gap)`（2.5D）：預設 gap 18；小於 12 看起來像疊在一起、大於 30 引線會拉太長。
- **主角落影** `D.shadow(inner)`：閱讀模式 `--dg-hero-sh` 柔和落影，科技 none。
- **卡片永遠在畫布左右兩側欄，不准壓在圖上。** v2 版面（`labelRow(..., side)`）：卡片是 HTML，
  `.dgwrap` 是容器（`container-type:inline-size`），`.dggrid` 依**容器**寬度換欄：

| 容器寬 | 版面 | 誰觸發 |
|---|---|---|
| ≥ 1280 | 左欄 ｜ 畫布 ｜ 右欄（`minmax(220px,1fr) minmax(0,984px) minmax(220px,1fr)`） | 1440 視窗、事件抽屜關（main 1358） |
| 960～1279 | 畫布 ｜ 右欄（左欄的卡片也排進右欄，`minmax(0,1fr) minmax(240px,32%)`） | 1440 視窗、抽屜開（main 998）；1100 視窗、抽屜關 |
| < 960 | 單欄：卡片在畫布下面，`auto-fit minmax(260px,1fr)`（800 兩張一列、390 一張一列） | 800／390 |

畫布 SVG **維持原尺寸**（`native`＝viewBox 寬；MLCC 660），不放大去填 —— 放大會讓高度破 700。
用容器而不是視窗來判：產業鏈頁的 main 旁邊有 360px 事件側欄，視窗 1440 時 main 只有 998 或 1358，用視窗量會判錯邊。
- **左緣對齊**：`.dghead`（標題／說明）、左欄卡片、畫布、章節列（`wireFolds` 把 `.fbar` 寬度改成畫布寬）全部對齊格線。
  `#dgQ`（「這張圖回答：…」）在 `industry.js` 的版面裡，這一批沒動它。
- **密度預算**沿用 `_TEMPLATE.md` §0：收合 ≤ 700、§1 ≤ 560、章節 2～4、§1 卡片 ≤ 10、分區 ≤ 3。

## 6. 流動（光／液／訊號）

- 用 `.flow` 虛線 ＋ 箭頭表示方向；顏色用語意色（`--dg-sig` 電、`--dg-pwr` 電力、`--dg-cool` 液冷、`--dg-cold/hot` 進出水）。
- **亮色不發光。暗色也只讓端點與被選的那一個發光** —— 流動線本身不加 drop-shadow：
  一張圖幾十條動態虛線每一幀重算濾鏡，會把 `#dgAnim` 的開關拖慢（`產業` 那一段就是在等它）。
  暗色的「發光虛線」由 3D（style-3d 的 `flow` 材質）負責；2D 用較亮的線色與 `--dg-flow-dot` 光點表達。
- 動畫一律受 `#dgAnim`（`.noanim`）控制；`processBar` 的光點是 SMIL，`industry.js` 會 `pauseAnimations()`。

## 7. 驗收清單（每張圖交付時逐條給過／不過）

1. 深色（科技）與淺色（閱讀）各截 1440 與 800，四張都看得清。
2. 對比度用機器量：正文 ≥ 4.5、次要 ≥ 3（`批次22-風格系統` 的量法）。
3. 12px 下限（閱讀 `.rs` 13px），1440／800／390 都量畫面真實字級；文字不重疊、不出畫布、不出卡片。
4. 一張圖一個主色，其餘灰階；發光只給端點與被選的那一個。
5. 卡片在兩側欄，不壓圖；引線從卡片邊緣到端點；寬度變了引線重算。
6. 互動一個都不少：點卡片亮零件、點零件亮卡片、點背景恢復、只亮不篩、動畫開關、章節開合。
7. 語意色在兩種模式都看得出是警示；不跟紅漲綠跌撞。
