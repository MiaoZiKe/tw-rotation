## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| **長晶爐內部：籽晶在上、熔湯在下、往上拉** | **不會。** 爐子是旋轉對稱的，轉一圈看到的每一面都一樣。關鍵是「上下關係」與「拉的方向」，那是剖面上的一個箭頭 | 2D 剖面 |
| **晶碇是一根圓柱、切成一片一片** | **會一點點** —— 「把圓柱切成圓片」確實是立體的動作 | **2.5D 等角小圖就夠**，不值得開一個 WebGL 場景 |
| **切片後的表面：損傷層 → 研磨 → 蝕刻 → 拋光 → 磊晶** | **不會，而且轉了更糟。** 這整段的資訊就是「粗糙度一級一級變細」與「磊晶層比基板薄很多」，兩者都是剖面上的厚薄關係 | 2D 剖面階梯 |
| **8 吋 vs 12 吋的面積差** | **不會。** 那是兩個圓的平面面積比 | 2D 俯視 |
| **邊緣切不出完整晶粒** | **不會。** 那是平面上的格線與圓邊的交集 | 2D 俯視 |

反面成本三條：
1. 長晶爐是旋轉對稱體，3D 的資訊量幾乎等於剖面，卻多了一整組 WebGL 生命週期要管。
2. 磊晶層與基板的厚度差兩到三個數量級，3D 渲染時薄層會消失在像素裡。
3. `semiconductor` 這條鏈已經有一個 3D 場景（`SCENES.semiconductor`）。

**什麼條件下才該回頭加 3D**（寫死）：

> 只有當這張圖要新增「**晶碇在多線鋸裡被鋼線陣列同時切成上百片**的空間關係」——
> 也就是需要同時看到「鋼線的排列方向」與「晶碇的軸向」時，才重開這一段、改規格書、重新簽。
> 「看起來比較立體」不算理由。

## 1. 這張圖要回答什麼問題

**「一片 12 吋晶圓是怎麼長出來的？為什麼晶圓越大越划算？台股這五家各自做到哪一段？」**

使用者看完要能自己講出這四句：

1. **晶圓不是「切出來」的，是「拉出來」的。**
   多晶矽在石英坩堝裡熔成一鍋湯，一顆籽晶沾上去、一邊轉一邊**往上拉**，
   熔湯就照著籽晶的晶格重新排列、凝固成一根**單晶**圓柱（§7-A1）。
2. **拉出來的柱子比目標尺寸大一圈，要先磨小再切。**
   12 吋晶圓的晶碇先拉到約 **306 mm**，再外圓磨到 **300 mm**，然後刻 notch、用線鋸切片（§7-A2）。
3. **切完的片不能用，要一級一級磨到鏡面。**
   切片 → 倒角 → 研磨（lapping）→ 蝕刻 → 拋光（CMP）→ 清洗，
   **粗糙度一路變細，而且順序不能顛倒**；要長磊晶的話，磊晶在**拋光之後**（§7-A3）。
4. **12 吋的面積是 8 吋的 2.25 倍，而邊緣浪費掉的比例更小** —— 這就是「越大越划算」的兩半（§7-A5）。

**這張圖的成敗**：Andy 指著流程列任何一段，要能說出
「這一段在做什麼、難在哪、**台股有沒有人在這一段**」。講不出第三句，圖就白畫。

### 2-B 區 B：晶碇 → 切片 三格 2.5D

| 格 | 畫什麼 | 一定要有的細節 |
|---|---|---|
| ① 外圓研磨 | 一根圓柱被磨掉外面一層 | **標「約 306 mm → 300 mm」**，磨掉的那層畫成半透明（§7-A2） |
| ② 刻 notch | 沿著圓柱的**軸向**刻一條溝 | **溝是一整根從頭到尾的**，不是只在一端點一個洞（§3-A C5） |

### 2-C 區 C：表面粗糙度階梯剖面 —— 五段（由左到右）

| 段 | 名稱 | 這一段的剖面長什麼樣 | 依據 |
|---|---|---|---|
| 1 | **切片後（as-cut）** | 表面畫成**明顯的鋸齒**，下面一層畫成**加工損傷層**（顏色不同的一層） | §7-A3 |
| 2 | 倒角（edge rounding） | 只有邊緣：把直角磨成圓角 | §7-A2、A3 |
| 3 | 研磨（lapping／雙面研磨） | 鋸齒變成**小很多的波浪**；損傷層變薄 | §7-A3 |
| 4 | 蝕刻（etching） | 波浪更小；損傷層**被化學移除** | §7-A3 |
| 5 | **拋光（polishing／CMP）** | 表面畫成**一條直線 ＋ 鏡面反光**；損傷層消失 | §7-A3 |
| 6 | **磊晶（epitaxy，選配的最後一段）** | 在拋光面上**長出一層薄的新矽**；**這一層要比基板薄很多**，而且中間有一條清楚的界線 | §7-A4、§3-A C9 |

⚠ 每一段下面要標**「這一段用到什麼」**：研磨與拋光那兩段要標「研磨液／拋光墊」，
並註明**耗材那一側見『前段製程材料』那張**。

## 3. 層別／順序（★ 可判定的條目）

### 3-A 長晶與切片：八條硬規則

- **C1**　**熔湯在下、籽晶在上。** 上下顛倒＝物理上不成立。
- **C2**　★ **提拉方向箭頭朝上。** 畫成往下＝那是在把柱子推進湯裡。這是這張圖最容易畫反的一條。
- **C3**　**晶碇上端（靠近籽晶那端）要有「頸縮 → 肩 → 等徑段」的形狀變化**，
      下端要有尾錐。畫成一根上下等粗的圓柱＝少了 CZ 的識別特徵。
- **C4**　★ **外圓研磨在切片之前。**（先把 306 磨成 300，再切片。）
      順序反了＝要對上百片分別磨外圓，實務上不成立。
- **C5**　**notch 刻在晶碇上（軸向的一整條溝），在切片之前。**
      畫成「切完之後在每一片上單獨挖一個缺口」＝錯。
- **C6**　**切片用的是一組平行鋼線（多線鋸）**，不是單一圓盤鋸。
      畫成圓盤鋸＝畫的是二十年前的做法。
- **C7**　★★ **這張圖的長晶爐必須是 CZ 提拉式（有熔湯液面、有往上拉的柱子）。**
      畫成「粉料在下、籽晶在上、中間沒有液面」的昇華爐＝那是 SiC 的 PVT 法，
      **是另一張圖的東西**，混用會在公開網站上把兩種材料的製程講錯（§0-B）。
- **C8**　加熱器要**環繞在坩堝側面**，不是畫在爐子頂上。

### 3-B 表面加工：粗糙度必須單調變細

```
切片(鋸齒最大) → 倒角 → 研磨(波浪) → 蝕刻(更小) → 拋光(直線＋鏡面) →〔磊晶〕
```

- **S1**　★★ **五段的表面起伏必須一段比一段小，量得出來。**
      任何一段比前一段粗＝不過。這是這一區唯一的命題。
- **S2**　**拋光一定是最後一道表面加工。** 拋光之後再畫研磨＝不過。
- **S3**　★ **磊晶一定在拋光之後。** 在粗糙面上長磊晶＝物理上長不出可用的單晶層（§7-A4）。
- **S4**　**加工損傷層必須在前三段看得到、在蝕刻／拋光之後消失。**
      從頭到尾都畫著損傷層＝把「為什麼要磨那麼多道」畫掉了。
- **S5**　**倒角只改邊緣、不改表面。** 把倒角畫成「整片變平滑」＝混淆兩件事。

### 3-C 磊晶層與基板

- **E1**　★ **磊晶層必須比基板薄很多**（畫面上至少差一個數量級的視覺厚度）。
      磊晶層畫得跟基板一樣厚或更厚＝不過。
- **E2**　**磊晶層與基板之間要有一條清楚的界線**（它們是兩次長出來的東西）。
- **E3**　磊晶層與基板**用同色系但不同階**（都是矽，不是兩種材料）。

### 3-D 8 吋 vs 12 吋

- **D1**　★ **兩圓的半徑比必須真的是 2:3**（量得出來）。畫成隨便兩個大小＝面積比那句話就沒有根據。
- **D2**　★ **兩圓上的方格必須一樣大。** 大圓畫大格＝把「同一顆晶粒」這個前提弄丟了，整個對比失效。
- **D3**　**兩個圓都要有 notch。**
- **D4**　邊緣殘缺方格**兩圓都要畫**，而且要能看出大圓的殘缺比例較小。

### 3-E 流程列

- **F1**　順序是 `多晶矽 → CZ 長晶 → 外圓磨+notch → 線鋸切片 → 倒角/研磨/蝕刻 → 拋光+清洗 → 磊晶`。
- **F2**　**磊晶在最後，而且要標「選配」** —— 不是每一片晶圓都有磊晶層。
- **F3**　**再生晶圓那一格是灰色的、畫在主線之外**，並用一條返回的箭頭接回去
      （它是「用過的片回頭再磨」，不是主線的一段）（§7-A6）。
- **F4**　流程列下方有**台股標示線**，照 §7-D2 的表逐段標，**查不到的段要真的寫「本圖查不到具名對應」**。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **CZ 長晶爐**：**看得到熔湯的液面** ＋ **往上拉的箭頭** ＋ **頸縮/肩/尾錐**。
- **切片**：**一組平行鋼線**。
- **表面階梯**：**鋸齒 → 波浪 → 直線** 的三級變化。
- **磊晶**：一層**很薄**、與基板之間有清楚界線的新矽。
- **晶圓**：**notch** ＋ **邊緣殘缺的方格**。

### 4-B 最常見的畫錯

| # | 畫錯的樣子 | 為什麼是錯的 | 對應審查 |
|---|---|---|---|
| 1 | **提拉箭頭朝下** | 那是把柱子推進湯裡。CZ 的全名就是「提拉法」 | **C2（紅線）** |
| 2 | 長晶爐畫成沒有液面的昇華爐 | 那是 SiC 的 PVT 法，是另一張圖的東西 | **C7（紅線）** |
| 3 | 晶碇畫成上下等粗的圓柱 | 沒有頸縮與肩＝看不出它是「從一顆籽晶長出來的」 | C3 |
| 4 | 切片畫在外圓研磨之前 | 切完再一片一片磨外圓，實務上不成立 | C4 |
| 5 | notch 畫成「每片單獨挖」 | notch 是在晶碇上刻一整條溝，切完每片自然都有 | C5 |
| 6 | 切片畫成圓盤鋸 | 現代 300 mm 用多線鋸 | C6 |
| 7 | **表面粗糙度不是單調變細**（例如拋光之後又畫了一段研磨） | 這一區的命題就是「一級一級變細」 | **S1、S2（紅線）** |

## 8. 2D 的驗收條件

- **結構**（`mechanical-engineer` 簽）：照 §6 的 C／S／E／D／F／M／H 七組逐條，寫出過／不過與證據。
  **C2（提拉朝上）、C7（CZ 不是昇華爐）、S1（粗糙度單調變細）是紅線**，不過就退回。
- **視覺**（`art-director` 簽）：字級全圖 ≥ 12px，實測**畫面真實字級**在
  **1440 / 1100 / 900 / 800 / 390** 下都 ≥ 12px；深淺主題各驗一次。
  **熔湯是全圖唯一該有「熱」感的東西**，其餘一律冷色系；發光只給選取中的零件。
- **互動**（`_uitest.py` 真的操作）：
  1. **驗「沒有 `data-seg`」**：`svg.querySelectorAll('[data-seg]').length === 0`，
     且畫面底部「這一格沒有對應環節」那一行**看得見**（反向驗收，證明沒有偷掛錯環節）；
  2. 點任一零件 → **該零件有 `data-part` 且高亮真的換人**；
  3. 「動畫：開／關」按了**真的停下來**，靜止時提拉箭頭與旋轉箭頭仍看得見；
  4. **800px 與 390px** 下可左右滑、無文字重疊、無整頁水平捲軸；
  5. 切到「休閒」配色 → 圖還在、語意色沒被覆寫。
- **效能**：不新增函式庫、不新增 CDN；動畫只有一個 rAF，頁面切走要停。
- **不畫**任何真實公司的產品外觀、logo、包裝、商標。

## 9. 給 `tech-illustrator` 的實作邊界

- **先畫長晶爐、先把「熔湯液面 ＋ 往上拉」這組關係定下來**，再補其他四區。
  那一組是這張圖的識別特徵；沒有它，整張圖跟 SiC 的 PVT 爐分不出來（C7）。
- **表面粗糙度階梯用同一支函式畫**，只換一個 `amp`（起伏振幅）參數，
  由左到右 `amp` 遞減。**這樣 S1 自動成立** —— 手刻五段的話一定會有一段畫歪。
- 兩個圓的半徑**直接用 200 與 300 當比例算**（例如 `r8 = k*200, r12 = k*300`），
  不要手填兩個看起來差不多的數字（D1 不過的唯一原因就是手填）。
- 兩圓上的方格用**同一個 `cell` 常數**畫（D2 自動成立）。
- 線鋸的鋼線用 `for` 迴圈畫 ≥ 8 條平行線（少於 8 條看起來像圓盤鋸的輻條）。
- 晶碇的頸縮／肩用一條 `path` 帶兩個控制點畫，**不要用矩形**（矩形＝C3 不過）。
- 流程列走既有的 `processBar`，**行距用改過之後的 40／+32**。
  **再生晶圓那一格要畫在主列之外**（用灰色 ＋ 一條返回箭頭），不要塞進主列（F3）。
- 顏色一律走 `--dg-*`，不准寫死 `#xxxxxx`。這張圖**沒有 `data-seg`**，
  所以 `var(--c)` 不會被環節色帶進來 —— 需要 `art-director` 指定一組本圖用的 `--dg-*`
  （矽一色、熔湯一色、耗材一色、示意灰一色）。
- **`data-part` 一律要寫**（沒有 `data-seg` 時 `stampParts` 自動補的 key 會退化成「`null` ＋ 序號」）。
  建議命名：`sw_poly` / `sw_melt` / `sw_seed` / `sw_pull` / `sw_ingot` / `sw_grind` / `sw_notch` /
  `sw_saw` / `sw_edge` / `sw_lap` / `sw_etch` / `sw_polish` / `sw_epi` / `sw_reclaim` / `sw_size`。
- 動畫：只做一件事 —— **晶碇緩慢往上長一點點**（或一個小點沿著籽晶桿往上跑）。
  **不要讓熔湯翻騰**（那會讓人以為在講流體）。靜止時箭頭仍看得見。
- **SVG 的 `<style>` 裡（含註解）一律不准出現角括號。**
