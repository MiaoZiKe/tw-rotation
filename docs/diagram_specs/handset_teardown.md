## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 從背蓋到螢幕的層序 | **不會**。層序在分解圖上一眼看得出來；透視會把中間幾層擋掉 | 2D 分解 |
| 電池與主機板是**同一層左右排**，不是上下疊 | **不會**。那是**俯視**上的位置關係，俯視才看得出「並排」 | 2D 俯視分層 |
| 均熱件夾在主機板與顯示模組之間 | **不會**。那是**側視剖面**的一條夾層 | 2D 側視 |
| 按鍵、聲孔在側面 | **會一點點**，但用一張側視條就講完了 | 2D 側視 |

反面成本：四個資訊點全在分解圖與側視剖面上；3D 在手機吃力；`electronics` 鏈目前沒有 3D 場景。

**什麼條件下才該回頭加 3D**（寫死）：
> 只有當這張圖要新增「**折疊機的轉軸動作**」（轉軸的多連桿只有動起來才看得懂）時，
> 才重開這一段、改規格書、重新簽。「看起來比較立體」不算理由。

### 0-B　★★ 這張圖的第一條紅線：**不准畫成任何一支真實手機**

`AGENTS.md` 的紅線是「**不畫任何真實公司的產品外觀、logo、包裝、商標**」。
手機是這批圖裡**最容易踩到**的一張 —— 圓角比例、後鏡頭的排列方式、瀏海／挖孔的形狀、
側鍵的位置，任何一個畫得像，就是畫了某一支機種的外觀。

**所以寫死**：
1. 機身畫成**通用的圓角矩形**，圓角半徑統一、**不模仿任何機種的比例**。
2. 後鏡頭畫成**一排等距的圓**（或一個模組方塊），**不准排成方陣、三角、藥丸等特定佈局**。
3. 正面**不畫瀏海、不畫挖孔、不畫任何開孔造型** —— 螢幕就是一塊滿版矩形。
4. **不准畫 logo、不准畫任何文字標示在機身上、不准畫特定的顏色配色。**

## 1. 這張圖要回答什麼問題

**「一支手機從背蓋到螢幕疊了哪幾層？台股做的是哪幾塊？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句**）：

1. **電池與主機板是「同一層並排」，不是上下疊。** 主機板佔上半、電池佔下半（或相反），
   兩者共用同一個厚度預算 —— 手機的厚度之爭就是在爭這一層。
2. **均熱件夾在主機板與螢幕之間。** 熱從晶片出來，往面積最大的那一面攤開，
   所以它貼在板子與顯示模組中間，不是貼在背蓋上。
3. **鏡頭模組是「站著」穿過去的。** 它從背蓋開孔往機身內部插，佔掉的是厚度，
   所以鏡頭越好、機身越難做薄 —— 這就是背面那一坨的由來。
4. **台股在這支手機裡分成四塊**：鏡頭、聲學、機構件與散熱、整機組裝。

**這張圖的成敗**：指著任何一層，要能說出「這是什麼、台股是誰在做這一層，或誠實說查不到」。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A 分層順序（由背面到正面）

`背蓋 → 無線充電線圈／NFC → 中框 → 主機板＋電池 → 均熱件 → 顯示模組 → 蓋板玻璃`
（攝影模組**穿過**背蓋與中框，不佔獨立一層）

**H1**　★★★ **主機板與電池在同一層**，在俯視上**左右（或上下）並排、互不重疊**。
把主機板畫成疊在電池上面，就把「手機厚度在爭什麼」這件事講反了。
**這一條不過就退回，不進二輪。**
**H2**　★★ **均熱件必須夾在「主機板那一層」與「顯示模組」之間**，
**不准貼在背蓋內側**。熱要往面積最大的那一面攤開，而那一面是螢幕那一側。**紅線。**
**H3**　★ **無線充電線圈在電池與背蓋之間**（也就是在中框的**外側**）。
畫在金屬中框內側＝被金屬擋住，無線充電就不會動。
**H4**　蓋板玻璃在最外（正面），顯示模組在它**底下**；兩者順序不准反。
**H5**　中框在背蓋與主機板之間，是**結構主體** —— 其他零件都掛在它上面。

### 3-B 攝影模組

**H6**　★ 攝影模組**從背蓋的開孔往機身內部插**，**長度方向垂直於背蓋**（站著），
並**穿過中框**。畫成平躺在板子上＝那是潛望式，是特例不是通例。
**H7**　攝影模組是**單一零件裡最厚的那一個**（量得出來：厚度 > 主機板那一層厚度的 0.6）。
**H8**　後鏡頭畫成**一排等距的圓**，**不准排成方陣、三角或藥丸**（§0-B 第 2 點）。

### 3-C 聲學與按鍵的「必須對孔」規則

**H9**　★ **揚聲器、受話器、麥克風都必須對到外殼上的開孔**（畫一條引線接到孔）。
封在內部沒有孔＝聲音出不來。
**H10**　★ **按鍵必須在中框的側面**，不在正面或背面。
**H11**　SIM 托盤在側面，畫成一條細槽。

### 3-D 區 B 側視與區 C 對應帶

**H12**　側視剖面的層序**必須與區 A 完全一致**（同一組層、同一個順序）。
**H13**　★ 區 C 的每一格**必須與區 A 的對應層在垂直方向對齊**（用同一組 y 座標算，不要目測）。
**H14**　區 C 裡**查不到的層要真的寫「本圖查不到台股對應」**，不准留空白（R4：留白會被讀成「漏了」）。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **F1 主機板＋電池那一層**：俯視上**兩塊並排、不重疊**。
- **F2 均熱件**：**面積最大、厚度最薄**的一片，夾在板子與螢幕之間。
- **F3 攝影模組**：**站立**的柱體，穿過背蓋與中框。
- **F4 無線充電線圈**：同心螺旋，在中框**外側**。
- **F5 中框**：一圈框 ＋ 內部肋條 ＋ **側面的按鍵孔與聲孔**。
- **F6 聲學件**：每一個都有一條引線接到外殼的孔。

### 4-B 最常見的畫錯（逐條對應 §6）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |
|---|---|---|
| 主機板疊在電池上面 | 兩者共用同一層厚度預算，疊起來手機會厚一倍 | L1（紅線） |
| 均熱件貼在背蓋內側 | 熱要往螢幕那一面攤，貼背蓋等於把熱關在板子旁邊 | L2（紅線） |
| 無線充電線圈畫在金屬中框內側 | 被金屬擋住，充不了電 | L3 |
| 攝影模組平躺在板子上 | 那是潛望式的特例，不是通例；而且厚度的由來就沒了 | M1 |
| 揚聲器封在內部、沒有對到孔 | 聲音出不來 | A1 |
| 按鍵畫在正面或背面 | 位置錯了 | A2 |
| 螢幕畫瀏海或挖孔 | 那是某一支機種的外觀特徵 | X1（紅線） |
| 後鏡頭排成方陣或三角 | 同上，那是機種辨識特徵 | X1（紅線） |
| 把顯示模組剖開畫 TFT 疊層 | 那是 `panel_stack.md` 的內容 | X3 |
| 把鏡頭模組剖開畫鏡片 | 那是 `handset_lens.md` 的內容 | X4 |
| 區 C 有一層留空白 | 留白會被讀成「漏了」，不是「查不到」 | C3 |

## 9. 給 `tech-illustrator` 的實作邊界

- **先畫區 A 的「主機板＋電池同層並排」、先用 bbox 把 L1 驗過**，再補其他層。

  這樣它永遠夾在對的位置（L2）。

- 聲孔與按鍵：**先在中框上開孔、再把零件用引線接到孔** ——
