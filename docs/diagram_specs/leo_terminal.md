## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 輻射貼片在正面、波束成形 IC 在背面 | **不會**。正反面的關係在**剖面**上一眼看得出來；透視反而要轉到底面才看得到 IC | 2D 剖面 |
| 貼片排成一個規則陣列 | **會一點點**，但陣列是**平面**的圖案，俯視小圖就夠 | 2D 俯視小圖 |
| 各單元加不同相位 → 合成波前傾斜 | **不會**。波前是一條線，傾角是角度 —— 平面圖才量得出角度 | 2D 幾何 |
| 板子的層數 | 不會。層數是疊層剖面 | 2D 剖面 |

反面成本：四個資訊點全在剖面與平面幾何上；3D 在手機吃力；`electronics` 鏈目前沒有 3D 場景。

**什麼條件下才該回頭加 3D**（寫死）：
> 只有當這張圖要新增「**衛星星座在軌道上的相對位置與交接（handover）**」時才重開這一段。
> 那是天文尺度的東西，跟這塊板子是兩件事，**比較好的做法是另開一張，不是把這張改成 3D**。

### 0-B　★★ 這張圖的第一條紅線：**不准畫成任何一家的用戶終端外觀**

`AGENTS.md` 與 `dg3d_standard.md` §3 的紅線是「**不畫任何真實公司的產品外觀、logo、包裝、商標**」。
低軌衛星用戶終端在公開資料裡幾乎都是拆機文，**照著拆機照畫就是畫產品外觀**。

**所以寫死**：
1. 天線畫成**一塊通用的矩形平板**，**不准畫成圓形碟、不准畫成有特定圓角或立柱造型的整機**。
2. **不准畫底座、不准畫線材走向、不准畫任何外殼開孔圖案。**
3. 整機那一段（區 C）**只畫成方塊 ＋ 文字**，不畫外觀。
4. 畫面上的文字可以引用 `supply_chain.yaml` 既有的 `tech` 欄字串（R3 允許），
   但**畫面上不准出現任何營運商或終端產品的外觀、logo**。

## 1. 這張圖要回答什麼問題

**「一塊平板天線不會轉，為什麼能追著衛星跑？台股在這裡做的是板子還是整機？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句**）：

1. **波束是「算」出來的，不是「轉」出來的。** 板子上有上千個小天線單元，
   每一個送出去的訊號**差一點點相位**，疊加之後的波前就會歪向某個角度 ——
   改相位就改方向，毫秒等級，沒有任何機械動作。
2. **正面是天線、背面是晶片。** 輻射貼片在最上層（天線罩底下），
   負責調相位的波束成形 IC 在**板子的另一面**，中間隔著接地層。
3. **這塊板子不是一般 PCB。** 它要同時滿足高頻的介電要求與大面積的平整度，
   層數與材料都跟主機板不是一回事 —— 這正是「做板子」本身變成一門生意的原因。
4. **台股在這條鏈上分成兩群**：做**天線板**的，跟做**終端整機／地面設備**的。

**這張圖的成敗**：指著圖上任何一層，要能說出「這是什麼、台股是誰在做這一層」。

## 2. 零件清單

### 2-A 區 A 天線板疊層（由上到下）—— 最少 8 層

| 層 | 相對厚度 | 材質觀感 | 備註 |
|---|---|---|---|
| 天線罩（Radome） | 中等，最上 | 半透明淺色 | ★ **必須蓋住整個貼片陣列** |
| 空氣間隙 | 薄 | 無色 | 罩與貼片之間 |
| **輻射貼片陣列** | 薄，**一格一格** | 銅色方塊，**每格一個饋入點** | ★ **必須在最上面的導體層** |
| 介質層（高頻基材） | **最厚的介質** | 淺色基材 | 與一般 FR-4 用不同色，並標「高頻基材」 |
| **接地層** | 薄，**連續一整片** | 銅色實心帶 | ★ **必須在貼片與饋入網路之間** |
| 介質層 | 中等 | 同上 | |
| 饋入／分配網路層 | 薄，**細長走線** | 銅色細線，**看得出等長蛇行** | 每條通到一個貼片 |
| **波束成形 IC ×N** | 小方塊，貼在**板子背面** | 深色晶片 ＋ 底部焊球 | ★ **必須在貼片的相反面** |
| 處理與電源區 | 一塊方塊 | 深色 | 在背面，與 IC 同側 |
| 金屬背板／散熱板 | 最下，實心 | 金屬灰 | |

### 2-B 區 A 的俯視小圖

一個 **8×8（≥ 64 格）**的規則貼片陣列俯視圖，每格大小一致、間距一致，
並標「實際單元數遠多於圖上（示意）」。

### 2-C 區 B 波束成形原理 —— 最少 4 個元素

| 元素 | 要畫成什麼 |
|---|---|
| 一排天線單元（5～8 個） | 一列等距的小方塊 |
| 每個單元的相位延遲 | **逐格遞增**的延遲量，用長度不同的短線或遞增的數字符號表示（**不寫具體度數**） |
| 每個單元發出的波（同心弧） | 每個單元一組同心弧，**起始半徑逐格不同** |
| 合成波前 | **一條斜線**，切在所有同心弧的公切線上；旁邊標一個傾角 θ |
| 對照：全部同相 | 一組小圖或一條註記：「全部同相時波前是水平的（正對天頂）」 |

### 2-D 區 C 三段分工帶（由左到右）

`天線板（PCB）` → `終端整機（天線＋數據機／路由器）` → `地面設備／CPE`

### 2-E 不要出現的東西（畫了就是別張圖，或是紅線）

- **任何一家用戶終端的外觀**（圓碟、特定造型的整機、底座、線材走向、外殼開孔）——§0-B。
- **任何營運商或終端品牌的 logo、包裝、商標。**
- **衛星本體、軌道、星座圖**（那是另一張圖的事，而且這張圖的範圍在地面）。
- **一般 PCB 的多層剖面細節**（防焊、表面處理、盲埋孔）—— 那是 `pcb_stackup.md`；
  這張圖只畫到「有幾層、哪一層是什麼」的程度。
- **任何頻率、增益、EIRP、層數、單元數、市占率、營收數字**（§7-B）。
- **「全球第幾大」「龍頭」「唯一」**這類法人用語（CLAUDE.md 紅線）。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A 疊層順序（由上到下）

`天線罩 → 空氣間隙 → 輻射貼片 → 介質 → 接地層 → 介質 → 饋入網路 → 波束成形 IC → 處理與電源 → 金屬背板`

**B1**　★★★ **輻射貼片必須是最上面的那一層導體**（天線罩底下第一層金屬）。
把它畫在板子中間或背面＝電波射不出去。**這一條不過就退回，不進二輪。**
**B2**　★★★ **波束成形 IC 必須在板子的背面**（與貼片相反的那一面）。
畫在正面＝晶片擋住天線口徑，而且散熱與訊號路徑都不對。**紅線。**
**B3**　★★ **接地層必須在貼片層與饋入網路層之間**，而且是**連續一整片**（不是一格一格）。
沒有這一層，饋入走線會直接對外輻射，天線圖形就毀了。**紅線。**
**B4**　天線罩**覆蓋整個貼片陣列**（左右兩端都超出陣列邊界），不是只蓋中間一段。
**B5**　饋入網路的走線**看得出等長蛇行**（每條長度一致），並且**每條通到一個貼片**。
**B6**　金屬背板在最下面，且**與波束成形 IC 有熱接觸**（畫一塊導熱介面）。

### 3-B 貼片陣列（俯視）

**B7**　★ 陣列是**規則的**：至少 **8×8 ＝ 64 格**，**每格大小一致、間距一致**。
畫成大小不一或間距不一＝相位關係就不成立了。
**B8**　★ **每一格都要有饋入點**（一個小圓點或一條短線接到格子邊緣／內部），
不是空心方塊。
**B9**　俯視小圖旁邊標「實際單元數遠多於圖上（示意）」。

### 3-C 波束成形（★ 這是本圖的命題，第四條紅線）

**B10**　★★★ 各單元的**相位延遲必須逐格遞增**（不是全部一樣）——
用長度遞增的短線或遞增符號表示。
**B11**　★★★ **合成波前必須是一條斜線**（與陣列面不平行），而且傾角 θ 標出來。
> B10／B11 任一條畫成「全部同相、波前水平」，這張圖的第一句話就變成假的。
> **兩條都是紅線，不過就退回、不進二輪。**
**B12**　★ 每個單元的同心弧**起始半徑逐格不同**（對應相位差），合成波前是它們的**公切線**。
**B13**　旁邊要有一句「**全部同相時波前是水平的**」的對照註記（沒有對照就看不出「歪」的意義）。
**B14**　★ 畫面上要明寫「**沒有任何機械轉動**」。
若畫了支架或底座（不建議），**必須標「只做粗指向，不是用來追星的」**。

### 3-D 區 C 分工帶方向

**B15**　由左到右是 `天線板 → 終端整機 → 地面設備`，箭頭方向一致，
且**板子在整機之前**（板子是零件、整機是成品）。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **F1 貼片陣列**：規則方格 ＋ 每格一個饋入點。
- **F2 接地層**：一條**連續**的實心銅帶，夾在貼片與走線之間。
- **F3 饋入網路**：等長蛇行的細線。
- **F4 波束成形 IC**：板子**背面**的小方塊 ＋ 底部焊球。
- **F5 波束成形幾何**：逐格遞增的相位 ＋ **一條斜的波前** ＋ 一個角度 θ。
- **F6 天線罩**：一片蓋住整個陣列的半透明板。

### 4-B 最常見的畫錯（逐條對應 §6）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |
|---|---|---|
| 貼片畫在板子中間或背面 | 電波射不出去 | S1（紅線） |
| 波束成形 IC 畫在正面 | 擋住天線口徑，訊號與散熱都不對 | S2（紅線） |
| 沒有接地層，或接地層畫在走線下面 | 饋入走線會直接對外輻射，天線圖形毀了 | S3（紅線） |
| 各單元畫成同相 | 波束就永遠指向正上方，「電子掃描」沒了 | P1（紅線） |
| 合成波前畫成水平線 | 同上 | P2（紅線） |
| 貼片大小或間距不一 | 相位關係不成立 | A1 |
| 貼片畫成空心方塊、沒有饋入點 | 那是裝飾圖案，不是天線單元 | A2 |
| 畫成某一家用戶終端的外觀 | 違反「不畫真實公司產品外觀」的紅線 | X1（紅線） |
| 畫了馬達／轉台當成追星機構 | 相位陣列的重點就是**不靠機械**追星 | P5 |
| 在畫面上寫頻率、層數、單元數 | 那些是某一家的設計數字，不是通則（§7-B） | X4 |

## 6. 結構審查清單（逐條驗，每條都要判得出過／不過）

**S 組・疊層（6 條）**
- S1　★★★ 輻射貼片是**最上面的導體層**（3-A B1）。**紅線，不過就退回、不進二輪。**
- S2　★★★ 波束成形 IC 在**板子背面**（與貼片相反面）（3-A B2）。**紅線。**
- S3　★★ 接地層在貼片與饋入網路**之間**，且是**連續一整片**（3-A B3）。**紅線。**
- S4　天線罩**左右都超出貼片陣列的邊界**（3-A B4）。
- S5　饋入走線**等長蛇行**，且每條通到一個貼片（3-A B5）。
- S6　金屬背板在最下，且與波束成形 IC 之間有導熱介面（3-A B6）。

**A 組・貼片陣列（3 條）**
- A1　★ 陣列 ≥ 8×8，**每格大小一致、間距一致**（3-B B7）。
- A2　★ **每一格都有饋入點**（3-B B8）。
- A3　俯視小圖旁邊標「實際單元數遠多於圖上（示意）」（3-B B9）。

**P 組・波束成形（5 條，本圖核心）**

## 9. 給 `tech-illustrator` 的實作邊界

- **先畫區 B 的波束幾何、先用程式把波前的斜率算出來**，再補疊層。
  P1／P2 是這張圖的命題本身；而且波前**一定要用公切線算**，不要目測畫一條斜線。
  做法：每個單元 `i` 的相位延遲 `d_i = i * k`，同心弧半徑 `r_i = R - d_i`，
  波前就是這些圓的公切線 —— **斜率是算出來的**，所以 P3 自動成立。
- **疊層用一個陣列 ＋ `forEach` 由上往下堆**
  （`['radome','gap','patch','diel','gnd','diel','feed','bfic','ctrl','plate']`），
  這樣 S1／S2／S3 自動成立、改不壞。**不要手刻十個矩形。**
- 貼片陣列用**雙層 `for` 迴圈**（`8 × 8`），格子邊長與間距各用一個常數 ——
  A1 自動成立。**饋入點也要在同一個迴圈裡畫**（畫在迴圈外＝很容易只畫到第一排，那是 A2 不過）。
- 饋入網路的等長蛇行：用**同一個蛇行樣板複製 N 份、只平移不縮放** ——
  這樣「等長」在結構上就成立。
- **不要畫底座、不要畫線材、不要畫外殼開孔**（X1 是紅線，而且這些東西畫了就很難說不是某一家的）。
- 章節列用既有的 `foldBar()` ＋ `<g class="dgbody" data-fold="…" data-y0 data-y1>`，
  **預設全部收合**，**章節列不准掛 `data-seg`**。
- 顏色一律走 `--dg-*` / `var(--c)`，不准寫死 `#xxxxxx`（AGENTS §15）。
- **`data-part` 一律要寫**。建議命名：`leo_radome` / `leo_patch` / `leo_diel` / `leo_gnd` /
  `leo_feed` / `leo_bfic` / `leo_ctrl` / `leo_plate` / `leo_array` / `leo_beam` /
  `leo_wavefront` / `leo_term` / `leo_ground` / `leo_stack`。
- **不做動畫。** 「波束掃過去」看起來很誘人，但**靜止時要看的東西（傾角與相位差）一個都沒有多**，
  而且動畫會讓 390px 下的波前更難量。
- **SVG 的 `<style>` 裡（含註解）一律不准出現角括號**（HANDOFF 2026-09-21 的坑）。
