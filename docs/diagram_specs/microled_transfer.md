## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 晶粒從**密**的磊晶片搬到**疏**的顯示基板 | **不會**。「間距被放大」是兩張平面陣列的**疏密對比**，俯視最清楚 | 2D 俯視 ＋ 2D 剖面 |

## 1. 這張圖要回答什麼問題

**「Micro LED 的晶粒早就做得出來，為什麼還沒普及？巨量轉移到底在搬什麼、難在哪？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句**）：

1. **難的不是「做小」，是「搬過去」。** 磊晶片上晶粒是**密排**的，
   顯示器上像素是**疏排**的 —— 轉移這一步要把**間距放大**，而且一次要搬幾百萬顆。
2. **一顆晶粒的發光層夾在中間。** n 型層 → **多重量子井（發光層）** → p 型層，
   電子與電洞在量子井裡復合才發光；順序錯了就不發光。
3. **良率是用「百萬分之幾」在算的。** 一片 4K 顯示器要幾百萬顆晶粒，
   轉移良率必須高到接近百分之百，剩下的靠**檢測與修補**站補。
4. **修補一定在轉移之後。** 先搬、再看哪顆不亮、再補 —— 順序反過來沒有意義。

**這張圖的成敗**：指著五站流程上任何一站，要能說出「這一站在做什麼、台股有沒有人在這一站」。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A 晶粒磊晶疊層，**由下到上**

1. 生長基板（藍寶石／矽）
2. 緩衝層
3. **n 型層**
4. **多重量子井（發光層）**
5. **p 型層**
6. 電極

**G1**　★★★ **量子井必須夾在 n 型層與 p 型層之間。**
放到最上面、最下面、或 n／p 順序對調，這顆就不發光 —— 那不是畫得不好看，是畫成了別的東西。
**這一條不過就退回，不進二輪。**
**G2**　★ 量子井畫成 **3～5 條平行細線**（多重），不是一條；而且它**必須是全圖最薄的一組層**
（量得出來：單條厚度 ≤ n 型層厚度的 1/8）。
**G3**　緩衝層在基板與 n 型層**之間**，不在 n 型層上面。
**G4**　兩個電極**分別接到 n 型層與 p 型層**，不准兩個都接同一層。
**G5**　生長基板畫成**虛線輪廓**，並標「轉移時會被剝離」（§7-B2，示意）。

### 3-B 巨量轉移的**方向與疏密**（★ 這是本圖的命題，第二條紅線）

**G6**　★★★ **方向：供體（上）→ 轉移頭 → 接收基板（下）**。
箭頭一律向下；**不准出現由下往上的箭頭**。
**G7**　★★★ **接收基板上的晶粒間距，必須明顯大於供體上的間距** —— 量得出來：
`接收間距 ≥ 供體間距 × 3`。
> 兩邊畫成一樣疏密＝把「巨量轉移到底在幹嘛」整個畫掉了。**這一條不過就退回，不進二輪。**
**G8**　★ 轉移頭**只抓供體上的一部分晶粒**（不是全部）——
被抓起的數量必須等於接收基板上那一批的數量，且**小於**供體上的總數。
**G9**　被抓起的晶粒在轉移頭上**保持與供體相同的排列方向**（不翻面、不亂序）。
**G10**　供體上的晶粒**朝下**（面向接收基板），不是朝上。

### 3-C 五站流程的順序

`磊晶 → 晶粒製作 → 巨量轉移 → 鍵合 → 檢測與修補`

**G11**　★ **檢測與修補一定在最後**，不准排在轉移之前（3-C）。
**G12**　流程列是**單向由左到右**，箭頭方向一致；**這一條不是迴圈**
（跟 `foundry_process.md` 的製程環不同，不要照抄那個畫法）。
**G13**　區 B 的放大圖**必須有一條引線接回區 A 的第 ③ 站**，讓人知道放大的是哪一站。

### 3-D 尺寸尺

**G14**　由大到小：`一般 LED 晶粒 → Mini LED → Micro LED`，三級有引線相連。
**G15**　★ 三級的大小關係**不准倒過來**，而且相鄰兩級的邊長比 ≥ 2（看得出來是「小一個等級」）。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **F1 晶粒剖面**：三段（n／量子井／p），中間那段是**一組平行細線**。

- **F6 尺寸尺**：三級方塊，逐級變小。

### 4-B 最常見的畫錯（逐條對應 §6）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |

| 量子井畫在最上層或最下層 | 不發光。整顆就不是 LED 了 | E1（紅線） |
| 量子井畫成一條粗帶 | 多重量子井的「多重」沒了，而且它應該是最薄的一組 | E2 |

| 轉移頭把供體晶粒全部抓走 | 實務上是分批抓、選擇性轉移；全抓等於沒有「選擇」 | T3 |

| 流程列畫成迴圈 | 這條線是單向的，不是晶圓廠那種重複迴圈 | S3 |

## 6. 結構審查清單（逐條驗，每條都要判得出過／不過）

**E 組・晶粒疊層（5 條）**
- E1　★★★ 由下到上是 `基板 → 緩衝層 → n 型層 → 量子井 → p 型層 → 電極`，
  **量子井夾在 n 與 p 之間**（3-A G1）。**紅線，不過就退回、不進二輪。**
- E2　★ 量子井是 **3～5 條平行細線**，單條厚度 ≤ n 型層的 1/8（3-A G2）。
- E3　緩衝層在基板與 n 型層**之間**（3-A G3）。
- E4　兩個電極**分接 n 與 p**，不是同一層（3-A G4）。
- E5　生長基板是**虛線**且標「轉移時會被剝離（示意）」（3-A G5）。

**T 組・巨量轉移（5 條，本圖核心）**
