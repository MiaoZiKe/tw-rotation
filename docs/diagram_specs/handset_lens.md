## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 鏡片一片一片疊、中間夾遮光環 | **不會**。那是縱剖上的層序；透視會被鏡筒整個擋住 | 2D 縱剖 |
| 光線穿過每一片鏡片、最後會聚在感測器上 | **不會**。光路是平面上的折線，3D 只會讓它糾在一起 | 2D 光路 |
| 對焦時動的是整個鏡筒 | **會一點點**，但用「同一張剖面畫兩個位置 ＋ 一個箭頭」更清楚，而且不用轉 | 2D ＋ 位移箭頭 |
| Pancake 的光在兩片之間折返三段 | **不會**。折返是平面上的來回，3D 會把三段疊在一起看不出來 | 2D 光路 |

反面成本：四個資訊點全在剖面與光路上；3D 在手機吃力；`electronics` 鏈目前沒有 3D 場景。

**什麼條件下才該回頭加 3D**（寫死）：
> 只有當這張圖要新增「**多鏡頭模組在手機背面的排列與潛望式的轉折路徑**」（同時需要平面位置
> 與垂直光路）時，才重開這一段、改規格書、重新簽。那件事比較好的做法是交給
> `handset_teardown.md`，不是把這張改成 3D。

## 1. 這張圖要回答什麼問題

**「一顆鏡頭模組裡面疊了什麼？對焦時動的是哪一塊？台股吃到的是哪一段？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句**）：

1. **由上到下的順序是固定的**：保護玻璃 → 光圈 → 鏡片組（中間夾遮光環）→
   **紅外截止濾光片** → 影像感測器。**濾光片在鏡片與感測器之間，不在最前面。**
2. **對焦時動的是整個鏡筒**，不是某一片鏡片、也不是感測器。音圈馬達（VCM）把鏡筒推上推下，
   讓成像面剛好落在感測器上。
3. **鏡片是非球面而且是塑膠射出的。** 非球面才能用少少幾片把像差壓下來；
   塑膠才做得到量產這個量級。
4. **台股吃的是「鏡片與鏡頭」那一段。** 這一疊裡價值最高的是影像感測器，
   而**本圖查不到台股在手機感測器這一段的具名供應** —— 這個缺口本身就是資訊。

**這張圖的成敗**：指著這一疊裡任何一層，要能說出「這是什麼、誰做的，或者誠實說查不到」。

## 2. 零件清單

### 2-A 區 A 模組縱剖（由上到下 ＝ 進光方向）—— 最少 9 個零件

| 零件 | 相對尺寸 | 材質觀感 | 備註 |
|---|---|---|---|
| 保護玻璃（鏡頭蓋片） | 薄平板，最寬 | 透明淺色 | 最上面 |
| 光圈（孔徑光闌） | 一片中間有孔的黑環 | 不透光深色 | 在第一片鏡片**之前或前幾片之間** |
| 鏡片 ×5 | 厚薄不一，**每片形狀都不同** | 透明，帶淡淡的鍍膜色 | ★ **非球面**，至少 5 片 |
| 遮光片／間隔環 | 薄黑環，夾在每兩片之間 | 不透光深色 | ★ 每一對相鄰鏡片之間都要有 |
| 鏡筒（barrel） | 包住整個鏡片組的外壁 | 黑色塑膠 | ★ 鏡片外緣**藏在它裡面** |
| 音圈馬達（VCM） | 環繞鏡筒的一圈 | 金屬＋線圈紋 | 帶一個向上／向下的位移箭頭 |
| 紅外截止濾光片（IR-cut） | 薄平板 | 半透明藍綠色 | ★ **在鏡片組與感測器之間** |
| 影像感測器（CIS） | 一小片，受光面**朝上** | 深色晶片 ＋ 表面格點 | |
| FPC 軟板 ＋ 連接器 | 感測器下方一條帶 | 琥珀色薄帶 | **不准剖開畫層**（§0-B） |

### 2-B 區 A 的光線

三條光線（或更多），**由上往下**，每經過一片鏡片折一次，**最後會聚在感測器的受光面上**。

### 2-C 區 B 價值帶

一條與區 A **逐層對齊**的縱帶，每一段寫「這一層是誰做的」或「查不到」。
**不寫任何百分比**（§7-B1）。

### 2-D 章節列 `ar_optics` 的兩格

| 格 | 要畫什麼 |
|---|---|
| Pancake 折反射 | 兩片光學件 ＋ 一條**折返三段**的光路 ＋ 眼睛符號；旁邊一條直線光路對照，標「同樣的光程，厚度差很多」 |
| 幾何／繞射波導 | 一片平板玻璃 ＋ **入耦合區** ＋ 板內**全反射至少 3 次** ＋ **出耦合區** ＋ 眼睛符號；左側一個微投影模組方塊 |

### 2-E 不要出現的東西（畫了就是別張圖，或是紅線）

- **手機外觀、電池、主機板、顯示面板、背光**（那是 `handset_teardown.md` 與 `panel_stack.md`）。
- **任何真實廠商的產品外觀、logo、料號、機種名。**
- **★ 任何終端品牌客戶的名字。** 證據表裡有「某系列 Pancake 透鏡供應商」這種寫法，
  信心只有 `reported`、公司自己沒證實 —— **一律不寫進畫面**
  （與 `supply_chain.yaml` 對大立光的處理一致：「客戶一律不具名」）。
- **任何價值百分比、市占率、營收、單價數字。**
- **「全球第幾大」「龍頭」「唯一」**這類法人用語（CLAUDE.md 紅線）。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A 模組縱剖，**由上到下（＝進光方向）**

1. 保護玻璃
2. 光圈（孔徑光闌）
3. 鏡片 ①（＋遮光環）
4. 鏡片 ②（＋遮光環）… 至少到鏡片 ⑤
5. **紅外截止濾光片**
6. **影像感測器**（受光面朝上）
7. FPC 軟板
8. 連接器

**L1**　★★★ **紅外截止濾光片必須在鏡片組與感測器之間。**
畫在鏡頭最前面（保護玻璃那一層）是最常見的錯 —— 那樣的話鏡片組自己就吃不到紅外修正，
而且實務上濾光片是貼在感測器封裝上的。**這一條不過就退回，不進二輪。**
**L2**　★ 感測器的**受光面朝上**（朝鏡頭），FPC 在它**下方**。畫反了光就射不進去。
**L3**　光圈在**第一片鏡片之前，或前幾片鏡片之間** —— 不准畫在鏡片組後面（那就不是孔徑光闌了）。
**L4**　**每一對相鄰鏡片之間都要有一片遮光環**，不准兩片鏡片直接貼在一起。
**L5**　鏡片數 **≥ 5**，且**每一片的形狀都不一樣**（同形狀複製五次＝畫成了望遠鏡的接目鏡組）。

### 3-B 非球面與鏡筒

**L6**　★ 每一片鏡片**上下兩面的曲率不同**，而且**至少 3 片**看得出「中心與邊緣的曲率不一樣」
（非球面的識別特徵）。全部畫成正圓弧＝畫成了球面鏡。
**L7**　★ **鏡筒包住鏡片組的外緣**，鏡片的邊緣**看不到露在鏡筒外面**。
**L8**　鏡筒是**一整段**，不是每片鏡片各一個環。

### 3-C 光路（★ 第二條紅線）

**L9**　★★ 光線**由上往下**，**每經過一片鏡片折一次**，**最後會聚在感測器的受光面上** ——
不是會聚在感測器上方的空氣裡，也不是穿過感測器。
> 會聚點畫錯＝把「對焦」這件事畫掉了。**這一條不過就退回，不進二輪。**
**L10**　光線至少 3 條，且**不是平行的三條直線**（平行直線＝沒有經過任何光學元件）。
**L11**　光線通過**紅外截止濾光片**時**不折**（它是平板，只擋波長不改方向）——
在那一層把光線畫彎是錯的。

### 3-D VCM 的作用對象（★ 第三條紅線）

**L12**　★★ **VCM 的位移箭頭必須指向「鏡筒＋整個鏡片組」這一整塊**，
不是指向單一鏡片、也不是指向感測器。
> 指錯對象＝把「對焦時動的是哪一塊」這句話講反。**紅線。**
**L13**　VCM 環繞在鏡筒**外側**，不在鏡片之間。
**L14**　箭頭是**雙向**（上下都能走），不是單向。

### 3-E 章節列 `ar_optics` 的兩格光路

**L15**　★ Pancake 格：光路必須**折返三段**（去 → 回 → 再去），
且旁邊的直線光路對照要畫出來，讓「光程一樣長、厚度差很多」看得出來。
畫成一次穿過＝畫成了普通透鏡。
**L16**　★ 波導格：光在平板內**全反射 ≥ 3 次**，且**入耦合區與出耦合區在不同位置**
（不能同一個位置進出）。
**L17**　兩格**同一個比例尺**，而且**眼睛符號在同一邊**（讓兩條光路的終點可比）。
**L18**　兩格都**不准畫成單一片透鏡**（那就沒有「為什麼要這樣折」的資訊了）。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **F1 鏡片組**：五片**形狀各不相同**的透明件 ＋ 片間的黑色薄環。
- **F2 非球面**：同一片上，中心與邊緣的曲率不一樣。
- **F3 鏡筒**：一段黑色外壁把鏡片邊緣全部藏起來。
- **F4 VCM**：環繞鏡筒的線圈紋 ＋ **指向整個鏡筒的雙向箭頭**。
- **F5 IR-cut**：一片半透明藍綠色平板，**夾在鏡片組與感測器之間**。
- **F6 感測器**：受光面**朝上**、表面有格點（像素陣列示意）。
- **F7 光路**：三條折線**會聚在感測器表面上**。
- **F8 Pancake**：光在兩片之間**來回三段**。
- **F9 波導**：平板內**鋸齒狀多次全反射**。

### 4-B 最常見的畫錯（逐條對應 §6）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |
|---|---|---|
| IR-cut 畫在鏡頭最前面 | 位置錯了；實務上它在感測器前 | A1（紅線） |
| 光線會聚在感測器上方的空氣裡 | 那是失焦，而且把「對焦」這件事畫掉了 | O1（紅線） |
| VCM 的箭頭指向單一鏡片或感測器 | 對焦時動的是整個鏡筒 | V1（紅線） |
| 五片鏡片畫成同一個形狀複製 | 非球面鏡組每片都不一樣，這是它的識別特徵 | A5 |
| 鏡片邊緣露在鏡筒外面 | 那樣會漏光，鏡筒的用途沒了 | A7 |
| 鏡片之間沒有遮光環 | 沒有遮光環會有雜散光；而且黑環是這一疊的識別特徵 | A4 |
| 感測器受光面朝下 | 光射不進去 | A2 |
| 光線穿過 IR-cut 時被畫彎 | 平板濾光片只擋波長、不改方向 | O3 |
| Pancake 畫成一次穿過 | 沒有折返就沒有「折疊光路」，就只是一片透鏡 | R1 |
| 波導的入出耦合畫在同一個位置 | 那樣影像會直接回到投影機，不會到眼睛 | R2 |
| 畫面上寫出終端品牌客戶名 | 公司沒證實，信心只有 `reported` | X3（紅線） |

## 9. 給 `tech-illustrator` 的實作邊界

- **先畫光路、先讓光線真的會聚在感測器表面上**，再補零件外形。
  O1 是紅線，而且「先畫零件再硬把光線塞進去」一定會落在錯的位置。
  做法：**先決定感測器的 y 座標，光線的會聚點就用那個座標算**，不要目測。
- **鏡片用一個陣列宣告五組曲率參數**（`[[r1,r2,t], …]`），`forEach` 畫 ——
  這樣 A5（每片形狀不同）自動成立，也擋掉複製貼上。
  非球面用 `path` 的二次／三次貝茲，**中段與邊段用不同控制點**（A6）。
- **遮光環在鏡片迴圈裡一起畫**（`i > 0` 時先畫一個環再畫鏡片）——
  畫在迴圈外最容易漏掉最後一組，那就是 A4 不過。
- 鏡筒用**一條包住整組鏡片外緣的 `path`**，並且**畫在鏡片之後**（蓋住邊緣）——
  A7 自動成立。
- VCM 的箭頭**掛在鏡筒那個 `<g>` 上**（同一個 group），不要獨立畫一支箭頭 ——
  這樣 V1 在結構上就成立，日後有人移動鏡筒箭頭也會跟著走。
- 章節列用既有的 `foldBar()` ＋ `<g class="dgbody" data-fold="…" data-y0 data-y1>`，

- 波導的全反射用 `for` 迴圈沿平板來回畫線段（至少 3 個來回），**不要手刻座標**（R2）。

- **`data-part` 一律要寫**。建議命名：`hl_cover` / `hl_stop` / `hl_lens` / `hl_spacer` /

  `hl_pancake` / `hl_waveguide` / `hl_proj`。
- **不做動畫。**
- **SVG 的 `<style>` 裡（含註解）一律不准出現角括號**（HANDOFF 2026-09-21 的坑）。
