## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：**不做真 3D**

這張圖的**全部內容都是「對應關係」**（哪個材料用在哪一站、哪一站台股有人做），
不是幾何結構。轉一圈不會多理解任何一件事。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 材料 ↔ 製程站的對應 | **不會。** 那是連線關係 | 2D 環 ＋ 連線 |
| 光阻／BARC 的上下關係 | 不會。那是剖面上的兩層 | 2D 放大剖面 |
| 鑽石碟 ↔ 拋光墊 ↔ 研磨液的三者關係 | **不會，而且轉了更糟** —— 關鍵是「誰壓在誰上面、誰在中間流動」，那是剖面 | 2D 放大剖面 |
| 靶材被濺出來變成薄膜 | 不會。那是剖面上的一個方向 | 2D 放大剖面 |
| 台股有／沒有 | 不會。那是一條對照帶 | 2D 帶 |

**什麼條件下才該回頭加 3D**（寫死）：

> 只有當這張圖要新增「**一台機台的腔體內部三維配置**」時才重開這一段。

## 1. 這張圖要回答什麼問題

**「光阻、靶材、特殊氣體、研磨耗材各自用在製程的哪一步？台股這七家分別卡在哪一站、哪幾站是台股完全沒有的？」**

使用者看完要能自己講出這四句：

1. **材料不是「一包一包買來堆著」，是綁在特定製程站上的。**
   靶材只在沉積站用、光阻只在黃光三站用、蝕刻氣體只在蝕刻站用、研磨耗材只在 CMP 站用。
2. **黃光那一段不是只有光阻。** 光阻底下還有 **BARC（底部抗反射層）**，
   旁邊還有 **EBR（邊緣去膜）** 與顯影後的沖洗（Rinse）——
   台股 4749 新應材做的就是這三樣（§7-A2）。
3. **CMP 站上有三件東西，台股只做其中一件。**
   研磨墊、研磨液、**鑽石碟（修整器）** —— **1560 中砂做的是鑽石碟，不是研磨液**（§7-A5、§3-C M3）。
4. **最硬的卡點是光阻。** 日本控制七成以上的光阻、**高階 EUV 光阻約九成五**，
   7 nm 以下幾乎是唯一供應來源（§7-A1）。**台股在光阻本體這一格是空的**，
   台股做的是光阻周邊的配套化學品（§7-D3）。

**這張圖的成敗**：Andy 指著環上任何一站，要能說出
「這一站吃什麼、**台股有沒有人做這個**、沒有的話是誰做的」。第三句講不出來，圖就白畫。

## 3. 層別／順序（★ 可判定的條目）

### 3-A 迴圈：與 S1 逐字對齊

- **L1**　★★ **九個站名必須與 `foundry_process.md` §2-E 的九個站名逐字相同**，
      順序相同、方向相同（順時針）。**任何一個字不同就退回。**
- **L2**　★ **迴圈必須是閉合的環**（第九站有線回到第一站），與 S1 同一條規則。
- **L3**　每一站的材料卡**用一條引線接到那一站**，不准只是擺在旁邊。
- **L4**　**④ 曝光與 ⑨ 量測那兩張卡必須是「留白卡」**，寫明「這一站吃的不是材料」。
      硬塞一個材料進去＝為了畫面對稱而編對應（R5 紅線）。

### 3-B 光阻疊層與靶材

- **B1**　★★ **BARC 在光阻底下。** 這是「Bottom Anti-Reflective Coating」名字的全部意義。
      畫反＝一個可以查證的事實錯誤，而且會讓 S1 的 P3 跟著錯。
- **B2**　**光阻比 BARC 厚**（BARC 是很薄的一層底塗）。
- **B3**　**EBR 畫在晶圓最外緣的一小圈**，不是畫在中央。
      EBR 是「Edge Bead Removal」——把塗佈時堆在邊緣的那一圈光阻清掉。畫在中間＝完全誤解。
- **T1**　★ **濺鍍的原子方向是「由靶材往晶圓」（由上往下）。** 方向畫反＝在把薄膜刮回靶材上。
- **T2**　**靶材與薄膜要用同一色系**（同一種金屬，一邊是原料一邊是產物），
      但薄膜**必須薄得多**（靶材是一塊板、薄膜是一層膜）。

### 3-C CMP 三件組（★ 這張圖最容易畫錯的一段）

```
        [鑽石碟]  ← 修整研磨墊（在晶圓旁邊）
   [晶圓，面朝下]
   ～～～[研磨液]～～～
 ━━━━━━━[研磨墊]━━━━━━━  ← 會轉的大盤
```

- **M1**　★★★ **鑽石碟壓在「研磨墊」上，不是壓在「晶圓」上。**
      它的工作是把研磨墊磨鈍的表面修整回來，**不是拿來磨晶圓的**。
      畫成鑽石碟直接磨晶圓＝把這一格的意義完全弄反，**直接退回**。
- **M2**　★ **晶圓面朝下**（要磨的那一面朝向研磨墊）。面朝上＝什麼都磨不到。
- **M3**　★★ **「研磨液」與「鑽石碟」是兩樣不同的東西，卡上不准混寫。**
      台股 1560 中砂做的是**鑽石碟**；**研磨液本圖查不到台股廠商**（§7-C2）。
      把兩者寫成一件事＝在公開網站上宣稱中砂做研磨液，那是錯的。
- **M4**　**研磨液畫在晶圓與研磨墊「之間」**，而且要看得出它是流動的（不是固體塗層）。
- **M5**　研磨墊要畫成**會轉的大盤**（有一個旋轉箭頭），晶圓也要有自己的旋轉箭頭。

### 3-D 對照帶

- **G1**　★ **對照帶的九格必須與環上的九站一一對齊**（第 n 格對第 n 站）。
- **G2**　**紅章那一格必須同時寫出「台股沒有人做」與「實際上是誰做的」**（R4）。
      只寫「台股沒有」＝留白，讀者會以為漏了（R4 明文禁止）。
- **G3**　**灰章那一格必須寫「本圖查不到具名對應」**，不准留空白、不准用推論填。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **迴圈**：九站、閉合、與 S1 同字。
- **光阻疊層**：**BARC 在下、光阻在上**，外緣有一圈 EBR。
- **靶材**：**一塊板在上、一層膜在下、原子由上往下**。
- **CMP**：**鑽石碟壓在研磨墊上而不是晶圓上**、晶圓面朝下、研磨液在中間。
- **對照帶**：**至少一格是紅的**，而且紅格上寫得出「那是誰做的」。

### 4-B 最常見的畫錯

| # | 畫錯的樣子 | 為什麼是錯的 | 對應審查 |
|---|---|---|---|

### D. `data-seg` 的掛法（★ 只掛一個，其餘都不掛）

**D1　只有「靶材」那一個零件掛 `semi_material`，其餘一律不掛。**

`supply_chain.yaml` 的 `chain: semiconductor` 底下有 **`semi_material`（半導體製程材料，layer 1, role material）**，
但底下**只有一家：1785 光洋科**（`tech: [薄膜濺鍍靶材, 蒸鍍材料, 貴金屬與稀有金屬回收精煉]`）。

而 `groups.yaml` 的 `fab_material` 族群有 **7 檔**，
其中 **4749、4772、5234、8091、4768、1560 這六檔在整份 `supply_chain.yaml` 裡一次都沒有出現**（代號 grep 確認）。

→ **後果與處理**：

| 零件 | 掛不掛 `data-seg` | 為什麼 |
|---|---|---|
| **靶材（② 沉積站的那一張卡與區 B ② 的放大剖面）** | **掛 `semi_material`** | 那一格底下就是光洋科，而光洋科做的就是靶材。**掛對了** |
| **光阻／BARC／EBR／蝕刻氣體／剝離液／鑽石碟／機台耗材** | **一個都不掛** | 掛上去會讓小卡列出「光洋科」，等於在公開網站上宣稱**光洋科做光阻／做鑽石碟**。**那是錯的** |

⚠ **代價**：六家在圖上**點了不會篩成分股**、小卡也不會出現（`renderPartCard()` 的 `if (!seg)`）。

## 8. 2D 的驗收條件

- **結構**（`mechanical-engineer` 簽）：照 §6 的 L／B／T／M／G／R／H 七組逐條。
  **L1（站名與 S1 逐字相同）、B1（BARC 在下）、M1（鑽石碟修研磨墊）是紅線**，不過就退回。
- **視覺**（`art-director` 簽）：字級全圖 ≥ 12px，實測畫面真實字級在
  **1440 / 1100 / 900 / 800 / 390** 下都 ≥ 12px；深淺主題各驗一次。
  **三種章（綠／灰／紅）在深淺兩個主題、四個配色下都要分得出來**，
  且**紅章不可以跟 `--dg-err` 撞用途**（`art-director` 裁定要不要另開一個 token）。
- **互動**（`_uitest.py` 真的操作）：
  1. 點 **靶材** 那個零件 → 小卡出現、**列得出 1785 光洋科**（這是全圖唯一列得出公司的零件）；
  2. 點**光阻**那個零件 → **沒有小卡**（因為沒有 seg），但**材料卡上的文字看得見「台股沒有廠商做」**；
     ⚠ 這是反向驗收 —— 它要證明的是「我們沒有為了讓小卡出現而掛一個錯的環節」；
  3. 點 `semi_material` 環節色標 → **成分股筆數真的變了**；
  4. **驗九個站名與 S1 逐字相同**（把兩張圖的站名抓出來比對，這一條要寫進 `_uitest.py`）；
  5. **800px 與 390px** 下可左右滑、無文字重疊、無整頁水平捲軸；
  6. 切到「休閒」配色 → 三種章仍分得出來、語意色沒被覆寫。
- **效能**：不新增函式庫、不新增 CDN；動畫只有一個 rAF，頁面切走要停。
- **不畫**任何真實公司的產品外觀、logo、包裝、商標。

## 9. 給 `tech-illustrator` 的實作邊界

- **先把九站環畫出來、先把站名字串從 `foundry_process` 那張圖抄過來**（最好抽成一個共用常數），
  再補材料卡。**站名如果是兩邊各自手打，L1 遲早會不過** ——
  建議在 `site/diagrams.js` 或兩張圖共用的地方放一個 `FAB_LOOP_STEPS` 陣列，兩張圖都讀它。
- CMP 那一格**先畫再自己問一次**：「鑽石碟碰到的是墊還是晶圓？」
  這是本圖唯一的三級紅線（M1），而且很容易在調版面時被推到晶圓上面去。
- 三種章用**形狀 ＋ 顏色雙編碼**（例如綠＝實心圓、灰＝空心圓、紅＝三角形），
  不要只靠顏色 —— 四個配色下顏色會變，形狀不會。
- 材料卡用同一支 `card()` 函式畫，**卡上的「台股」那一行是必填欄位**，
  值只有三種：公司名單／「本圖查不到具名對應」／「台股沒有廠商做，實際上是 …」。
  **函式層面就不要讓它有「空的」這個可能**（G2／G3 自動成立）。
- 顏色一律走 `--dg-*`，不准寫死 `#xxxxxx`。這張圖**只有一個零件有 `data-seg`**，
  所以 `var(--c)` 幾乎用不到 —— 需要 `art-director` 指定一組本圖用的 `--dg-*`
  （化學品一色、氣體一色、金屬一色、耗材一色、三種章各一色）。
- **`data-part` 一律要寫**。建議命名：
  `fm_target` / `fm_resist` / `fm_barc` / `fm_ebr` / `fm_rinse` / `fm_dev` / `fm_gas_depo` /
  `fm_gas_etch` / `fm_strip` / `fm_pad` / `fm_slurry` / `fm_disc` / `fm_parts` / `fm_clean` /
  `fm_litho_blank` / `fm_metro_blank`。
- 動畫：只做一件事 —— **一個小點沿著環繞一圈**（與 S1 同一個動作，兩張圖看起來是同一個迴圈）。
  靜止時箭頭方向仍看得見。
- **SVG 的 `<style>` 裡（含註解）一律不准出現角括號。**
