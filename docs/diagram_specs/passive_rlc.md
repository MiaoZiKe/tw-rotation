## 0. 開畫之前要先簽掉的三件事

### 0-A　要不要 3D —— 結論：不做真 3D

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 電感的繞線被磁粉包起來（一體成型） | **有一點點**，但「線被埋起來」在切開的剖面上更清楚，轉一圈看到的是一顆不透明的方塊 | 2D 剖面 ＋ 切開一角 |
| 晶片電阻的三明治（基板／電阻膜／保護層／端電極） | 不會。全部資訊都在**剖面**，正面看只有一塊黑色小方塊 | 2D 剖面 |
| 雷射修整溝是切在電阻膜上的一道缺口 | 不會。那是**頂視**看得最清楚的圖形 | 2D 頂視小圖 |
| 石英晶片被兩點導電膠架在陶瓷底座裡、金屬蓋縫焊密封 | 不會。密封腔的重點是「裡面是空的」，剖面才表達得出來 | 2D 剖面 |
| 三種零件的大小關係 | 不會，而且會更糟。大小是**並排比**，透視一斜就比錯了 | 2D 並排 |

**三種零件都不是「靠外形被認出來」的東西** —— 它們的識別特徵全部在剖面裡。
這正是不做 3D 的核心理由，跟 MLCC 那張的判斷同源。

**什麼條件下才該回頭加 3D（寫死，避免下次又變成事後補簽）**：

> 只有當這張圖要新增「**這三種零件在伺服器主板上的實際位置與密度**」
> （例如 GPU 周圍一整圈電感的空間排列、或整塊板子上被動元件的分布）時，
> 才重開這一段、改規格書、重新簽。也就是說：**只有「空間關係」本身變成主題，3D 才成立。**
> **單純為了「看起來比較立體」不算理由；「MLCC 那張有 3D 所以這張也要」更不算** ——
> MLCC 那張的 3D 是實作時加的、規格書沒寫，那是要避免重演的事，不是先例。

### 0-B　三種零件放同一張圖，怎麼排才不會變成三張圖硬擠（★ 這一段要先被簽掉）

**結論：上方一條共同舞台（板上情境帶）＋ 下方三欄等高等寬剖面。**

先講被否決的兩個排法，以及為什麼：

| 排法 | 為什麼不行 |
|---|---|
| （甲）三張獨立小圖左中右並排 | 這就是「三張圖硬擠在一起」本身。三者沒有共同的座標、共同的尺度、共同的提問，讀者只會覺得這一頁塞了三件不相干的事 |
| （乙）排成一條流程列（電源進來 → 電流被量 → 時脈在旁邊） | **會暗示一個不存在的因果順序**。這三種零件之間沒有上下游關係，畫成流程等於在宣稱一件假的事 —— 跟「金像電被放進 ABF 載板」是同一類錯：版面本身在講一個錯的結論 |

採用的排法（丙）與它成立的理由：

```
┌──────────────────────────────────────────────────────────┐
│  共同舞台：一小塊伺服器主板的頂視（2.5D 微斜），上面有         │
│  ① GPU 旁邊一排電感   ② 供電路徑上一顆檢流電阻   ③ 角落一顆晶振 │
│  三條引線從這三個位置往下拉                                   │
└────────┬──────────────┬──────────────┬───────────────────┘
         ↓              ↓              ↓
┌────────────┐ ┌────────────┐ ┌────────────┐
│ 欄 A 電感   │ │ 欄 B 電阻   │ │ 欄 C 石英   │   ← 三欄等高等寬
│ 剖面        │ │ 剖面        │ │ 剖面        │
│ 一句「它解決 │ │ 一句「它解決 │ │ 一句「它解決 │
│  什麼」      │ │  什麼」      │ │  什麼」      │
│ 三行標註     │ │ 三行標註     │ │ 三行標註     │
└────────────┘ └────────────┘ └────────────┘
     底部一條共同的尺：三種零件的外形並排比大小（同一把尺）
```

成立的理由有三個，每一個都可驗：

1. **有共同舞台**：三者確實同時出現在同一塊板子的同一個區域（供電與時脈區），
   所以「放在一起」不是版面湊合，是事實。
2. **有共同提問**：三欄的第一行都回答同一個問題 ——
   **「這顆一塊錢的零件，規格差在哪裡？」**（電感差在兩種電流、電阻差在準不準、石英差在準不準且要密封）。
   共同提問讓三欄互相對照而不是互相搶戲。
3. **有共同的尺**：底部那條尺用**同一個比例**把三種零件的外形並排，
   讓「它們其實差不多大」這件事被看見 —— 這是三合一版面唯一真正的增值。

**硬規則**：

- **三欄必須等高等寬**（`新-版面等高與多寬度` 這一段驗收本來就在管這件事）。
  一欄長一欄短＝退回。
- **三欄的內部結構必須一致**（剖面 → 一句話 → 三行標註），順序不准各排各的。
- **共同舞台那一條的高度不得超過整張圖的三分之一** —— 它是引子不是主角。
- **窄畫面（800px 以下）三欄改成上下堆疊**，但**順序不准變**（A→B→C）。

## 1. 這張圖要回答什麼問題

**「除了電容之外，板子上另外三種一塊錢的零件各自長什麼樣，各自有一個最容易選錯的規格。」**

使用者看完要能自己講出這三句：

1. **電感要看兩種電流，不是一種**：一種是「磁芯會不會飽和」（飽和電流 Isat），
   一種是「零件會不會燒燙」（溫升電流 Irms）。
   **兩個數字通常不一樣，哪個小哪個才是天花板。**
2. **晶片電阻是印出來、再用雷射刻一刀修準的**：先印電阻膜，量測之後用雷射切一道溝
   把阻值**往上**修到規格。那道溝就是它的身分證。
3. **石英元件裡面是一個被密封的空腔**：一片按特定角度切出來的石英片，
   只靠兩點導電膠架著，四周不能碰到東西，外面用金屬蓋縫焊封起來。
   **封不住，頻率就跟著壞掉。**

**這張圖的成敗**：Andy 指著三欄裡任何一個零件，要能說出
「這一塊變好會讓什麼變好、選錯會出什麼事」。講不出這句，圖就白畫。

## 3. 層別／順序（可判定的條目）

### 3-A 欄 B（晶片電阻）的層序，由下到上 —— **這是三欄裡最容易畫錯的一段**

1. 氧化鋁陶瓷基板（B1）
2. **上面電極（B2）**（印在基板上，兩端各一塊）
3. **電阻膜（B3）**（印上去，**兩端壓在 B2 上面**）
4. **雷射修整溝（B4）**（切在 B3 上）
5. 玻璃保護層（B5）（蓋住 B3 與 B4）
6. **外部端電極 Cu → Ni → Sn（B6）**（由內到外，包住兩端）

**硬規則**：

- **B2 必須在 B3 之下**，而且**B3 的兩端要壓在 B2 上**（電阻膜與電極是重疊的，不是對接）。
  畫成「電阻膜跟電極頭碰頭」＝不過。
- **B4 只准切在 B3 上**，不准切到基板、不准切穿保護層。
- **B5 必須蓋住 B4**（修完才上保護層）。B4 露在最外面＝順序錯。
- **B6 的順序是 Cu → Ni → Sn 由內到外**，把 Ni 畫在 Sn 外面是最常見的錯
  （與 MLCC §3-B 同一條規則）。
- **B7 底面電極與 B2 上面電極要被 B6 連起來** —— 那正是「三面包覆」的意思。

### 3-B 欄 A（功率電感）的結構關係

1. 繞組（A2）在本體中央；
2. **磁粉（A1）把繞組包起來**，繞組**不得露出側面或頂面**；
3. 繞組兩端折出來成為端子（A3），**只在底面**；
4. 磁通（A5）是一條**繞著繞組的封閉迴路**，走在磁粉裡。

**硬規則**：

- **一體成型那一顆：繞組必須被磁粉完全包住**，只有端子露出來。
  畫成「線圈套在一個磁芯外面、上面加個蓋子」＝那是對照小件 A6 的畫法，不是 A1。
- **A6（繞線＋鐵氧體）必須看得到縫隙與外露的圓線** —— 兩顆的差別要一眼分得開，
  不然「一體成型 vs 繞線型」這一句就沒有畫面上的證據。
- **扁平線的剖面是橫躺的長方形**，不是圓形；A6 的圓線剖面才是圓形。
- **磁通迴路不得穿出本體之外**（那是漏磁，畫了會與「磁屏蔽」的說法矛盾）。
- 兩顆**大小要畫成差不多**，差別在結構不在體積。

### 3-C 欄 C（石英）的結構關係

1. 陶瓷底座（C4）在最下，是一個有階梯的凹槽；
2. 石英片（C1）**只靠同一端的兩點導電膠（C3）架住**，
   **另外三邊與上下都不得碰到任何東西**；
3. 電極（C2）上下兩面**對稱且中央對齊**；
4. 金屬蓋（C5）蓋上去，**四周一圈連續的縫焊焊縫**；
5. 腔內（C6）**是空的**。

**硬規則**：

- **C1 四周懸空** —— 碰到殼＝振不動，這是這一欄的決定性規則。
- **C3 只有兩點，而且在同一端**（懸臂式）。四個角都黏＝不過。
- **C2 上下必須對齊**；上下電極錯開＝不過。
- **C5 的焊縫必須畫成一圈連續的線**，不是一段一段的點。
- **C6 一定要看得出是空的**（留白或極淡）。填滿＝不過。
- **C8（振盪器）的 IC 要畫在腔內的底座上、在石英片下方**，
  而且**不得碰到石英片**。

### 3-D 三欄共同的「一句話」（每欄第一行，位置固定）

| 欄 | 那一句話 |
|---|---|
| A 電感 | **它把脈衝電流變成平順的電流** —— 選錯會飽和或過熱 |
| B 電阻 | **它把電流變成看得懂的電壓** —— 選錯會不準或發燙 |
| C 石英 | **它決定整塊板子的時間** —— 封不住就走鐘 |

**硬規則**：三欄的這一行**字數要接近**（±4 字以內），不然三欄視覺上不等高。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **電感**：**看得見圈數，而且圈被埋在粉裡**。看不到圈數就只是一顆灰方塊；
  圈露在外面就變成另一種零件（繞線型）。
- **電阻**：**雷射修整溝**。這是晶片電阻**唯一的決定性特徵** ——
  沒有那一道溝，剖面看起來跟任何一種三明治小方塊沒兩樣。
- **石英**：**懸空的薄片 ＋ 空腔 ＋ 一圈焊縫**。三者缺一，讀者就會以為那是一顆 IC。
- **三顆的端子都在底面**（都是表面黏著件），共同舞台上看得出它們是貼在板子上的。
- **底部共同的尺**：三種零件並排，看得出「它們其實差不多大」。
- **每一欄都有一個對照小件**（A6 繞線型／B8 合金檢流／C8 振盪器），
  用來表達「同一類零件裡還有另一種做法」。

### 4-B 最常見的畫錯（逐條對應 §6 的審查條目）

| 常見錯法 | 為什麼是錯的 | 對應審查條目 |
|---|---|---|
| 電感畫成「線圈套在磁芯外、上面加蓋」還標「一體成型」 | 一體成型的定義就是繞組被壓在粉裡 | L1 |
| 扁平線畫成圓線 | 兩種線的剖面形狀不同，而且那正是兩種做法的差別之一 | L3 |
| 磁通迴路穿出本體 | 那是漏磁，跟「磁屏蔽」的說法矛盾 | L5 |
| 電阻的電阻膜與電極頭碰頭、沒有重疊 | 電阻膜是印在電極上的，不是對接 | R1 |
| 雷射溝切穿保護層、或切在基板上 | 溝只切在電阻膜上，而且切完才上保護層 | R2／R3 |
| 端電極把 Ni 畫在 Sn 外面 | 由內到外是 Cu → Ni → Sn（同 MLCC 那張的規則） | R4 |
| 石英片四個角都黏住 | 只有同一端兩點；四點固定會壓住振動 | Q2 |
| 石英片碰到腔壁或蓋子 | 碰到就振不動 | Q1 |
| 腔體被填滿、看不出是空的 | 密封腔是這一欄的重點 | Q4 |
| 金屬蓋的焊縫畫成虛線或斷續的點 | 縫焊是一圈連續的焊縫 | Q5 |
| 三欄高度不一樣 | 版面等高是既有驗收項，而且不等高會讓人以為某一欄比較重要 | X1 |
| 把三欄排成流程箭頭 | 三者沒有上下游關係，畫成流程等於宣稱一件假的事 | X3 |
| 圖上出現任何電容 | 那是 MLCC 那張的主題 | X4 |
| 在電感或石英欄掛 `data-seg` | 那兩格的公司不在 `passive_comp` 裡，掛了會列出錯的公司 | D2／X5 |

## 5. 標註文字

一律引線拉到外側文字框，**不壓在零件上**，最小 12px。
主標題：`電感·電阻·石英：板子上另外三種一塊錢的零件，各自有一個最容易選錯的規格`

### 欄 A　功率電感

| 指到哪個零件 | 文字寫什麼 |
|---|---|
| 本體（A1） | **金屬磁粉壓製的本體**／磁芯與外殼是同一塊，繞組直接壓在粉裡。金屬磁粉的飽和磁通密度比鐵氧體高，所以同樣體積能扛更大電流 |
| 繞組（A2） | **扁平銅線繞組**／扁平線立繞，同樣的空間能塞進更多銅，直流電阻更低 |
| 對照件（A6） | **另一種做法：繞線型＋鐵氧體磁芯**／磁芯、線圈、上蓋是分開的件。鐵氧體在電流與溫度升高時比較容易飽和，飽和之後電感值會急降 |
| 兩種電流（固定說明框） | **電感的規格要看兩個電流，不是一個**／**飽和電流 Isat**＝電感值掉到規定幅度（常見 10%／20%／30%）時的電流；**溫升電流 Irms**＝讓零件溫度升高一個規定值（功率電感常用 40°C）的直流電流。**兩個數字通常不一樣，小的那個才是天花板。**（來源：磁性元件原廠應用手冊） |

### 欄 B　晶片電阻

| 指到哪個零件 | 文字寫什麼 |
|---|---|
| 陶瓷基板（B1） | **氧化鋁陶瓷基板**／整顆零件的底，也是散熱的路 |
| 電阻膜（B3） | **電阻膜（釕系厚膜）**／網印上去再燒結，兩端壓在電極上 |
| 雷射修整溝（B4） | **雷射修整溝**／印出來的阻值不會剛好，量完用雷射切一道溝，把阻值**往上**修到規格。這道溝就是晶片電阻的身分證 |
| 保護層（B5） | **玻璃保護層**／修完才蓋上去，保護電阻膜 |
| 端電極（B6） | **端電極三層（Cu／Ni／Sn）**／由內到外，Ni 擋焊料侵蝕、Sn 幫助焊接。**原理與 MLCC 那張相同，細節見「被動元件：MLCC 疊層剖析」** |
| 對照件（B8） | **另一種做法：合金檢流電阻**／整片金屬合金當電阻體，兩端是厚銅端子；為了量得準，量電壓與走電流用不同的接點（四端量測）。**專門用在「要知道電流有多大」的地方**，不是拿來分壓的 |

### 欄 C　石英頻率元件

| 指到哪個零件 | 文字寫什麼 |
|---|---|
| 石英片（C1） | **石英晶片**／從人工培養的石英晶體上，依特定角度切下來的薄片。常見的 AT 切是把 Y 板轉約 35°15′ 切出來的（來源：AT 切製法專利，US6629342） |
| 電極（C2） | **激發電極**／上下兩面各一片，對齊；靠它把電壓變成機械振動 |
| 固定點（C3） | **只有兩點固定**／石英片只靠同一端的兩點導電膠架著，**四周都不能碰到東西** —— 碰到就振不動 |
| 空腔（C6） | **密封的空腔**／裡面是空的。封不住，頻率就跟著環境跑掉 |
| 縫焊（C5） | **金屬蓋＋縫焊密封**／用電阻加熱把金屬蓋焊在陶瓷底座上，一圈連續的焊縫 |
| 對照件（C8） | **同一個封裝裡多一顆 IC，就變成振盪器**／只有石英片的叫晶體（XTAL）；裡面多一顆振盪電路的叫 XO；再加溫度補償電路的叫 **TCXO**，用來把溫度造成的頻率漂移補回去（TCXO 的穩定度落在 ppm 等級；把石英放進恆溫槽的 OCXO 更穩，但更大更耗電） |

**一塊固定說明框（這張圖的結論，不可省略）**：

「**三顆都只值一塊錢，但三顆都會讓整塊板子壞掉**」：

1. 電感選錯 → 磁芯飽和、電感值急降，或零件過熱；
2. 電阻選錯 → 量到的電流不準，或本身發燙讓阻值漂；
3. 石英封不住 → 時脈漂掉，整塊板子的時間就錯了。

**畫面上一定要有的兩行**（左下角）：

- `示意圖，非實物比例｜各層厚度與圈數均為示意`
- `點零件篩到的是「環節」不是整個族群：這張圖只有「電阻」那一欄對得到供應鏈環節，
  電感與石英目前在供應鏈圖上還沒有自己的一格`

## 6. 結構審查清單（`mechanical-engineer` 逐條驗）

> 寫法規則：每一條都是「A 必須在 B 之前」「A 不可以碰到 B」「A 的數量／形狀必須是 X」
> 這種**看圖就能判定**的句子。**不准出現「要畫得清楚」「要好看」這種驗不動的條目。**

**L 組・電感**

- L1　一體成型那一顆的繞組**被磁粉完全包住**，側面與頂面都沒有露出繞組。
- L2　繞組的**圈數數得出來**（至少 3 圈），不是一團色塊。
- L3　扁平線的剖面是**橫躺的長方形**；對照件 A6 的圓線剖面是**圓形**。兩者不同。
- L4　端子**只在底面**，沒有畫在頂面或整個側面。
- L5　磁通迴路是**封閉的**，而且**完全走在本體之內**。
- L6　A1 與 A6 **大小相近**，差別在結構不在體積；A6 看得到**縫隙與外露的線**。

**R 組・電阻**

- R1　電阻膜的兩端**壓在上面電極之上**（有重疊），不是頭碰頭對接。
- R2　雷射修整溝**只切在電阻膜上**，沒有切到陶瓷基板。
- R3　保護層**蓋住**修整溝（溝沒有露在最外面）。
- R4　端電極由內到外是 **Cu → Ni → Sn**。Ni 畫在 Sn 外面＝不過。
- R5　端電極**把上面電極與底面電極連起來**（看得出三面包覆）。
- R6　對照件 B8 **沒有陶瓷基板**，電阻體是一整片金屬合金，兩端是明顯更厚的銅端子，
  且**畫得出四個接點**（兩個走電流、兩個量電壓）。

**Q 組・石英**

- Q1　石英片**四周與上下都沒有碰到底座或蓋子**。
- Q2　固定點**只有兩個，而且在同一端**。
- Q3　上下電極**對稱且中央對齊**。
- Q4　腔內**看得出是空的**（留白或極淡），沒有被填滿。
- Q5　金屬蓋四周是**一圈連續的焊縫**，不是斷續的點或虛線。
- Q6　對照件 C8 的 IC 畫在**底座上、石英片下方**，且**沒有碰到石英片**。

**X 組・版面與分工**

- X1　三欄**等高等寬**（誤差在 2px 以內）。
- X2　三欄**內部結構順序一致**（剖面 → 一句話 → 三行標註）。
- X3　三欄之間**沒有任何箭頭或流程線**（不得暗示上下游關係）。
- X4　圖上**沒有任何電容**（MLCC／鋁質電解／固態／鉭質），
  **沒有交錯指狀電極**，**沒有板彎裂紋**。
- X5　**只有電阻欄的零件掛 `data-seg`**；電感欄、石英欄、共同舞台、共同的尺
  **一個 `data-seg` 都沒有**（§7-D2）。
- X6　共同舞台的高度**不超過整張圖的三分之一**，GPU 只有輪廓、沒有內部細節。
- X7　底部共同的尺用**同一個比例**畫三顆，沒有各自縮放。
- X8　圖上**沒有**磁環、有骨架的變壓器、音叉型石英片。
- X9　圖上**沒有**任何廠商 logo、料號絲印或商標。

**N 組・誠實性（紅線，違反任一條就退回，不進二輪）**

- N1　畫面上**沒有任何良率數字、單價、市占率百分比**。一個都不准。

  畫面上**都附了來源或「常見值」字樣**，沒有寫成唯一標準。
- N3　畫面上同時有 §5 那兩行（非實物比例／環節不等於族群）。

✔ **卡片與幾何的落差已收掉（2026-09-26 第二批查證）**：`ind_wind` 的 3D 卡片原本寫「斷面是長方形（高 > 寬）」，
跟立繞的定義**相反** —— 立繞是扁平線的**長邊沿徑向、短邊朝內外周**（＝徑向寬、軸向薄，R1、R3），
長邊平行於軸（寬面朝外）的那種叫**平繞（flatwise）**。已改成「斷面是橫躺的長方形（徑向寬、軸向薄）」；
2D 卡片（`site/dg/power_inductor.js`）本來就寫「剖面是橫躺的長方形」，跟這個一致，沒動。
卡片最後一句「一段一段拼成的環」也一併改成「一條連續的銅帶繞上去，兩端折到底面當端子」—— 第一批已經把幾何改成連續銅帶，舊句子跟畫面對不上。

⚠ Andy 的例子提到「石英音叉晶片形狀」：那是 32.768 kHz 的音叉型；本圖卡片寫的是 **AT 切**（MHz 級厚度剪切片），
所以石英片維持長方片＋斜角，不畫成音叉 —— 畫成音叉就跟卡片矛盾。
