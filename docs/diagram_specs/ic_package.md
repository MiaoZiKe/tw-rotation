## 1. 要不要 3D —— 判斷與理由（★ 這一段要先被簽掉）

**結論：不做真 3D。`SLOTS` 的 `scene` 留 `null`。**

判準照 AGENTS.md §11：「3D 只有在『轉一圈真的能多理解一件事』時才用」。逐項對：

| 這張圖要講的事 | 轉一圈會多理解嗎 | 判定 |
|---|---|---|
| 凸塊內部的五層（UBM 三層 → 銅柱 → Ni → 焊錫帽） | **不會。** 這五層只存在於剖面；凸塊從外面看就是一顆圓柱，轉到哪個角度都一樣 | 2D 局部放大 |
| C4／µbump／混合鍵合的**尺度差**（§7-A2、A3） | **不會，而且會更糟。** 這是一條**一維的大小比較**，要靠並排的比例尺；透視投影一旦介入，近大遠小就把比較毀掉 | 2D 等比例尺度尺 |
| CoWoS-S／R／L 的差別（整片矽 vs 有機 RDL vs RDL＋局部矽橋） | **不會。** 三者的差別是「中介層那一層是用什麼做的、TSV 有沒有」，全在剖面的那一條帶子上 | 2D 三格並排剖面 |
| 底部填充的圓角（fillet）與模封包住的範圍 | **不會。** 圓角是剖面上的一條曲線；模封包不包住上表面也是剖面上的事 | 2D 剖面 |
| TIM1／TIM2 的上下夾層關係 | **不會。** 純粹是「誰在誰上面」 | 2D 剖面 |
| 圓晶圓 vs 方板的面積利用率（§7-A11） | **不會。** 這是**俯視**的二維鋪排問題，轉成立體反而看不出邊角浪費 | 2D 俯視小圖 |

**唯一一個「3D 可能有用」的候選**是「多顆晶粒在中介層上的**平面配置**（floorplan）× 垂直堆疊層數」
—— 那是真的二維以上的空間關係。但那件事**既有的 `scene: 'semiconductor'` 已經在做**
（同一條鏈上已經有一個 3D 場景），再開第二個只會讓讀者問「哪一個才是這顆封裝」。

反面成本四條，都查得到或量得到：
1. 同一條鏈開兩個 3D 場景 ＝ 兩組 WebGL context 與 rAF 迴圈（`dispose3D()` 那條既有的坑）。
2. 3D 在手機吃力（AGENTS §11 明列）。
3. 這張圖的六個資訊點有五個是「剖面上的層」，3D 只會把它們擋住。
4. 尺度尺一旦進到透視投影就失效 —— 而尺度尺是這張圖的核心（§2 的 #14）。

**什麼條件下才該回頭加 3D**（寫死，避免重演 MLCC 的事後補簽）：

> 只有當這張圖要新增以下**其中一項**，才重開這一段、改規格書、由 `mechanical-engineer` 重新簽：
> ① 多顆晶粒在中介層上的**平面配置**與光罩尺寸（reticle）限制的空間關係；
> ② SoIC **三層以上**垂直堆疊的疊放關係，且必須同時看到平面位置；
> ③ 封裝體翹曲（warpage）的**三維變形**形狀。
>
> 而且就算符合，**第一選擇是把它加進既有的 `SCENES.semiconductor`**，不是新開一個場景。
> **「看起來比較立體」「別張有 3D 這張也要有」都不算理由。**

## 2. 這張圖要回答什麼問題

**「一顆 AI 晶片被『包』起來的時候，裡面到底多了哪幾層？為什麼接點越做越小、載板越做越大？」**

使用者看完要能自己講出這四句（畫面上會把這四句印在右側說明欄的抬頭）：

1. **封裝不是「套個殼」，是多長出一整套接線**：晶粒的接點是奈米級的，主機板的接點是毫米級的，
   中間差了六個數量級 —— 凸塊、中介層、載板、錫球就是這一段**逐級放大的階梯**。
2. **「2.5D」和「3D」差在接法，不是差在堆幾層**：
   2.5D 是把幾顆晶粒**並排**放在同一片中介層上、靠微凸塊接；
   3D 是把凸塊**整個拿掉**，兩顆晶粒的銅墊直接壓在一起（混合鍵合）。
   接點越小 → 單位面積能接的線越多 → 但對平整度與潔淨度的要求越兇。
3. **中介層有三種做法，各自在換一件事**：
   整片矽（密度最高、但受光罩尺寸與成本限制）／有機 RDL（便宜、可做大、但線沒那麼密）／
   RDL＋局部矽橋（只在需要高密度的地方鑲一塊矽）。
4. **封裝體是為了「撐住」與「散熱」**：底部填充撐住凸塊、模封護住晶粒、補強環防翹曲、
   上蓋＋TIM 把熱帶出去。**這幾層一個都不是裝飾。**

**這張圖的成敗**：Andy 指著圖上任何一層，要能說出
「這一層是**誰**做的（晶圓廠／封測廠／載板廠／設備商／材料商），它變好會讓什麼變好」。
講不出這句，圖就白畫。

## 4. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 4-A 主剖面由下到上（違反其一就退回）

```
 ┌ 散熱上蓋（lid／IHS）                      ← 最外
 │   TIM2 在上蓋「之上」（通往外部散熱器）
 │   TIM1 在上蓋「之下」、只壓在晶粒頂面
 │ 模封 EMC（包住晶粒側面）
 │ ┌ 邏輯晶粒 ── SoIC 上層晶粒（無凸塊，銅對銅）
 │ │ HBM 堆疊（只畫外形）
 │ 底部填充 underfill（填滿 µbump 之間，邊緣有圓角）
 │ µbump（微凸塊）
 │ 中介層 interposer（內含 RDL；S 型還有 TSV）
 │ C4 凸塊
 │ 封裝載板（ABF 增層基板，內含 ABF 增層膜與雷射盲孔）
 │ BGA 錫球
 └ （主機板：**本圖只畫一條示意線，不畫板子**）  ← 最外
```

**硬規則**：

- **R1**　`C4 凸塊必須在中介層之下`、`µbump 必須在中介層之上`。上下對調＝不過。
- **R2**　**µbump 一定畫得比 C4 小**，C4 一定畫得比 BGA 錫球小。
  三者的大小順序 `BGA > C4 > µbump` 不准倒過來（§7-A2、A4）。
- **R3**　**混合鍵合的界面不可以有任何凸塊**。畫了凸塊就不叫混合鍵合（§7-A3）。
- **R4**　**底部填充必須有圓角（fillet）爬上晶粒側壁**，不是一條齊邊的矩形（§7-A8）。
- **R5**　**TIM1 只壓在晶粒頂面**，不准畫成蓋滿整個封裝上表面。
- **R6**　`TIM1 → 上蓋 → TIM2` 的上下順序不准對調（§7-A12）。
- **R7**　**補強環不可以碰到晶粒、也不可以碰到上蓋的中央**；它貼在載板邊緣（§7-A10）。
- **R8**　**中介層在橫向上必須比邏輯晶粒寬**（它要同時接住晶粒與 HBM），
  且**載板必須比中介層更寬**。三者的寬度順序 `載板 > 中介層 > 晶粒` 不准倒過來。
- **R9**　**TSV 只出現在 CoWoS-S 那一格與主剖面的矽中介層**；
  **CoWoS-R 那一格不准出現 TSV**（它根本沒有矽，§7-A1）。
- **R10**　TSV 畫成**細長**（深遠大於直徑），不是短胖的圓（§7-A6）。

### 4-B 凸塊內部由下到上（#14，第二常錯）

1. 晶粒上的焊墊（pad）
2. **UBM**：附著層 → 阻障層 → 濕潤層（三層，由下到上）
3. **銅柱（Cu pillar）** ← 最厚的一段
4. **Ni 阻障層**
5. **焊錫帽（solder cap）** ← 最外

**硬規則**：
- **R11**　順序不准對調。**焊錫在最外、Ni 在中間、銅柱在最內**；把 Ni 畫在焊錫外面是最常見的錯。
- **R12**　**銅柱一定畫得比 Ni 層厚**（§7-A13 的厚度量級差一個數量級以上）。
- **R13**　UBM 要**看得出是三層**，不是一條線。

### 4-C 三種中介層對照（#17，第三常錯）

- **R14**　S ＝ 有矽、有 TSV；R ＝ **沒有矽、沒有 TSV**；L ＝ RDL 為底、**局部**鑲矽橋。
  把 R 畫成有 TSV，或把 L 的矽橋畫成整片，都＝不過。
- **R15**　L 的矽橋**只出現在兩顆晶粒的交界正下方**，不准畫在晶粒正中央底下。
- **R16**　三格**必須用同一個比例與同一種畫法**，只有中介層那一層不同；
  其他層（載板、晶粒）畫成一樣，差別才看得出來。

### 4-D 流程順序（#3-D，第四常錯）

- **R17**　**晶圓凸塊（1）在接合（3）之前**。反過來＝沒有凸塊可以接。
- **R18**　**晶圓測試 CP（2）在接合（3）之前**。
  CP 的意義就是「先挑出好的晶粒再拿去接」，放到接合後面等於整個作用消失（§7-A14）。
- **R19**　**底填與模封（4）在上蓋（5）之前**。
- **R20**　流程列上要有一條**分界線**，把「晶圓廠／封裝廠做的」跟「封測廠做的」分開。

## 5. 識別特徵 ＋ 最常見的畫錯

### 5-A 一定要有的識別特徵（看到什麼才認得出是先進封裝，而不是一般打線封裝）

- **晶粒是「臉朝下」的**：接點在晶粒的**下表面**，直接對著中介層。
  **畫面上不准出現任何一條打線（wire bond）的弧線** —— 有弧線就變成傳統打線封裝，整張圖就錯了。
- **接點有三個量級**：由下到上一路變小（BGA → C4 → µbump），**一眼看得出縮小的階梯**。
  這是這張圖最重要的一個視覺事實。
- **中介層比晶粒寬、載板比中介層寬**：兩級「往外擴」的台階。
- **底部填充的圓角**：填充膠從凸塊之間擠出來、沿著晶粒側壁爬上一小段。
- **RDL 是多層、方向交錯的細線**，跟載板裡那種粗得多的線一眼分得開。
- **混合鍵合那一段的界面「什麼都沒有」**：兩塊矽之間只有一排銅墊對銅墊的接點，沒有球、沒有柱。
- **三格中介層對照的中間那格（R）沒有任何垂直的孔**。
- **方板俯視格的邊角是滿的、圓晶圓格的邊角是被切掉的殘片**。

### 5-B 最常見的畫錯（逐條對應 §6 的審查條目）

| 常見錯法 | 為什麼錯 | 對應條目 |
|---|---|---|
| µbump 畫得跟 C4 一樣大 | 整張圖的核心就是「接點逐級縮小」，一樣大就沒有內容了 | R2 |
| 混合鍵合的界面照樣畫了小球 | 混合鍵合的定義就是**沒有焊料凸塊**，銅直接對銅 | R3 |
| 底填畫成一條齊邊的矩形 | 少了圓角，就跟「一層膠」沒有區別，看不出是毛細填進去的 | R4 |
| TIM1 蓋滿整個封裝上表面 | TIM1 的作用是把**晶粒**的熱導到上蓋；蓋滿就跟 TIM2 混在一起了 | R5 |
| CoWoS-R 那格畫了 TSV | R 沒有矽中介層，TSV 是「矽」穿孔 | R9、R14 |
| TSV 畫成短胖的圓孔 | TSV 的工程難點就在長寬比 | R10 |
| Ni 層畫在焊錫帽外面 | 跟 MLCC 端電極同一種錯：阻障層一定在內側 | R11 |
| 畫了打線弧線 | 那是傳統打線封裝，跟這張圖講的是兩件事 | 5-A、C5 |
| 把 HBM 的內部層數畫出來 | 那是 `hbm` 族群的圖；而且層數會過期 | §0-C |
| 把主機板／散熱器／機櫃也畫進來 | 那是 `ai_server` 鏈，會搶掉封裝本身的版面 | §0-C |

## 6. 結構審查清單（`mechanical-engineer` 逐條驗，每條都要判得出過／不過）

> 寫法規則：每一條都是「A 必須在 B 之前」「A 不可以碰到 B」「A 的數量／大小關係必須是 X」
> 這種**看圖就能判定**的句子。**不准出現「要畫得清楚」「要好看」這種驗不動的條目。**

**S 組・主剖面堆疊**
- S1　由下到上的順序是 `BGA → 載板 → C4 → 中介層 → µbump → 晶粒` （R1）。
- S2　大小關係 `BGA > C4 > µbump`，三者一眼看得出差別（R2）。
- S3　寬度關係 `載板 > 中介層 > 晶粒`（R8）。
- S4　**沒有任何一條打線弧線**（5-A）。
- S5　晶粒的接點畫在**下表面**（覆晶朝下）。
- S6　SoIC 那一段的兩塊晶粒之間**沒有任何凸塊或球**（R3）。
- S7　底填有**圓角爬上晶粒側壁**，不是齊邊矩形（R4）。
- S8　模封**包住晶粒側面**，但**沒有把上蓋也包進去**。
- S9　補強環**沒有碰到晶粒**，也**沒有碰到上蓋中央**（R7）。
- S10　`TIM1 → 上蓋 → TIM2` 順序正確，且 **TIM1 只在晶粒頂面**（R5、R6）。
- S11　HBM **只畫外形、沒有標層數、沒有畫內部 DRAM 層**（§0-C）。
- S12　圖上**沒有**主機板、散熱器、風扇、機櫃、晶圓廠、EDA 方塊（§0-C）。

**V 組・中介層與穿孔**
- V1　TSV 是**細長**的（深遠大於直徑），不是短胖圓孔（R10）。
- V2　TSV **只出現在有矽的中介層**；R 那一格沒有 TSV（R9、R14）。
- V3　RDL 畫成**多層且相鄰層方向交錯**，線寬**明顯細於載板的線**。
- V4　三格中介層對照**用同一比例與同一畫法**，只有中介層那一層不同（R16）。
- V5　L 的矽橋**只在兩顆晶粒的交界正下方**、且**不是整片**（R15）。
- V6　三格各自有標籤寫出是 S／R／L，且**標籤講出它換掉了什麼**（不是只寫代號）。

**B 組・凸塊內部特寫**
- B1　由下到上是 `焊墊 → UBM（三層）→ 銅柱 → Ni → 焊錫帽`（R11）。
- B2　**銅柱畫得比 Ni 層厚**（R12）。
- B3　UBM **看得出是三層**（R13）。
- B4　尺度尺三根柱子**在同一個比例上**，且由左到右（或由大到小）是 `C4 → µbump → 混合鍵合`。
- B5　混合鍵合那一根**畫的不是柱子**，是兩片平面貼合、中間一排銅墊。

**P 組・流程列**
- P1　**凸塊（1）在接合（3）之前**（R17）。
- P2　**CP 測試（2）在接合（3）之前**（R18）。
- P3　**底填模封（4）在上蓋（5）之前**（R19）。
- P4　流程列上有**一條分界線**分開「晶圓廠／封裝廠」與「封測廠」（R20）。
- P5　流程列**沒有出現** IC 設計、晶圓製造、上主機板這三站（§0-C）。

**M 組・面板級對照**
- M1　圓晶圓格與方板格**在同一比例上**。
- M2　圓晶圓格的**邊角畫出被切掉的殘片**；方板格的邊角是完整的。
- M3　這一格的標籤**沒有寫任何良率、成本、市占的數字**（§7-C）。

**N 組・誠實性（紅線，違反任一條就退回，不進二輪）**
- N1　畫面上**沒有任何良率數字、成本金額、市占率百分比、產能片數**。一個都不准。
- N2　凡是帶年份的東西（CoPoS 時程、CoWoS-L 量產年），畫面上**都附了
      「來源：媒體報導，年份」或等價的時效標示**，讓它自己會過期。
- N3　畫面上有「示意圖，非實物比例」這一行。
- N4　§7-B 裡標為低信心的每一項，畫面上**都沒有寫成確定的單一數值**
      （尤其 CoPoS 的時程，§7-B2）。
- N5　畫面最底下有 §7-D1 那一行：「**先進封裝 CoWoS/SoIC 這一格目前沒有台股成分股**，
      台股的位置在封測、封裝設備與測試介面三格」。
- N6　所有節距／厚度數字**都寫成量級或區間**，不寫單一精確值（§7-B1）。
