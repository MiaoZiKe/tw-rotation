## 1. 這張圖要回答什麼問題

**「鋁電容的容量是怎麼來的？為什麼要把箔咬出洞？固態電容把什麼換掉了？」**

使用者看完要能自己講出這四句（畫面上印在右側說明欄抬頭，**只有這四句**）：

1. **介電質不是買來的，是長出來的。** 鋁箔通電做陽極氧化，表面長出一層氧化鋁，那就是介電質；
   膜有多厚由**加多少電壓**決定，所以耐壓越高、膜越厚、容量越小。
2. **容量靠「把箔咬出洞」放大。** 素箔先電化學蝕刻，把表面咬成蜂窩狀，
   同樣一張箔的**有效表面積**可以放大很多倍 —— 這一步就是這個產業的核心製程。
3. **陰極箔不是陰極。** 真正的陰極是**含浸在紙裡的電解液**，
   它鑽進孔洞、貼住氧化膜；陰極箔只是把電解液的電引出來的**集電體**。
4. **固態電容只換了一樣東西**：把電解液換成導電高分子。等效串聯電阻大幅下降，
   而且沒有液體可以汽化，所以不會鼓脹爆漿。

**這張圖的成敗**：指著圖上任何一層，要能說出「這是什麼、誰做的」。
特別是 **6175 立敦做的不是電容、是電容用的箔** —— 讀者要能從圖上看出它站在**更上游**。

## 3. 層別／順序（★ 可判定的條目，最常錯的四組全部寫死）

### 3-A 捲芯四層帶，**一個週期由下到上**

1. **陽極箔**（表面覆氧化膜）
2. **電解紙**（含浸電解液）
3. **陰極箔**（無氧化膜）
4. **電解紙**（含浸電解液）
→ 回到 1。

**P1**　★★★ **必須畫成四層一個週期，不是三層。**
三層（陽極／紙／陰極）捲起來之後，**上一圈的陽極會直接碰到下一圈的陰極** —— 短路。
**這一條不過就退回，不進二輪。**
**P2**　★★ **氧化膜只畫在陽極箔上，陰極箔上不准有那層半透明膜。**
兩面都畫＝畫成了「雙極性電容」，那是另一種產品，而且把「為什麼有極性」這件事畫掉了。
**P3**　陽極箔與陰極箔**在帶的長度方向稍微錯開**（橫向偏移），這是捲繞時避免邊緣接觸的做法。
**P4**　電解液的色塊**必須同時出現在紙裡與陽極箔的孔裡**（只畫在紙裡＝沒有接觸到介電質，電容不成立）。

### 3-B 陽極箔放大剖面，**由外到內**

1. 電解液（最外，填在孔裡）
2. **氧化膜**（貼著孔壁，等厚）
3. 鋁基體（最內）

**P5**　★★ **氧化膜必須貼著孔壁的曲面走、且等厚**，不可以畫成一條平的直線蓋在箔上面。
畫成平的就把「表面積被放大」這件事畫掉了 —— 那正是這張圖的第二句話。
**P6**　★ **氧化膜必須是全圖最薄的層**，量得出來：厚度 ≤ 箔厚的 1/20。
**P7**　蝕刻孔至少 12 個、由表面往內凹，**兩面都有**，中間留一條實心芯（沒有芯的箔會斷）。

### 3-C 整顆縱剖的位置關係

1. 鋁殼（最外）
2. 捲芯（在鋁殼裡）
3. 橡膠封口（**一端**）＋ 兩根導針（**從同一端穿出**）
4. 防爆閥刻痕（**在另一端**）

**P8**　★ 兩根導針**從同一端出來**（徑向引線型）。一端一根＝那是軸向型，跟捲芯畫法對不起來。
**P9**　捲芯的渦旋斷面**看得出四層交替**（至少數得出 3 圈）。
**P10**　防爆閥與橡膠封口在**相反的兩端**（§7-B1，畫面上標「示意」）。

### 3-D 區 D 兩格對照

**P11**　★ 兩格**只有中間那一層不同**，其餘（陽極箔、氧化膜、孔洞、陰極側）**完全一樣**。
改動其他層＝把「只換了一樣東西」這句話畫掉了。
**P12**　固態那一格的中間層畫成**實心固體**（不是半透明流體色），且**同樣鑽進陽極箔的孔裡**。
**P13**　兩格**同一個比例尺、同一套材質色**，之間用分隔線而不是不同底色。

## 4. 識別特徵 ＋ 最常見的畫錯

### 4-A 一定要有的識別特徵

- **F1 陽極箔**：**兩面海綿狀的孔** ＋ 貼孔壁的半透明薄膜。
- **F2 陰極箔**：一樣有蝕刻孔，**但沒有那層半透明薄膜**。
- **F3 電解紙**：纖維線 ＋ 半透明電解液色塊。
- **F4 捲芯**：同心渦旋，四層交替。
- **F5 整顆**：圓筒 ＋ **同一端兩根導針** ＋ **另一端一道刻痕**。
- **F6 固態格**：中間那一層是**實心**的。

### 4-B 最常見的畫錯（逐條對應 §6）

| 畫錯 | 為什麼那是錯的 | 對應審查條目 |
|---|---|---|
| 捲芯畫成三層 | 捲起來陽極會碰到陰極，短路 | K1（紅線） |
| 陰極箔也畫氧化膜 | 那是雙極性電容；而且「為什麼有極性」被畫掉了 | K2（紅線） |
| 氧化膜畫成一條平直線蓋在箔上 | 「表面積被放大」這句話沒了，整張圖的命題垮一半 | E1（紅線） |
| 氧化膜畫太厚 | 它是全圖最薄的層；畫厚了讀者會以為它是主角結構 | E2 |
| 電解液只畫在紙裡 | 沒有接觸到介電質，電容不成立 | K4 |
| 把陰極箔標成「陰極」 | **真正的陰極是電解液**。標錯就是把這張圖第三句話講反 | K5（紅線） |
| 兩根導針一端一根 | 那是軸向型，跟捲芯畫法不一致 | C1 |
| 固態格連陽極箔也改畫 | 「只換了一樣東西」被畫掉了 | D1 |

| 6175 立敦被標成「做電容」 | 它做的是**電蝕箔與化成箔**，是更上游的材料 | Y3（紅線） |

- **四層帶用一個陣列 ＋ `forEach` 畫**（`['anode','paper','cathode','paper']`），
  這樣 K1 自動成立、也改不壞。**不要手刻四個矩形。**
- **氧化膜用「把孔的 `path` 往外 offset 一個固定量」畫**，不要另外畫一條直線 ——
  offset 出來的路徑天生貼曲面、天生等厚，E1 自動成立。
- 蝕刻孔用 `for i` 沿箔的長度方向重複一個孔形，**上下兩面各一圈**，
  孔深用同一個常數，中間留的實心芯 = 箔厚 − 2×孔深（**這個減法要真的算**，不要目測）。
- 捲芯渦旋用極座標 `r = a + b·θ` 畫四條交錯的螺線（每層一條），`θ` 至少跑 3 圈（C2）。
- 兩格對照（區 D）**用同一個繪製函式、只換「中間那一層的填色與是否半透明」一個參數** ——
  這樣 D1／D3 自動成立。
- 章節列用既有的 `foldBar()` ＋ `<g class="dgbody" data-fold="…" data-y0 data-y1>`，
  **預設全部收合**，**章節列不准掛 `data-seg`**。
- 顏色一律走 `--dg-*` / `var(--c)`，不准寫死 `#xxxxxx`（AGENTS §15）。
- **`data-part` 一律要寫**。建議命名：`ac_anode` / `ac_oxide` / `ac_pore` / `ac_paper` /
  `ac_elyte` / `ac_cathode` / `ac_lead` / `ac_winding` / `ac_can` / `ac_seal` / `ac_vent` /
  `ac_sleeve` / `ac_solid` / `ac_mlcc_ref`。
- **不做動畫。**
- **SVG 的 `<style>` 裡（含註解）一律不准出現角括號**（HANDOFF 2026-09-21 的坑）。
