## 1. 這張圖要回答什麼問題

**「800G／1.6T 交換器板上到底有什麼、為什麼高階印刷電路板（PCB）的層數這麼重要。」**

使用者看完要能自己講出這三句：

1. 交換器板的拓樸是**一顆 ASIC 對上所有的埠**：一顆交換器晶片坐在板子正中央，
   上千條高速差動對從它底下呈放射狀出發，一路等長走到前面板每一個光模組。
   這跟伺服器主機板（兩顆中央處理器 ＋ 一排記憶體插槽）是完全不同的長相。
2. **層數是被訊號逼出來的，不是為了堆料**：每一層高速訊號層的上下都必須各有一層完整的
   接地參考層，否則阻抗守不住；上千條差動對塞不進少數幾層，只能往上堆。
   速率每升一級（100G → 400G → 800G），層數就再往上跳一級（§6-A5）。
3. **層數一上去，難的就不只是層數**：板材要換成超低損耗等級的銅箔基板（CCL）、
   銅箔要換成低粗糙度（HVLP）、通孔要**背鑽**掉多餘的孔柱、疊構必須上下對稱不然壓合會翹，
   而且是**多次壓合**——任何一次對位或壓合出問題，整片幾十層的板子報廢。

**這張圖的成敗**：使用者指著板子側剖面上任何一層，要能說出
「這一層是訊號還是地、拿掉它會怎樣」。看不出這件事，圖就白畫。

## 3. 層別／流向順序（★ 最常錯，四組全部寫死）

### 3-A 板子疊構（右側放大剖面，**由下到上**）

這一段是整張圖的核心，順序錯了主標題就答錯。以 **對稱的 N 層板**為準：

1. **底面外層（L_N）**：防焊 ＋ 表面處理（化鎳浸金 ENIG／有機保焊 OSP）
2. 底面外層線路（銅）
3. **接地層**（完整的銅面，不准開一堆槽）
4. 高速訊號層（差動對，帶狀線 stripline）
5. **接地層**
6. 電源層（厚銅，走大電流到第 7 項 VRM 與晶片）
7. 〔中段〕「**訊號 → 地 → 訊號 → 地**」重複 N 次
8. 電源層（厚銅）
9. **接地層**
10. 高速訊號層
11. **接地層**
12. 頂面外層線路（銅）：晶片球柵陣列銲墊、元件銲墊、扇出線
13. **頂面外層**：防焊 ＋ 表面處理

**硬規則（違反其一就退回）**：
- **每一層高速訊號層的正上方與正下方，都必須各有一層完整的接地參考層。**
  兩層訊號層直接相鄰、中間沒有地 ＝ 畫錯。**這一條就是「為什麼層數這麼多」的全部答案**，
  缺了它，這張圖等於沒回答主標題。
- **疊構必須上下對稱**（層數、銅厚、材料分布鏡像）。不對稱＝壓合後翹曲。
  畫成上半厚下半薄就是錯。
- **內層芯板（core）與半固化片（prepreg）要交替**：core 是兩面已覆銅的 CCL，
  prepreg 是把 core 黏起來的膠片。畫成「一層銅一層樹脂一路疊到頂」＝畫錯，
  那樣看不出「一片 38 層板是很多片薄板壓起來的」。
- **外層是線路層，不是接地層**；外層之外才是防焊。防焊畫在銅之下＝錯。
- 圖上畫 **12–16 層**代表 38–48 層，中段要放「⋮ ×N」省略記號，**不要假裝畫滿**（§6-C）。

### 3-B 訊號流向（前面板 → 晶片 → 前面板，**由外到內再回到外**）

1. 光纖從機房拉進來，插進**前面板光模組**（8）
2. 光模組內部把光訊號轉成電訊號（**這一步在模組裡面，不在板子上**）
3. 電訊號經**籠架的連接器**進到主板外層銲墊
4. 走**外層扇出**幾 mm 後，用**通孔（PTH）**沉到內層的高速訊號層
5. 在內層以**等長蛇行差動對**走到晶片底下（**成雙成對、兩條線長度要配對**）
6. 再用通孔升回頂面外層，進入**晶片球柵陣列**（3）
7. 晶片內部查表、決定要往哪一個埠出去
8. **原路反向**：球柵陣列 → 通孔 → 內層 → 通孔 → 另一個籠架 → 另一支光模組 → 光纖出去

**硬規則**：
- **方向是雙向、對稱的**：不准畫成「左邊全部進、右邊全部出」的單向流水線。
  交換器的每一個埠都同時收與發，箭頭要畫成雙向，或至少畫出「進來的那一條」與
  「回去的那一條」接的是**不同的埠、同一顆晶片**。
  （2026-09-19 圖十的教訓就是方向：看起來很順的那個方向不一定是對的方向。）
- **每一條高速線的兩端一定是「一個籠架」與「那顆 ASIC」**，不准有兩個籠架直接連在一起，
  也不准有線從 ASIC 走到管理用處理器（10）—— 那是低速管理匯流排，要畫成不同樣式的細線。
- **等長**：所有從 ASIC 走到籠架的線，畫面上要看得出**近的埠有蛇行繞路、遠的埠直走**。
  畫成「近的短、遠的長」就是漏掉了等長這件事，而等長正是高速板難做的原因之一。
- 飛越纜線（9）**是替代路徑，不是額外路徑**：畫了它的那幾個埠，
  **內層就不該再有同一條訊號的走線**，不然等於畫成同一個訊號走兩條路。

### 3-C 供電流向（**由後往前、由下往上**）

1. 機房交流電（或直流母線）→ 後方 **PSU**（6）
2. PSU 輸出 12 V／48 V → 板上**電源匯流排／粗銅走線**往前送
3. 進**板上多相穩壓器 VRM**（7）→ 降到 ASIC 核心電壓（**次伏特級，例如 0.8 V**）
4. 經**電源層（厚銅）與密集的過孔陣列**往上送
5. 從**球柵陣列底部**進入 ASIC

**硬規則**：
- **VRM 一定緊鄰 ASIC**，不准畫在板子另一頭。理由是電流大、壓降走不遠（§6-A9）。
  這是一個一眼就能驗的結構事實。
- **電壓由高到低是單向的**：PSU（高壓）→ VRM（降壓）→ ASIC（最低壓、最大電流）。
  順序倒過來或把 VRM 畫在 PSU 前面＝錯。
- 供電線要畫得**明顯比訊號線粗**。電源線畫得比差動對細＝錯。

### 3-D 氣流（**前進後出**）

1. 冷風從**前面板**、光模組籠架之間的縫隙吸入
2. 橫掠過光模組（光模組本身就是發熱大戶）
3. 通過 **ASIC 散熱片鰭片**（鰭片方向要**順著氣流**，不是橫著擋住）
4. 經過 VRM 與電源區
5. 由**後方風扇**（5）抽出，與 PSU 一起在機箱後方

**硬規則**：
- **風扇在後、埠在前。** 風扇畫到前面板上＝錯。
- **散熱片鰭片必須平行於氣流方向**（前後向）。鰭片畫成左右向＝擋住風＝錯。
  這是「鰭片方向」那一類最典型的結構錯誤。
- 畫面上要註明「本圖畫的是**埠側進風（front-to-back）**版本；
  實機另有反向氣流（back-to-front）機種」（§6-A10）。

### 3-E 製程順序（底部流程列，**由左到右**）

講的是第 1 項那片 38–48 層板怎麼做出來：

1. 內層芯板（core，即雙面覆銅的 CCL）線路成形 → 蝕刻 → 光學檢查（AOI）
2. **疊合壓合**（lay-up：core 與半固化片交替疊起，高溫高壓壓成一片；高層數要**多次壓合**）
3. 鑽孔（機械鑽通孔／雷射鑽盲埋孔）
4. 電鍍通孔（PTH）→ 外層線路成形
5. **背鑽（back-drill）**：把通孔用不到的那一段銅柱鑽掉
6. 防焊 → 表面處理（ENIG／OSP）
7. 成型 → 電測 → 阻抗與插入損耗抽測

**硬規則**：
- **壓合（2）一定在鑽孔（3）之前。** 先鑽再壓＝孔會被膠糊掉，這是流程圖最常見的順序錯。
- **背鑽（5）一定在電鍍通孔（4）之後。** 先有鍍銅的孔柱，才有東西可以鑽掉；
  把背鑽畫在鑽孔旁邊當成同一步＝錯，那樣看不出它是一道**額外的、專門為高速加的**工序。
- 流程列合併成 5 格即可：`內層線路／壓合／鑽孔電鍍／背鑽／防焊電測`。

## 4. 一定要有的識別特徵

看到這些才認得出這是**交換器板**，而不是伺服器主機板：

- **整面前面板被同一規格的 I/O 籠架佔滿、而且全部朝同一個方向**（上下兩列、左右排開）。
  這是第一眼的決定性特徵。伺服器主機板不會有一整面同規格光口。
- **一顆巨大的正方形晶片獨自坐在板子中央，走線以它為圓心呈放射狀向四周散開。**
  「一對多」的星狀拓樸 ＝ 交換器；「兩顆處理器 ＋ 一排記憶體插槽」的平行匯流排拓樸 ＝ 伺服器。
- **走線是成雙成對的等長蛇行差動對**，轉彎一律走 45°、不走直角，線寬一致
  （`dg3d_standard` §2-1 已經是共同條件）。**不是隨機亂畫的線**。
- **板上沒有記憶體插槽、沒有 PCIe 插槽、沒有處理器插座**；
  只有角落一小塊管理用處理器與記憶體。
- **側剖面看得出這片板子很厚、而且是一層層的**，並且看得出「訊號—地—訊號—地」的節律。
  畫成一片實心綠板＝這張圖最重要的那個答案不見了。
- **散熱片的鰭片是一片片等距的薄片，方向前後向**；不是一塊光滑的方塊。
- **風扇看得出扇葉與輪轂**（AGENTS §11 明列），在**後方**。
- **光模組看得出拉環與籠架**（金屬盒 ＋ 前端開口 ＋ 拉把），不是一排色塊。
- **CPO 那一格：光引擎與 ASIC 在同一片基板上，光纖直接從基板邊緣拉出去到前面板**
  —— 對照組（可插拔）的前面板上是**電訊號走 PCB 到籠架**。
  兩格並排、共用同一組引線樣式，差別只有「電訊號走多遠」這一件事。
- **背鑽孔畫得出「上半段有銅、下半段孔徑較大且沒有銅」**。畫成一根從頭到尾一樣的銅柱
  ＝ 沒有背鑽 ＝ 這張圖少了高速板最貴的那一道工。

### D. 掛 `data-seg` 的限制（★ 這條不照做會變成資訊錯誤）

先講機制，因為兩種掛點行為不一樣：
- 掛成**產業鏈圖**（`window.Diagrams.*`）：只有 `data-seg` 有作用
  （`industry.js` 的 `wireDiagram()` → `onSeg()`），`data-codes` **不會被讀**。
- 掛成**題材圖**（`window.ThemeDiagrams.*`）：`data-seg` 與 `data-codes` 都有作用
  （`app.js` 的 `wireThemeDiagram()`）。

**硬規則一：交換器晶片（零件 3）不准掛 `data-seg="ic_design"`。**
- 實際驗過：`ic_design` 這個環節的台股是 **聯發科、瑞昱、祥碩、聯詠**
  （`supply_chain.yaml` 的 `companies`）。`industry.js` 的 `members()` 會用
  `twOf(sc,'ic_design')` 去濾成分股；濾不到就落到空狀態文案，
  **畫面上會直接印出「這個環節的台股不在本鏈成分股裡：聯發科 瑞昱 祥碩 聯詠」**。
- 也就是說，使用者點一個標著「800G 交換器晶片」的零件，
  會看到四家**不供應這一級 ASIC** 的台灣 IC 設計公司被列出來。**那是資訊錯誤，不是不完整。**
- 另外 `ic_design` 的 `chains` 是 `semiconductor`，不是 `ai_server`，跨鏈掛本來就不成立。

## 7. 給 `tech-illustrator` 的實作邊界（不是規格，是省時間的提醒）

- 版面沿用 `semiconductor()` 的四分割：
  **左**＝速率換算尺 ＋ 一般主機板厚度對照條；
  **中**＝2.5D 等角的板子（`DG.box` 畫板體、`DG.onTop` 貼走線與元件、
  `DG.panel` 立起前面板放籠架）；**右**＝說明欄（`DG.lrow3` 引線）；
  **下**＝製程列（`DG.processBar`，5 格）。
  右下另開一小格：**可插拔 vs CPO 對照**（同一組引線樣式，差別只有電訊號走多遠）。
- `DG.box()` 只畫頂／右／左三個面、沒有深度排序，**要自己控制由遠到近的繪製順序**，
  不然後面的元件會蓋到前面的。板體先畫、`onTop` 的走線次之、立體元件最後。
- 疊構剖面用純 2D（不要等角）：一疊細長方塊 ＋ 交替填色 ＋ 中段「⋮ ×N」。
  **接地層要用跟訊號層明顯不同的填法**（例如實心 vs 條紋），
  不然「訊號—地—訊號—地」的節律在畫面上看不出來，主標題就沒答到。
- 等長蛇行差動對：用一個 `for` 迴圈，**近的埠多繞幾折、遠的埠少繞**，
  這一行就是 §3-B 的等長硬規則，寫反了整張圖就錯。
- 動畫：只做兩件事 —— ① 封包沿差動對從一個籠架進、經 ASIC、從另一個籠架出
  （`flow` 虛線，**雙向**）；② 風扇 `spin`。
  **不要讓層跑來跑去、不要讓元件浮起來**；靜止模式下走線與疊構仍然看得見。
- 800px 窄畫面要先驗（CLAUDE.md 規則）：右側說明欄在窄畫面改成圖下方堆疊，
  疊構剖面改放到板子下方而不是右邊。
- 顏色一律走 `--dg-*` CSS 變數（`dg3d_standard` §2-2），
  **JS 不准寫死任何 `#xxxxxx`**；三種色票 × 深淺主題都要驗。
