# 每日次數覆蓋稽核（2026-10-07）

> Andy（10-07）：「確實落實每個功能都被使用次數有限制到，不可以漏洞情況」。
> 做法：每個功能各開一個乾淨的瀏覽器環境，範本只設「這個功能每日 1 次」→ 打開第 1 個單位（照常看得到、計數 1）→ 打開第 2 個不同的單位 → **一定要被擋**
> （區塊蓋上「今日已用完 1/1 次」卡；只有工具鈕的功能＝按了跳卡、工具沒打開）。桌機 1440、手機 390 各一次。
> 自動掃描：`python scripts/_uitest.py --sections 次數覆蓋掃描1007`（約 12 分鐘；`TW_QSCAN_ONLY=<功能鍵,…>` 只掃幾項、`TW_QSCAN_OUT=<檔>` 存結果）。
> 結果檔（這次）：116 格全部通過、0 格不適用。

## 全站共通的修法

1. **工具鈕型功能**（指標設定、畫線、四週期同看、主題外觀）以前沒有畫面區塊可蓋 → 完全不計。現在 quota.js 在捕獲階段攔工具鈕的點擊：按一下＝用一次，用完攔下這一下、跳同款卡片。
2. **手機分段**（總覽「錢往哪跑／貴不貴／理由」、資金流向「輪動／資金去向／法人／集中度」）只換 class 不增刪節點 → quota.js 的 MutationObserver 只看 childList 時，切到下一段那張圖不會被判定。改成連 class／hidden／data-tab 一起看。
3. **手機 `.m3host`** 會用 `!important` 藏掉卡片裡「不是 .m3keep」的子節點 → 遮罩卡也被藏，只剩模糊的內容。qcard.js 加一條權重更高的規則，卡片一律顯示。
4. **單位依功能決定**：產業鏈頁上的族群總覽（一條鏈一次）與剖析圖（一張圖一次）以前共用同一個 key，切剖析圖分頁也會讓族群總覽多扣一次。

## 已知限制（照實寫）

- **前端計數按 F12 改得掉**。伺服器端真正擋得住的：個股檔（data-gw，逐功能＋全站額度）、全站額度（data-gw dq）、登入者的 `/v1/quota/hit`（回 over）。
  沒有對象的付費檔、剖析圖、題材 —— 一支檔就含全部對象，伺服器分不出看了幾個；要靠 pipeline 拆檔（docs/quota_plan.md 第 5 節）。
- **data-gw 還沒上線**（正式站現況），所以現在線上只有前端這一層。
- 手機載入時偶爾會在桌機版面閃一下（mobile3 還沒接手前），那一瞬間看得到的區塊會被算一次 —— 是「多算」不是「漏算」。
- 訪客沒有帳號：訪客的共用 3 次只存在這台瀏覽器（清掉網站資料就重來）；伺服器只能靠付費資料閘道的訪客範本開關。
