# 第九輪：大型股增強指數（前 50 大市值代理 0050 ＋ 小幅傾斜）

> **免責**：研究用，非買賣建議、不下單；純個股，不持有 0050 或任何 ETF（0050 只當含息還原基準）。

## 結論（先講）

**沒有任何候選三段都贏含息 0050，冠軍 0 組。** 共三個家族（9a／9b／9c），每個家族都是「只用訓練期決定、先凍結、再一次揭露兩個已被看過的窗口」。
最接近的是 9b 的 `roe｜m15_05`（ROE 前三分之一 x1.5、後三分之一 x0.5）：訓練 +1.3pt、2023+ +1.7pt，但 2019–2022 -0.2pt，且 t 值全部不顯著。

累計試驗：1,766（前八輪＋7b）＋ 50（9a）＋ 24（9b）＋ 18（9c）＝ **1,858 組**。

## 做法

- 股池：每月最後一個交易日收盤後，取前 50 大市值（未還原收盤價 x 財報股數，財報法定可用日才生效）。`etf_holdings` 只有 2026-10-07 起，沒有歷史 0050 成分，**所以用市值前 50 代理**。
  驗證（2026-10-22）：代理前 50 與 0050 實際成分重疊 45 檔、權重相關 0.999；但台積電代理 51% vs 實際 57%（0050 的權重含流通調整與上限規則，代理不重現），2023 年後台積電行情會讓代理略吃虧。
- 權重：市值加權 x 傾斜倍數（隔日開盤成交，月調一次）。倍數：`m15_05`（訊號前 1/3 x1.5、後 1/3 x0.5）、`m125_075`、`ex10／ex20`（排除最弱 10%／20%）、`ex20_up15`、`lin3／lin6`（連續傾斜）、`bin_up15`（達標者 x1.5）。台積電：照實，或單檔上限 20%（多出的按比例分給其他檔）。
- 成本：手續費 0.1425% x 2、證交稅 0.3%、滑價 0.1%/邊，只對實際成交差額收，窗尾平倉也收；0050 基準同樣扣進出成本與 ETF 稅。
- 追蹤誤差＝日主動報酬年化標準差；資訊比＝主動年化報酬／追蹤誤差；t 值用 Newey-West（Bartlett 核，落後 10 日）檢定日主動報酬平均 = 0。
- **訓練窗是 2013-05-02～2018-12-31（不是 2013-01）**：股數資料最早 2013-04-01 才有（2012Q4 財報法定可用日 3/31）。2013～2015 有市值的只有約 374～406 檔（回補名單）。

## 觀察

1. **基準本身就有拖累**：純市值加權的代理在兩個已看過窗口輸 0050 約 1.0／1.6pt（台積電代理權重偏低、月調成本、2013–2015 股池只有回補名單）。傾斜的 alpha 必須先補平這個缺口；所有候選的追蹤誤差 4.4%～5.4%，以 1～2pt 的主動報酬計，資訊比 < 0.35、NW t 全部 < 1.7，**沒有一個在統計上顯著**。
2. **台積電設上限一律更差**（訓練 0.0、2023+ -7.0pt）：這是賭台積電不要太強，與 2019 年後的事實相反。
3. **營收動能在大型股沒有傾斜價值**（9a 訓練期 rev 系列全負）；新高訊號略正但在已看過窗口不穩。
4. 傾斜 alpha 與雜訊同量級：訓練期好的 roe／低波動在已看過窗口時好時壞，符合「1,858 組裡挑到的最好者」的預期，不應採用。

## 限制

- 代理不是 0050：成分以市值前 50 近似，台積電權重偏低，沒有 0050 的半年定期審核與流通調整。
- 存活者偏誤沒修正；2013–2015 股池只有回補名單（約 400 檔），前 50 大都在其中，但名單本身帶事後選股痕跡。
- 已看過窗口只能當描述；9c 設計有看過 9b 的痕跡。
- 月調頻率、20%／1.5 倍等參數是事先定的少數水準，沒有網格最佳化。
