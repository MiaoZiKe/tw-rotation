> **免責**：這是歷史資料的研究回測，不是買賣建議、不是交易系統，未下單、未接券商。過去績效不代表未來；
> 所有數字都含樣本內挑選與資料偏誤，詳見「風險與偏誤」。

產生：`python pipeline/compute/strategy_lab.py pit` 與 `... cur`，再 `python pipeline/compute/strategy_lab_report.py`。
明細：`all_results_pit.csv`（主）、`all_results_cur.csv`（對照），每列一組「策略x參數x週期」，含樣本內／外／全期指標。

## 一、結論（先講）

1. 共測 **138 組**（策略家族 9 種 x 參數 x 週期 + 跨週期濾網 27 組）x 2 種股票池。
2. **沒有任何一套策略在日K、週K 的樣本外贏過同池買進持有的夏普**（主結果：日K 0/46、週K 1/37）。
   趨勢策略的價值是把最大回撤壓到買進持有的約六成（日K 約 -19% 對 -34%），代價是年化只剩約一半。
   這 2019 年後的台股是大多頭，「持有」本身很難被打敗；這不代表策略沒用，代表它們是「降波動」而非「增報酬」。
3. **4H** 樣本外有 7/55 組夏普贏過買進持有（趨勢類：SuperTrend、唐奇安、均線），年化 30-41% 對買進持有 77%，
   但最大回撤只有 -8% 至 -10%（買進持有 -23.5%）。**4H 樣本外只有 18 個月（2025-04 至 2026-10）且是單邊多頭，樣本不足，只能當線索。**
4. 均值回歸類（RSI 超賣、KD、布林回歸）在日K／週K 穩健性差（家族樣本外夏普中位數接近 0 或為負），4H 看起來還行但同樣樣本短。
   RSI(2) 這類原本為美股日K設計的策略在台股成效差，與網路上「僅適用日K、不適合盤中」的說法一致。
5. **跨週期濾網**（週K 趨勢濾網日K、日K／週K 濾網4H）：幾乎都讓最大回撤變小（主結果 26/27 組），
   但只有少數讓夏普變好（主結果 6/27），多數是把報酬一起砍掉。結論：濾網是「降風險」工具，不是「找 alpha」工具。
6. 各週期收斂後的冠軍見下方表格（按事先定好的規則選，不是挑最好看的）。**最強家族是趨勢跟隨（SuperTrend／唐奇安／均線／布林突破）**，
   且同家族參數鄰域的樣本外夏普落差小（SuperTrend 日K 0.79-0.97）= 參數不敏感，這是比單一最高分更可信的訊號。

## 三、方法與口徑

| 項目 | 設定 |
|---|---|
| 資料 | 資料湖 `price_daily`（2011-2026，日K）、`intraday_60m`（2023-09-19 起，4H 由此合成）；週K 由日K 重採樣（週五為界，標記為全市場該週最後交易日） |
| 4H 口徑 | 台股 09:00-13:30 切兩根：第一根 09:00-13:00（60m 四根合併）、第二根 13:00-13:30（30 分）。訊號在 13:00 收盤、13:00 第二根開盤成交；第二根收盤訊號隔日 09:00 成交 |
| 股票池 | 流動性（成交值中位數）前 100 檔個股，排除 00 開頭 ETF。**主結果 pit**：只用樣本內期間的流動性選股（日／週用 2018 年；4H 用 2023-10 至 2025-03），**cur**：用最近一年的前 100（存活者偏誤，僅作對照） |
| 部位 | 單檔只做多、全倉進出、不加碼、不放空；組合＝資本平分給已上市標的，空手那份報酬 0（所以「平均持倉」是各檔平均有多少時間在場內） |
| 無前視 | 訊號用收盤、次根開盤成交；ATR 停損／高週期濾網只用已完成的 K（單元測試 `tests/test_strategy_lab.py` 驗證） |
| 成本 | 手續費 0.1425% x 買賣各一次（不打折）、證交稅 0.3%（賣）、滑價 0.10%/邊。來回約 0.79% |
| 指標 | 與 `pipeline/indicators.py` 同口徑（KD 9,3,3 初值 50、RSI Wilder、MACD 12/26/9、ATR Wilder）；布林／唐奇安／SuperTrend 在 `strategy_lab.py` 自算；不用 TA-Lib |
| 樣本內外 | 日K、週K：2011-2018 樣本內、2019-01 起樣本外；4H：2023-09 至 2025-03 樣本內、2025-04 起樣本外。參數網格事先固定（每家族 3-5 組常見參數），**沒有針對樣本外調參** |
| 收斂規則 | 樣本內夏普>0 且樣本外夏普>0；樣本外交易>=200 筆；同家族同週期的所有參數變體樣本外夏普中位數>0 且最差>-0.2（鄰域不崩）；依樣本外夏普排序，同家族只取一個，取前三 |
| 基準 | 同池等權買進持有（每根再平衡）。價格未還原除權息，只還原明顯分割（0050 1 拆 4 等），故兩邊絕對報酬都低估股利約 2-4%/年，相對比較公平 |

## 四、風險與偏誤（務必讀）

1. **過度擬合**：共 138 組、挑冠軍本身就是在樣本外「選」，樣本外分數已被汙染（多重比較）。真正乾淨的驗證是之後的新資料（前向／模擬盤）。
   緩解：參數網格事先固定、看家族鄰域穩健性，而非單點最高分。
2. **存活者偏誤**：pit 池用 2018 年流動性選股，但下市／被併購股票若不在資料湖，仍會高估；cur 池偏誤明顯（買進持有年化 44% vs pit 20%）。
3. **牛市偏誤**：2019 以後是台股大多頭（AI 行情），趨勢策略的樣本外未經歷過長期空頭（僅 2022 一年）。4H 樣本外只有一段多頭。
4. **4H 樣本不足**：只有 3 年資料、樣本外 18 個月；冠軍數字（夏普 2+）絕對不可外推。
5. **執行落差**：未模擬漲跌停鎖死買不到／賣不掉、成交量衝擊（前100大流動性夠，但小型股的最慘單出場可能更差）、除權息日價差、融資券、當沖稅減半。
6. **失效條件**：趨勢策略在盤整震盪（假突破連續停損，勝率僅 31-45%、靠賺賠比 3-5 倍撐）與急跌後 V 轉（出場晚、進場晚）會失效；
   均值回歸策略在單邊下跌時接刀。最慘的單筆損失多在 -20% 至 -45%（見各冠軍的最慘五筆）。
7. 勝率低（日K 冠軍約 38%）是趨勢策略的正常形態，賺賠比 3-4 倍；心理上要能承受連續停損，這一點回測不會告訴你。

## 五、下一步建議（需要什麼）

- **前向模擬盤（paper trading）**：每日盤後用同一支 `sig()` 產生訊號表（日期／代號／進場價／出場價），隔日開盤價記帳，累積 3-6 個月再與回測比對；不需要任何券商 API，只需要資料湖每日更新（現已有）。
- 補強資料：取得還原股價（含股利）、含下市股票的完整歷史、更長的 60m 或分 K（4H 至少涵蓋一段空頭）。
- 驗證加強：滾動 walk-forward（每年重選參數）、Monte Carlo／區塊重抽樣的信賴區間、依市場狀態（大盤月線上下）分段報告、部位上限（同時最多 N 檔）與資金曲線版本。
- 接券商 API 之前需要：Andy 選定券商、API 與沙盒／模擬環境、風控規則（單檔上限、日損失上限、斷線處理）、金鑰管理（只放 Secrets，不入 repo）、下單前人工確認機制；且前向模擬盤需先通過。
