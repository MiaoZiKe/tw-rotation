## 0. 先交代：price_daily 讀檔問題查清了

- 症狀：`pd.read_parquet('data/price_daily')` 報 `Float value ... truncated converting to int64`。
- 根因：`year=2026` 分區的 schema 與 2000~2025 不同。2026 多了 `name`、`px_source` 兩欄，且 `volume`／`turnover`／`transactions` 由 int64 變成 double，內含小數值。資料夾整批讀入時以第一個分區的 int64 合併，遇到小數就失敗。`dividend` 另有一個類似問題（`year` 欄 int64 與 dictionary 型別衝突）。
- 繞法（已用在腳本）：逐檔 `read_parquet` 再 `concat`。
- 治本建議：寫入端（`store.append()`）在欄位型別漂移時要統一 cast（量與金額一律 double 或一律 Int64），否則下次年度分區換新，所有只讀整個資料夾的腳本都會壞。這是資料層的 bug，我沒有改既有檔案，列給資料負責人。
- 副產品：0050 在 2025-06-18 一拆四（188.65 -> 47.57），前面價格要除以 4；`etf_dividend_events` 的 0050 現金股利只有 2009 起，**2003～2008 沒有股利資料**，所以自建含息報酬只有 2009 起可信。
- 對帳成功：我自建的 0050 含息年化 2017~20 為 18.4%、2021 起 27.7%，與前輪引用的 18.3%／27.6% 差 0.1 點。基準口徑可信。

## 3. 五個爭議的裁決

1. **正二核心怎麼抱**：裁決——**單一規則不可信，不要把成敗押在 200 日線上**。理由：`alloc` 的滾動 3 年 12/21、`trend` 的訊號來源敏感度（B 段 +2.9 對 -10），以及我在台指期上獨立得到同樣的現象（滾動 8/15 對不擇時 11/15）。我支持「持有為底、只在災難停損」（trend／skeptic 的共通交集），但災難停損的保護力必須量化，目前沒有（我的立場：假說）。
2. **每一段都要贏怎麼定義**：裁決——**同時要求固定四段（含 2003-07～2007 這個少被看過的大多頭）與滾動 3 年勝率 >= 2/3**，滾動 3 年為下限（更短的窗口雜訊太大）。一段最短 3 年。理由：固定切段我 F1 過 4/4、滾動只有 8/15 = 53%，說明單用固定切法會高估，單用滾動又會被單一年份主宰。
3. **台指期要不要取消平均曝險 <= 1.2**：裁決——**取消，改為明講的風險預算：最大回撤與最大曝險由 Andy 決定。**理由：1.2x 在 2021 起邊際只 +0.3 點；1.3x 是最小的「有餘裕」曝險（+2.4）。我的表格證明曝險才是旋鈕。代價：1.3x 全期回撤 -68%，比 0050 的 -59% 差，Andy 若不接受就沒有純期貨解。
4. **1 倍台指期輸 0050，是股利還是台積電 beta**：裁決——**兩者都有，約 55% 是權值股 beta，約 45% 是股利／carry 差**。證據（第 1 節腳本 (B)）：2021 起加權價格報酬 21.7%、0050 價格報酬 24.1%（差 2.4 點，是台積電集中度）；0050 殖利率約 2.1～4.1%/年；我的 1 倍期貨比加權價格多出的 carry 約 1.8 點（23.5% 對 21.7%），0050 含息 27.7% 對價格 24.1% 的股利貢獻 3.6 點，差 1.8 點。合計 4.2 點，與 1 倍輸 4.1 點吻合。2017~20 則是 0050 價格 14.3 對加權 12.4（差 1.9 點），輸家幾乎剛好被股利差抵銷（我的 1 倍 18.3% 對 0050 18.4%）。結論：**差距是會隨市場結構變動的**，在台積電權重大幅攀升的 2021 後才擴大；因此不能把「1x 輸 0050」當結構定律。
5. **個股衛星：投信是否只是動能影子**：我不做個股，**裁決：沒有證據支持它是獨立訊號**。chips 自己的數字（投信濾網沒提高平均報酬 36.1% vs 35.6%，只降低 2021 航運依賴 102.8% -> 48.0%）正是動能影子的樣子：同一批強勢股被同時買超，濾網只換了持股的樣貌。除非 chips 補上「控制動能後的偏相關」，否則不採信。（我對個股的判斷是局外人意見，標為意見而非證據。）
6. **多重比較**：裁決——**目前沒有任何人拿出過 Bonferroni 門檻的證據**，包含我。我的台指期結論只依賴「單調的曝險效果」而非挑出的參數格，這是我少數站得住腳的特點。S2 的 t 值 1.4～2.1 同意不顯著。

（註：任務書的五個爭議中，第三項「台指期」含三個子題，我把「取消 1.2 倍上限」與「股利或 beta」分成第 3、4 條各給裁決，所以共六條；口徑差異的裁決見第 4 節驗證 1。）

## 5. 最終方案

### 5.1 台指期方案 F2：靜態 1.3 倍 + 回撤熔斷（不用均線）

規則（照做會做出同樣的單）：
- 標的：台指期（TX）近月；權益 = 帳戶淨值。
- 目標曝險：**1.3 倍名目**。口數 = 取整（權益 x 1.3 / （指數點 x 200 元））。
- 進場：一次建立（可分 3 日各 1/3，降低單日時點風險，**分批本身未回測**）。
- 調整：每個月結算日後第一個開盤重算口數，使曝險回到 1.3 倍；偏離不到 0.15 倍不動。
- 展期：結算日前一個交易日收盤前換到下月契約（結算日 -18bp 的額外成本我無法繞過，已含在回測）。
- 停損：無個別停損、不用均線。
- **組合層熔斷（未回測，假說）**：權益自高點回檔 >= 25% 時，曝險降到 0.7 倍；權益回到前高 -10% 以內才恢復 1.3 倍。熔斷以收盤判斷、隔日開盤成交。
- 停利：無。
- 風控底線：權益 >= 原始保證金 x 4；低於即減到 1.0 倍。
- 證據：全期 2009 起年化 23.0%、2017~20 +5.1、2021 起 +2.4、2003-07~07 +5.6、2008~16 +2.8（表格 3.2 與驗證 3），四段全過；滾動 3 年勝 10/15（67%，剛好到我定的 2/3 下限）。
- 預期（誠實版）：年化比 0050 高約 3～4 點，回撤 -39%（2009 起）到 -68%（含 2008），逐年約 11/18 勝。若 2021 後的台積電紅利消退，優勢會縮到 1～2 點；若 1.3 倍的回撤不被接受，**純台指期沒有穩定贏 0050 的方案**。
- 失效盤勢：長時間盤整下跌（2008 型）與 V 型急殺急彈（2020-03）下，1.3 倍會比 0050 多虧 30%；沒有均線保護，必須靠熔斷與人（Andy）的紀律，這是這個方案的最大風險。
