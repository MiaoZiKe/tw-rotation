## 1. 視角與核心信念

1. 台指期的優勢不在「猜方向」，而在**它是一條便宜、可調節的 beta 管線**：保證金約 1/6、換月後長期持有等於領股利、成本單邊約 3 點（約 0.01～0.03%）。
2. 前六輪把問題問成「1 倍或 1.2 倍曝險能不能贏 0050」，並且把「平均曝險 <= 1.2」寫成冠軍條件（`docs/futures_lab/round6/README.md` 標題與〇節）。**這個上限是研究者自設的，不是 Andy 的規則。** Andy 的規則是：純台指期年化高於含息扣成本 0050，每段都要成立。曝險多少是風險預算問題，不是資格問題。
3. 部位大小與回撤紀律的影響力大於進場訊號：我的實測顯示，同一條 200 日線濾網，只改曝險倍數（1.0x -> 1.5x），最差一段的差距就從 -5.4 變 +5.1 個百分點（見第 3 節表格）。訊號挑一千種都比不上這個旋鈕。
4. 微結構只當加分，不當主力：結算日、夜盤、選擇權資料在 repo 內樣本都短或已被窺視（見第 4 節）。

## 2. 個股（可搭配 ETF）

我不做個股，只提一個**與期貨連動的組合假說（未驗證）**：把期貨保證金以外的約 5/6 閒置現金改放 0050，期貨只當 0.5 倍 overlay，等於「0050 + 0.5x 台指期」。這是合規的「搭配 0050」做法，年化應 ≈ 0050 + 0.5 x（加權報酬 - 現金利率）。**假說，我沒有驗證**（本容器 `price_daily` 讀取失敗，且 0050 的券商可否充當保證金需查期交所規定，我不知道）。若成立，它比單純買正二少了每日重設耗損，但仍有 1.5 倍 beta 的回撤，不是免費午餐。

## 3. 台指期：我主張的方案

### 3.1 方案 F1（建議）：200 日線「軟降槓桿」

規則（任何人照做會做出同樣的單）：
- 標的：台指期（TX）近月，日盤；訊號用加權指數（TSE）收盤價。
- 每日收盤後判斷：加權收盤 > 其 200 日均線 -> 目標曝險 **1.5 倍名目**；否則目標曝險 **1.0 倍名目**。
- 隔日開盤成交，調整到目標口數（口數 = 權益 x 目標倍數 / （指數點 x 200 元））。差距不足 0.25 倍就不動，避免碎單。
- 結算日（每月第三個週三）不特別處理，持倉過結算日、近月轉下月。
- 不設個別停損（曝險已被趨勢降下來）；**組合層級硬規則**：權益自高點回檔 >= 30% 時降到 0.5 倍，回到前高 -15% 以內才恢復（這條**未回測**，列為假說，見第 6 節驗證 2）。
- 保證金：權益永遠 >= 2.5 倍原始保證金；實際上 1.5 倍名目只用掉約 1/4 的權益做保證金。
- 預期：全期年化約 18%，最大回撤約 -64%（與 1.3 倍永遠持有 -68% 同級）。

### 3.3 誠實的解讀

- **1 倍本身就是輸在最近一段**：持有 1x 在 2021 起輸 0050 4.1 點。這不是訊號問題，是 0050 台積電集中度比加權指數更強的結構性落差（`docs/futures_lab/round4/README.md` 同樣量級：23.2 vs 27.6）。前六輪花五輪調訊號去補這 4 點，方向錯了；補這 4 點最便宜的是 0.2～0.3 倍額外曝險。
- **能過四段的只有「曝險足夠 + 趨勢只降不空」**：沒有任何「趨勢濾網降到 0」的版本四段全過（上 1.5x/下 0x：2003-07~07 只有 5.2%，差 -6.5）。原因是 2004～2005 區間盤整，200 日線來回洗。
- **回撤沒有被濾網救到**：F1 回撤 -64% 與持有 1.2x 的 -65% 幾乎一樣，因為 2008 的下跌發生在濾網降到 1.0x 之後仍有 1.0x 曝險。要壓回撤只能降到 0.5x 以下，而那會讓 2003-07~07 掉隊（-1.7）。**這是一個沒有免費解的取捨**，我不會宣稱找到了。
- 規格上 F1 算是「通過」，但最大回撤 -64% 比 0050 同期（`lev_lab` 記載 -59%）還差。Andy 若把回撤也算進「長期致勝」，F1 不是最優，只是最不吃虧的一個。我把決策交給委員會：**要贏 0050 的年化，就必須接受約 1.3～1.5 倍 beta 的回撤，這是算術。**
- 單日風險：現貨最慘日 2025-04-07 -9.7%；1.5 倍單日權益損失約 -14.5%，2 倍約 -19.4%；期貨日內最大不利偏移約 -10%（2025-04-07、2024-08-05、2017-08-03）。保證金追繳在權益 >= 25% 時不會發生，但 2 倍搭配 -85% 回撤就會逼近強平，**我不建議 2 倍**。

## 4. 前面各輪最大的錯誤或盲點

1. **自設 1.2 倍曝險上限是方法論偏誤。** `docs/futures_lab/round6/README.md` 以「平均曝險 <= 1.2」當冠軍條件，直接把「槓桿 1.3 倍」這條最便宜的補差路徑封掉。我的表格顯示單純持有 1.2x 在 2021 起只贏 +0.3，1.3x 贏 +2.4、四段全過，且比 round6 最接近的候選（`R6 T+SM`，最差一段 -1.7）好。六輪研究最終結論是「沒有冠軍」，部分原因是題目被限縮，不是策略空間真的空。
2. **把「1 倍輸 0050」歸因給訊號太差。** 輸的主因是 0050 的台積電 beta 比加權指數強（約 4 點/年，最近一段），訊號層面（旗標、投票、分批減碼）在 round6 的邊際分析中大多沒有一致貢獻（`round6/README.md` 第一節：「+分批減碼」「+動態曝險」多數讓差距更差）。投入三輪調訊號，報酬率不比調曝險倍數有效。
3. **成本與資料口徑沒有完全對齊，不同輪的 1x 持有結果差到 2 點。** 我的 1x（隔日開盤成交、單邊 3 點、現金 1%）在 2008～2016 是 6.3%，而 round4/5 記載 3.7%/4.2% 附近（`round4/README.md` 影響表）。差距我沒查清（可能是成本口徑、現金利息、結算日處理），**意味著所有輪次的「差幾個百分點」都有至少 1～2 點的口徑不確定**，而冠軍／淘汰判斷經常就卡在 1～2 點。需要一個共用引擎對帳（見第 6 節）。
4. **結算日當天 -18bp 的處理被當成「真實損益」保守保留，但我測的結算日空手版本結果不一致**（上表最後一列：2008～16 +1.1，2003-07~07 -3.3，2021 起 -2.9），所以那 -2.2%/年並不是穩定可繞過的成本。round6 第四節的「提早一天換月可多 +2.5 點」是假設上限，需要真正的遠月合約資料才能驗證，目前資料湖（連續近月）驗不了。
5. **窺視問題**：2017～2020 與 2021 起兩段在 round5/6 已被反覆看過。我的新數字同樣落在這兩段，所以也不是乾淨證據。真正能驗證的只有未來資料（2027 後）與 2003-07~2007（early，各輪少用）。
