# 策略委員會 第一回合立場書：trend（趨勢跟隨／多週期技術分析）

> 研究用，非買賣建議、不下單。凡沒有數字佐證的句子都標「假說」。

## 1. 專業視角與核心信念

- 價格已經反映所有資訊；我不預測，只跟隨。順勢、截斷虧損、讓獲利奔跑。
- 週K 定方向、日K／60 分 K 找點；SMC（結構破壞 BOS、供需區）只用來決定「在哪裡進、在哪裡認錯」，不用來決定「要不要做」。
- **最重要的趨勢不是個股，是指數本身。** 台股 2015 起的超額報酬集中在權值股長多（0050 2021 起含息年化 28.9%，見下方回測），任何偏離指數的選股都在跟一個極強的趨勢對賭。趨勢派的第一原則是「別跟最強的趨勢作對」，所以我主張**用槓桿吃指數趨勢，而不是用選股找趨勢**。

## 3. 台指期主張

證據：`futures_lab/round6` 最接近的 R4 W+DD（週線＋回撤出場、base 1.2 倍）最差一段 -1.6 點；而**「基準 持有 1.2 倍」最差一段 -1.9 點、平均 +0.6 點**，幾乎和所有擇時規則打平。翻成趨勢派的話：前六輪所有擇時都只是在「1.2 倍持有」附近擺動，差距不是擇時能補的，是**曝險倍數**的問題。

主張：
| 項目 | 規則 |
|---|---|
| 部位 | 名目曝險 **1.3～1.4 倍**常態做多（假說：補足 1.2 倍的 -1.9 點缺口；需驗是否觸犯「平均曝險 ≤1.2」冠軍條件——若條件不改，台指期在現有規則下我判斷**結構上無解**） |
| 出場 | 加權指數週收盤跌破 40 週均線 → 降到 0.5 倍；不做空（`futures_lab` README 多空版全數更差、`wu` 多空版保留期 -2.2%～-3.1%） |
| 回場 | 週收盤站回 40 週均線 → 回到常態倍數 |
| 進場細節 | 日K 回測前波突破點或 60 分 K BOS 才加碼（假說，資料湖只有現貨 60 分代理約 3 年，見 `wu/README.md` 但書） |
| 換月 | 依 `round4/round5` 修正後的換月口徑 |

預期：若曝險上限允許 1.4 倍，預期最差一段約 0～+1 點（假說，依 1.0→1.2 倍提升約 2.9～3.0 點的線性外推）；若不允許，承認台指期無法在三段都贏 0050。

## 4. 前面各輪最大的錯誤或盲點

1. **把「贏 0050」當成選股問題，其實是曝險問題。** `round1~7` 加 `factor_lab` 累計 1,445 組個股試驗 0 冠軍（`factor_lab/README.md`），而沒有任何參數的買進持有正二三段全過（`lev_lab` 第 1 點）。最強訊號一直擺在眼前卻花了大部分算力在選股。
2. **濾網的成績被當成穩健結論，但它對訊號來源極敏感。** `lev_lab` 用加權指數得 B 段 +2.9，我用 0050 收盤得 -11.0（本文 2.1）。同一個 200 日線想法，換個輸入差 14 點，代表「事後挑選 2」不能當推薦，只能當候選。
3. **台指期的冠軍條件互相打架。** 要求「平均曝險 ≤ 1.2」又要求「三段都贏含息 0050」，但期貨本身不含息，1.2 倍持有本身就輸 -1.9 點（`round6`）；所有擇時只是在這條線附近擺動。條件設定已經決定了結論，再加家族也不會變。
4. **SMC／60 分 K 從未被真正測過。** `wu` 主結果是日K 版（資料湖沒有台指期 60 分 K），所以「日K 找點」這一層到現在仍是假說，不能說趨勢派的進場工具已被否證。

## 6. 下一步必做驗證（資料湖做得到）

1. **訊號來源敏感度**：同一套 200 日／40 週切換，分別用加權指數（`index_ohlc`）、0050 未還原、0050 還原含息三種輸入跑 2015~2020，量化差距；若差距 >5 點，所有濾網類候選降級為「不穩」。
2. **災難停損（40 週均線 ＋ 52 週回落 >20%）回測**：在 `lev_lab` 同一套 A／B／C 三段（A 用代理序列）跑，檢查是否三段仍過 1.5 倍門檻且 2008 回撤明顯低於 -83%。
3. **台指期曝險倍數掃描**：用 `round5` 修正後引擎，持有 1.2／1.3／1.4／1.5 倍＋週線 40 週減碼，算三段最差差距；據此讓委員會決定「平均曝險 ≤1.2」是否該改，或正式宣告台指期無解。
