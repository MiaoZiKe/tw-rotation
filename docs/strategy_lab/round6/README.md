## 四、為什麼停在這裡（誠實的統計理由）

- 累計 858 組變體、1716 次評估。訓練期兩池都通過篩選的有 11 組（占本輪 246 組的 4.5%），**內部保留 0/3 全軍覆沒**，與「訓練期通過只是運氣」相符。
- 內部保留已經被看過。若我現在針對「為什麼失敗」改設計（例如修濾網的反應速度）再去選，就是用保留期的資訊調參，結果不再是乾淨證據。
- 最終保留 2023～2026 尚未打開（`holdout_log.csv` 沒有最終保留紀錄），除非有新的、**不是從 2019～2022 失敗中學到的**候選，否則不應該打開它。
