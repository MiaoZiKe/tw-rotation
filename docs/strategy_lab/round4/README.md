## 一、結論先講

1. **衛星個股在這套規則下全部拖累 0050**：衛星 20% 的版本樣本外輸 6.0～11.9 個百分點，衛星 40% 輸 12.1～23.0 個百分點，衛星越大輸越多。
   也就是說「用一部分資金追強勢族群個股」平均而言**不如把這部分資金放在 0050**。
2. **「大盤分數極低才降水位」幾乎從不觸發**：重新縮放後的大盤分數平均 7.1，分數 < 2 的日子 1348 天中只有 1 天（樣本外那一天），所以「極低降水位」與「核心永遠滿倉」結果幾乎一樣；
   0050 + 極低降水位（無衛星）與純 0050 的差只有 0.1 個百分點；純 0050 引擎與 0050 基準逐位相同，確認比較基礎一致。第一層在這個用法下等於沒有作用。
3. **停損放寬／回檔進場有幫助，但不夠**：5 ATR 或 3 ATR 收盤確認配回檔進場，衛星 20% 的版本離 0050 約 6 個百分點，已比第三輪（以現金為底、差 35～48 個百分點）接近許多，但沒有一個正規版本追上 0050。
4. **機械式分群（滾動殘差相關、階層式平均連結、每月重分、只用過去 120 日）沒有事後偏誤，但在樣本內也沒有可用的預測力**：四個族群子項的 5/20 日 IC 全部 ≤ 0，與法定產業別一樣。
   所以在去掉事後偏誤後，「由大到小」的第二層（找強勢族群）沒有證據支持。第三輪看到的族群貢獻確實主要是分類的事後偏誤。
5. **walk-forward 串接樣本外 43.7% vs 0050 46.6%（差 2.9 個百分點）-> 淘汰**；四段贏大盤 2/4（2025、2026），但贏幅只有 +0.3、+1.9 個百分點，輸的兩段（2023、2024）分別輸 0.1、9.0 個百分點。

## 二、這一輪做了什麼

| 項目 | 做法 |
|---|---|
| 核心／衛星 | 0050（還原含息價）預設滿倉；衛星最多 6 檔，總預算 S（20% 或 40%），每檔 S/6，買衛星時從 0050 賣出等額；大盤分數 < 2（極低）時核心降到 50% 並停止新增衛星。核心再平衡容忍帶 3%，ETF 證交稅 0.1%，滑價 0.1%/邊 |
| 停損 | 兩種：(a) 5 ATR 盤中觸價（收盤算出停損價、只上移；隔日開盤跳空破價用開盤價、盤中觸價用停損價）；(b) 3 ATR **收盤確認**（收盤跌破才隔日開盤出）。開盤高於前收 1 ATR 的進場取消 |
| 進場 | 兩種：「回檔進場 PB」＝20 日線 > 60 日線 且 收盤 > 60 日線，近 3 日最低價碰到 20 日線，今天收回 20 日線之上且高於昨收，出場＝收盤跌破 60 日線；「突破 ST」＝SuperTrend(7,3) 轉多＋量 > 1.2 倍 20 日均量 |
| 分群 | 每月第一個交易日，用截至前一日的 120 日「去除等權大盤後的日報酬」相關係數，階層式平均連結分成 20 群，少於 3 檔者不入群（平均 16.9 群、194 檔有分群）；對照＝證交所法定產業別（company_info）。分數 = 相對強度 3 + 法人買超 3 + 成交比重上升 2 + 營收動能 2 的群間百分位，EMA(5) 平滑，前 5 群合格 |
| 子項檢驗 | 與第三輪相同的 IC／t 值，**但修正第三輪的輕微洩漏**：檢驗窗結尾提早 30 個日曆日，避免未來 5/20 日報酬跨過切點 |
| walk-forward | 四段擴展窗（測試 2023／2024／2025／2026 年初至今），每段重估子項；在 8 種組合（進場 PB/ST × 衛星 20/40% × 停損 5ATR 觸價/3ATR 收盤確認）中選**訓練期超額年化（對 0050）**最高者；每段與 0050 同窗比 |
| 補資料 | 抓不到（出口代理 403、沒有金鑰）；已寫好一鍵腳本，見 `data_fetch_log.md` |

  **勝率低（28%）靠少數大贏家撐（賺賠比 6.8 倍）**，但贏家被 40% 的衛星預算稀釋到對整體幾乎沒有貢獻；虧損筆數多，成本（來回約 0.8%）吃掉大部分。

整體需要檢討：
1. **衛星 alpha 不存在或小於成本**：每筆平均虧損、勝率 28%，衛星越大整體越差。回檔進場／突破進場在多頭股市裡追不上直接持有大盤。
2. **第一層分數沒有用**：極低門檻幾乎不觸發，降水位機制等於沒有；而且分數子項在樣本內沒有統計上可證明的預測力。
3. **第二層族群**：去掉事後偏誤後沒有預測力；兩種分群方式在樣本外差約 1 個百分點。
4. **沒有任何一個版本在樣本內（含 2022 空頭）贏過 0050**（2022 年單年衛星版本反而輸更多），所以也沒有「空頭保護」的賣點。

## 六、限制

- 資料：VIX、事件日曆、更長的法人期貨歷史**沒補到**（網路不通），所以大盤子項的樣本內仍只有 2021-04～2023-12 的約 2.7 年，統計力有限。
- 股票池是 2020 年成交值前 200 檔（避免事後偏誤）；仍有存活者偏誤（下市股可能不在資料湖）。
- 名義通過者是在 22 個變體裡以樣本外挑出，存在多重比較問題；WF 的選擇準則（訓練期超額年化）全為負，等於選擇沒有訊號。
- 4H 未做；漲跌停鎖死未模擬；0050 基準於窗首買、窗尾賣。
