## 回放與前向的界線（重要）

  這段已被第五輪的資料看過（第五輪樣本外含 2026 年），所以本來就不乾淨。
- **前向**：2026-10-23 起資料湖新增的交易日才算成績。目前前向交易日為 0，沒有任何成績可言。

## 事先寫好的前向判讀規則（不得事後更改）

1. 前向至少累積 6 個月、且至少經過 2 次換股，才做第一次判讀。
2. 判讀標準與前幾輪相同：前向累積報酬 < 同期含息、扣成本 0050 -> 淘汰；同時列最大回撤與夏普，但不能豁免。
3. 三組是「同一批想法」，多重比較只算一次，不能挑其中最好的一組當冠軍；三組都贏才算有證據，只有一組贏視為運氣。

## 限制

- 季末訊號日的「預告」在資料湖還沒有隔日資料時以營業日推算；遇到未預期的假日，隔天重跑會以資料定義的訊號日為準，不影響帳務重放。
- 無法模擬漲跌停鎖死、流動性衝擊、除權息實際入帳時點（價格已還原含息）。
- 資料湖必須每天更新；若某天資料缺漏，該日權益沿用前一日價格。
