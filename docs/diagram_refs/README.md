## 翻成規格（給 style-3d／style-system／逐張改造的人）

### 3D（科技＝暗、閱讀＝亮，**兩個都要有顏色**）
- 托盤依語意上色：訊號／網通＝藍、運算 PCB＝**綠板**（板上元件看得到）、電力／風扇＝橙、液冷迴路＝青綠發光、機構＝霧面玻璃。
- 閱讀模式：底 `#F4F3EF`～`#F8F9FA`，托盤與水管**保留中等飽和**（不是灰掉的粉彩），流動線可有**柔光**（強度約科技模式的 40%）。
- 科技模式：底 `#080C14`→`#0E1626`，風扇／接口／走線／水路發光，AO 與陰影壓出層次。
- 卡片：亮＝白底圓角、深灰字、公司名膠囊有淡色底；暗＝半透明深色 HUD、發光端點。編號圓點保留（參考圖沒有編號，但我們卡片多、要對得到元件）。

### 2D（全部 17 張的視覺語言；是不是「爆炸層疊」看主題）
- **材質語言一律套**：厚度＋圓角＋半透明漸層的「玻璃板」、少量發光（只給流動與光束）、卡片＋引線＋端點。
- **構圖看主題**：層疊／組裝類（面板、MLCC、HBM、CoWoS、ABF、PCB、矽晶圓、CCL）走等角爆炸層疊；迴路／流程類（液冷迴路、電源鏈、製程流程）維持示意圖構圖，但元件用同一套玻璃／漸層材質。
- 亮色版＝米白底＋柔陰影，暗色版＝深藍底＋發光；兩版**構圖相同、只換材質與光**。
- 效能：發光濾鏡只給靜態元素或少數流動線（#239 的限制不變）。
