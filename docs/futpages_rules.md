## 資料合約
- `site/data/fut_oi.json`：`dates／taiex／foreign／trust／dealer`（各有 `long／short／net`，單位口，淨＝多−空）。

- `order` 為 `desc` 時前端自己反轉成由舊到新。任一份讀不到 → 該區顯示「資料準備中」，不報錯。

## 共用互動
- 期間鈕一組（1月／3月／6月 預設／1年／3年／5年／全部），資料不夠長的反灰並在圖上方寫原因；微台資料比台指期短，微台區會註明「資料自 YYYY-MM 起」，不反灰整組。
- 兩張圖共用同一條日期軸（兩份資料日期聯集）；滑過任一張圖、任一個表格列，另一區的圖（垂直標示線）、表格列（`.hl`）、大數字都換成那一天；點一下鎖定（`.sel`、實線），再點同一天或換期間時不在範圍內就取消（style_guide §18）。

## 自動解讀規則（只陳述資料，不給買賣建議）
台指期三大法人（外資、投信、自營商各一句）：
1. 最新淨部位的正負號連續幾個交易日相同 → 「淨多／淨空｜連續 N 日○○台指期淨部位偏多／空（目前淨多／空 X 口）」；淨部位剛好 0 → 「持平」。
2. 外資淨部位較前一交易日增加／減少多少口。
3. 所選期間起點到最新的外資淨部位變化。
4. 三大法人合計淨部位及正負。

微台指散戶多空比：
1. 多空比連續同號天數 →「偏多／偏空｜連續 N 日散戶偏多／空」。
2. 所選期間起點到最新：多空比變化（pp）與加權指數漲跌（%）若方向相反 →「分歧」，相同 →「同向」。
3. 位階：最新多空比在所選期間內的百分位（比它低的筆數 ÷（筆數−1））。

## 口徑
- 散戶多（空）單＝全市場未平倉－三大法人同方向未平倉；多空比＝（多單－空單）÷ 全市場未平倉 × 100%。是近似值（大額交易人會被一併當散戶）。
- 顏色照台股慣例：多／正紅、空／負綠。
