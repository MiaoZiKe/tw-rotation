Andy 11-07 原話：「每日簽到功能，這功能需要你幫我去發想，請專業的企劃思考如何留住讀者，並且我能提供什麼好處給他們比較妥當？」

## 0. 先講結論（我的判斷）

建議做**方案 B「簽到＋三句話＋Plus 天數券」的精簡版**，分兩步上：先上簽到與內容（約 3.5 工作天），觀察兩週數據，再開 Plus 天數兌換。
核心理由：**簽到本身不留人，「簽到之後馬上看到今天資金往哪跑」才留人**；好處只給「確定、小額、有上限」的東西（不抽獎、不現金、不實體），而且**不給已付費的人 Plus 天數**，避免傷轉換。

### 2-3 金融網站發獎勵的法規風險

| 事實 | 來源 | 信心 |
|---|---|---|
| 投信投顧法 §4、§107：收費對有價證券提供分析意見或推介，未經許可有刑責。網站內 B 類功能（今日關注、選股完整名單、AI 分析）本來就是紅區，**簽到獎勵不能再加碼 B 類功能的使用量** | `docs/launch_gap_legal_1009.md`、`docs/legal/20261101_subscription_signals.md` | 中（需專業人士確認） |
| §70-1（2024 打詐五法）：非投信投顧業者廣告不得招攬勸誘投資、不得用推薦函／過去績效讓人誤信必賺 | 同上 | 中（罰則條號未確認） |
| 抽獎是否違法，重點在有沒有「用錢對賭」；免費參加、獎品不是對賭輸贏，風險較低，但**沒查到官方明文指引** | <https://uptogo.com.tw/商業/行銷公關/廣告/抽獎犯法嗎？/>（非官方科普）、嘉義簡易庭 114 年嘉簡字第 314 號判決摘要（賭博罪案例） | 低 |
| 另有英文律所 FAQ 說贈品價值有上限（商品價值 100 元以上者為 50%），**沒寫法條依據，且針對實體商品** | <https://eiger.law/wp-content/uploads/2016/10/Sweepstakes-and-Promotions-in-Taiwan-FAQ.pdf> | 低，不引用 |
| 沒有查到「證券投資顧問事業」專屬的贈品禁止規定（搜到的是銀行業函釋與馬爾他規定，都不適用） | 搜尋結果 | **未確認** |

**由此推出的硬規則（我的判斷，已寫進各方案）**：
1. **不辦抽獎、不做隨機獎勵**。獎勵一律「達成就給、數量固定」，避開賭博罪與公平交易法的灰區，也避開「像老虎機」的變動獎勵。
2. **獎勵不能以「買賣」或「看多空」為條件**。不做「猜明天漲跌得點數」（CMoney 有類似的大盤猜多空，我們不跟，因為像賭博又像誘導交易）。
3. **簽到後顯示的內容只能是事實描述**（資金流入前三的族群、大盤漲跌、今日事件），不寫「可以買」「該進場」，並附既有免責連結。
4. 對外宣傳**不寫「簽到賺 Plus」**，寫「每天花 30 秒看今天資金往哪跑」；不貼任何使用者報酬心得。
5. 不給現金、不給實體獎品（Andy 已定）。

## 3. 三套方案

三套都以「註冊會員」為對象；**訪客看得到簽到卡的預覽與連續天數說明，但按下去要先登入**（把簽到變成註冊的又一個理由）。

### 方案 A（輕）：每日簽到＋三句話＋徽章

| 項目 | 內容 |
|---|---|
| 觸發 | 首頁「今日重點」卡上的「簽到」鈕，手動按；當天網站有送出心跳才算數（防腳本直接打 API） |
| 連續規則 | 以**交易日**計：週末與國定假日不算斷簽（假日名單用靜態設定檔維護，來源待確認，見第 9 節） |
| 斷簽補救 | 每月自動發 2 張「保護卡」，斷一天自動消耗，不用按、不能買 |
| 好處 | ① 簽到後立刻看到**「今天資金往哪跑」三句話**（內容見第 5 節）② 徽章與稱號（連續 3／7／30 天）③ 當日研究額度 +2（註冊會員 10→12，當天有效，不累積） |
| 不給 | Plus 天數、試看券 |
| 轉換影響 | 幾乎中性：+2 次是「更常用」的味道，會員額度本來就是用完才跳升級（判斷，無數據）。徽章零成本 |
| 工時 | 前端 1.5 天、後端 1 天、測試 1 天 ≈ **3.5 天**。**要更新會員後端**（新表、新端點、事件白名單） |
| 另有 A0 | 完全不碰後端：只存 localStorage，只顯示連續天數與三句話，不給額度。約 **1.5～2 天**，**不用 Andy 同意部署**，缺點是換裝置歸零、無法量測留存，只能量 `ev` 次數 |

在 A 的基礎上加「累積簽到日」階梯（**累積，不必連續**，避免連續中斷的挫折感）：

| 累積 1 天 | 當日額度 +2（同 A） | 近乎零 |
| 連續 3／7／30 天 | 徽章、稱號（「連續七天」「常客」） | 零 |
| 連續 7 天 | **A 級功能單次試看券 ×1**（可選 3D、關聯圖、畫線其中一項用 1 次；14 天內用完；同時最多持有 2 張）| 讓人嚐到付費功能，是轉換的前菜；**B 類功能（今日關注、選股完整名單、AI 分析）不能當試看券** |

|---|---|
| 觸發／連續／補救 | 同 A |
| 轉換影響（判斷） | Plus 1 天：好的一面是「用過才知道好」；壞的一面是已有 14 天新會員體驗＋問卷 7 天＋邀請 14 天 Pro，**免費 Plus 疊太多會讓人永遠不用付**。所以設三道上限：月 1 次、終身 12 天、已付費者不給。付費者另有徽章與許願權，不領天數 |
| 防白嫖 | 見第 6 節 |
| 工時 | 前端 3 天、後端 2.5 天、測試 2 天 ≈ **7.5 天**。**要更新會員後端** |
| 分兩步 | 第 1 步＝方案 A 全部＋累積計數（3.5 天）；第 2 步＝兌換階梯（4 天），中間觀察兩週數據再決定要不要開 |

### 方案 C（重）：B＋每日一題＋每週任務

| 項目 | 內容 |

## 4. 為什麼不做這些（我主動排除的好處）

| 想法 | 排除原因 |
|---|---|
| 抽獎、盲盒、隨機額度 | 賭博罪／公平法灰區（第 2-3 節）、也是變動獎勵的成癮設計 |
| 現金、實體獎品 | Andy 已定不做 |
| 排行榜（誰簽最久） | 沒有社群，榜單只會讓少數人焦慮；也有個資面風險 |
| 賣補簽卡 | 對斷簽焦慮收費，品牌傷害大 |
| 猜漲跌得點數 | 像賭博又像誘導交易（§70-1 精神）；CMoney 有類似功能，我們不跟 |

| 簽到送「今日關注完整名單」等 B 類 | 法遵紅區，簽到不能加碼它 |

## 5. 讓人每天回來的內容（簽到的真正理由）

簽到只是開門，**內容才是回訪原因**。三項都用站上現有資料，不新增資料來源，也不需要人工逐日寫稿：

| 內容 | 做法 | 風險 |
|---|---|---|
| **今天資金往哪跑（三句話）** | 盤後管線用模板產生：①大盤與成交值一句 ②資金流入前三族群一句 ③明天要留意的事件一句（取自「今日事件」）。寫入既有的 `site/data/` 輸出；模板由 CEO 審，不用 LLM 現寫 | 只描述事實，不下「買／賣」；每句附免責連結。**這是 M1 資金面事實，不是 M3 時機或進場結論** |
| 簽到後揭曉區 | 按下簽到才展開三句話＋「去資金流向看細節」連結 | 純前端 |
| 每日一題（僅方案 C） | 見方案 C | 只出概念題 |

資料時效：日更資料 15:30／18:30 才更新（見 daily.yml），所以簽到卡**早上顯示的是前一個交易日的三句話**，晚上 18:30 之後換成當天的。這會自然形成「晚上回來看一次」的習慣，也是我選手動簽到而非打開就自動簽的理由（要有一個「揭曉」的動作）。

## 6. 防白嫖、防多帳號

| 風險 | 做法 | 沿用或新增 |
|---|---|---|
| 一人多帳號刷 Plus 天數 | 一個 Google 帳號一份（現有）；天數獎勵要求**帳號註冊滿 3 天**；同 IP（HMAC）每天最多 3 個帳號領到天數獎勵 | 沿用 `grant_ip` 的作法，新增一欄 |
| 改手機時間或腳本打 API | 日期一律以 Worker 的台北日期（`tpeDay`）為準；簽到要求當天已有心跳（`session_login`）；同一帳號一天只算一次 | 沿用 |
| 簽到後立刻關頁（純刷） | 累積天數靠簽到日，但**天數獎勵另要求該日有至少 1 次實際功能使用事件**（任何一個既有功能事件），否則該日不計入兌換進度 | 新增，**實作成本最高的一條**，可降級為只看心跳 |
| 付費者領天數 | 已付費者不給天數，只給徽章與許願權 | 新增 |
| 與其他體驗疊加 | 兌換的 Plus 天數透過既有的 `promoGive`（寫 perm、不記 first_paid、不出現退款鈕）發放；**與 welcome、問卷、邀請疊加時是延長還是取最大值，我沒讀完該函式，未確認，開工第一步先讀** | 沿用／待查 |
