# 臺灣50指數歷史成分股——來源與限制

產出：`pipeline/groups/tw50_history.yaml`（0050 追蹤臺灣50指數，供「大型股增強 0050」股池使用）。

## 結論先講

- **連續可驗範圍：2023-06-19 至今**（13 次生效），每期剛好 50 檔。
- **2013～2023-05 的完整名單做不到**：找得到的只是零散的新增／刪除報導，缺口太多，回推會誤差累積，所以刻意不補（寧缺勿造）。
- 方法：以 `data/etf_holdings`（0050，2026-10-27 快照，50 檔）為終點，逐季「反向套用」增刪名單。

## 自我檢查（程式驗過）

1. 每期恰 50 檔：13 期全部通過，連回推到 2023-06 之前也是 50。
2. 「納入者在生效後名單、刪除者不在」：13 筆全吻合，等於前後季互相驗證。
3. 候補名單獨立驗證：13 次公告的候補（各 5 檔）**皆不在當期成分內**。
4. 對照公開報導的三個時點：2024-03（世芯-KY 納入、豐泰刪除）、2025-06（台光電納入、欣興刪除）、2026-06（貿聯-KY、創意、南電、臻鼎-KY 納入；康霈*、中鋼、台塑、和泰車刪除）。

## 已知限制與缺口

- 2013～2023-05 缺。2022-06、2022-12、2023-03 搜尋不到；2022-03、2022-09、2021-12、2019-06、2017-06 僅單季變動，接不成連續鏈。
- 媒體摘要會互相矛盾：「世芯-KY 納入、豐泰刪除」有報導寫成 2023，依 0051 同步異動等旁證判為 2024-03（udn 內文年份誤植）。
- **生效日是推算值**：公告為「第三個週五（2026-06 為週四）收盤後生效」，本檔記下一個交易日；2023-09-18 為慣例推算，未見公告原文。
- 信心「中」的四筆（2023-06、2023-09、2024-03、2025-03）為單一媒體來源，建議用 taiwanindex.com.tw 公告覆核。
