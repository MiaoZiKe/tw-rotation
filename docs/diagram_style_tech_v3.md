# 3D 科技模式 v3：色彩與細節規格（Andy 2026-09-22 提供的提示詞，整理成可實作的規格）

> Andy 原話：「以上內容是提供給你關於圖片色彩優化的提示詞，依上述方式再優化一次並給我看看。」
> 適用範圍：**3D 場景的「科技」模式**（深底）。「閱讀」模式維持 DECISIONS #238 的低飽和粉彩，不套這一份。
> 這份不是要生一張獨立的圖 —— 是把提示詞裡的視覺語言搬進 `site/three3d.js` 的實際場景（互動一個都不能少）。

## 1. 底色與光
- 背景：深邃漸層科技暗藍黑 `#080C14` → 中心微亮 `#0E1626`（徑向漸層），token `--dg-bg-tech` / `--dg-bg-tech-2`。
- 所有大件要有厚度、細微高光、環境遮蔽（AO：接縫與托盤底面壓暗）；發光只給流動線、接口、被選零件與引線端點。

## 2. 五色系（互相交織，但每一類元件固定一個主色）
| 語意 | 色 | 用在 |
|---|---|---|
| 螢光藍 Cyber Blue | `#58C4FF`（亮）/ `#2F7FE0`（暗） | 訊號、網通、機櫃玻璃邊緣折射、冷水管 |
| 松石綠 Neon Turquoise | `#22E5C8` | 光模組／CPO、光纖、光路流線 |
| 活力亮橙 Energetic Orange | `#FF8A3D` | 電力（PSU／BBU／匯流排）、快接頭 |
| 富貴紫 Violet | `#9B6DFF` | 運算（GPU／NVSwitch 晶粒、CoWoS 中介層） |
| 金屬紅銅 Rose Gold / Copper | `#E8A97E`（高光）/ `#B8694A`（暗） | 冷板銅質、載板銅箔、金色走線用 `#FFD37A` |
| 熱水 | `#FF4D5E`（發光） | 液冷回水管 |
| 氣流 | `#BFE9FF` → 白，透明度 0.15～0.4 | 風扇氣流波紋 |

## 3. 元件細節（每一條都要在畫面上找得到）
- **01 機櫃／機構件**：19 吋機櫃與導軌 = 半透明霧面玻璃（`transmission` 0.6～0.8、`roughness` 0.35）＋ **藍色邊緣折射**（fresnel 邊光用 `#58C4FF`），立柱與橫樑深灰金屬。
- **15 ToR 交換器**：前面板排滿微弱發光的 RJ45 與 800G／CPO 光纖接口（instanced 小方格，兩排，青綠色微光），接出幾條細彩色線纜到「交換器板卡 ＋ 800G 光模組 ＋ CPO」。
- **03 NVSwitch 托盤／04 運算托盤 GPU 模組**：多層硬板，板上布滿微小晶片、BGA 錫球陣列（instanced 球）、金屬顆粒；處理器上蓋 CoWoS／SoIC 晶粒（紫）＋ **HBM4 多層堆疊 6～8 顆**（層與層有細縫），板上有微發光的金色走線。
- **09 液冷冷板／CDU**：銅質水冷頭壓在晶片上，接**半透明霓虹藍冷水管**與**發光紅色熱水管**、UQD 快接頭與 manifold，水流有流動（`flow` 材質；靜止時要停 —— 既有 E4 驗收）。
- **08 CCL 銅箔基板／07 主機板 PCB**：50 層以上的層疊剖面（金／銅／綠交疊），層間有微小導通孔（vias）與髮絲細的 3D 走線；IC 載板（ABF／BT）另外一小塊剖面。
- **11 後門風扇模組**：扇葉要有葉形（7～9 葉、扭角），向外旋轉出淡藍白的氣流波紋與箭頭（`airflow` 材質，同樣靜止時停）。

## 4. 卡片與引線（HUD）
- 左右兩側卡片 = 半透明磨砂玻璃（`backdrop-filter: blur(10px)`，底 `rgba(12,20,36,.55)`），邊緣微光暈。
- 繁體中文＋英文雙語標題；編號 badge 的顏色 = 該元件的主色（01 藍、14 青、03 靛藍、04 紫、08 橙、07 綠、09 霓虹綠、06 深藍、11 紅、10 橘黃…），卡片邊框同色（走 `--dg-card-c`）。
- 引線細 1px、端點一個發光圓點（元件色），不交叉、不壓字；resize 重算。

## 5. 產業族群點綴（主圖下方那一排）
- 既有的族群晶片列（IP／EDA、製程材料、IC 設計、前段設備、載板材料、晶圓代工、HBM、企業級儲存、DRAM／NOR、先進封裝、封測、IC 載板、封裝設備、測試介面）在科技模式下每一顆加**彩色發光小點**（顏色 = 對應元件主色），滑過或選取時畫一條細線連到機櫃內對應的元件。
- 這一段是 style-system（晶片列）與 style-3d（連線端點）共用，介面用 `data-dgcolor` ＋ 元件 id。

## 6. 不變的事
- 互動：點零件亮卡片、點卡片亮零件、點背景恢復、E4 動畫開關、localStorage、縮放、≤700 收合。
- 效能：BGA 球、接口格、氣流粒子一律 instanced；1440 下 FPS 不掉到 30 以下。
- 色值一律走 `--dg-*` token，不寫死在 three3d.js 裡。
- 閱讀模式不套這份（低飽和、無發光）。
