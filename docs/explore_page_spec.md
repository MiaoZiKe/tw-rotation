# 選股探索頁（`#explore`）規格 —— 2026-10-05

> Andy 需求：參考 stockintelli「策略研究中心」新增一個分頁，但 ① 名稱全部不一樣 ② 功能不要太像
> ③ 更站在新手（小白）角度 ④ 以視覺化為主。本文件先定規格，再實作（site/explore.js）。

## 1. 頁名與位置

| 項目 | 決定 | 理由 |
|---|---|---|
| 頁名 | **選股探索** | 不含「策略／研究中心／雷達／掃描」任何一個字；「探索」講的是「自己去看」，不是「我們挑給你」 |
| 路由 | `#explore`、`#explore/<問題 id>` | 跟其他頁同一套 hash 路由；問題 id 帶在網址上，連結可以分享 |
| 側欄 | 「族群與個股」組，排在「市場明細」下面 | 它跟市場明細一樣是「從全市場找出符合條件的公司」，只是入口換成白話問題 |
| 手機 | **不顯示**（≤820 藏分頁） | 這批只做桌機（手機版暫停中，見 layout4.js `MOBILE=false`） |
| 權限 | `features.js` 新分類 `explore`（選股探索），四個開關：`explore.page`、`explore.chart`、`explore.combo`、`explore.list`，預設全開 | 之後管理者在 `#admin/perm` 依會員等級關；這次不改 admin.js（它讀 CATS／LIST 自動長出來） |

## 2. 頁面區塊（由上到下）

| 區塊 | 名稱（畫面上的字） | 回答的問題 | 互動 |
|---|---|---|---|
| 頂端固定列 | 法遵提示 | — | 一行：「條件篩選結果僅供研究，不構成投資建議；本站非證券投資顧問。」不可關閉 |
| A | **六個好問題**（問題卡列） | 「我想找什麼樣的公司？」 | 六張大卡，每張：白話問題、一句解釋、目前符合幾家。點一張＝切換下面的圖 |
| B | **問題放大鏡**（主圖） | 「符合這題的公司在哪裡？跟其他公司比起來差多少？」 | 泡泡圖：每顆泡泡一家公司，符合條件的上色、其餘淡灰；條件區塊用底色框起來（「這一塊就是答案」）。點泡泡 → 白話卡。寬鬆／標準／嚴格三段門檻 |
| B-側 | **這代表什麼／要小心什麼** | 「所以我該怎麼用這張圖？」 | 每題兩段固定白話 ＋ 指標「?」名詞小教室 |
| B-下 | 符合名單 | 「是哪幾家？」 | 依**成交值**排序（不是名次），每列帶 20 日迷你走勢、條件值；點列 → 白話卡 |
| C | **條件積木**（交集） | 「同時符合兩、三題的有誰？」 | 勾 2～3 題 → 文氏圖（每一塊寫家數）＋交集清單；點文氏圖的一塊 → 清單換成那一塊 |
| 浮動 | **白話卡** | 「這家是做什麼的、為什麼符合、要小心什麼？」 | 原地展開在頁面右側（不離開本頁）；底部「看個股頁 →」才進 `#stock/<代號>` |
| 浮動 | **名詞小教室** | 「ROE 是什麼？」 | 每個指標旁的「?」打開一則白話解釋 |

## 3. 與參考站的差異（為何不構成抄襲）

| 面向 | 參考站（策略研究中心） | 本站（選股探索） |
|---|---|---|
| 組織單位 | 44 組「策略」，依基本／技術／籌碼／估值／事件分類晶片篩選 | **6 個白話問題**（「哪些公司很會賺錢？」），不分類、不叫策略 |
| 主呈現 | 策略卡清單：每卡列前 3 檔＋走勢小圖＋指標值 | **一題一張泡泡圖**：看整個市場的分佈，符合的那一塊用底色圈起來；清單是配角 |
| 排序 | 策略內依指標排出前 3 名 | **不排名次**：只列「符合條件的公司」，預設依成交值（流動性）排序 |
| 組合 | 單一策略 | **條件積木**：使用者自己勾 2～3 題做交集，以文氏圖顯示每一塊家數 |
| 個股說明 | 指標數字 | **白話卡**：做什麼（族群／產業）、為何符合（逐條、帶數字）、要小心什麼（逐條） |
| 新手輔助 | 無 | 每題「這代表什麼／要小心什麼」＋名詞小教室「?」＋0 筆時給「放寬條件」 |
| 付費區 | Pro 專屬「策略雷達」 | 無對應功能；權限開關只是本站既有的會員制度（features.js） |
| 用語 | 策略、雷達、掃描、研究中心 | 問題、放大鏡、條件積木、白話卡、名詞小教室（全部不同） |

可受著作權保護的是**表達**（文案、版面、圖像），不是「用財務指標篩股票」這個概念；
本頁的文案、視覺形式（泡泡圖＋門檻框、文氏圖）、資訊架構（問題而非策略）都是獨立設計，
沒有複製參考站的任何文字、圖示或版面。

## 4. 法遵用字

- 頁頂固定一行提示（見上）；白話卡底部再寫一次短版。
- **禁用字**：推薦、買進、賣出、目標價、必漲、最值得買、排名第一。`_uitest` 段落「選股探索1005」會掃整頁文字確認沒有出現。
- 不排「最值得買」名次；預設依成交值排序，並在清單標題寫明「依成交值排序（不是好壞名次）」。

## 5. 六個問題的白話口徑與資料來源

門檻分三段：寬鬆／**標準（預設）**／嚴格。全部排除 ETF（`group_id = ind_ETF`）與近 20 日平均成交值 < 1,000 萬元的冷門股（成交太少，價格不可靠）。

| id | 問題 | 條件（標準） | 寬鬆 | 嚴格 | 資料來源欄位 |
|---|---|---|---|---|---|
| `earn` | 哪些公司很會賺錢？ | ROE ≥ 15% 且 毛利率 ≥ 20%（毛利率缺值的金融業只看 ROE） | ROE ≥ 10%、毛利 ≥ 15% | ROE ≥ 20%、毛利 ≥ 30% | `fundamental.json`：`roe`、`gross_margin` |
| `cheap` | 哪些股票比自己過去便宜？ | 目前本益比在**自己近 5 年**各季本益比的第 30 百分位以下，且有獲利 | ≤ 40 | ≤ 20 | `explore.json`：`pe_pct`（自 `stock/<代號>.json` 的 `pe_history`；至少 8 季才算） |
| `grow` | 誰的營收正在變好？ | 月營收年增連續 ≥ 3 個月，且最新一月年增 ≥ 10% | 連 2 月、≥ 5% | 連 6 月、≥ 20% | `fundamental.json`：`rev_streak`、`rev_yoy`、`rev_ym` |
| `inst` | 法人最近在買誰？ | 三大法人合計連續淨買超 ≥ 5 個交易日 | ≥ 3 日 | ≥ 10 日 | `explore.json`：`buy_days`、`net10`（自 `inst_daily.inst_total`） |
| `steady` | 哪些股價走得穩？ | 60 日年化波動度 ≤ 30%，且收盤站上 20 日與 60 日均線 | ≤ 40%、站上 60 日 | ≤ 22%、站上兩條 | `explore.json`：`vol60`、`above20`、`above60`、`ret60`（還原日 K） |
| `div` | 配息穩定的公司？ | 近 12 個月現金殖利率 ≥ 4%，且連續 ≥ 5 年配現金 | ≥ 3%、≥ 3 年 | ≥ 5%、≥ 8 年 | `explore.json`：`dy`、`div_years`（自 `dividends.yield_ttm`／`by_year`，今年不算） |

### 每題的圖（X／Y 軸＝那一題的兩個條件，答案區＝右上或左上那一塊）

| id | X 軸 | Y 軸 | 答案區 |
|---|---|---|---|
| earn | 毛利率 % | ROE % | 右上 |
| cheap | 本益比歷史位置（0＝歷史最便宜） | ROE %（順便看「便宜但賺不賺」） | 左側 |
| grow | 最新月營收年增 % | 連續年增月數 | 右上 |
| inst | 連買天數 | 近 10 日淨買超（張） | 右側 |
| steady | 60 日波動度 % | 近 60 日漲跌 % | 左側（且站上均線者上色） |
| div | 現金殖利率 % | 連續配息年數 | 右上 |

泡泡大小＝近 20 日平均成交值；顏色＝族群（成交值前 8 大族群各一色，其他灰）。

### 資料日期標示

每題卡片與主圖標題旁寫資料日期：基本面＝`fundamental.json` 的 `latest_period`（季）與 `rev_ym`（月營收月份）；
其他＝`explore.json` 的 `asof`（交易日）。

## 6. 資料與退回（預覽版）

- 新增 `site/data/explore.json`（`pipeline/compute/explore.py`，在 build_payload 逐檔寫個股頁的迴圈裡順手抽）。

  - `cheap`：改用 `fundamental.json` 的**同族群**本益比百分位（`percentile`），標題標「暫用同族群比較」。
  - `inst`：改用 `inst_streak.json`（只有前 60 名）的 `total` 連買天數。
  - `steady`：改用 `candidates.json`（約 640 檔）：均線多頭排列＋乖離 |bias20| ≤ 5%，標「暫用候選股」。
  - `div`：沒有替代來源 → 該題卡顯示「資料準備中」並不可勾入積木。
  退回時頁頂法遵列下面多一行灰字說明「部分題目暫用簡化口徑」。

## 7. 驗收（`_uitest.py` 段落「選股探索1005」）

切問題 → 主圖的系列資料真的換掉；勾兩題 → 交集數字＝兩集合實際交集（用頁面公開的集合重算對帳）；
點泡泡 → 白話卡出現且代號對 → 點「看個股頁」→ 網址變 `#stock/<代號>`；「?」→ 名詞小教室打開；
門檻切嚴格 → 符合家數不增；整頁文字不含禁用字。
