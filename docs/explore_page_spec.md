## 1. 頁名與位置

| 項目 | 決定 | 理由 |
|---|---|---|
| 側欄 | **選股策略**（中文） | 側欄全站都是中文，混一個英文分頁會很突兀 |
| 頁標題 | **Strategy Lab**＋一行中文說明 | Andy 要「策略寫成英文」，頁標題與卡標題用英文，說明用中文 |
| 路由 | `#explore`（卡片牆）、`#explore/<策略 id>`（完整名單） | 連結可分享 |
| 手機 | 不顯示（≤820 藏分頁） | 這批只做桌機 |
| 權限 | `features.js` 分類 `explore`：`explore.page`（整頁）、`explore.chart`（卡片牆 `#slGrid`）、`explore.combo`（條件與出處 `.sl-info`）、`explore.list`（完整名單 `.sl-ftbl`） | id 沿用第一版，管理者已設的開關不失效 |

## 2. 版面

- 頂端固定：法遵列（不構成投資建議；本站非證券投資顧問；名單依成交值排序，不是好壞名次）。
- 分類晶片（英文＋數量）：All／Fundamentals／Valuation／Growth／Technicals／Institutional／Dividend／Momentum；下方一列英文子標籤（Tags）可再篩。
- 卡片牆：1440 三欄、≤1180 兩欄。每張卡＝分類圖示＋英文標題＋一行中文翻譯＋資料日期徽章＋「i」＋「›」；
  「符合 N 家・依成交值排序，非推薦名次」；前 3 檔，每列：序號徽章、logo、名稱代號、現價與漲跌（紅漲綠跌）、迷你走勢（sparks.json）、右側關鍵指標。
- 點一列 → 原地展開「為什麼入選」：每條條件 ✓／✗＋實際值＋門檻，底部「看個股頁 →」。滑過一列也有同內容的提示。
- 點「i」→ 原地展開：篩選條件、計算方式、共同門檻、資料日期、**資料出處**、要小心什麼。
- 點「›」→ `#explore/<id>`：上方同一份條件與出處；下方表格列出**全部**符合的公司（先 100 家，可「顯示全部」），欄位：公司（連個股頁）、現價／漲跌、走勢、關鍵指標、為什麼入選（逐條實際值／門檻）、也符合哪些策略。
- **泡泡圖與條件積木移除**：卡片牆已經把「為何入選」寫在每一列，泡泡圖要使用者自己對座標（多一步推論）；
  交集需求改由完整名單的「也符合」欄回答。

## 4. 與參考站差異

| 面向 | 參考站 | 本站 |
|---|---|---|
| 名稱 | 參考站自有策略名 | 全部自行命名（見 §3），沒有沿用任何一個 |
| 排序 | 依指標排前 3 名 | 依成交值（流動性），每張卡與名單都寫明「非推薦名次」 |
| 為何入選 | 只顯示一個指標值 | **每一列可展開逐條 ✓＋實際值＋門檻**（本站特色） |
| 資料出處 | 無 | **每張卡「i」揭露條件、計算方式、資料日期、資料集名稱**（本站特色） |
| 完整名單 | 指標排行 | 原因欄＋「也符合哪些策略」交叉欄 |
| 版面細節 | — | 版面骨架（晶片＋三欄卡）依 Andy 指定參考；圖示、配色、文案、子標籤為自行設計 |

## 6. 驗收（`_uitest.py` 段落「選股策略1005」）

1440／1100 與名單頁無橫捲、禁用字。
