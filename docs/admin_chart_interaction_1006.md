# 管理區圖表互動對照表（2026-10-06）

Andy 要求：管理區所有圖表一致互動——滑過高亮、浮動提示、甜甜圈中心字換成該段、圖例連動、可點的才給點擊。
實作在 `site/admin.js` 的 `bindHover`（事件委派在 `#admBody`／`#v-admin`，圖重畫不用重綁）；提示框是 `#trTip`（掛在 body，跟著游標、不超出視窗）。
斷言在 `scripts/_uitest.py` 的「流量觀測1005」「管理區v3」（每張圖 hover 後要有提示、且圖上有高亮狀態）。

共通行為（滑鼠）：滑過一個元素 → 該元素加 `.hl`、整張圖加 `.hov`，其餘元素透明度降到 .3～.4（120ms；`prefers-reduced-motion` 關掉過渡）；滑出還原；提示內容＝名稱（粗體）＋數值＋占比。

## 手機觸控（390px，2026-10-06 補）

- 點一下圖上的元素（柱、長條、扇區、圖例、散佈點、時鐘扇形）→ 出提示＋高亮；點圖外面（標題、空白處、別張卡）→ 全部收起來。
- 有「下一步」的元素（「全部」頁的長條與扇區、每日直條）：**第一下只出提示，同一個再點一下才執行**（進入該頁／選取那一天），避免一碰就跳走看不到數字。
- 實作：`pointerdown`（`pointerType` 非滑鼠）＋ 擷取階段的 `click` 攔截；觸控期間忽略瀏覽器補發的 mouseover／mouseout，不會互相打架。

## 沒做、已知缺口

1. 沒有鍵盤的等價操作：提示與高亮只在滑鼠滑過、觸控點擊時出現。
2. 只有「全部」頁的長條與扇區、每日直條可以點，因為只有這幾處有「下一層」；其餘圖點了沒有意義，所以沒有點擊。
3. 「點某天」要正式站的會員系統（Worker）支援 `from`／`to` 才會動；目前預覽用示範資料所以可用，正式站在更新前會顯示白話提示。
4. 個股頁熱門個股表格內的小長條、功能晶片沒有滑過互動。
5. 會員權限展開明細那一組圖，用的是同一批元件，但自動化斷言只覆蓋了上方統計的四種（功能長條、股票長條、每日直條、狀態甜甜圈），明細裡的沒有單獨斷言；它們也沒有逐一做 390 的觸控驗證。
