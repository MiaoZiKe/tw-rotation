## 三、檢討會（六個角度，各 5 行內，我的判斷）

**市場研究（market-researcher）**
- 讀者真正停下來的是「大事件剛發生」的那一刻：640 都在消息出來 1 小時內。
- 本週有輝達財報（11/17 起）與執行長交接後續，是頻道①國際財經短片的主場。
- 熱門串留言 20,000＋觀看、但追蹤 +1：曝光有、品牌記憶沒有（頭像與名稱沒讓人想點進來）。
- 新自介「每句標已確定／媒體報導／推測／查不到」是差異點，市面財經帳號很少這樣標。
- 風險：上週有兩則留言是嗆人（「注意你的言論」），大量曝光下會被記成吵架帳號。

**內容規劃（content-planner）**
- 公式沒被執行：11 篇只有 1 篇帶網站圖與「怎麼用」。下週每支短片的第一則留言固定放隱藏文章直連。
- 短片 20～30 秒照 `video_logic.md`，結尾「下集追哪份文件」要真的接得上隔天那支，做成連續劇。
- 時事熱點當天發「快訊短文」（3 行、標狀態），隔天才發短片，搶第一小時。
- 教學內容 20% 上週是 0 篇；每週至少 1 支「這張圖在網站哪裡、怎麼看」。
- 文案一律過 `.claude/skills/ig-threads-copy/SKILL.md` 交件清單。

**社群營運（social-ops-lead）**
- 11-15 短片因 Gemini TTS 免費額度（每天 10 次、四頻道共用）用完而卡住，至 11-16 10:06 沒有新貼文：**沒有保底**，違反 10-29 規則。
- 已在 `video_logic.md` 加「旁白額度與保底」：頻道①每天保留 2 次、先做頻道①、額度用完改「字幕版＋純配樂」照樣發。
- 自動回覆 A 層一週只送 2 則，因為自家貼文少、留言少；不是壞掉。
- 熱門串留言要有守則（第四節），由人寫、不自動化。
- 發文時段改 12:00～13:00 或 20:00～21:30，不再半夜發。

**手機介面（mobile-ui）**
- 讀者從 Threads 點進來是手機：隱藏文章頁要第一屏就看到影片與「查證狀態」標籤。
- 影片下載鈕在手機要能點（≥ 44px），不能被同意橫幅蓋住（重新出發計畫第五節第 1 項）。
- 頁首要看得出「LIGULIGU」站名，否則從短片點進來不知道到了哪。
- 這三點只列為檢查項，不改 site/ 程式碼；交給網站維護排工、桌機守門照跑。
- 驗收：390×844 截圖一張，第一屏同時有影片、標題、站名。

**行銷策略（marketing-strategist）**
- 「沒流量什麼都不用談」：下週唯一主目標是追蹤淨增，不是功能。
- 把熱門串留言的曝光轉成追蹤：留言要有一個具體數字＋「我們查過」的口吻，讓人想點頭像。
- 置頂自介換新方向（查出沒人講清楚的地方＋狀態標示），讓點進頭像的人 3 秒懂。
- 盤後自動主貼文前週中位數約 250，是穩定的基本盤；是否恢復要 Andy 決定（第四節提案 B）。
- 量不到網站來訪就無法證明「社群→網站」有效，補資料是前提。

**資源稽核（resource-auditor）**
- Gemini TTS 免費額度是四頻道共用瓶頸：每天 10 次，四頻道各一支＋重錄就用完。
- 付費方案要花錢，列「待 Andy 點頭」，先用分配＋保底撐。
- 網站統計在 account-api Worker 的管理區，要站主登入，本 session 無權限、repo 也沒有匯出快照 → 每週檢討拿不到網站數字。
- Threads 連結點擊／個人頁瀏覽 API 有提供但沒抓，是程式小改、不花錢。
- IG 每週二／四短片卡在「先審樣片」，IG 一週觀看 18，等於沒有在經營。

## 六、固定做法（下週起每篇照做）

**每篇自家貼文／短片**
1. 開頭照 `video_logic.md` ① 鉤子；每個說法標狀態（已確定／媒體報導（誰）／推測／查不到）。
2. 第一則留言：「完整查證與影片在這」＋隱藏文章直連（`https://liguligu-puipui.com/?u=th-ligu-<yyyymmdd>#article/<文章id>`，`?u=` 放在 `#` 前面）。依據：`restart_1109/00_plan.md` 開頭「已核可：簡介放網站連結＋第一則留言放網址」（11-09／10，晚於 11-03「貼文不放網址」；自動發文程式的 `PROMOTE_SITE=False` 不在本次範圍、不動）。
3. 時段：12:00～13:00 或 20:00～21:30；熱點事件例外，消息出來 1 小時內先發 3 行快訊。

**熱門串留言守則（人寫，不自動化）**
1. 只留在財經、科技大事的熱門串；一天最多 3 則。
2. 每則要有一個具體數字或日期，口吻是「我們查過」，不用網址、不推銷。
3. 不嗆人、不回罵、不評論個人（上週有兩則語氣偏衝，之後不這樣寫）。
4. 不給投資建議、不預測漲跌。
5. 每週檢討看「留言觀看 → 追蹤淨增」的換算，換不到追蹤就調整留言寫法。
