## 二、為什麼薪資文爆：拆解（判斷，低～中信心）

單一樣本（1 則爆、9 則平）不足以證明因果，下面是**可被後續資料推翻的假說**。

| 假說 | 薪資文具備 | 我們一般文（盤前／盤中／盤後） |
|---|---|---|
| H1 切身：每個人都有薪水，不需要持股 | 是 | 否，要先持有或關心台股 |
| H2 可比較：讀者立刻拿自己去對（「我比他高／低」），留言動機＝表態 | 是 | 弱，看完只能點頭 |
| H3 有排名：有第一名、有落差，天然能轉貼 | 是 | 有，但是輪動排名，非人人關心 |
| H4 引發討論：數字會被質疑口徑，留言互相辯論，回覆 54 是證據之一 | 是 | 低 |
| H5 受眾破圈：非投資人上班族，不被「財經」標籤過濾 | 是 | 否，演算法把我們分給財經小圈 |
| H6 年度事件：6 月底～7 月薪資資料公布，有新聞接力 | 是（時間點） | 日常，無事件 |

觀察：回覆 54／觀看 68,541 ≈ 0.08%，讚 450 ≈ 0.66%（事實推算）。留言與觀看都遠高於其他篇，符合 H2、H4。**但也可能只是單次演算法加權或被轉推**——要靠「第二、第三次同公式複製」驗證（見第五節 V1）。

### 可複製的爆文公式（假說版 v0.1）
> **切身身份 ＋ 一個可比較的數字 ＋ 排名落差 ＋ 一個留得出意見的缺口 ＋ 站內「查自己那一格」的落點**

| 要素 | 檢核問題（選題簡報必填） | 不合格例子 |
|---|---|---|
| 切身身份 | 非投資人一秒內知道「這跟我有關」嗎？ | 「外資本週買超族群」 |
| 可比較的數字 | 有一個讀者能拿自己去對的數字嗎？ | 只有百分比、沒有絕對值 |
| 排名落差 | 有前後名／倍數／年增落差嗎？ | 單一數字無對照 |
| 討論缺口 | 讀者會想反駁、補充或表態嗎？（口徑爭議也算） | 無爭議的事實陳述 |
| 站內落點 | 想「查自己／查自己公司」時，站內有可點的地方嗎？ | 沒有對應頁面 |
| 紅線 | 沒有任何買賣暗示、沒有未標示口徑 | 「所以這檔值得買」 |

## 四、給 GPT 幫手的「每週選題簡報」

分工：**CEO 端自動產出數據＋題目＋鉤子＋落點＋紅線；GPT 只負責寫與畫。** GPT 不需要讀 repo。

### 檔案位置
- `docs/marketing/briefs/brief_<yyyy>w<週次>.md`（給人看，Andy 週日確認；GPT 讀這份）
- `docs/marketing/briefs/brief_<yyyy>w<週次>.json`（給機器：發文排程、成效回收對帳）
- 產生時間：每週日 20:00（台北），由排程產出（工單待立：`scripts/make_weekly_brief.py`，**本檔不寫程式**）。

### 欄位（每個題目一筆）
| 欄位 | 說明 | 必填 |
|---|---|---|
| `id` | `<yyyy>w<週>-<序>`，例 `2026w44-1` | 是 |

### 通用法遵紅線（每份簡報頂部固定附）
1. 不給買賣點、目標價、「值得買／該賣」字眼；不出現「推薦」個股。

### 一般規則
1. **單一題目只當線索，不當結論**：結論至少要 4 則以上同公式（V1）。

3. **主要比較對象是自己的歷史基線**，不是業界數字（業界數字都是低信心二手）。
