## 動畫手法

- 字卡：大字由下往上淡入、底線由左往右（或由中間往兩邊）畫出；小字晚 0.25 秒進場。
- 截圖：Ken Burns（慢推近／平移，三次方緩動），1.6 秒後周圍壓暗、青色框沿外框描一圈，**畫完就靜止**（不閃、不脈動；光暈 shadowBlur 最大 8）。
- 吉祥物：用原本 8 格動圖的彈跳動作，功能段縮小放在角落陪看；開場那次有掉落＋阻尼回彈＋一次性震波。
- 轉場：段落交界一道淡青色掃光（0.4 秒）＋前段淡出、後段滑入。
- 底部一條細細的播放進度條。

## 音樂

`make_music.py` 用 numpy 從零合成（沒有任何取樣，沒有版權問題）：90 BPM、C 大調，Cmaj7 → Am7 → Fmaj7 → G7 電鋼琴和弦＋五聲音階小旋律＋搖擺輕鼓（大鼓／小鼓／腳踏鈸）＋極淡黑膠底噪。前兩小節只有琴（配合痛點開場），第 3 小節進鼓；最後壓一個 Cmaj7（加九音）長延音，3.5 秒淡出，不會突然斷掉。
