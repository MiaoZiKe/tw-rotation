## 〇、先看這一段

**一句話結論：可以做，而且這題的法律風險比股票帳號低 —— 前提是把它做成「行情與職涯資訊」，不是「爆料」。真正會出事的是四件事：① 寫公司的負面「事實」而沒查證、② 讓投稿者的身分或薪資單被認出來、③ Andy 講出台積電的具體製程數字或客戶、④ 科技帳號講某家上市公司的訂單／產能／良率傳聞，又導流到有該公司個股頁、而且有收費方案的股票網站。**

白話五點：

1. **薪資區間本身風險低到中。** 法務部函釋：薪資屬個人資料；但**不帶姓名、不帶可認出是誰的組合**時，通常認不出特定人。薪資是不是公司的「營業秘密」法院沒有統一見解，而且廣達、華碩的薪資在 PTT／Dcard／104 早就大量討論，「不為一般人所知」這一要件很弱。**風險主要落在提供資料的在職員工身上（違反保密條款、被公司處分），不是 Andy。**（中；營業秘密的刑事部分必須由專業人士確認）
2. **最危險的不是薪資數字，是「缺點」那一欄。** 例如華碩那篇的「水池事件站錯邊會面臨中年失業」—— 這是在講公司「因為派系而讓人失業」的事實指摘，屬於刑法 §310 誹謗的典型形態。憲法法庭 112 年憲判字第 8 號：**涉及公共利益的言論，要在發表前合理查證才不罰**；「若有誤請指正」是發表**後**的補救，**不等於發表前的查證**。（中高；刑責，必須由專業人士確認）
3. **轉貼網友投稿 ＝ 你自己說的。** 判決實務：轉寄、轉貼一樣要為內容負責；有粉專經營者因「轉載爆料前只問網友、沒向當事人查證」被起訴。Andy 是編輯、決定刊登的人，台灣沒有美國那種「平台免責」可以套。（中）
4. **Andy 的前台積電背景要畫線。** 台積電的 14 奈米以下製程技術已被列為國家核心關鍵技術；2025 年 2 奈米機密外洩案，檢方求刑 7～14 年。講教科書與公開資料可以；**具體良率、製程參數、機台設定、客戶產品對應、內部代號，一律不要講**。（高；具體邊界必須由專業人士確認）
5. **兩個帳號互相導流本身不違法，但要切開內容。** 科技帳號只要出現「某上市公司的訂單、產能、良率傳聞」，就同時碰到證交法 §155（散布流言，三年以上十年以下）、§157-1（內線消息的傳遞）與投顧法（網站已開銀行轉帳收費）。**規則很簡單：科技帳號講人、講職涯、講技術原理；不講任何一家上市公司的營運傳聞，也不連到個股頁。**（中；刑責，必須由專業人士確認）

另外順手發現兩件股票帳號的事（第六節）：**自動財報卡把經濟日報的整段原文貼上、標成「摘述」**（著作權，中）；**華碩那篇 IG 版與 Threads 版的起薪、分紅月份數字不一樣**（IG 58K-66K、1、7 月；Threads 65K-75K、1-2、7-8 月）—— 同一個帳號對同一件事給兩種數字，本身就是「沒查證」的證據。

## 三、匿名投稿（網友提供薪資）怎麼處理

### 3-1 處理流程（照順序，一步都不省）

| 步驟 | 做法 | 為什麼 |
|---|---|---|
| ① 收件 | 只收**文字**；不收薪資單、offer letter、內部系統截圖（收到就請對方刪、自己也刪） | 截圖帶姓名、工號、內部格式 → 個資＋營業秘密＋投稿者被認出 |
| ② 查證 | 同一家公司**至少 2 位彼此獨立**的來源，或 1 位來源＋1 個公開來源（104 薪資情報、PTT 多篇、媒體報導、公司公開的非主管平均薪資）對得上，才刊 | 112 憲判 8 的「發表前合理查證」；只有 1 位來源就標「單一來源」或不刊 |
| ③ 去識別化 | 數字寫**區間**（至少 ±5K）；不寫部門＋職等＋年資三者同時出現；時間只寫到年；不寫只有一兩人的稀有職位 | 個資「間接識別」；保護投稿者 |
| ④ 只放「可查證的事實」或「明講是意見」 | 負面內容只寫「網友普遍回報工時長」這種**意見**；涉及公司做了什麼事（裁員、違法、派系）一律不刊，除非有公開來源 | 誹謗只罰事實指摘，意見評論保護較強 |
| ⑤ 標示 | 每篇底下固定一行：「資料來自 N 位網友提供，非公司公告，期間 YYYY」 | 讓讀者知道是什麼等級的資訊 |

| 技術原理解說、職涯建議、面試題型方向 | 公開知識 |
| 引用公司法說會、年報、重大訊息（附日期連結） | 公開資訊 |
| 業界俗稱代號（肉鬆、石頭）不帶貶意 | 113 憲判 3 限縮 |

### ⚠️ 要改做法才能做

| 項目 | 怎麼改 |
|---|---|
| 匿名投稿 | 照第三節七步驟；只收文字、兩個獨立來源、區間化 |
| 「缺點」欄位 | 只寫意見與普遍回報，不寫公司「做了什麼事」的指控 |
| 升等、調薪規則 | 寫「依單位而異」，不寫內部倍數或公式 |
| 薪資文導流 | 連首頁或待遇統計頁，不連個股頁、不寫股價推論 |
| 自動財報卡、盤前焦點 | 數字照用、句子重寫；一手來源優先；引用一句以內 |
| 盤後籌碼 | 維持事實，不加方向判斷 |

### ❌ 不要做（每一條附替代做法）

| 不要做 | 替代做法 |
|---|---|
| 貼薪資單、offer、內部系統截圖 | 投稿者用文字描述，Andy 改寫成區間 |

## 八、發文守則（10 條，給科技圈頻道）

1. **只講三件事：待遇、職涯、技術原理。** 不講任何上市公司的營運（訂單、產能、良率、客戶、財測）。
2. **數字一律區間＋來源數＋年份**：「58K–64K（3 位網友，2026）」。
3. **兩個獨立來源對得上才刊**；只有一個來源，寫「單一來源」或不刊。
4. **不收、不貼任何截圖**（薪資單、offer、內部系統、內部文件）。
5. **部門＋職等＋年資不同時出現**，稀有職位不寫，避免投稿者被認出。
6. **負面只寫意見，不寫指控**：「網友普遍覺得工時長」可以；「公司用派系決定裁誰」不行（除非有公開報導並附連結）。
7. **台積電經驗：沒有公開連結能佐證的，就不講。** 良率、參數、客戶、代號永遠不講。
8. **不連個股頁、不寫股價推論**；導流只連首頁或待遇統計頁。
9. **每篇文末兩行固定句**（第三節 3-4 B），簡介寫「非官方資訊、不談個股」。
10. **收到更正 48 小時內改並註記；收到公司來函先下架再回；收到存證信函直接找律師。**
