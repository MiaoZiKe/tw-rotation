## 一句話診斷
不是 LOGO、不是免費給太多。10-27 起帳號從「Andy 手寫、讀者切身（科技業薪資）」換成「機器資料摘要、一天十幾則」，而且唯一爆文沒有路通到網站；IG 則是幾乎沒被平台分發。

## 弱點排名
1. 自動資料摘要取代人味內容（手寫薪資 2 篇平均 3.6 萬觀看；自動盤前盤後中位 56）
2. 爆文沒接到網站、沒留住人（6.9 萬觀看 → 追蹤只到約 200，主文無網址）
3. 帳號定位混雜（七種內容混一起）；受眾（科技上班族）≠ 產品受眾（股票）
4. 發太多又同質（放大器，非主因）
5. 網站第一眼講不清楚（一般訪客 12 個頂層分頁）——流量起來後會升到第一
6. 免費給太多、LOGO：目前影響小
