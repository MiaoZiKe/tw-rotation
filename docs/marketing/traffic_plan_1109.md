## 一、Threads 與 IG 熱門帳號的共通點
| 面向 | Threads | IG |
|---|---|---|
| 第一句／封面 | 結論或問題先講；不放欄目名 | 「數字＋身分＋衝突」（例：30歲淨資產 -69,374 元） |
| 長度 | 50～150 字，細節放串文 | 輪播 5～8 張，一篇一個重點，第 2 張能單獨成立 |
| 形式 | 純文字／1 張圖即可 | 小帳號 Reels 陌生觸及約輪播 3 倍 |
| 互動 | 回覆權重最高；發文後 1 小時內回完留言 | 傳送（分享）權重最高；收藏次之 |
| 標籤 | 只放 1 個話題標籤 | hashtag 3～5 個，效果不大 |
| 時段（台灣） | 週四 20 點最佳，週三四 20～21 點前三；週日最差 | 無可靠數據，自己測 12／20／22 點 |
| 頻率 | 每天 1～3 則固定 | 每週 2 Reels＋1～2 輪播，固定不爆量 |
| 連結 | 不放內文 | 不放 |
| 成長主力 | 去熱門串留言（我們實測單則 5,000～9,000 觀看） | 被轉傳的短影片 |

## 三、自動回覆系統（分支 claude/auto-reply-1109）
- A 層：回自家貼文留言。30～80 字、不帶網址、不點名個股、不預測、模板句與相似度擋；09:00～23:00 隨機分散；每天日報。
- B 層：主動回別人熱門串。需 `threads_keyword_search` 等權限，送 Meta 審查前只搜得到自己的貼文；審查要企業驗證、隱私權政策網址、操作錄影。
- 風險：Meta 對自動化互動有反垃圾規範，上限先抓每天 8～15 則，從低量開始。
