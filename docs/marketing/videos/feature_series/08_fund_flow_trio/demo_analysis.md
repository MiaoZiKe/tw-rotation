## 二、從示範抽出的節奏標準

1. 一次操作 ≈ 游標移動 0.5～1.0 秒 ＋ 點下 ＋ 結果停留 1～2.5 秒。示範裡純瀏覽最長停 3.5 秒（開場），看提示框最長停 2.5 秒。
2. 示範全長 28 秒做了約 14 個操作（平均每 2 秒 1 個），其中「連續取消 4 個勾選」「連換 3 個產業鏈」是 0.5～1 秒一個的快段。Andy 說「上面節奏太快了」指的就是這種連點；他自己示範時，每個「看結果」的動作（提示框、換鏈）都有停。
3. 游標不瞬移：每次落點前會有 0.3～0.5 秒的緩移與微幅修正；沒有連續兩次點擊之間游標不動的情形。
4. 示範沒有做的事（分鏡不要硬加）：沒有拖拉桿把手（回放是自動跑的）、沒有點象限卡、沒有點長條。

## 三、示範裡看到的網站行為（分鏡要避開或利用）

| 現象 | 影響 |
|---|---|
| 滑過排行長條：輪盤同步只留該族群、其他淡掉 | 這就是「兩圖連動」，最適合示範，且不蓋住內容 |
| 選產業鏈後，「族群」勾選清單自動彈出並蓋住輪盤左上 | 遮擋；錄影要在選完後立刻關掉（Escape 或點空白，實測兩種都能關） |
| 勾選族群後，右側排行區跳出「族群→公司」卡片，內有股票代號 | 違反法遵「畫面不出現個股代號」＋遮擋排行；正式片不勾族群 |
| 單一族群、占比變化接近 0 時，排行只剩極短淡條，數值字擠在族群名上 | 長條不是真的消失，是值太小＋標籤疊字；選的族群與天數要讓數值離 0 夠遠 |
| 回放期間排行長條不動（只有輪盤在動） | 示範「兩圖同步變」要用拉桿或換產業鏈，不能用回放 |
