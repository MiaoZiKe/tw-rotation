## 1. 一條主線（追同一個族群貫穿三頁）

> 哪些族群的資金占比在增加（輪動）→ 這份錢從大盤一層層分到哪個產業、哪個族群（分流樹）→ 這個族群裡，外資、投信、自營各站哪一邊（族群×法人）

**貫穿族群：半導體鏈底下的「晶圓代工」。** 2026-10-24 本機資料實測，三頁都出現且位置前段：

| 頁 | 實測（20 天視角、10-08 資料） |
|---|---|
| 資金輪動 | 選半導體鏈後，晶圓代工排行第 1（占比變化 +1.18pp） |
| 資金分流樹 | 半導體 47.6% 底下第一個葉節點，占該鏈 27.4% |
| 族群×法人 | 選半導體鏈後排第 2（占 18.5%，外資＋自營為主） |

**錄影當天要重驗（資料每天變）。** 選取規則：「半導體鏈內，輪動排行、分流樹葉節點、族群×法人三頁都在前 3 名的族群」；晶圓代工不符合就換符合的族群，泡泡裡的族群名跟著換，其他步驟不變。泡泡只講「占比」「分到」「站哪邊」，不講強弱買賣。

**三頁的篩選不會帶到下一頁**（實測：輪動選了半導體，進分流樹與族群×法人都被重設成「全部」），所以每頁各選一次「半導體」。這也剛好是「同一個族群連看三次」的畫面節奏。

## 2. 網站實際確認（本機站＋訪客身分，site/ 未改動）

| 頁 | 能操作的東西 | 訪客實測結果 |
|---|---|---|
| 資金輪動 | 滑過排行長條（提示框＋輪盤只留該族群）、拉桿換天數（1～30）、▶ 回放、產業鏈下拉、族群勾選、軌跡／腳印／水波／掃描四個勾、四個象限鈕 | 拉桿、回放、產業鏈、長條提示框都可用 |
| 資金分流樹 | 點節點（右側名單換成該節點底下的族群、其他枝淡掉）、滑過葉節點（旁邊展開公司名）、產業鏈／族群下拉、看哪一天拉桿、流入最多／流出最多分頁、動態開關 | 點「半導體」節點可用；點葉節點會在名單列出個股代號（不用） |
| 族群×法人 | 滑過長條（提示框顯示外資／投信／自營張數與占比）、圖例點選（單獨隱藏外資等，座標自動重新縮放）、產業鏈／族群下拉、近 N 天雙把手拉桿；右邊另有資金集中度折線圖 | 提示框、圖例、產業鏈都可用；**點長條會直接跳去產業地圖頁（不用）** |

**「族群下拉勾一個族群後排行長條會不會消失」**：照實寫——不會消失，但會「看起來消失」。
- 本機訪客實測：選半導體→只勾晶圓代工，長條正常（+1.18pp，約 440px 寬）。
- Andy 示範那一段（回放日 10/15）：該族群占比變化只有 -0.10pp，長條極短又淡，數值字（-0.10、-5.1%）擠在族群名上，看起來像消失。所以是「值接近 0＋標籤疊字」，不是畫不出來。
- 另外勾族群時會**彈出「族群→公司」卡片，卡片上有股票代號，並蓋住排行區上半**（本機實測、示範 20.0 秒也有）。這違反法遵與遮擋規則，**正式片不示範勾族群**；Andy 示範裡「族群下拉只留一個」的效果，改用「產業鏈下拉」達成（排行與輪盤同樣只留那一條鏈，沒有彈卡片）。

## 4. 共同規格

- **每一鏡的欄位**：秒數｜畫面（頁、框哪塊、鏡頭）｜滑鼠或手指｜停｜比比泡泡（≤14 字）｜比比（表情／道具）｜遮擋風險。大標題（≤12 字）寫在畫面欄開頭【】。
- **泡泡**：比比用泡泡說話、不配旁白；一泡一句；成片停留 ≥1.4 秒；泡泡與尾巴只指向比比，放網站框外的空帶（網頁在框下方左側、手機在框下方窄帶），不壓網站任何字。
- **比比**：整支 ≥2 種表情，**每個功能段各 1 個題材道具**（不用金錢圖示）。素材取自 `docs/anim/bibi_library/`：`face_think`、`face_curious`、`magnifier`、`point_r`／`point_ur`、`clock`、`folder`、`spotlight`、`face_thinking_bulb`、`talk_explain`、`face_nod`、`face_proud`、`face_bow`、`tap`。缺的題材道具（輪盤、樹枝、三色小旗）不阻擋，先用上述近似動作；提示詞日後補在本資料夾 `asset_prompts.md`。
- **游標**：每次落點前 0.4～0.8 秒緩移＋0.1～0.2 秒微幅修正；點下前先停 0.2～0.3 秒；移動路徑沿「看過的地方」走（先看輪盤、再看排行），不直線瞬移；游標只在點下去的瞬間可停在被點目標上，其餘時間避開文字外框。
- **訪客真實畫面**：未登入、不藏客服鈕、不放角標備註；全片零模糊（錄影端關掉所有 blur／backdrop-filter）。
- **法遵**：畫面不出現個股代號、評分、買賣字眼（網站自己的「淨買超」等欄位名照原樣，不是我們加的文案）；泡泡不點名個股、不做推薦；片尾搜尋「哩股哩股」＋免責字卡照 `docs/launch_gap_legal_1009.md` 第 251 行起「影片片尾版」一字不改，停 ≥3 秒（這裡排 4.5 秒）。
- **鏡頭**：全片只有「單向往下捲」（分流樹 B3 一次、手機各頁一次）；無推拉往返、無硬切、無淡化霧罩、無標題卡換場。
- **回報行（交片必寫）**：「重疊檢查：程式 N 幀 0 筆；人工 M 格 0 筆」「遮擋檢查：程式 N 幀 0 筆；人工 M 格 0 筆」「模糊檢查：程式 N 幀 0 筆；人工 M 格 0 筆」。人工每 0.5 秒抽一格、全解析度逐張看（87 秒＝174 格；手機 179 格）。
