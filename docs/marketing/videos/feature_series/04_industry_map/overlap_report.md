# 重疊與畫面檢查報告 v3（render_ind.py 原片每一幀自動產生＋人工抽格）

裁切檢查（v2 起改嚴）：介紹區塊用「元素本身的完整外框」（不以視窗裁切，露在視窗外也算），比的是每一格「實際裁切範圍」（含鏡頭慢移的內縮），區塊有任何一邊超出就記一格；鏡頭在兩拍之間推移的途中（目標取景還沒到位，每次約 0.4～0.8 秒）另列「推移中」不計入。手機關聯圖另外逐格檢查「框邊有沒有切過任何一張環節卡」（卡片外框與實際裁切範圍部分相交就記一格）。
