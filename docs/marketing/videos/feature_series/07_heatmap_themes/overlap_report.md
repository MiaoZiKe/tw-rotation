# 重疊與畫面檢查報告（render_ev.py 原片每一幀自動產生＋人工抽格）

裁切檢查：介紹區塊用「元素本身的完整外框」（不以視窗裁切，露在視窗外也算），比的是每一格「實際裁切範圍」（含鏡頭慢移的內縮），區塊有任何一邊超出就記一格；鏡頭在兩拍之間推移的途中（目標取景還沒到位，每次約 0.4～0.8 秒）另列「推移中」不計入。

## 網頁版

- 片長 44.17 秒；程式逐幀檢查 1985 幀；元素外框外擴 6px 兩兩比對：**重疊 0 筆**；其他問題（泡泡字出框、尾巴離比比、超過 14 字、泡泡停留不足 1.45 秒）**0 筆**。
- 登記的元素：膠囊、標題、右上（上方）說明、功能導覽（網頁）、網站畫面框、泡泡（含尾巴）、比比（每一幀實際不透明外框）、片尾卡內各元素。
- 人工抽格：原片每 0.5 秒存一張全解析度（scratchpad `feat07/samples_d/`，共 133 張），排成縮圖總表（網頁每張 960 寬、手機每張 300 寬）逐張看過（重疊、出框、黑畫面、泡泡與比比）：0 筆重疊、0 筆出框、0 張黑畫面。網頁版點方塊拍的提示框、剖析圖下緣在鏡頭推移那幾格（約 0.4～0.8 秒）會被取景下緣裁到，屬推移中、不計入裁切數。只看縮圖、未逐張開全解析度原圖。
