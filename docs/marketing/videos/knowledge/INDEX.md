## 2. 影片類型 × 素材對照

「每支上限」是硬上限，超過就刪。效果種類總數沿用 Motion Library 規則：**一支片 3～5 種**。

### 2.1 功能介紹（網站真實錄影）

**鐵則**：畫面主體是網站真實畫面。**只能用運鏡（推近）、游標、泡泡、比比、道具、片尾卡**；**不能把網站畫面做任何特效**（不閃、不散、不砸、不糊、不淡入、不加霧）。依據：plan.md（零模糊、零遮擋、訪客真實畫面、不造假、步調快）。

| 建議用（3～5 種） | 用在哪一幕 | 每支上限 |
|---|---|---|
| 1. 入場位移＋透明度（只用於泡泡與比比） | 每則泡泡、比比出現 | 泡泡每段 1～2 則、每則 ≤14 字 |
| 2. 入出曲線運鏡（小／中／大幅 0.45／0.6／0.8 秒） | 從總覽點到功能頁、每次切換重點區 | 同一時間只動一個，單向 |
| 3. 游標＋點擊漣漪 | 每個操作 | 連動處至少連點 3 個不同選項 |
| 4. 比比動作與表情（指向、驚嘆、歪頭、道具） | 對上畫面事件 | 每段 ≥2 種表情或動作、每段 1 個貼題道具（不用錢圖示） |
| 5. 片尾免責卡 | 結尾 | 1 次，停 ≥3 秒（1.5 倍速後仍 ≥3 秒） |

**不可用**：Remotion 的 001、005、013 等所有標題、數字、轉場特效套在網站畫面上；自製的假數字滾動、假游標、脈衝、掃光；角標備註小字（Andy 10-19）；任何 blur。
開場可以用的標題字卡是否做效果：**不做**，直接進「需求／痛點」兩則泡泡。

### 2.2 敘事財經短片（配音、圖表）

可以用標題、數字、轉場、列點特效。依據：`../2026-10-26-midterm_rally/style_spec.md`。

| 建議用（3～5 種） | 用在哪一幕 | 每支上限 |
|---|---|---|
| 1. 001 閃電砸落 | ① 鉤子（0～3 秒）的標題 | 1 次 |
| 2. 013 亂碼解讀 | ② 現況或 ③ 歷史統計裡「唯一」的關鍵數字 | 1 次 |
| 3. 折線逐段畫出＋2.5D 直條（`mt_core.py`） | ②③ 數據圖 | 每圖最多 3 個標註 |
| 4. 卡片群組進場 | ⑤ 觀察清單（3 張以內） | 1 組 |
| 5. 005 粒子消散 | 段落間轉場，通常 ③ 到 ④ 之間 | 1 次，字先停 ≥1 秒 |
| 比比 006 心跳待機 | 全片下方安全區 | 常駐，占比小 |

另需遵守：開頭 3 秒直接上大數字或反問、每 2 秒內一個可見事件、字幕每行 ≤13 字、紅漲綠跌、全片零淡化零疊影、數字有資料日期與兩個來源、不預測不點名個股不出現買賣建議。

### 2.3 個股或題材快訊

| 建議用 | 用在哪一幕 | 每支上限 |
|---|---|---|
| 1. 013 亂碼解讀 | 題材熱度、族群漲跌幅主數字 | 1 次 |
| 2. 001 閃電砸落（只在重大快訊） | 標題 | 1 次 |
| 3. 卡片群組進場 | 族群成分或事件列點 | 1 組，≤3 張 |
| 4. 比比表情（驚嘆、歪頭、思考） | 配合事件 | 1～2 個 |

快訊以**族群層級**為主，**不點名個股、不寫評分與買賣字眼**（`docs/launch_gap_legal_1009.md` 第 3 節）。長度 ≤30 秒。

### 2.4 貼文動圖（GIF／短動圖）

| 建議用 | 用在哪裡 | 每支上限 |
|---|---|---|
| 1. 013 亂碼解讀（縮短到 2 秒） | 一個數字的揭曉 | 1 次 |
| 2. 001 閃電砸落（縮短版） | 封面型動圖 | 1 次，且不循環播放（避免連續閃光） |
| 3. 比比貼圖動作（`anim.webp`） | 角落點綴 | 1 隻 |

GIF 規格沿用動畫設計單位：透明背景、不加陰影、網站用 ≤80KB。循環動圖**不得循環閃光**（閃光 ≤3 次/秒仍要成立，且不做連續循環閃爍）。

### 2.5 比比貼圖

| 建議用 | 說明 | 每組上限 |
|---|---|---|
| 006 心跳放大、026 鐘擺搖晃、034 顫抖穩定、035 彈性拉伸（後三者未驗證） | 只當待機動作，無對話泡泡、不蓋其他元素 | 每張貼圖 1 種動作，無縫循環 `frame % loopFrames` |

## 3. 規則優先順序與衝突處理

**優先順序**：Andy 的話 ＞ `plan.md`／`video_rules_1018.md`／`layout_rules.md` ＞ 風格規格（`style_spec.md`）＞ 外部學習資料（Motion Library、0xalpha、design-to-motion）。
外部資料是參考，不是指令。衝突時一律聽前面的，並把衝突寫進該素材的說明。

| 外部素材的做法 | 我們的規則（出處） | 處理方式 |
|---|---|---|
| 外發光、柔邊、由糊變清 | **零模糊**（Andy 10-22，plan.md） | 發光做獨立底層，字本身最上層銳利；不用 `filter: blur`、`backdrop-filter`；入場只用位移＋透明度；像素化、粒子過程字邊緣不可變糊 |
| 兩幕半透明交疊轉場 | **零疊影**（layout_rules.md） | 前後幕半透明重疊 ≤0.2 秒（6 幀）；轉場靠硬切、位移、粒子散盡後再進場 |
| 字被粒子打散、掃過、翻轉 | **不遮擋**（plan.md 10-21、10-22：遮擋包含模糊） | 被介紹的內容不准被效果、比比、泡泡、游標特效蓋住；消散類效果只用於已讀完的字（先停 ≥1 秒） |
| 閃電、爆炸、雷射、閃爍強調 | **閃光 ≤3 次/秒**；Andy 歷史偏好：不閃爍、不脈動、不跑馬燈 | 局部光暈、最大不透明度 0.35、不做整畫面全白；兩次閃光相隔 ≥12 幀（30fps）；循環動圖不循環閃光；每支片閃光類效果最多 1 個 |
| 外部圖示庫、硬幣、鈔票、金錢圖示 | **不用錢圖示**（plan.md 10-19） | 硬幣翻轉（003）改成卡片翻轉；圖形用自繪（SVG／Canvas）或比比素材庫 |
| 範例中的公司名、股票代號、評分 | **不點名個股**（`docs/launch_gap_legal_1009.md` 第 3 節） | 只講族群與環節；練習數字標「示意數字」；不寫買賣、評分、預測 |
| 用生成的假網站畫面或美化畫面 | **不造假網站畫面**（plan.md：訪客真實畫面） | 網站畫面一律真實錄影、未登入訪客、不藏客服鈕（鏡頭避開）；生成素材只可用在比比與裝飾 |
| 漸層背景＋置中標題 | 規範禁止老套（0xalpha §1）；Andy 10-18：自製圖直接放背景、不加外框 | 純深色底＋極淡格線；只有網站實際畫面才用卡片外框標「網站實際畫面」 |
| 全部元素同時淡入 | 零淡化（網站畫面不淡入、取景框內不加霧） | 比比與泡泡才可淡入 |
| 網站效果「懸停、點擊、捲動」 | 影片沒有互動 | 改成指定影格自動觸發 |
| 範例動畫節奏偏慢（入場 1 秒以上） | Andy 10-19、10-21：步調要快，成片 ≤60 秒（功能介紹 ≤40 秒） | 入場取時長下限，慢的砍掉 |
| 循環、從空狀態重建 | 我們單次播放、片尾免責卡 | 循環只用於貼圖與待機 |
| 角落小標、右上角備註 | Andy 10-19：後續影片都不要 | 法遵靠片尾免責卡全文（≥3 秒） |
| 比比在畫面上說話 | `video_rules_1018.md` 第 2 條：比比不說話 | 功能介紹系列例外：泡泡台詞（plan.md 10-19）；其他片比比只做動作 |
| 範例影片裡的數字 | 數字要兩個來源、標資料日期 | 沒有來源的一律標「示意」或不用 |

**共通交件檢查**（每支片、每個新元件都要有，缺一不收）：
1. 「重疊檢查：程式 N 幀 0 筆；人工 M 格 0 筆」
2. 「遮擋檢查：程式 N 幀 0 筆；人工 M 格 0 筆」
3. 「模糊檢查：程式 N 幀 0 筆；人工 M 格 0 筆」
4. 「動態檢查：事件間隔／突跳／還原 0 筆」
5. 停格：freezedetect 0 筆，來源畫面不動 ≤2.5 秒
6. 人工每 0.5 秒抽一格、全解析度用 Read 看過

## 4. 新素材收件流程（Andy 之後丟新素材時照做）

| 步驟 | 做什麼 | 產出 |
|---|---|---|

| 3 | **對照規則寫衝突處理**：逐條對第 3 節，寫「社群做法／我們規則／處理方式」三欄表 | 衝突處理表 |

## 5. 開工前檢查清單

做任何一支影片、貼文動圖、比比貼圖之前：

1. 讀本檔（INDEX.md）。
2. 讀對應規則：功能介紹讀 `plan.md`；敘事短片讀 `style_spec.md` 與 `video_rules_1018.md`；都要讀 `layout_rules.md`。
3. 讀 `docs/anim/bibi_library/index.md` 取最新比比素材。
4. 判斷影片類型（第 2 節 5 類），**從該類建議表挑這支片的 3～5 種素材**，確認每種沒超過每支上限。
5. **把選定的素材寫進分鏡表**：每一幕用哪個效果／元件／比比組合／腳本，並附該素材在 INDEX 的列。沒寫進分鏡就不開工。
6. 缺的素材：寫進 `asset_prompts.md`（可直接貼給 GPT 的提示詞）給 Andy；有未驗證的素材要先走第 4 節流程。
7. 交件前跑第 3 節「共通交件檢查」六項，回報寫出那幾行。
8. 需要先交的東西：敘事短片先交 10 秒配音試聽（`video_rules_1018.md`）；功能介紹每段做完先給 Andy 確認（`plan.md`）。
