# 效果拆解表（階段 × 影格區間 × 屬性變化，30fps）

## 練習 1：001 閃電砸落（72 幀＝2.4 秒，`LightningSlam`）
| 階段 | 影格 | 屬性變化 |
|---|---|---|
| 靜候 | 0–3 | 純背景 |
| 第一次閃光 | 4–11 | 局部放射光暈不透明度 0→0.35→0（峰在第 6 幀）；閃電折線同步出現（固定 seed） |
| 第二次閃光 | 16–23 | 同上，形狀不同；兩次起點相隔 12 幀＝2.5 次/秒（≤3） |
| 砸落 | 20–25 | 字第 20 幀硬切出現（不漸變、不糊），縮放 1.8→1（Easing.in cubic）。原稿 2 倍，1080 寬放不下，改 1.8 |
| 落地 | 25–36 | 阻尼震動（位移 16px 指數衰減）＋縮放小彈（4.5%）＋震波細橢圓 330→540 外擴、透明度 0.55→0（不穿過字） |
| 發光 | 30–42 | 底層外發光 0→0.45（10px），之後固定不脈動 |
| 停留 | 42–72 | 靜止（落地後停留 1.4 秒） |

## 練習 2：013 亂碼解讀，數字版（90 幀＝3 秒，`DecodeNumber`）
| 階段 | 影格 | 屬性變化 |
|---|---|---|
| 標籤 | 0 起 | 「近一季漲幅」固定顯示 |
| 亂碼 | 6–24 | 每 2 幀由 `random(seed-位-tick)` 換字，灰色 |

| 停留 | 49–90 | 靜止 1.4 秒；標「練習用示意數字，非實際資料」 |

## 練習 3：005 粒子消散轉場（105 幀＝3.5 秒，`ParticleDissolve`＋B 幕）
| 階段 | 影格 | 屬性變化 |
|---|---|---|
| A 完整停留 | 0–36 | 字完整 1.2 秒（≥1 秒） |
| 消散 | 36–60 | 4px 取樣，由左至右依序離開；每顆飛行 ≈11 幀，向右上飄＋重力，透明度 1−t²、尺寸縮 45%；固定 seed=3 |

| B 停留 | 70–105 | 靜止 |
