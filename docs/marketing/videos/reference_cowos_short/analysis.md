# 範例片拆解：cowos_short.mp4（「每日財經筆記」CoWoS 一分鐘）

Andy 2026-10-18 上傳，要求「詳細拆解這影片的格式、規劃，最重要的是配音來源」。量測工具：ffprobe、ffmpeg silencedetect／volumedetect、每秒抽格總覽、Python 頻譜與基頻分析（腳本在 scratchpad，不進 repo）。

## 一、檔案規格

| 項目 | 值 |
|---|---|
| 畫面 | 1080×1920 直式、30fps、H.264 High、約 0.41 Mbps（畫面以平面色塊為主，碼率很低） |
| 長度 | 76.1 秒 |
| 聲音 | AAC 單聲道、**96 kHz**（不常見，代表後製程式重新取樣過） |
| 封裝 | 由 ffmpeg 6.1（Lavf60.16／libx264）輸出 → 程式自動合成，不是剪輯軟體手剪 |
| 響度 | 平均 -16.1 dB、峰值 -1.3 dB |
| 配樂 | **沒有**：句與句之間的空檔低於 -40 dB，整條音軌只有人聲 |

## 二、版面（由上到下，固定不動）

1. 頂端品牌膠囊「● 每日財經筆記」（深底、青綠細框、橘點）。
2. 進度條（青綠→橘漸層）：顯示目前講到全片第幾段。
3. 大標（米白粗體約 90px，例如「什麼是 CoWoS？」）＋副標（青綠，例如「Chip on Wafer on Substrate」）。
4. 中央圖解區：**圖直接畫在深色背景上，不加外框**；平面＋微立體色塊（橘＝主角、青綠＝中介層、紫＝HBM、灰藍＝基板）。
5. 字幕卡：深色圓角卡、左側橘色豎條、白色粗體約 56px，一次一句重點（不是逐字稿）。
6. 頁腳：「**非投資建議**｜資料：大摩、DIGITIMES、優分析、科技新報（2025.12–2026.09）｜數字為市場推估」。

背景：深藍黑（約 #0b1218）＋淡格線＋右下角暖色暈光。

## 三、段落規劃（6 段，每段一張圖，圖會「長出來」）

| 段 | 時間（秒） | 大標／副標 | 圖怎麼長 | 字幕卡依序 |
|---|---|---|---|---|

## 四、配音來源（重點）

**結論：是「文字轉語音」（合成人聲），不是真人錄音。最可能是微軟神經語音（Edge 朗讀／Azure 語音同一套聲音）的女聲，而且每段分開產生再接起來。** 信心：合成語音＝高；微軟系＝中；確切是哪一個聲音＝低（我沒辦法「聽」，只能量測）。

證據：

| 量到什麼 | 代表什麼 |
|---|---|
| 頻譜在 **約 11 kHz 處像刀切一樣斷掉**，以上完全沒有聲音（音軌卻標 96 kHz） | 原始音檔是 **24 kHz 取樣的 MP3**，後來被放大到 96 kHz。24 kHz MP3 正是 Edge／Azure 神經語音、OpenAI 語音、Google 翻譯語音的標準輸出；真人錄音或配音員檔案通常是 44.1／48 kHz，會有 11 kHz 以上的氣音與齒音。 |
| 段落之間的停頓 **固定約 0.7 秒**（6.7、21.7、36.5、49.6、60.9 秒），句內停頓 0.14～0.3 秒 | 每段各自送去產生一個音檔，再用程式插 0.7 秒靜音接起來；句內短停是語音引擎依標點自己停的。 |
| 6 個段落邊界跟畫面換段 **完全同一秒** | 畫面時間軸是照每段音檔長度排的（我們 10-18 比比版也是這樣做）。 |
| 沒有任何呼吸聲、背景底噪 | 合成語音特徵。 |
| 基頻（音高）中位數 **約 245 Hz**、起伏小（標準差約 2.1 個半音，比我們試過的各聲音都平） | 年輕女聲；語調偏平，就是 Andy 說的「一聽就知道 AI」那種感覺。 |

跟我們已產生的 8 個微軟女聲試聽檔比對（同樣量音高與音色頻譜，數字越小越像）：

| 聲音 | 音高中位數 | 音色距離 |
|---|---|---|
| **zh-CN-XiaoxiaoNeural（曉曉，中國口音）** | 255 Hz | **2.9（最接近）** |
| zh-TW-HsiaoChenNeural（曉臻，台灣） | 212 Hz | 3.7 |
| en-US-AvaMultilingualNeural | 221 Hz | 3.8 |
| zh-TW-HsiaoYuNeural（曉雨，台灣，音高 +15Hz） | 222 Hz | 4.4 |
| zh-TW-HsiaoYuNeural（曉雨，原音高） | 200 Hz | 4.7 |
| 其他（曉伊、Emma、Vivienne、Seraphina） | — | 5.6～6.8 |

⚠ 最接近的是**中國口音**的曉曉，但距離不是零，不能下定論；也可能是 OpenAI 語音或其他 24 kHz 引擎。最快的確認方式：問產生這支片的人（若是 ChatGPT 做的，直接問它「配音用哪個語音引擎、哪個聲音」）。

## 五、我們要學的、不要學的

- 學：深色底＋圖直接畫在背景上不加框、一段一張圖逐步長出來、一句一張字幕卡、進度條、頁腳固定「非投資建議＋資料來源＋數字為推估」、時間軸由配音長度決定。
- 不學：語調平的合成聲（Andy 要台灣口音、口語、不像 AI）；點名客戶與個股（我們的法遵規則不允許）；沒有配樂（可以保留很輕的底樂）。
