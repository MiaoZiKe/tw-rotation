## 二、版面（由上到下，固定不動）

1. 頂端品牌膠囊「● 每日財經筆記」（深底、青綠細框、橘點）。
2. 進度條（青綠→橘漸層）：顯示目前講到全片第幾段。
3. 大標（米白粗體約 90px，例如「什麼是 CoWoS？」）＋副標（青綠，例如「Chip on Wafer on Substrate」）。
4. 中央圖解區：**圖直接畫在深色背景上，不加外框**；平面＋微立體色塊（橘＝主角、青綠＝中介層、紫＝HBM、灰藍＝基板）。
5. 字幕卡：深色圓角卡、左側橘色豎條、白色粗體約 56px，一次一句重點（不是逐字稿）。
6. 頁腳：「**非投資建議**｜資料：大摩、DIGITIMES、優分析、科技新報（2025.12–2026.09）｜數字為市場推估」。

背景：深藍黑（約 #0b1218）＋淡格線＋右下角暖色暈光。

## 三、段落規劃（6 段，每段一張圖，圖會「長出來」）

## 四、配音來源（重點，2026-10-18 第二次辨識，蓋掉第一次的結論）

**結論：是合成語音（把握高），但「不是」微軟 Edge／Azure 語音，也「不是」Google 翻譯語音（把握中高）。原始音檔是 22.05 kHz 取樣，最可能來自 ElevenLabs 這類可輸出 22.05 kHz 的 AI 配音服務（把握低）。確切來源要問做這支片的人。**

第一次我說「最可能是微軟語音」，是只比了 8 個試聽檔、而且台詞不同。第二次的做法：在 GitHub 上用同一段台詞產生 14 個候選（微軟中國、台灣、香港、遼寧、陝西女聲共 8 個＋3 個調速調音版，Google 語音 3 個），逐一跟範例片比對。

| 證據 | 範例片 | 微軟／Google 候選 | 代表什麼 |
|---|---|---|---|
| 高頻截止點（0.1 kHz 一格細量） | **11.05 kHz** 斷掉 | 全部在 11.3～11.4 kHz 才斷 | 範例片原始取樣率是 **22.05 kHz**（一半剛好 11.025 kHz）；微軟、Google、OpenAI 輸出都是 24 kHz，截止點對不上 |
| 語調起伏（音高標準差，半音） | **2.13**（很平） | 14 個候選都在 2.77～4.01 | 沒有一個候選平到這個程度 |
| 音高中位數 | 242 Hz | 音高對得上的（曉臻調高 30Hz＝240、陝西曉妮＝240）語調起伏和音色又對不上 | 沒有一個候選「同時」對上 |
| 段落停頓 | 固定約 0.7 秒 | — | 分段產生、程式接起來（第一次的判斷不變） |
| 呼吸、底噪 | 沒有 | — | 合成語音（第一次的判斷不變） |

會輸出 22.05 kHz 的常見來源：ElevenLabs（有 22.05 kHz 輸出選項）、Coqui／Piper 這類開源語音模型、部分剪輯 App 內建配音。**光靠量測沒辦法再縮小範圍**；最快的確認方式是問產生這支片的人（若是 ChatGPT 或其他 AI 工具做的，直接問它「配音用哪個服務、哪個聲音」）。

候選試聽檔在 `voice_id/`（同一段 4 句台詞），產生腳本 `voice_id_script.json`；比對腳本在 scratchpad，未進 repo。

## 五、我們要學的、不要學的

- 學：深色底＋圖直接畫在背景上不加框、一段一張圖逐步長出來、一句一張字幕卡、進度條、頁腳固定「非投資建議＋資料來源＋數字為推估」、時間軸由配音長度決定。
- 不學：語調平的合成聲（Andy 要台灣口音、口語、不像 AI）；點名客戶與個股（我們的法遵規則不允許）；沒有配樂（可以保留很輕的底樂）。
