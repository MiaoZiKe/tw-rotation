# 盤前貼文「盤面解讀」判斷規則

> 2026-10-26 Andy：「CEO 需要安排專業金融專家進行盤面分析，例如近期股市不斷下跌，昨日費半原先下跌後來開高…台積電 ADR 也一樣開低走高」。
> 程式：`scripts/social_premarket.py` 的 `bar_read()`／`market_reads()`。門檻經金融口徑專家審查（同日），對照鉅亨、經濟日報、工商時報的盤勢用語。

## 只寫事實、不寫預測（投信投顧法）
- 不用：可望、有望續攻、將反彈、支撐有守、壓力在 X 點、超賣、止跌、漲多拉回、逢低布局、強勢股、目標價。
- 改用事實句：「連 4 黑後收紅」「距 60 日高點 −8.5%」「站回月線」。

## 判斷式（c 收、o 開、h 高、l 低、pc 前收）
| 項目 | 規則 |
|---|---|
| 平開 | \|o/pc−1\| < 0.15%（費半、台積電 ADR 0.3%），或 o＝pc（Yahoo 指數常回傳開盤＝前收） |
| 走高／走低 | (c−o)/pc ≥ +0.2% 走高；≤ −0.2% 走低；中間寫「開高後震盪／開低後震盪」 |
| 盤中翻紅／翻黑 | 開高走高但 l < pc →「開高後一度翻黑、隨後拉高」；開低走低但 h > pc →「開低後一度翻紅、隨後走低」；開低走高且 c > pc →「開低走高、翻紅作收」 |
| 窄幅 | 振幅 (h−l)/pc < 0.5% →「窄幅震盪」 |
| 收盤位置 | 振幅 ≥ 0.8% 才寫；(c−l)/(h−l) ≥ 75%「收在日高附近」、≤ 25%「收在日低附近」；已寫走高／走低時不重複 |
| 連 N 黑／紅 | 昨天往回連續收黑 ≥ 3 天且今天收紅 →「連 N 黑後收紅」；反之「連 N 紅後收黑」 |
| 近 5 日 | 累計 ≤ −3%（費半、ADR −5%）或 ≥ +3% 才寫 |
| 距 60 日高點 | c ÷ 近 60 日最高收盤 − 1 ≤ −5% 才寫（＝「近期不斷下跌」的數字版） |
| 均線 | 只寫穿越：昨天在線下、今天收在線上「站回」，反之「跌破」。美股指數寫 20 日線／60 日線，台積電 ADR 寫月線／季線 |
| ADR 量能 | 成交量 ÷ 前 5 日均量 ≥ 1.5「量增」、≤ 0.7「量縮」（指數成交量不可靠，不寫） |
| VIX | **2026-10-26 Andy：「vix 拿掉」→ 盤前貼文與文案都不再提 VIX**（以下規則停用、保留備查）。原：Andy：「VIX 怎麼可能叫做平穩區」→ 不再用「平穩區」。水位：<15「處於低檔」、15–20「逼近 20 警戒線」、20–30「站上 20 警戒線」、≥30「進入 30 以上恐慌區」；加上圖上一個月第一天到今天的變化 ≥ +15%「避險情緒明顯升溫」、≤ −15%「降溫」；收在 20 以下但近 10 日盤中碰過 20 以上，寫「近 10 日盤中最高 x」；單日 ±10% 加「單日急升／回落」 |
| 美股未收盤 | 標「（盤中）」，不寫「作收／收在」、不比量能（只會出現在示範；正式 08:20 發文時美股已收盤） |
