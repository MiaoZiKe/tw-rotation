# 哩股哩股社群貼文版型規範（盤前／盤中／盤後共用，2026-10-26 第 1 版）

Andy 10-26 原話：「這排版還是不好看　CEO 幫我優化　我需要盤前、中、後都需要看起來專業點」。
適用：Threads 輪播（1080 寬）、IG 限動（1080×1920）。由 `scripts/social_snap.py`（盤中、盤後法人、盤後融資融券）與 `scripts/social_premarket.py`（盤前）產出。
示意稿與產生器：`scratchpad/post_design/`（`gen.py` 一支腳本產 6 張，數值全部照本文件）。實作階段另派（階段 2，抽成 `scripts/social_theme.py`）。

> 依據說明：容器打不開外部網站，沒有競品截圖可量。「財經媒體做法」一欄是我對 Bloomberg 終端、CNBC、券商 App 社群圖的**一般認知（推估，沒量過）**；
> 所有數值是為了「手機上看 1080 圖縮成約 390pt 寬仍讀得到」自己訂的（縮放比約 0.36），不是抄任何一家。只學間距、層次、色階的通用做法，不用對方的識別。

## 二、選擇：深色「財經終端」風為主，淺色為備用

**主版型＝深色終端風**（底 `#0A0F1C`、卡 `#111A2F`）。理由（證據而非偏好）：
1. 網站預設主題就是深色（`site/index.html` `:root` `--bg:#070b16`），社群圖與網站同色系，Andy 10-20 規矩「搭配截圖色調」；`social_snap.py` 已有 `FRAME["dark"]`、`--frame dark`，截圖來源不必改。
2. 紅 `#FF5A73`／綠 `#2EE59D` 在深底對比比淺底高（紅 5.74:1、綠 10.56:1，實算，對卡色 `#111A2F`），小字、細線也讀得到。
3. Threads／IG 動態牆多為白底，深色圖塊在動態中第一眼被看見；券商 App 與終端同樣用深色呈現行情，使用者對「深色＝行情」有既定認知。
4. 盤前／盤中／盤後用同一底色，靠標題列「時段膠囊」的顏色區分，不再靠三種底色。

**淺色版只當備用**（`--frame light`，沿用 `FRAME["light"]` 現值 `#F4F3EF`／`#fff`）：Andy 若看完示意稿偏好淺色，只換第三節的 token 表，版面規則全部不變。**不做兩種並行**——一個品牌一個主風格。

## 四、畫布與安全邊距

| 項目 | Threads 輪播 | IG 限動 |
|---|---|---|
| 尺寸 | **1080×1350（4:5）**，全組輪播同尺寸（Threads 輪播第一張決定比例，之後不可不同） | **1080×1920（9:16）** |
| 左右邊距 | 40px | 48px |
| 上邊距 | 36px | **250px**（IG 頂部頭像／進度條蓋掉約 14%，內容全放安全區） |
| 下邊距 | 40px | **230px**（回覆欄、貼紙區蓋掉） |
| 內容區 | 1000×1230 | 984×1440（上下安全區的底色照畫，不放任何字） |
| 卡片間距 | 14～16px | 14～16px |
| 卡片內距 | 24～26px（KPI 小卡 14～18px） | 同 |
| 圓角 | 卡片 18～20px、LOGO 17px（72px 方塊）、膠囊 12px | 同 |
| 陰影 | `0 6px 24px rgba(0,0,0,.35)`（深色）；淺色改 `0 2px 10px rgba(0,0,0,.08)` | 同 |

規則：**內容撐滿內容區**（卡片用 flex 均分剩餘高度，不留底部空白；內容少就放大字級與圖表，不補裝飾）。限動上下安全區是「刻意留的」，不算大空白；Threads 版不准有。
例外：圖表卡高度若不足以讓圓盤／K 線至少 600px 高，改把上方名單改成單段文字（見輪盤示意稿）。

## 五、標題列（所有張共用，唯一的品牌位置）

由左至右一列，高 88px，下方 2px 強調線（左 `--accent` 漸層到透明）：

| 元素 | 規格 |
|---|---|
| LOGO | 比比 App 圖 `site/brand/icon-192.png`，72×72、圓角 17px，貼左邊距 |
| 時段膠囊 | 「盤前／盤中／盤後」28px／800，內距 6×18、圓角 12px、底色見色票，LOGO 右 18px |
| 標題 | 功能名稱（今日焦點、資金輪盤、三大法人買賣超…）54px／800（限動 ×1.1＝59px），單行不換行，不放日期 |
| 日期 | **靠右對齊**，Inter 36px／600（限動 40px），格式 `10/27 週二`（盤前）、`10/27 11:05`（盤中）、`10/21`（盤後；資料日） |

- **日期只出現在標題列**，圖上其他地方不寫日期。
- **圖上不放任何備註與來源**（Andy 規定）：免責、資料來源、網址、「示意」「僅供參考」全部放 Threads 貼文文字，不進圖。
- **品牌浮水印＝標題列的 LOGO，不另加第二個**（標題列已佔左上；再放右下會變成兩個）。不放網址、不放文字浮水印。截圖若是直接截網站畫面，要把網站自己的 LOGO／網址列用遮罩切掉，只留圖。

## 六、字體與字級階層

字體：中文 `Noto Sans CJK TC`（現有 fallback 鏈不變）；**所有數字、日期、代號用 Inter＋`font-variant-numeric:tabular-nums`（等寬數字）**，`letter-spacing:-.01em`。
縮放基準：1080 圖在手機約縮成 0.36，所以**畫布字級下限 24px（約 8.6pt）**、內文 ≥ 28px。這比網站 12px 下限嚴，因為網站是 1:1 看、社群圖是縮小看。

| 層級 | Threads | 限動（×1.1） | 字重 | 用途 |
|---|---|---|---|---|
| 標題 | 54 | 59 | 800 | 標題列功能名 |
| 日期 | 36 | 40 | 600 | 標題列右側 |
| 卡片標題 | 34 | 37 | 700 | 卡片頂端（左側 6×30 強調豎條） |
| KPI 主數字 | 42～60 | 同 ×1.1 | 800 | 大數字（單位另用 28px／600、`--ink2`） |
| 重點內文（新聞標題等） | 40 | 44 | 700 | 行高 1.36，最多 3 行 |
| 一般內文、名單 | 29 | 32 | 600 | 行高 1.5 |
| 副標、卡片右上註記 | 26 | 29 | 500 | `--ink3`，單行 |
| 圖內軸字、圖例 | 25（**下限 24**） | 25 | 400 | Inter |
| 圖內資料標籤 | 30（viewBox 內，縮後約 24） | 同 | 700 | 輪盤名稱等 |

規則：同一張圖字級階數 ≤ 5 階；不用粗斜體；不用字級小於 24 的任何字（含圖例）。

## 七、卡片類型與版型

1. **KPI 小卡**：標籤（28）→ 主數字（42，紅／綠）＋單位 → 副數字（26）→ 進度條（高 10px、圓角 5px、`--accent`，底 `--line`）。Threads 一排 4 張；限動 2×2。
2. **名單卡（象限／排行）**：卡框色＝該象限色（框 1.5px，底為象限色 14～16% 到 `--card` 的漸層）；標題 34／800 同色；項目一行起頭用 9px 小圓點（象限色）當項目符號，不用 chip 底色、不用句點分隔（句點會落在行尾）。
3. **新聞列**（今日焦點）：高度均分剩餘區域，**左側 8px 類別色條**、左欄序號 `01`～`05`（60px／800、類別色）、右欄「類別小標籤（26px／800、類別色底、深字）＋標題 40px／700」。**不再用整塊紫／橘實心大膠囊**，也不用整卡底色區分類別。卡高目標 ≤ 215px（Threads），新聞少於 5 則時放大標題字級（42→46），不留空。
4. **圖表卡**：標題列（豎條＋標題＋右上單位註記 26px）→ 圖（吃滿剩餘高度）。單位寫在右上，不放圖內。雙軸圖兩軸單位都要標（例：「左 億元　右 點」）。
5. **一句話總結卡**（盤前）：改為「一排四個指標小卡（那斯達克、費半、標普 500、台指期夜盤較日盤）高約 180px＋下方整段文字卡」，不再四大格各高 500。

## 八、圖表樣式

| 圖 | 規格 |
|---|---|
| **K 線** | 紅漲綠跌**實心**柱（上漲實體 `--rise`、下跌 `--fall`，影線同色 2px）；實體寬＝間距 62%；背景格線 `--line` 1.2px，不畫縱格線；最後一根旁標收盤價（等寬數字、粗體 28px、底 `--card`）；不畫十字游標 |
| **均線** | 六色同 `chart.js`（5／10／20／60／120／240），線寬 3px、圓角端點；圖例一行置於圖上方，字 25px，每條標 `MA5` 這類名；**同一張圖最多顯示 3 條**（Threads 縮小後 6 條糊成一團），要看六條另做一張 |
| **RSI／KD／MACD 副圖** | 高度為主圖 1/3；RSI 畫 30／70 兩條虛線（`--line2`），超買區（>70）底淡紅、超賣區（<30）底淡綠；線 `--accent` 3px；軸字 24px 以上 |
| **長條（單色）** | 一個系列一色（`--accent`）；漲跌類用 `--rise`／`--fall`；圓角 2px；柱寬＝間距 58%；柱頂不標數字，改只標「最大」與「最新」兩根 |
| **堆疊長條（法人）** | 外資藍／投信橘／自營紫，**買超往上、賣超往下**各自堆；零軸線 2px `#3A4C78`；疊加加權指數折線（白、4px、末端圓點）；左軸億元、右軸點 |
| **橫條排行** | 一列一行：公司 LOGO 或序號 → 名稱＋代號（28／ink、24／ink3）→ 長條（紅／綠）→ 右對齊等寬數字；列高 ≥ 64px |
| **熱力圖** | 色階離散 7 格（深綠→淺綠→灰→淺紅→深紅，中間為平盤），圖例畫在圖下方、每格標區間；方塊間隙 3px、圓角 4px；**方塊內文字 ≥ 24px，放不下就不寫字**（不縮小到看不見）；產業與題材各一張，不併成一張超高圖 |
| **輪盤（RRG 圓盤）** | 圓盤底分四象限色 16% 透明；虛線環 3 圈（100%／66%／33%）；點 9px 半徑＋外暈 17px；**只標每象限前 2 名**（名稱框 `rgba(10,15,28,.82)`＋象限色細框、30px／700），其餘點不標，名單在上方四卡；標籤不得互相重疊、不得蓋住別的點；象限名放圓內靠外側 |
| **進度條／環** | 進度條見 KPI 卡；環圖照 `docs/chart_library.md` 的 A／B 款，圖例在右側 |

圖上每個標籤都要指到圖上真的有的值；標籤互相重疊或被裁掉＝退件（沿用 `layout_report` 重疊檢查）。動效：靜態圖不適用。

## 九、資訊密度

- 內容區底部不留空白（限動的上下安全區除外）：卡片均分剩餘高度，內容撐不滿就放大主圖／加大字級，不補裝飾。
- 一張圖一個主題、一個主圖；輔助資訊放卡片右上單行註記或下方名單，**不另開第二個大圖**。
- 名單最多 5 項、新聞最多 5 則；超過放進貼文文字，不縮小字級硬塞。
- 空狀態：資料缺漏的卡整張不發（沿用 `social_gate` 規矩），不用「資料未更新」佔版面。

## 十三、Andy 可能不同意的地方

1. **全面改深色**：現在三種都是淺色系，改深色是最大的視覺變動。若偏好淺色，只換第三節 token 欄，其餘規則照用。
2. **標題列只放日期不放來源／網址**（照 Andy 規定），貼文文字要承接免責與網址。
3. **示意稿的輪盤圓盤只佔卡片寬度約 64%**（卡片寬 1000、圓 640），兩側有空；要吃滿需把上方名單縮成單行或改左右分欄，這會讓名單變小——我選了「名單 29px 清楚、圓盤略小」。
4. 均線限 3 條、輪盤只標前 2 名，是為手機縮小後的可讀性，會少一些資訊（名單與貼文文字補）。
5. 沒有任何競品截圖可量，「專業感」是用層次、等寬數字、固定標題列、類別色條與去除大色塊達成，不是複製特定媒體。

## 十四、沒驗到的部分

- 只做 3 種題材×2 比例，K 線、均線、RSI、熱力圖、橫條排行、盤後融資融券、一句話總結新版**只有規格沒有示意稿**。
- 沒在真手機（Threads／IG App）上看縮圖，字級下限 24px 是用縮放比 0.36 推算。
- 淺色備用版沒出示意稿。
- 範例圖的字體是容器內的 fallback 字體，實際 Actions 環境的中文字型可能略有差異。
