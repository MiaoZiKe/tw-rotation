# 「精選文章」欄目與選單（產業鏈・供應鏈・產品）

> Andy 10-11：「需要你給我多個主題，我編號去選擇；需要新增一個精選文章，先以介紹產業鏈、供應鏈、產品等為主。」

## 一、欄目定位
- **名稱（暫定）：** 比比產業百科（IG 精選動態圓圈＋Threads 長文串）。
- **和影片的分工：** 影片＝最新消息＋一個知識點（20～45 秒）；精選文章＝常青、可收藏、可分享的長版「產業說明書」，影片可以引用文章當延伸閱讀。
- **形式：** ① IG 輪播 8～10 張（封面＋每張一個重點＋總結）② Threads 長文串（5～8 則）③ 站內長文稿（800～1,500 字，日後可放網站「知識」區）。
- **每篇固定結構：** 一句結論 → 這個東西是什麼 → 上中下游怎麼分工（附網站產業地圖 2D／3D 剖析圖畫面）→ 台灣的位置 → 常被誤解的點 → 延伸閱讀（連回影片與網站）。
- **規矩：** 不推薦個股；公司只當「這一環有哪些代表」的事實列舉，來源取自本站公司資料並二次查證；數字與市占標日期與信心度；新聞用自己的話。每篇交件前過 semi／pcb／ai-server 分析師查證與法遵。
