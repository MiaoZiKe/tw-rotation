# 盤前消息資料格式（premarket_news）

> 產生者：`scripts/social_premarket.py`（盤前貼文，kind=premarket）。
> 使用者：網站「每日精選 → 盤前消息」分頁（前端另派人做）、社群文案。
> 起因：Andy 2026-10-26 盤前範例改版：「事件與消息只留標題，分新聞／事件／科技／總經四類，以最受關注為主，有 5 則就列 5 則」。

## 放在哪裡

每一輪盤前貼文的輸出資料夾（workflow 推到 `social-snaps` 分支的 `snaps/premarket-<yyyymmdd-HHMM>/`）裡有兩份，內容相同：

| 檔案 | 位置 |
|---|---|
| `premarket_news.json` | 單獨一份，前端直接讀這個 |
| `manifest.json` | `premarket_news` 欄位（給發布程式與之後的自動私訊用） |

## 格式（version 1）

```json
{
  "version": 1,
  "target_date": "2026-10-27",
  "window": {"start": "2026-10-24T04:00:00+08:00", "end": "2026-10-27T08:45:00+08:00"},
  "categories": ["新聞", "事件", "科技", "總經"],
  "items": [
    {
      "category": "科技",
      "title": "長江存儲重大突破！傳開發9600MT/s LPDDR5X 導入4F²架構挑戰三星、美光",
      "url": "https://news.cnyes.com/news/id/…",
      "source": "鉅亨",
      "published_at": "2026-10-24T13:10:05+08:00",
      "coverage": {"sources": 3, "articles": 8}
    }
  ]
}
```

| 欄位 | 型別 | 說明 |
|---|---|---|
| `version` | 整數 | 格式版本；欄位意思改了才加 1，只是加新欄位不加 |
| `target_date` | `YYYY-MM-DD` | 這份盤前是給**哪一天開盤前**看的（台北日期），不是產出日 |
| `window.start`／`window.end` | ISO 8601（+08:00） | 收新聞的時段：前一個美股交易日收盤（美東 16:00 換成台北時間：夏令 04:00、冬令 05:00）到目標日 08:45 |
| `categories` | 字串陣列 | 分類的固定順序，前端排分頁或篩選時照這個順序 |
| `items` | 陣列 | 最多 5 則，**排序＝受關注程度高到低**（不是時間順序） |
| `items[].category` | 字串 | `新聞`／`事件`／`科技`／`總經` 其中一個 |
| `items[].title` | 字串 | 媒體原標題（只把連續空白、全形空白收成一個半形空白，不改寫字） |
| `items[].url` | 字串 | 原文連結（資料湖 `news.url`）；可能是空字串，前端要能處理 |
| `items[].source` | 字串 | 媒體中文名：鉅亨／聯合新聞網／科技新報 |
| `items[].published_at` | ISO 8601（+08:00） | 原文發布時間，已換成台北時間 |
| `items[].coverage` | 物件 | `sources`＝幾家媒體報導同一主題、`articles`＝幾篇；補位的單篇是 `{1, 1}` |

## 怎麼挑、怎麼分類（可重現，不靠人工）

1. **時段**：只取 `window` 內的新聞（資料湖 `news`）。
2. **排除**：喊盤、權證、促銷、名嘴選股這類（`SKIP_RE`）。
3. **最受關注**＝同一個主題被**幾家媒體**、**幾篇**報導。主題＝新聞附的關鍵字（鉅亨、科技新報有附），加上出現在其他標題裡的同一個詞（聯合新聞網沒附關鍵字，用標題比對）；太泛的字（AI、美股、台股、半導體…，`GENERIC`）不算主題。
4. 每個主題留一則：跟同主題其他篇共用關鍵字最多的那篇（最居中的角度），同分取標題較完整（較長）的。
5. 同一類最多 3 則（`CAT_CAP`）；主題不夠 5 個時，用剩下最新的單篇補滿。
6. **分類**依序判斷（`news_category`）：
   - 事件：戰爭、停火、制裁、關稅、選舉、示威、天災、休市、政策、法案……
   - 總經：利率、Fed、通膨、CPI／GDP／PCE、就業、衰退、油價、金價、美元指數、美債……
   - 科技：AI、半導體、台積電、輝達、記憶體、蘋果、伺服器、雲端、大型科技公司……
   - 新聞：都不是的（台股個股、ETF、產業消息等）

## 前端注意

- 圖片與分頁都**只顯示標題**；來源、時間要放的話用小字或 tooltip（社群圖上不放）。
- `url` 開新分頁；空字串時標題不做成連結。
- `items` 可能少於 5 則（新聞量少的早上），也可能是空陣列（不顯示這一區，不要寫「沒有資料」）。
