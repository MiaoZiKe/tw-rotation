# 盤中／盤後「盤面分析」判斷規則

> 2026-10-26 Andy：「盤前盤中盤後都需要有 CEO 安排專業的金融專家分析盤面」。盤前規則見 `premarket_read_rules.md`。
> 程式：`scripts/social_snap.py` 的 `intraday_reads()`、`close_reads()`；文案第二段「🧭 盤面分析：」。
> 原則同盤前：只寫看得到的事實與對照，不寫預測、不給買賣建議（投信投顧法）；不用「可望、將、建議、布局、止跌、超賣」。

## 盤中（12:00）
| 項目 | 規則 |
|---|---|
| 族群漲跌 | 熱力圖族群數 N 漲 M 跌、平均漲跌；漲 ≥ 跌×2「族群普漲」、跌 ≥ 漲×2「族群普跌」，其餘「漲跌互見」 |
| 資金與股價同向 | 資金流入前五 ∩ 熱力圖漲幅前 10 名 |
| 資金流入但股價收黑 | 流入前五裡熱力圖漲跌 < 0 的族群 |
| 漲幅逾 1% 但資金流出 | 流出前五裡熱力圖漲幅 ≥ 1% 的族群 |
| 權值族群資金流出 | 晶圓代工、AI 伺服器組裝出現在流出前五 |

## 盤後
| 項目 | 規則 |
|---|---|
| 大盤 | 加權指數漲跌點數與%、上漲／下跌家數；一邊 ≥ 另一邊 2 倍時寫倍數 |
| 外資／投信 | 同號連續天數 ≥ 2 寫「連 N 日買超／賣超，累計 X 億」；今天換號寫「由買轉賣／由賣轉買」（用初版數字 rev 優先） |
| 外資賣超集中 | 外資賣超第 1 名金額 ÷ 外資當日賣出金額 ≥ 15% 才寫 |
| 外資期貨 | 台指期淨空單（淨多單）口數、較前日增加／減少口數 |
| 散戶多空比 | 小台 ≥ +20% 或 ≤ −20% 才寫「散戶部位明顯偏多／偏空」；與外資淨部位方向相反時加註 |
| 融資維持率 | 上市估算值與單日變動百分點 |

文案超過 480 字時，依序拿掉次要段落（ETF 買超 → 融券 → 融資 → 維持率 → 散戶 → 未平倉 → 投信 → 外資），盤面分析與網址一律保留（`DROP_ORDER`）。

## 2026-10-27 金融口徑審查後修正（Andy：「照專家修正」）
- 外資賣超集中：分母改「外資當日賣超（官方淨額）」→「占外資當日賣超 37%」；原本寫「賣出金額」分母用錯。
- 「由買轉賣」：前一日只是 < 50 億的小額反向，或近 10 日有 ≥ 8 日同方向 →「近 10 日 9 日賣超，累計 X 億」；真的換向才寫「轉賣超／轉買超」。
- 法人數字一律用 15:00 首次公布值（新聞用的那個），不用晚間修訂值 rev。
- 漲跌家數標明「上市櫃（含 ETF）」。
- 期貨：寫「外資加空台指期 N 口，未平倉淨空單升至 X 口」／「空單回補」；淨多空翻轉寫「由淨多單轉為淨空單」。
- 散戶：「（多方部位較多）」中性寫法，不寫「明顯偏多」。
- 盤中 12:00 沒收盤：「收黑」改「族群走低」；「資金流入／流出」改「成交比重增加／下降」；寫「族群平均」；1.5～2 倍寫「漲多跌少／跌多漲少」。
- 新增：站上月線比例 < 30%、漲停或跌停 ≥ 10 家、成交量較 20 日均量 < 85% 或 > 120%。
- 不准用：提款、下狠手、棄守、倒貨、接刀、反指標、籌碼凌亂／安定、空方力道、可望、將、偏多操作。
