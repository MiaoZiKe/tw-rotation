## 重點查核

1. 第 3 頁「市場原本預期 +0.3%、比預期差 0.4 個百分點、路透：預期中位數」：文章 JSON 與 image_sources 都沒有這個數字，JSON 只有路透標題「unexpectedly shrinks」，只能推得「預期為正」。我另外用網路搜尋也查不到 2026 年 7–9 月的預估中位數。你提到的另一份素材寫彭博彙整 +0.2%，兩家預估本來就可能不同（路透、彭博、日經各自調查的對象不同），但現在無法確認哪個對。結論：無法確認，扣分；「差 0.4 個百分點」是由這個未證實數字算出來的，一併不可信。
2. 沒有出現「已確定」，沒有預測、投資建議。狀態標示（分析推測、只看摘要、原文未讀、預定）做得好。
3. 其他在文章 JSON 找不到出處的數字（圖上標「本站資料庫」或「路透」，但發文包裡沒留查證紀錄）：
   - 第 3 頁「淨出口拉低 0.6 個百分點（路透）」、「個人消費走弱＝日經標題寫的主因」（JSON 只列日經標題「0.1%減、4四半期ぶりマイナス」，沒有寫個人消費）。
   - 第 2 頁「11/16 台股加權單日跌 6.0%」、「11/5 那指單日跌 5.5%」、「10/6 美台同日高點」。
   - 第 5 頁台股加權 −17.6%、費半 −23.2%、那指 −8.9%、標普 −3.3%、恐慌指數 47.9、VIX 19.3／28.2。
   - 第 4 頁標普 −5.9%（10/6 到 11/5）、VIX 80.9（2008/11/20，數字本身與公開紀錄相符）。
   - 第 6 頁德銀「改革後資產移往銀行以外，政策也更早介入」：JSON 沒有這句；美銀「2007 年中到 2008 年中」比 JSON 的「2007–08」更具體。
   - 第 7 頁美國 GDP／PCE（11/25）、非農（12/4）、CPI（12/10）：JSON 沒有，只寫「本站經濟日曆」。
4. 2008 年 −38.5%：JSON 出處標題是 ABC「Dow 跌 33.8%」，38.5% 是標普價格指數，圖上已註明以 2007 年底收盤起算，可接受。

## 扣分原因（3 條內）

1. 第 3 頁預期值 +0.3% 與「差 0.4 個百分點」無出處，且與另一份素材（+0.2%）不一致。
2. 數字出處只寫「本站資料庫／路透」，沒有逐項對到文章 JSON 或留存查證表；淨出口 0.6、個人消費主因、台股 −6.0% 等查不到底。
3. 第 5 頁把標普（到 11/13）與台股（到 11/16）放同一張圖，又把台股恐慌指數 47.9 和美股 VIX 19.3 並排，兩者是不同指數、不同算法，容易被誤讀成直接比較；版面也有留白（第 4 頁深色框下方、第 6 頁左欄、第 7 頁底部、第 8 頁出處卡底部）。

## 下次避免（3 條內）

1. 每個比較用的基準數字（預期、前值）先在查證表留一列來源與取得日，查不到就不放，或改寫「媒體稱出乎預期」。
2. 圖上出現的新數字，要同步補進文章 JSON 或 image_sources 的逐項對照表，發文包才算完整。
3. 不同口徑的指標（台股恐慌指數 vs VIX）分開放，或加「算法不同，不能直接比」一行；小字（出處、日曆格內字）至少 24px。

## 必改項目（發文前一定要改）

1. 第 3 頁「市場原本預期 +0.3%」與「差 0.4 個百分點」：先取得可驗證的路透或彭博原文數字；無法確認就整格換成「市場原本預期為正成長（路透稱『出乎預期』）」，不放具體數字。
2. 第 3 頁「淨出口拉低 0.6」「個人消費走弱（日經標題）」：補出處，補不到就刪或降為「只看摘要」。
3. 第 2 頁台股 6.0%、第 5 頁各指數漲跌幅與 47.9：在 image_sources 補「本站資料庫、查詢日期、計算基準日」。
4. 第 6 頁德銀「改革後資產移往銀行以外」與美銀「年中到年中」：對回原摘要，對不上就刪到只剩 JSON 有的說法。
5. 第 5 頁恐慌指數與 VIX 並排處加「算法不同，不能直接比」。
6. 文案開頭「年率只少 0.1%」改成「年率 −0.1%」，避免讀成「少了 0.1% 的某個東西」；「聽起來很嚴重，但」這種先降低嚴重性的寫法，建議改成中性：「日本負成長，年率 −0.1%；11 月初全球股市大跌，有人問像不像 2008。」
