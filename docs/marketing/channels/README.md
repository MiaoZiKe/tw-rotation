## 圖片規則（所有頻道）
Andy 要求「圖片越真實越好，重點要說明來源出處」。CEO 依法遵決定：註明出處不會讓轉用新聞照片合法（通訊社／媒體照片受著作權保護，外國帳號同樣會被檢舉下架）。允許來源：
1. 自己操作／自己網站的截圖、自製圖表（首選）
2. 公司官方新聞室／媒體素材區明示可供媒體使用的素材（標「圖：○○官方素材」，保存授權頁網址）
3. Wikimedia Commons、Unsplash、Pexels 等 CC／CC0 照片（照授權標示）
4. 政府機關開放授權照片
5. 公開資料自行重繪
新聞內容只能用自己的話摘要＋標題引用＋連結；不截新聞頁、不轉貼新聞照。每篇附 image_sources.md（圖、來源網址、授權、取得日期）。AI 生圖須 art-director 審。
