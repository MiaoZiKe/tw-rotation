## 我的排名（好看、像會紅的帳號、可量產）
1. C 便當格：資訊密度最高、格內都是真資訊，改文案不易破版。
2. A 白紙大字：最穩、最好量產，缺點是辨識度低，靠強調色撐。
3. D 新粗獷：停留感強，但黑邊加硬陰影在密集文字頁較吵。
4. B 手繪筆記：氣質最親切，但沒有手寫體，手繪感靠框線與塗鴉，字本身偏硬。
5. F 日系海報：版面最有設計感，但沒有明體，字形偏硬，資訊頁較弱。
6. E 對話氣泡：口語自然，但表格頁與待截圖頁被氣泡限制，空間利用最差。
