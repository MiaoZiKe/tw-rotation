# 頻道③「AI 介紹頻道」視覺版型規格（2026-11-03 第 1 版）

適用：IG 輪播 1080×1350、IG Reels 封面 1080×1920、Threads 配圖（同輪播尺寸 1080×1350）。
承接 `docs/marketing/social_unit/post_design_system.md`（尺寸、安全區、重疊規矩沿用）。
不出現比比；LOGO 不走吉祥物路線（用文字標「AI 實測 NO.xx」當系列標）。
範例圖與產生器：`layouts/`（`gen.py` 產 HTML、`render.js` 用 Playwright 截圖並跑重疊檢查）。
> 依據：容器打不開外部網站，沒有量過競品；所有數值是「手機看 1080 圖縮成約 390pt（縮放 0.36）仍讀得到」自訂，屬推估。
> 範例圖用 Chromium 的後備字型（文泉驛正黑）繪製，字體實際長相會與下列建議字型不同，字寬要用建議字型再跑一次檢查。

## 一、三套方向（與前兩頻道區分）

頻道①陽光糖果（亮、暖、圓）、頻道②瑞士極簡（白、黑、網格）。頻道③的辨識點：**底色明度與色相和前兩者拉開 ＋ 固定的「實測標章」**。

| | A 實測終端（推薦） | B 紙本實驗報告 | C 清晨薄荷儀表 |
|---|---|---|---|
| 氣質 | 深藍黑底、等寬感、「我真的跑過」的工程實測 | 米紙底、襯線標題、像實驗記錄本 | 薄荷底、圓潤乾淨的儀表板 |
| 與前兩頻道距離 | 最遠（唯一深底，縮圖一眼分得出） | 中（米色接近糖果的暖，但襯線＋朱紅可分） | 近（亮底，和糖果、極簡都像） |
| 底／卡／線 | `#0F1722`／`#182334`／`#2A3A52` | `#F6EFE2`／`#FFFBF3`／`#D9CBB2` | `#EAF7F3`／`#FFFFFF`／`#BFE3D8` |
| 主文字／次文字 | `#F3F7FB`／`#B4C2D3` | `#2A2118`／`#6B5B49` | `#0C2B2A`／`#3F6361` |
| 強調色（系列標、重點字） | 螢光綠 `#7CF29A` | 朱紅 `#D4401F` | 青綠 `#0E9F8A` |
| 次強調（「非 AI 生成」標章） | 天藍 `#5AB0FF` | 墨綠 `#1F6F6B` | 紫 `#6D5BD0` |
| 標註色（框、箭頭、編號） | 琥珀 `#FFC857` | 焦糖 `#B7791F` | 橘 `#C26A00` |

免費可商用繁中字體（皆 SIL OFL）：Noto Sans TC、Noto Serif TC（Google Fonts）；備選「霞鶩文楷 TC」（LXGW WenKai TC）、「粉圓 jf open huninn」。三套共用的字級（以 1080 寬計，縮 0.36 後最小仍 ≥ 9pt）：

| 用途 | 字級／字重 |
|---|---|
| 封面鉤子大字 | 132px／900，行高 1.12，≤ 3 行、每行 ≤ 9 字；強調字用強調色，每張最多 1 處 |
| 封面副標 | 44px／500 |
| 內頁標題 | 58px／800，≤ 2 行 |
| 重點說明 | 34px／600，≤ 3 行 |
| 系列標、標籤膠囊、編號 | 28～36px／700～800 |
| 日期、頁碼 | 28px／500 |
| **揭露列** | **26px／500（下限；任何版面不得小於 26px）** |

**推薦 A「實測終端」**：深底在 Threads／IG 動態裡縮圖最醒目，和前兩個亮底頻道一眼可分；深底也讓真實截圖（多半是白底工具介面）自然「浮」起來，不需加重陰影。
**Andy 可能不同意的地方**：他曾要求 AI 圖「不要暗沉」（`ai_image_review.md` 第 4 條，灰階平均 ≥ 120）。該條針對 AI 生成圖；A 的畫面以白底截圖＋螢光綠為主、本頁灰階平均約 55～60，**不適用該條但風格上偏暗**。若他要全系列偏亮，就選 B（與糖果最像）或 C。

## 二、安全邊距與輪播固定結構

| 項目 | 輪播／Threads 1080×1350 | Reels 封面 1080×1920 |
|---|---|---|
| 左右 | 64px | 64px |
| 上／下 | 72px／72px | **250px／230px**（IG 介面蓋掉） |
| 內容區 | 952×1206 | 952×1440 |
| 元素間距 | ≥ 24px | ≥ 24px |

| 頁 | 內容與位置（A 方向座標，B、C 同） |
|---|---|
| 1 封面 | 左上系列標「AI 實測 NO.07」30px、右上日期；鉤子大字從 y=162 起；副標、三個賣點膠囊（≤ 3 個，每個 ≤ 6 字）；下方露出一角截圖卡（高 300px）當「有真東西」的信號；最底揭露列。 |
| 2～N 截圖頁 | 左上「STEP n」膠囊、右上頁碼「2/6」；標題 y=150；截圖框 952×640 放 y=300；框下 y=980 重點說明；y=1130 「實測｜非 AI 生成」標章；最底揭露列。一頁**一張截圖、一個重點、最多 3 個標註**。 |
| 比較表頁 | 標題＋表格（最多 4 列 × 4 欄，欄頭 32px／800、格內 34px／600、列高 ≥ 96px）；勝出格用強調色底 12%＋粗字，不只靠顏色（加「✓」）；表下一句「怎麼比的」（測試條件）。 |
| 結論頁 | 標題「結論：…」；三條 ≤ 20 字的結論，各配編號；第一條放「誰適合／誰不適合」；最後一條放行動（例：先用免費版測 1 週）。不放投資買賣建議或保證效果的字。 |
| 最後頁 | 同結論頁版面，加「完整測試條件」一行與追蹤提示一行；不另做結尾品牌頁。 |

**揭露標示位置與大小（每一張都要有，含封面）**
1. **揭露列**：固定貼底（距底 72px，Reels 距底 230px），左右 64px，上方 2px 分隔線，**26px／500**，左側「無業配」或「業配：○○」或「含聯盟連結」用 700 主文字色，右側「圖文含 AI 協助」。業配、聯盟連結要**每一張**寫，不可只寫第一張。
2. **來源標章**：截圖頁截圖框正下方、重點說明之後，28px／800 邊框膠囊，文字二擇一：「實測｜非 AI 生成」（真截圖）、「AI 生成示意圖」（只要頁面有任何 AI 生成圖就必須標，且圖角再加 24px「AI 生成」小字）。
3. 揭露列與標章不得被圖、箭頭、標註蓋住；不得用比內文淡的色（對比 ≥ 4.5:1，已實算：A 揭露字 `#B4C2D3` 對 `#0F1722` ≈ 9:1）。

## 三、截圖處理規範

| 項目 | 規範 |
|---|---|
| 遮個資 | 姓名、信箱、電話、帳號 ID、API 金鑰、付款資訊、公司內部名稱、瀏覽器分頁與書籤列一律遮；用**實心色塊**（與截圖底同色系深灰 `#3A4352`）蓋住並寫「已遮」，**不用模糊或馬賽克**（可還原）；遮完用 EXIF 清除工具另存新檔（去定位、裝置資訊）。 |
| 範例資料 | 能用假資料就重跑一次再截，不要靠遮；資料量要真，不編造輸出（見揭露）。 |
| 裁切 | 只留與該頁重點相關的區域；去掉作業系統工具列、通知、書籤列；框內截圖寬度 ≥ 952px 的 1×（原圖寬 ≥ 1904px 以保 2× 清晰，retina 截圖直接用）；截圖內文字縮放後實際高度 ≥ 20px，否則放大裁切或改拆兩頁。 |
| 外框 | 圓角 22px、框 3px（`--line`），標題列 56px 放三點與「工具名 · 畫面名」24px（此行屬截圖框內裝飾，可小於揭露列下限但不承載重點）。 |
| 深淺色 | 截圖維持工具原樣（深色就深、淺色就淺），不做反白、不調色；A 方向若截圖是深色介面，框線改 `#3C4F6B` 免與底融在一起。 |
| 放大重點 | 小到看不清的重點，另做「放大泡泡」：從原圖裁出重點區放大 2 倍，貼在截圖框**外側空白處**，用 3px 琥珀細線連到原位置，**不蓋住截圖內其他文字**。 |
| 標註 | 色用各方向的標註色（A 琥珀、B 焦糖、C 橘），一頁只用一個標註色；高亮框 6px 圓角 16px、底 14% 透明色；箭頭 9px 線寬；編號圓 64px／36px 粗字，放在高亮框外側。**標註不得蓋住截圖裡任何要讀的字**（範例圖已示範：框框住字、編號放空白處）。不用紅色（與紅漲綠跌混淆，且與頻道 B 強調色衝突）。 |
| AI 生成圖 | 只當氣氛或示意，一律走 `ai_image_review.md` 十條審；有 AI 圖的頁面必標「AI 生成示意圖」；不得拿 AI 生成圖冒充工具實測畫面。 |

## 四、重疊檢查規則

沿用 CLAUDE.md 規矩：畫面元素兩兩不得相交，要用程式量，不能只靠眼睛。
1. **元素清單**：每個版面元素標 `data-o="名稱"`（系列標、日期、鉤子、副標、膠囊列、截圖框、高亮框、編號、箭頭、重點說明、標章、揭露列）。一整列膠囊、一整段文字算「一個元素」，量的是外框 `getBoundingClientRect()`。
2. **組（容器）**：截圖框是容器；高亮框、編號、箭頭標 `data-in="截圖框id"`，**允許與截圖框重疊、不允許與其他標註彼此重疊**，也不得越出截圖框。截圖「內容」（像素）本身不是元素，標註與它的重疊靠人工看（第 5 點）。
3. **判定**：任兩個非「容器—成員」關係的元素，外框交集寬 >0 且高 >0 即為違規（0 容忍，不設像素寬限）；另查元素是否超出畫布（`oob`）。
4. **最小間距**：除了容器成員，兩元素外框距離 ≥ 24px；揭露列與上方任何元素 ≥ 24px。（範例檢查只做交集，間距另列待補。）
5. **人工**：每頁全解析度看一遍，確認標註沒遮到截圖內文字、遮個資色塊確實蓋住。
6. **回報格式**：「重疊檢查：程式 N 頁 0 筆；人工 M 頁 0 筆」，沒這行不收件。
7. **實作**：`layouts/render.js` 內 `check.js.txt` 已實作 1、2、3（Playwright 在頁面內量）。實測第一版曾抓到「編號圓與高亮框重疊 48×24px」，已修正。

## 六、沒驗到的部分
- 未用建議字型（Noto Sans/Serif TC、JetBrains Mono）渲染（容器只有文泉驛），換字型後鉤子大字換行與膠囊寬度要重跑檢查。
- 比較表頁、結論頁沒有出範例圖，只有規格。
- 在手機實機上縮小後的可讀性是推算（0.36 縮放），沒實機驗。
- 元素「最小間距 24px」尚未寫進檢查程式。
