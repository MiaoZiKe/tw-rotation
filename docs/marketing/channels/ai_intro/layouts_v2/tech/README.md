## 裝飾規則
1. 裝飾一律是背景層（SVG，不帶 `data-o`），只放在色塊的頂邊／底邊 padding、封面色塊右下留白、左右 64px 邊距、底部 72px 安全邊距。
2. 不穿過任何文字：程式把每條裝飾線與每個文字節點的矩形逐一比對（`decoOnText`），0 筆；人工看過。
3. 截圖框與表格仍是最清楚的主角：框角只在 c 出現，往外 9px、線寬 5px、不蓋內容。
4. 不用對角大斜線；只用 45° 小折角，避免看起來像背景圖案搶戲。
5. 角標內分隔符改半形「|」（全形「｜」在等寬字下間距過寬）。
