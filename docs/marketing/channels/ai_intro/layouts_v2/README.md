## 推薦排名
1. **方向四 色塊海報**：縮圖最醒目、標題最大，亮色且與頻道①（暖糖果圓角）②（白黑細格）都不像；硬框讓真截圖與表格最有力。
2. **方向三 對話串**：與①②最好分（唯一深底）、最貼「AI 實測」主題；但深底偏暗，Andy 曾偏好不暗沉，且氣泡版面對長表格較吃空間。
3. **方向一 檔案櫃**：最穩、資訊密度高；但白卡＋圓角偏安全，辨識度不如 4、3。
4. **方向二 筆記本**：人味最重，橫線紙在小圖上略雜、文字底下有線干擾。

## 檢查結果（16 張）
程式：元素重疊 0 筆、最小間距 24px 不足 0 筆、越界 0、揭露字級 28px、可見文字小於 28px 0 處（程式只量帶 data-o 的主要元素；色塊內成員彼此也量）。人工：以縮圖逐張看過 16 張，截圖框內為占位、不遮字；未逐張全解析度細看。

## 沒驗到／Andy 可能不同意
- 容器只有文泉驛正黑，字體實際長相與建議的 Noto 不同，換字型後換行要重跑 `node render.js`。
- 頻道①②版型圖取不到（fetch 逾時、MCP 讀不到該路徑），差異是依文字描述（陽光糖果＝亮暖圓；瑞士極簡＝白黑網格）判斷，未並排比對。
- 表格字級 30～32px，低於規格 34px（為了 4 欄不換行）。
- 方向四的粗黑框、方向一的深書脊較重；「來源 2｜信心 中」為示範值。
