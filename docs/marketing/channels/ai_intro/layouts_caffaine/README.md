# 頻道③「CaffAIne」IG 貼文版型（依 LOGO「07 八位元衝框」）

標語：一杯咖啡的時間，看懂一個 AI 新知。產生器 `gen.js`（`node gen.js samples`、`node gen.js posts`），HTML 在 `html/`。
全部手寫 HTML／CSS，沒有 AI 生圖、沒有比比、沒有下載字型。

## 樣張（`png/`，1080×1350）
s1_post2_封面、s2_post2_新聞卡、s3_post1_比較表、s4_post1_待截圖頁、s5_深色變體_post2封面。

## 字
- 標題與內文：文泉驛正黑（容器唯一的繁中字型），標題加 0.022em 描邊增粗。
- 像素字（Unifont，容器現有）：只用在標籤、頁碼、資料角標、封面編號、步驟前綴與標題裡的「AI」。
- 等寬字（JetBrains Mono）：LOGO 字標、公式。
- 字級：標題 64（封面 76～128）、內文 34～38、表格 34、標籤 32、膠囊 30、備註 30、標章 28、揭露列 32。

## 版型零件
- 像素階梯角框：和 LOGO 外框同語言，每階 8px、共兩階、線 6px，用 clip-path 做，硬陰影用焦糖色偏移 8px；小元件（標籤、膠囊、頁碼）階 4px、線 4px，無陰影。
- 像素蒸氣：LOGO 蒸氣的 12px 方塊鋸齒，固定放頁首 LOGO 與頁碼之間（x 640、y 16），不進內容區。
- 背景：奶油底加焦糖 6px 像素點（48px 間距，透明度 .28），不是格線。
- 頁首：LOGO 小圖＋字標（直接取自 LOGO SVG）＋頁碼「02/06」。左上 LOGO 88×92。
- 揭露列：焦糖像素虛線＋「無業配｜自製圖文｜圖文含 AI 協助」32px（截圖頁改「截圖已遮個資」）。

## 六種頁
1. 封面：大卡（標籤、日期、角標、標題 76～128、副標）＋3 張編號卡（像素大號 01／02／03）。
2. 新聞卡：像素前綴「新聞 1／3」、標題、資訊膠囊三枚、卡片（發生什麼／怎麼說／差在哪）、標章。
3. 比較表：3 欄、表頭可可底、第一欄淺焦糖，儲存格 34px，外框為階梯角框。
4. 步驟頁：像素前綴「步驟 N」＋編號清單（編號方塊像素字）或程式碼卡（可可底、等寬字）。
5. 待截圖頁：階梯角框內焦糖虛線框，像素相機＋「待 Andy 截圖」＋要截的畫面＋要遮的項目。
6. 結論頁：3 張編號清單卡＋備註。

## 檢查（程式，每張 1080×1350 全解析度）
重疊、24px 最小間距、越界、文字溢出、裝飾（蒸氣）穿字、小字 <28、表格字 <34、揭露列 <28、英文句，共 5 張樣張＋20 張範例：0 筆。人工逐張看過。
