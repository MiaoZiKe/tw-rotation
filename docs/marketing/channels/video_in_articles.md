# 做好的影片放進網站文章（四個頻道共用）

Andy 2026-11-15：「做好的影片都需要放在網站上對應的文章內，文章內並且都具備下載功能」。
適用：頻道①②③④，凡是有做影片的貼文，存檔成精選文章時，影片要**直接放在文章裡能播、能下載**，不再只放一條連結。

## 1. 檔案放哪裡、叫什麼

| 項目 | 規則 |
|---|---|
| 影片檔 | `site/media/<頻道小寫英文>/<資料夾>/<檔名>.mp4`（例：`site/media/healing/20261115v_marriage/video.mp4`） |
| 封面（poster，選填但建議） | 同一個資料夾，`.jpg`／`.png`／`.webp`（例：`cover.jpg`） |
| `<頻道小寫英文>` | 2～20 字，只能小寫英文、數字、`_`、`-`（healing、tech、caffaine、ligu…） |
| `<資料夾>` | 1～80 字，英數與 `_ . -`（建議 `<日期>v_<主題>`） |
| `<檔名>` | 1～120 字，英數與 `_ . -`，副檔名一定小寫 `.mp4` |

不符合上面規則的路徑，網站**一律不畫這個區塊**（也不會報錯，只是沒影片），所以交件前一定要自己打開文章看。

## 2. 大小上限與壓縮建議

- 站在 Cloudflare Pages 上，**單一檔案上限 25 MiB**，超過會讓整個部署失敗。驗收腳本會擋：`site/media` 底下任何 mp4 超過 25 MiB 就紅燈。
- **頻道的規定上限：≤ 20 MiB**（留緩衝）。目前最大的一支是 16.5 MiB（頻道④職場工時）。
- 建議規格：1080×1920（直式 9:16）或 1920×1080，H.264（High profile）＋AAC，30 fps，影片 2～3 Mbps、聲音 128 kbps，30～60 秒大約 8～15 MiB；加 `-movflags +faststart` 讓網頁邊下載邊播。

  ```
  ffmpeg -i 原檔.mp4 -c:v libx264 -preset slow -crf 26 -maxrate 3M -bufsize 6M -pix_fmt yuv420p \
         -vf "scale=1080:-2" -c:a aac -b:a 128k -movflags +faststart video.mp4
  ```
- 超過 20 MiB：先把 `-crf` 調高到 28～30、或縮到 720×1280、或剪短；**不要**把大檔放別處再貼外部網址（網站只收站內路徑）。真的需要更長的影片，先告訴 CEO，再評估放 R2。

## 3. 文章 JSON 怎麼寫

在文章 `blocks` 裡放一個 `mp4` 區塊（取代原本「封面圖＋觀看影片連結」那兩塊）：

```json
{
  "t": "mp4",
  "src": "media/healing/20261115v_marriage/video.mp4",
  "poster": "media/healing/20261115v_marriage/cover.jpg",
  "title": "10年，結婚登記少了近3成",
  "note": "影片 1080×1920；下方可下載。"
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `t` | 是 | 固定 `"mp4"` |
| `src` | 是 | 站內相對路徑，**開頭是 `media/`，沒有前導斜線、沒有網址**（`https://…` 不收） |
| `poster` | 否 | 封面圖，規則同上（副檔名 jpg／jpeg／png／webp）；不合格就忽略，影片仍畫出來 |
| `title` | 否 | 影片上方標題；**同時是下載檔名**（`<title>.mp4`，不合法字元會換成空白、最多 60 字）；沒寫就用資料夾名 |
| `note` | 否 | 下載鈕左邊的一行小字 |

網站怎麼畫：`<video controls playsinline preload="metadata">`，有 poster 就用；直式影片限高 78% 視窗（桌機最多 720px），手機 390 寬不溢出；下方一顆「下載影片 ⬇」鈕。

## 4. 誰能下載

- 播放：**任何人**都能在文章裡直接播。
- 下載：功能鍵 `art.video.dl`——訪客關（鈕顯示「登入後可下載」，點了開登入視窗）、註冊會員／Plus／Pro 開、不限次數。次數與開關 Andy 可在「權限」頁調整。
- 提醒：mp4 是公開靜態檔，這個閘門只擋畫面，不是防盜；影片本身不放需要保密的內容。

## 5. 交件前自查（沒做完不算完成）

1. 影片與封面已放進正確資料夾，檔案 ≤ 20 MiB（`ls -l`）。
2. 文章 JSON 用 `mp4` 區塊，路徑一字不差（大小寫、底線）。
3. 推上線後，**用訪客身分**開 `https://liguligu-puipui.com/#article/<文章id>`：能播、鈕寫「登入後可下載」。
4. **登入後**再開一次：鈕寫「下載影片 ⬇」，按了真的下載，檔名是影片標題、檔案能在手機／電腦打開。
5. 手機（約 390 寬）看一次：沒有橫向捲軸、影片沒有超出畫面。
6. 回報時附文章網址＋上面 3、4、5 的結果。

示範：`site/articles/healing/2026-11-15-healing-marriage-video.json`、`2026-11-16-healing-worktime.json`。
驗收腳本：`scripts/uitest_sections/20261115_文章影片下載.py`（`python scripts/_uitest.py --sections 文章影片下載1115`）。
