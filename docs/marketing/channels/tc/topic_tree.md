## 一、規則（摘自 playbook 第十一節，可檢查）

1. **每支接得上一支、開得出下一支**：片尾「下一支」＝本表的下一個節點（上游、下游，或同一節點往下拆一層）。沒有關聯的跳題＝退件。
2. **兩種走法輪流**：① 沿供應鏈主幹走（上下游）；② 同一節點往下拆（有哪幾家、各家差在哪、流程、每步的設備與廠商）。
3. **點名廠商可以**：講它做什麼、市占或公開數字，**附出處與狀態**（已確定／廠商公布／研究機構估計／媒體報導（誰報的）／查不到）；不給投資建議、不念股票代號推薦、不放公司商標圖案。本表「Vendor」欄標「待查證」的，製作前由 market-researcher 用 WebSearch 查（至少 3 類來源）才准上片。
4. 類別輪替：設備／產品／產業／原理／運作，同一類不連兩天（必要時可，寫理由）。
5. 狀態：**已發**／**排程中**（Andy 核准已排）／**製作中**／**規劃完成**（research＋念稿＋script）／**待做**。
