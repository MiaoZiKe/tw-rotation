# 頻道②「科技透明圈」：Andy 的發文方式筆記

> Andy 2026-11-09 原話：「首先你的文案有夠 AI，什麼叫做網友回報、網路上說，你就單純說一件事情。從現在開始的幾篇文章我會親自做，你需要筆記我的發文方式。」
> 這份是活文件：Andy 每親自寫一篇，就回來補一節「這篇學到什麼」。之後 Claude 擬稿一律先照這份寫，再交 Andy 看。

## 一、總原則（從廣達這篇歸納）

1. **直接講事情，不加說明腔。** 不寫「網友回報」「網路上說」「據了解」「僅供參考」「未經查證」這類保留語；一句話就是一個事實或一個感受。
2. **像朋友在茶水間講話。** 口語、短句，可以有情緒字（例如加班一欄直接寫「操」）。
3. **個人經驗放最後一段。** 用第一人稱講自己的經歷與聽到的近況（例：疫情那波面試很簡單、聽說進去很難受所以沒去、近年題目變難），結尾可以用「…」收，不硬做結論、不硬問問題。
4. **不放大段聲明。** 主文沒有免責段、沒有樣本數、沒有資料口徑。只有授權規定一定要標的（照片出處、政府地圖資料）用一行放在 Threads 第 1 則留言／IG 文末。
5. **標題一行**：「☕ 茶水間常聊的那些：代號「○○」的公司名」，不再加「碩畢待遇長怎樣？」這種問句。
6. **公司介紹一句話**：起家靠什麼、近年哪個單位最多人討論。

## 二、欄位格式（公司待遇文）

```
📍 總部：○○
💰 碩畢：約 ○～○K（補充說明放括號）
🎁 整包：約 ○～○ 個月（補充說明放括號）
⏰ 加班：一兩個字的感受（細節放括號）
✈️ 出差：一句話
```

- 欄位名用兩個字（碩畢、整包、加班、出差），不寫「碩畢月薪」「年終・分紅」「加班時數」。
- 數值後面的補充一律放全形括號。
- 第 2 頁圖卡只放括號**外**的內容（Andy：「第二頁只需要寫不包含括號內容即可」），欄位標題是「待遇透明圈」，不加單位括號。
- 「升等」「繁忙程度」這篇沒有，就不要硬補欄位。

## 三、面試段

- 格式：`🎤 FW 面談題型（朋友分享）：……`，直接寫考什麼、難度落在哪。
- 這段是 Andy 親寫的用法，Claude 不自行改寫成其他說法。

## 四、Claude 不要再犯的寫法（Andy 指出的 AI 味）

| 不要寫 | 改成 |
|---|---|
| 網友回報、網路上說、據了解 | 直接講那件事 |
| 非公司公告，未經查證，僅供參考 | 不寫（授權一定要標的出處，一行放文末） |
| 樣本數、篩選口徑（業內朋友 1 位＋網友 21 筆…） | 不寫進貼文（口徑留在 crosscheck.md 內部存檔） |
| 結尾硬問「你那一組落在哪？下一家想看誰？」 | 用自己的經驗或感受收尾 |
| 一欄好幾個子句的長說明 | 一個詞或一句話，細節進括號 |
