## 量法

- **時間**：開工到交件（台北時間）。交件＝傳給 Andy 的時間；審片中的片交件欄留空。
- **Claude 費用**：以本對話 session_018gakVSrB1mzzbUYo7WW6Ug 於台北 11-27 10:33 讀 get_session 的數字換算：
  cost_usd 46.27；輸入 710,139、快取寫 2,974,722、快取讀 123,986,337、輸出 604,143。
  加權 token＝輸入×1＋快取寫×1.25＋快取讀×0.1＋輸出×5＝19,847,890，換算率約 **2.33 美元／百萬加權 token**。
- 子 agent 回報的 token 是各自總量（未分輸入輸出），不能直接套上面的換算率，所以費用改用估算：
  **本 session 費用 × 該片子 agent token 佔本 session 全部子 agent token 的比例**。本 session 子 agent 合計約 275 萬 token，
  約 **16.8 美元／百萬子 agent token**（已含主聊天室分攤）。所有「Claude 費用」都是估算，不是帳單。
- 兩支同批做、共用規格查證與配音的，子 agent token 按工作量對半；只屬某一支的另加。
- **Actions 分鐘**：用 GitHub API（mcp__github__actions_list 的 list_workflow_jobs）取各 run 每個 job 的起訖時間，
  每個 job 以秒數無條件進位成整分鐘後加總（plan、各台 render、finalize 全算）。同一 run 兩支同做時，各自的 render＋finalize 歸各自，plan（1 分）平分。
  本 repo 為公開，Actions 不計費；此欄是用量，不是帳單。
- 舊對話沒記、資料夾與 git 查不到的格，一律寫「舊對話未記，查不到」，不推算。
- 本檔 11-27 之前（11-16～11-26）的資料取自各資料夾 retro.md、video_review.md、_batch_status.md、narration_take.wav.request.json（內有 TTS 呼叫時間）；
  git 歷史在本環境被截斷（只剩 11-27 00:05 之後的提交），不能用 git log 補時間。
