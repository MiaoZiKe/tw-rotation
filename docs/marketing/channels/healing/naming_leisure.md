# 頻道④ 命名・悠閒版（2026-11-04，品牌命名顧問）

> 起因：Andy 11-04 最新原話：「有點太悲觀 改悠閒一點 名稱修改成悠閒一點 雖然生活辛苦但努力生活 生活中還是有美好事務 以這概念命名」；先前「名稱不要那麼直白 請專業的人來命名」。
> 已被退件、本份不再提：燭窗、我們這一代、還是會開燈、一邊累一邊好、西窗燭、庭燎、窗與窗之間、燈籽、微明、夜溫差（見 naming_v2／v3／pro／final）。
> 本檔不 commit／push，由 CEO 決定。

## 一、品牌個性與命名禁忌

**品牌個性（3 個形容詞）：悠閒、溫和、帶笑。**
觀察家的角色保留，但從「在夜裡看見窗」變成「在日常裡溫柔地看，順手記下好事」：知道日子辛苦，但鏡頭永遠對著晚霞、熱湯、陽光、巷口的貓。

**命名禁忌**

| 禁忌 | 說明 |
|---|---|
| 不直白 | 不出現「2000後」「上班族」「生活」「日常觀察」這類說明書字眼 |
| 不悲觀 | 不用夜、雨、燈（求救感）、累、撐、孤、冷、末、殘等字當主體；雨只能是「雨後」「晴有時」這種有出口的 |
| 不療癒宣稱 | 不用「療癒」「治癒」「解藥」「陪你走出」，避免功效／輔導聯想（法遵） |
| 不像財經 | 不用「盤」「漲」「資金」「輪動」「K」等；也不用「筆記」「週報」類財經帳號慣用結尾 |
| 不用濫用詞 | 不用「小確幸」「慢活」「微光」「日常」「美好」「治」「暖暖」「森」系詞 |
| 長度 | 2～5 字，唸出聲不拗口 |

## 二、候選（23 個，7 個領域）

### A. 季節與天氣
**1. 小滿**
- 手法：節氣直取（二十四節氣之一）
- 內部含義：麥子將滿未滿，「小得盈滿」，日子不必全滿，小滿就好
- 第一眼：舒服、有點文青，但像咖啡店名
- IG 副標：日子不必圓滿，小滿就好
- LOGO：一粒將熟的麥穗，穗頭一點暖黃

**2. 晴有時**
- 手法：天氣語法轉義（「晴有時」≈ 預報裡的「晴時多雲」，倒過來說）
- 內部含義：日子本來就是有時晴、有時雨；我們負責記下晴的那幾個時刻
- 第一眼：像天氣預報又不太像，好奇「有時什麼」
- IG 副標：日子有時晴，我們幫你記
- LOGO：圓形太陽被雲遮一半，雲邊緣發亮

**3. 雨後有光**
- 手法：場景白描
- 內部含義：下過雨，路上有積水映天；辛苦是真的，亮也是真的
- 第一眼：溫柔，略文藝，略帶「經歷過什麼」的重量
- IG 副標：下過雨的路，會反光
- LOGO：地面小水窪映出一小塊藍天

**4. 晚霞備忘**
- 手法：美好事物＋備忘錄（反差：浪漫對上瑣碎）
- 內部含義：把下班路上抬頭看到的晚霞，像待辦事項一樣記下來
- 第一眼：有畫面，會心一笑，不像財經
- IG 副標：今天抬頭了嗎？記一筆
- LOGO：便條紙一角，上面一抹橘粉漸層

### B. 時間
**5. 日落前**
- 手法：時間點
- 內部含義：下班、收工、天還沒黑，一天最舒服的那段
- 第一眼：安靜，像電影名
- IG 副標：天黑之前，慢慢走
- LOGO：地平線上半顆落日

**6. 週末午後**
- 手法：時間場景
- 內部含義：沒有鬧鐘、陽光斜進來的那種午後
- 第一眼：立刻放鬆，但太通用
- IG 副標：把週末的陽光，分你一點
- LOGO：窗格光影落在木地板

**7. 午後三點半**
- 手法：精確時刻（具體感）
- 內部含義：下午最想喝杯東西、發一下呆的時刻；（內部彩蛋：15:30 也是本站盤後資料更新的時間，不對外說明）
- 第一眼：好奇、有畫面、有點日劇感
- IG 副標：休息一下，三點半了
- LOGO：杯子冒煙，煙的形狀是時鐘指針 3:30

### C. 生活物件轉義
**8. 巷口有貓**
- 手法：場景句
- 內部含義：回家路上總有一隻貓，讓人慢下來看兩眼
- 第一眼：可愛、溫暖；容易被當寵物帳號
- IG 副標：回家路上，順便看看
- LOGO：巷子剪影與一隻坐著的貓背影

**9. 一碗熱**
- 手法：省略賓語
- 內部含義：一碗熱湯／熱麵，最樸素的「今天辛苦了」
- 第一眼：像小吃店，有點好笑
- IG 副標：先喝口熱的，其他再說
- LOGO：碗口蒸氣升成小圓

**10. 陽台日記**
- 手法：空間＋記錄
- 內部含義：陽台是租屋族最小的戶外，盆栽、曬衣、看天
- 第一眼：親切，但很常見
- IG 副標：在最小的戶外，看天
- LOGO：陽台欄杆上一盆小植物

**11. 窗邊小綠**
- 手法：物件特寫
- 內部含義：窗邊那盆撐著不死的小植物，象徵「努力活著也長新芽」
- 第一眼：可愛、清新
- IG 副標：新芽冒出來了，你看
- LOGO：窗框內一片新葉

### D. 古詩詞化用（皆為公共領域）
**12. 悠然見**
- 出處：陶淵明〈飲酒〉其五「採菊東籬下，悠然見南山」
- 含義：不刻意找，一抬頭就看見好風景
- 第一眼：悠閒度最高，三字好唸；略像茶莊
- IG 副標：一抬頭，就是好風景
- LOGO：一扇窗框住遠山

**13. 日夕佳**
- 出處：陶淵明〈飲酒〉其五「山氣日夕佳，飛鳥相與還」
- 含義：傍晚最好看，飛鳥也回家；呼應下班路上的晚霞
- 第一眼：陌生但好看，需副標
- IG 副標：傍晚，最好看
- LOGO：兩隻歸鳥飛過橘色天

**14. 坐看雲起**
- 出處：王維〈終南別業〉「行到水窮處，坐看雲起時」
- 含義：走到沒路也不慌，坐下來看雲；「坐看」正是觀察家的動作
- 第一眼：從容、有格局，四字穩
- IG 副標：走不通的時候，先坐下來看
- LOGO：一個小人背影坐著，頭頂一朵雲

**15. 竹裡館**
- 出處：王維〈竹里館〉（獨坐幽篁裡，彈琴復長嘯）
- 含義：一個人也自在的小空間
- 第一眼：像餐廳／茶館，有古意
- IG 副標：一個人的時候，也自在
- LOGO：竹影落在小屋窗上

**16. 也無風雨**
- 出處：蘇軾〈定風波〉「回首向來蕭瑟處，歸去，也無風雨也無晴」
- 含義：風雨走過了，回頭看也就那樣；不悲不喜
- 第一眼：豁達；但「風雨」二字略重
- IG 副標：走過了，也就那樣
- LOGO：雨傘收起、斜靠門邊

**17. 紅泥爐**
- 出處：白居易〈問劉十九〉「綠蟻新醅酒，紅泥小火爐。晚來天欲雪，能飲一杯無」
- 含義：天冷了，有人點好一爐火問你「來喝一杯嗎」；溫暖是朋友的邀約，不是雞湯
- 第一眼：暖、有畫面，三字好記
- IG 副標：天涼了，來坐一下
- LOGO：紅陶小爐，爐口一點橘紅

**18. 閒看庭花**
- 出處：洪應明《菜根譚》「寵辱不驚，閒看庭前花開花落」（明末，公共領域）
- 含義：不為得失所動，閒閒看花開花落；「閒看」＝觀察家
- 第一眼：雅，略老派
- IG 副標：閒閒看，花自己會開
- LOGO：窗外一朵花與落下的花瓣

### E. 自創詞
**19. 日日小晴**
- 手法：自創四字，化用「日日是好日」的語感，但降到「小晴」
- 含義：不要求天天大晴，每天有一小段晴就好
- 第一眼：軟、亮、順口，看得出是在講天氣又不全是
- IG 副標：每天，都有一小段晴
- LOGO：圓形太陽縮成小點，旁邊一道小雲

**20. 微暖日**
- 手法：自創（微＋暖＋日）
- 含義：不是大太陽，是有一點暖的日子
- 第一眼：柔和；略像保養品
- IG 副標：有一點暖，就夠了
- LOGO：杯墊上的圓形暖光

**21. 日子有糖**
- 手法：口語自創
- 含義：苦日子裡總有一顆糖
- 第一眼：甜，但接近「小確幸」套路
- IG 副標：含一顆糖，繼續走
- LOGO：糖紙包著的小太陽

### F. 輕鬆反差
**22. 今天還行**
- 手法：口語反差（不誇大，也不抱怨）
- 含義：這一代最誠實的晚安；累是真的，好事也是真的
- 第一眼：會心一笑、很有共鳴；少數人覺得偏淡
- IG 副標：不算滿分，但還行
- LOGO：圓形笑臉只有一邊嘴角上揚

**23. 先吃飽再說**
- 手法：口語玩笑
- 含義：天塌下來也先吃飯
- 第一眼：好笑、接地氣；像美食帳號
- IG 副標：什麼都先放著，吃飽再想
- LOGO：筷子與碗組成的笑臉

## 四、推薦前 6 名與品牌故事

分數同分時，以「悠閒感、觀察家角色貼合度」優先。

**1. 日日小晴（31）**
日子不會天天大晴，但每天總有一小段是亮的。我們不趕路，只慢慢數那些小晴：晚霞、熱湯、巷口的貓。

**2. 紅泥爐（30）**
白居易寫：晚來天欲雪，能飲一杯無？天涼了，有人點著一爐火等你。這裡不催你，只有爐、有茶，也有人在。

**3. 坐看雲起（30）**
王維走到水窮處，不慌，坐下來看雲。日子走不通時，換個角度看看，雲自己會起。我們在這裡慢慢看，也看見你。

**4. 今天還行（29）**
不吹噓也不抱怨，一句「今天還行」，是這一代最誠實的晚安。累是真的，晚霞和熱湯也是真的。

**5. 晴有時（28）**
日子有時晴、有時雨。我們不預測，只觀察，然後把晴的那幾個時刻，好好記下來。

**6. 晚霞備忘（28）**
把下班路上的晚霞、一碗熱湯、週末的陽光記成備忘。忙完回頭翻翻，原來日子沒那麼糟。

## 五、我的判斷（與事實分開）

- **事實**：上述古詩皆為唐宋與明末作品，已進入公共領域；撞名查詢結果如第三節，信心度低。
- **判斷**：①「日日小晴」最完整地承接 Andy 的新概念（承認有晴有不晴、目標只是一小段晴）。②「坐看雲起」最貼觀察家角色（動詞就是觀察）。③「紅泥爐」是唯一把「溫暖」放在朋友邀約而不是自我打氣的，最有人味。④「今天還行」最口語、最有共鳴，但悠閒感略低、可能被讀成疲憊，建議當 IG 簡介口頭禪，不一定當帳號名。

## 六、Andy 可能不同意的地方

1. 我把「今天還行」排進前 6，雖然它可能讓人覺得仍帶一點疲態；若覺得還是悲觀，直接否決，改補「巷口有貓」。
2. 「紅泥爐」「坐看雲起」仍有古詩味，對年輕讀者可能偏文；已用副標翻譯，但若 Andy 要更口語就只留「日日小晴」「晴有時」。
3. 我沒推「小確幸」系詞（日子有糖、微暖日）：怕被當成已經濫用的類型。
4. 「午後三點半」藏了 15:30 盤後更新的彩蛋，我判斷不對外講；若覺得太像財經梗可否決。
