# 「燭窗」LOGO 12 款（2026-11-04）

頻道④定名「燭窗」（Andy：「燭窗 用這個，因為我們是觀察者，我們是在訴說這世代的問題」）。名稱靈感來自李商隱〈夜雨寄北〉「何當共剪西窗燭，卻話巴山夜雨時」：現在的累（巴山夜雨），總有一天會在窗邊燭光下笑著當成往事。**窗＝觀察的視角，燭＝窗裡那一點光。**

全部自繪向量（SVG＋PNG），不用 AI 圖、比比、吉祥物。文字已轉成字形路徑（來源：~/.fonts 的 Noto Sans／Serif CJK TC、霞鶩文楷，皆 OFL），SVG 不依賴系統字型。第 7 款「篆刻」用宋體仿白文印（無篆書字型），第 8 款「書法」用文楷加毛邊濾鏡，非真手寫，正式上線前可請人手寫替換。
重跑：`python3 gen.py && node render.js && python3 compose.py`

## 守則自查
- 燭火一律是暖色小火苗／燈火／窗內透出的光，沒有白燭、燭台長柱、香爐、追思氛圍；第 6 款是小桌上的油燈，不是蠟燭。
- 沒有高處、繩索、吊掛、藥、尖銳物、墓碑形狀（第 2 款曾像子彈／主教帽，已改成火苗形窗，避開）。第 6 款人影無五官。
- 紅色：米白紙色調的暖光用暖橙 #E58A2E，沒有朱紅。
