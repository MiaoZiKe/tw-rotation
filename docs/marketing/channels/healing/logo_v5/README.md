## 驗收
- 重疊檢查：程式 437 項 0 筆（頭像安全圓 864 內 48 張、暖光存在 36、字標留白 ≥30px 64、字標符號與字間距 ≥20px、字在窗／樓內、總覽含義不超格 12、配合示意 12 張寬 ≥220 且不壓「往右滑」、對比）；人工看總覽、色調比較、可讀性、配合示意 4 張 0 筆。明細 overlap_report.json。
- 對比：線條 ≥3、字標 ≥4.5、暖光 ≥3（8 種色調皆過）。
- 安全：無高處、陽台、欄杆、月台、軌道、繩索、吊掛、藥、尖銳物、墓碑形。大樓為平頂、門是室內門，日出為水平地層；款 11 年輪非繩圈，款 2 無拱形頂。
