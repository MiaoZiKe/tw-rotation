# 頻道命名提案（文案總監版）

> 2026-11-04 獨立作業，未參考 repo 內其他命名檔案。
> 對象：2000 後出生的台灣年輕人；口吻：冷靜的觀察家；視覺：深色低飽和夜景＋一盞暖黃的燈／一扇亮著的窗。
> 方向：不直白。名稱只給一個「場景」或「溫度」，讓讀者自己把處境填進去。
> 避開：療癒、諮商、治癒、正能量；自傷、死亡、墜落相關字詞；財經投資感的字詞。

## 三、最推薦的 5 個

1. **庭燎**
   字面是「院子裡的火把」，但出處那句「夜如何其？夜未央」本身就是這個頻道的世界觀：夜還沒過完，光是我們自己點的。完全不直白，視覺上就是深色夜景加一團暖光；查核也幾乎沒有撞名。唯一的成本是「燎」字要在第一則貼文解釋一次——那正好可以當開場文。

2. **夜溫差**
   自創詞，聽起來像天氣預報，其實講的是「白天撐住、夜裡才鬆下來」的落差。冷靜、帶觀察家的距離感，又藏著冷與暖兩種溫度，跟深色低飽和加暖黃燈的視覺很合。沒有撞名，最好註冊。

3. **西窗燭**
   熟悉李商隱的人會讀出「有一天會把今天當往事講」的期盼，不熟的人也看得到一扇窗、一根蠟燭。無力感與希望同時在場，最貼近擁有者那句「知道很累，但願意繼續」。

4. **頂加**
   最在地、最有自嘲感，一眼就是這一代人的居住處境，卻沒有說出「房價」兩個字。頂加的窗常是整條街最晚熄的那一盞，正好接上視覺主題。風險是語氣偏生活、偏幽默，若要更文學，可以把它留作系列欄名。

5. **天欲雪**
   前半句是處境變冷，後半句（能飲一杯無）是有人邀你坐下——不說安慰，安慰已經在詩裡。三個字安靜、有季節感，適合冷靜敘事；小雪節氣前後還能做年度企劃。缺點是搜尋時會被節氣文章淹沒，帳號 ID 要另外設計。
