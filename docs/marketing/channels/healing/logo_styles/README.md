## 驗收
- 重疊檢查：程式 65 項 0 筆（安全圓 864 內 24 張頭像、頭像內元素 4 組、字標符號與字間距≥0.25 倍字高 18 張、總覽版面 8、封面示意 8、對比 1）；人工逐張看總覽、可讀性、配合示意 3 張 0 筆。明細 `overlap_report.json`。
- 對比：線條 ≥3、字標 ≥4.5、燈 ≥3 皆達標；單色為純黑白。
- 最細線寬：頭像線條在 1080 圖上 ≥20px，縮 110 後 ≥2px；款 1／8 橫式字標與款 2 的「我們」小字不受此限。
- 第 5、8 款為純字標，無獨立符號，不適用「符號與字標間距」；第 3 款印章的燈與字已程式驗不相交。
- 單色版不靠色差：收據、徽章改用實心／反白；顆粒只在霧紫灰版，單色版不加。

## 美術自評與 Andy 可能不同意的地方
1. 封面右下角規範寬 ≤160px，此時第 3、4、6、7 款字只剩約 17px、符號約 40px，偏小；建議角落只放符號或把寬度放寬到 ~220。
2. 款 5「代」只有末字被結構化，「我們」仍用字型；若要整個名稱都幾何化需再做。
3. 款 3 印章以低飽和玫瑰灰 #E3B3A8 取代朱紅，離「印章」感略遠，換來與霧紫底協調。
4. 美術推薦順序：5 > 7 > 3（小尺寸最強），1 最貼「一盞燈」母題但最素。
