# 「談晴說礙」LOGO 9 款（2026-11-06）

Andy 原話：「名稱就定談晴說礙 做LOGO給我看」。
主軸：雲＝礙（擋在前面的難），太陽＝晴（希望、正向）。字標「晴」太陽橘、「礙」雲灰；副標「礙還在，晴也在。」

| 款 | 名稱 | 含義 |
|---|---|---|
| 01 | 雲帶缺口 | 第二輪 07 原版：雲帶是礙，缺口露出一小塊晴 |
| 02 | 雲帶精修 | 同上，小太陽加光暈 |
| 03 | 晴時多雲 | 雲在前、太陽在後，光從沒被擋住的那邊灑出 |
| 04 | 半晴半礙 | 一顆圓，一半雲灰、一半太陽橘，交界是雲朵波浪 |
| 05 | 談與說 | 兩個對話框：灰雲說礙、橘太陽談晴 |
| 06 | 雲朵對話框 | 雲朵形狀的對話框，裡面有顆小太陽 |
| 07 | 磚牆日出 | 一排矮磚是礙，太陽從後面升起 |
| 08 | 晴礙字章 | 圓章裡「晴」橘、「礙」灰 |
| 09 | 太陽露臉 | 雲擋住太陽一角，光從另一邊照出 |

自評：03、09 和天氣 App 的「晴時多雲」圖示很像，辨識度高但不夠獨特；08 縮到 44px 字讀不出來；04、05、06 最能對應「談／說」與「晴／礙」兩半。
刻意的前後遮擋：03、09 雲壓在太陽前；07 磚牆擋住太陽下半；06 太陽在對話框裡。
