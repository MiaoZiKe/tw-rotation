## 〇、頻道主軸（2026-11-15 Andy：「頻道主軸可以回顧我之前提到的，我們是觀察者，觀察目前年輕人遇到的困境」）

**以觀察者角度，記錄這一代年輕人（約 20–35 歲）遇到的困境（礙），用數據說清楚，也看見還在的晴。**

- 依據：簡介定稿「用觀察者的角度，記錄時代年輕人的生活」（`bio_談晴說礙.md`）；首篇「薪水、房租、催婚，是這一代的『礙』：不美化，也不抱怨，只把它說清楚」（`queue/20261108_intro/caption.txt`、`intro_談晴說礙.md`）。
- **每一題都要扣回「年輕人的處境」**：平均薪資 → 年輕人起薪與中位數；房價 → 年輕人買房要幾年；物價 → 外食族的一餐；失業 → 青年失業；利率 → 首購族的房貸；結婚生育 → 晚婚晚生；學貸；勞保 → 年輕人的退休。
- **選數字的規則**：優先用官方最貼近年輕族群的分組（例如主計總處薪資「未滿 25 歲」「25–29 歲」、人力資源調查「15–24 歲」「25–29 歲」、內政部「初婚年齡」）；並寫明為什麼是這個分組。只有全體數字時，文案要寫清楚「這是全體，不是年輕人」，並說明它怎麼落到年輕人身上（例如全體房價所得比 → 剛出社會的人要存幾年）。**與年輕人無關的總體數據不選**（例如 GDP、股市、企業獲利）。
- 口吻：觀察者，不用「我／我們」；不說教、不灌雞湯；收尾是「一起觀察、一起努力」的提問，不叫人做事。
- 本表第四節每一題都有一欄「這跟年輕人的關係」；寫不出這一句的題目就不排。

## 二、形式：影片為主、輪播為輔

### 2-1 影片（每天 1 支）

| 項目 | 規格 |
|---|---|
| 平台 | IG Reels（同時分享到動態牆）＋ Threads 影片貼文，同一支 |
| 尺寸 | 1080×1920（9:16）、30fps、H.264＋AAC、**20～30 秒、6～8 鏡**（11-15 共用內容邏輯；Andy 11-15「影片步調可以再快點」→ 每鏡 2.5～4 秒、鏡內每 0.5～1.5 秒有變化、數字與圖表動畫 0.4～0.6 秒、硬切不淡出到空白） |
| 內容 | 數字動畫（數字從 0 跑到真實值）＋圖表生長（長條長出來、折線畫出來、點陣填滿）＋每段一行字幕 |
| 結構（2026-11-15 起，照 `docs/marketing/channels/video_logic.md`） | ① 0～3 秒鉤子：第 0 格就是完整主張（標題＋大數字），1 秒內有動作（劃線、蓋章、折線畫出）→ ② 講清楚：發生什麼 → 資料從哪來（機構、報告、日期、口徑＋圖表）→ 大家以為 vs 數據 → 逐一查證（每個說法標狀態：已確定／官方統計／常見說法／自行計算）→ 最合理的解釋 → ③ 最後 3～5 秒：還不知道的事＋二選一提問＋下集預告（下集必須是真的會發的題）。畫面常駐「查證截至 YYYY/M/D」。交件附「自查五項」 |
| 圖上 | 晝版；LOGO 左上；每一段畫面底部一行出處（機構、報告名稱、日期）；不放頁碼元件；不放叫人做事的話 |
| 上下留白（2026-11-15 Andy「紅框處還有空間」，蓋掉原本 Reels 安全區 上 220／下 420） | 頂端、底端留白各 ≤60px（LOGO 頂 56px；出處 1806–1850＋細頁尾帶 1866–1874）；字幕卡下緣 ≤1700，1700 以下只放出處與頁尾帶。`render_video.js` 逐 0.5 秒檢查，頂端或底端連續 60px 以上沒內容＝error |
| 聲音 | AI 旁白（2026-11-15 Andy 定）：`docs/prompts/tanqing-旁白-深度報導.txt`，gemini-3.8-flash-tts、音色 Sulafat、單人，每秒約 4.6～5.5 字；語氣＝深度報導記者、數字清楚肯定、轉折稍慢。每支旁白約 90～120 字，每段一句、觀察者口吻、不用「我／我們」。旁白稿存 `queue/<資料夾>/narration.txt`（每行「段 id｜文字」）；TTS 做好後放 `segments.json`（每段 id、text、start、end，＋ `audio` 音檔名）到同資料夾，重跑產生器即自動用旁白時間戳決定每鏡長度、字幕換成旁白文字、音軌換成旁白。沒有旁白時：每鏡長度＝旁白字數 ÷ 5 字／秒＋0.35 秒，靜音音軌。片尾若加音效，音量要明顯（Andy：「可以再大聲點」） |
| 檢查 | 每 0.5 秒抽一格做元素重疊檢查＋人工抽看；回報寫「重疊檢查：程式 N 格 0 筆；人工 M 格 0 筆」 |
| 產生器 | `templates_tqsa_v3/video/gen_video.py`（內容設定）＋`video_runtime.js`（動畫）＋`render_video.js`（逐幀渲染、ffmpeg 編碼、重疊檢查） |

### 2-2 輪播（每週 2～3 篇）

- 挑「資料最豐富、值得收藏」的題目：有分組、分行業、分縣市、時間序列的那種（例如年薪中位數分行業、CPI 分項、失業率分年齡）。
- 規格照 11/11～11/15 已確認版：晝版、3 張（資料特別多時做 8～10 張完整版，避開 4～7 張）、同篇圖表類型不重複、素材不跨篇重複。
- 同一天有影片＋輪播時，**兩者講同一個大題但切面不同**（影片講一個最強的數字，輪播放完整細節），避免同一天重複。
