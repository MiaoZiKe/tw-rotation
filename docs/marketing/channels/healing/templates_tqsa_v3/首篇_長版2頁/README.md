## 三種色系
- 奶油晨光：底 #FFF6E5，線 #7A746E，晴光橘 #D9822B，字 #3A3A3A。
- 晝版：底 #F6F1E8，線 #6E6A66，晴光橘 #D9822B，字 #2F2D2B。橘色文字（強調句、第 2 頁 CTA）用加深橘 #9C530C 以達對比 4.5。
- **黑白混搭（我對這個詞的解讀）**：同一組貼文內第 1 頁黑底白線（礙，偏暗），第 2 頁白底黑線（晴，轉亮），兩頁只用黑白灰；光點在黑底是淺灰＋白光暈，在白底是中灰（#8A8A8A，不做全黑實心太陽，避免像日蝕）；強調句用粗體加深灰。LOGO 黑底用單色白、白底用單色黑（由 `字標_單色白／黑.png` 去底後存成 `src/logo_mono_白／黑.png`）。若 Andy 的意思是「黑白＋奶油混搭」，改 `src/gen_long.py` 的 `PAL` 即可。

## 貼文內文（說明文字，原文未改字，結尾無「留言告訴我們」）
談晴，也說礙：說這一代的難，也說還在的光。

我們是一個觀察者。
看這一代年輕人怎麼生活：
薪水追不上房價，租屋一換再換；
長輩問什麼時候結婚、生小孩，我們還在算下個月的房租；
大家都說台灣在成長，但多數人的日子，好像沒有跟著變輕。

這些是「礙」。我們不美化，也不抱怨，只是把它說清楚。
說清楚了，才知道不是自己不夠努力。

但我們也看見「晴」：
下班路上的一段夕陽、朋友傳來的一句「我懂」、
存款終於多了一點點、今天的晚餐剛好很好吃。
日子很硬，這一代還是很會在縫裡找光。

這裡每天說一點礙，也談一點晴。
你今天的一小段晴是什麼？
