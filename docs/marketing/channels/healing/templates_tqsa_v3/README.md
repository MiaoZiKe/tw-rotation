2. LOGO（圖片字標，「礙」為黃昏灰紫 #655A72）固定左上，左緣對齊 96px；換頁記號固定右下，用圖形表示。
   - 換頁記號：頁點，目前頁用小太陽（晴光橘），其他頁雲灰空心圓；最後一頁前面的頁點淡色實心、最後一點是小太陽，不放箭頭，不放頁數文字。

## 怎麼換 LOGO
改 `src/logo.json` 後重跑。現行 `mode: text`：純文字字標「談晴說礙」，襯線粗體、字距 .34em，「晴」晴光橘、「礙」雲灰，位置在每頁右下（y1222，右緣 984）。簡約 LOGO 完成後：`mode` 改 `image`，`image_night`／`image_day` 填圖檔路徑（相對 `src/`，夜版用淺色 LOGO、晝版用深色 LOGO），`image_height` 填高度（預設 44，原字標約 40）；座標不用動。要換字標文字、大小、字距改 `text`、`size`、`letter_spacing`。

## 怎麼重跑
`cd src && python3 gen.py && node render.js && python3 contrast.py && python3 sheets.py`（需 Playwright 與 /root/.fonts 的 Noto Serif／Sans CJK TC）。文案在 gen.py 的 JOBS；插圖在 illus.py（`SCENES`）。
