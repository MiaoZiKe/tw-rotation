## 驗收
- 重疊檢查：程式 112 項 0 筆（安全圓 864 內 30 張頭像、頭像內文字／點／數字不相交 15 組、字標符號與字間距≥0.25 倍字高 30 張、總覽版面 20、封面示意 10、對比 1）；人工逐張看總覽、可讀性、配合示意 3 張 0 筆。文字以墨跡範圍（基線上 0.88、下 0.12 字高）判定。明細 `overlap_report.json`。
- 安全檢查：無品牌、無高處／陽台／欄杆／月台／軌道／藥／繩索／尖銳物。款 3 只畫立柱＋座椅＋地面線；款 7 的衣架只是帽口上的小掛鉤，沒有橫桿與垂掛物。
- 對比：線條 ≥3、字標 ≥4.5、燈 ≥3 皆達標；單色版純黑白，燈改為實心。

## 美術自評與 Andy 可能不同意的地方
1. 推薦（小尺寸最強、也最有共鳴）：1 電量3%、4 熱便當蒸氣、8 小套房平面。
2. 款 3、6、9 在 44px 偏弱；款 6、10 含文字，44px 不可讀，只當氣氛。
3. 款 10 的「0.695」是生育率，數字本身偏沉重；若覺得太冷可換「15.41」。
4. 款 7 帽口那點燈像人頭，掛鉤可能被讀成「吊著」，保守可淘汰。
5. 封面右下角寬 160px 時字標字級約 11px，符號只有 40px，建議角落放寬到 ≥220。
