## 首篇文案
3 張版：①大字「談晴，也說礙」／小字「說這一代的難，也說還在的光。」②「我們是觀察者」／「記錄這一代的難，也記錄難裡的晴。」③「每天說一點礙，也談一點晴」／「傳給一個也在撐的朋友。」／底部「今天的晴，留一個字給我們 →」（CEO 11-06 補充：新帳號粉絲少，改成「傳給朋友」＋一個字就能回；5 張版第 5 張同改）。
5 張版：談晴，也說礙／我們是觀察者（小字用上一版「記錄這一代年輕人，怎麼過日子。」）／有些難，說清楚了／但我們也看見晴／每天說一點礙，也談一點晴。

自介（模板內沒放，給帳號簡介用）：
談晴，也說礙：說這一代的難，也說還在的光。
用觀察者的角度，記錄這時代年輕人的生活。
阻礙再多，也會等到放晴的那一天。
等晴的日子，我們一起記下來。

## 怎麼換 LOGO
改 `src/logo.json`：`src` 是圖檔路徑（`{tone}` 換成色調中文名，蜜桃傍晚沒有對應檔，借 `fallback_tone` 奶油晨光）。
- `mode: symbol_text`（現行）：取圖左邊 `crop_x` 像素內的符號，字標「談晴說礙」用 HTML 文字畫。
- `mode: image`：整張圖當字標（logo_tqsa2 做好含「晴、礙」二字的新 LOGO 後用這個），不再另畫文字。`height` 是 LOGO 高度。
改完照下面重跑即可，版面座標不用動（LOGO 寬度自動算，字標跟在右邊）。

## 重跑
`cd src && python3 gen.py && node render.js && python3 contrast.py && python3 sheets.py`（需 Pillow、playwright 在 /opt/node-tools、字型 Noto Sans CJK TC）。`html/`、`bg/`、`logo_*.png`、`report.json` 是中間檔，不進版控。

## 檢查結果
- 重疊：程式 64 張 0 筆（所有文字框、插圖框、LOGO、頁碼、膠囊、週曆、小圖兩兩不相交；不超出左右 96px 與上下邊界；無橫向溢出；字級最小 32px）。
- 對比：實取「無字底圖」每個文字框最亮最暗兩端算 WCAG（含「晴」「礙」兩個字），64 張最差 4.58，全過 ≥4.5。
- 人工：原尺寸看過 9 張（首篇 3 張版 cream_1、sky_3；5 張版 cream_3、matcha_3、peach_4；5_sources_sky；7_reels_peach；2_data_peach；threads_matcha），加 6 張總覽／對照圖；其餘 55 張只看過縮圖總覽。
- 未驗：手機 IG／Threads 實機；蜜桃傍晚沒有專屬 LOGO 圖檔（借奶油晨光）；②數據頁 38,406 與出處沿用日日小晴示範值，上線前要回主計總處核對（我沒查證）；5_sources 的出處段落也是示範值。
