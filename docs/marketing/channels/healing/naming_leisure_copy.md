# 生活頻道命名提案（悠閒版）

- 撰寫：文案總監（獨立作業，未參考 repo 內任何 naming 開頭檔案）
- 日期：2026-11-04
- 對象：2000 後出生的台灣年輕人；口吻溫柔觀察、悠閒、有留白
- 核心概念（擁有者原話）：「雖然生活辛苦但努力生活，生活中還是有美好事務」，名稱「不要直白」、「悠閒一點」
- 已退回：「我們這一代」「一邊累一邊好」「還是會開燈」（太直白）、「燭窗」（太悲觀）
- 刻意避開：療癒、治癒、正能量、小確幸、慢活；悲傷、自傷、死亡相關字；財經感字眼

命名原則：辛苦只「藏」在名字的背面，不寫出來；讀者第一眼只看到一個悠閒的畫面，想一想才發現裡面有「先苦後甘」「撐過去」的意思。

## 三、最推薦的 5 個

### 1. 回甘日常
最貼近擁有者的概念：「回甘」本身就包含「先苦」，辛苦不必寫出來，讀者自己會懂；而落點是甜，整體是悠閒不是悲觀。四個字好念、好記，搜尋結果乾淨，帳號與品牌名都還有空間。

### 2. 晾衣日
最有畫面的一個：陽台、陽光、肥皂香，是租屋族與家裡都有的共同場景。「把一週曬乾、明天再出門」藏著努力過日子的意思，但字面完全是悠閒的。三個字短，做封面字或 LOGO 都好排。

### 3. 且徐行
古詩化用裡最自然的一個：蘇軾在大雨裡照樣慢慢走、還吟嘯，正好對應「生活辛苦但照樣過」，又不像「坐看雲起」那樣已被大量使用。搜尋沒有撞名，文雅但不艱澀，簡介可直接引全句當彩蛋。

### 4. 折一角
把頻道的工作說得很溫柔：替這代人的日子，把好看的那一頁折起來。動作小、口語化、有文具與閱讀的質感，適合長期做「記錄」型的內容；搜尋沒有同名帳號或品牌。

### 5. 綠燈很長
五個裡最輕快、最有幽默感的：每個在城市通勤的人都懂「遇到長綠燈」那一下的小開心，反差在於它把最日常的等待，翻成好運。適合 Threads 的短句口吻；搜尋沒有同名。

備選：「午後有風」（乾淨但辨識度較普通）、「蔥花多一點」（很台灣、很可愛，適合當系列欄名）。
