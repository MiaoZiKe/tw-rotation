# 頻道④「心靈雞湯／療癒」視覺規格（2026-11-04 第 1 版，美術總監）

適用：IG 輪播 1080×1350、Threads 配圖 1080×1350、IG Reels 封面 1080×1920。
承接 `docs/marketing/social_unit/post_design_system.md`（尺寸、安全區、重疊規矩）與頻道③ `../ai_intro/visual.md` 的格式。
硬規矩：不出現比比；LOGO 不走吉祥物（用文字標「小口氣」暫名，Andy 定名後替換）；全圖中文；元素不可重疊，須程式檢查；AI 圖必經審。

> 依據與限制：搜尋只能取得摘要，容器打不開外部網站，沒有量過台灣療癒帳號的實際數據。色彩對比用 WCAG 公式實算；字級、留白比例是「手機看 1080 圖縮成約 390pt（縮放 0.36）仍讀得到」的自訂推估。

## 一、療癒系視覺語言

### 1. 情緒關鍵字
**安靜、被接住、溫暖、慢、有人味、輕。**
反面：吵、急、教訓、過度勵志、廉價雞湯感。
一句判準：**看完要讓人「肩膀放下來」，不是「被喊加油」。**

### 2. 趨勢依據（摘要級，僅作方向參考）
- 2026 設計趨勢偏向「有人手痕跡」：手工質感、墨水、紙張、自然光，刻意遠離 AI 過度光滑的外觀（[Creative Bloq](https://www.creativebloq.com/design/graphic-design/texture-warmth-and-tactile-rebellion-the-big-graphic-design-trends-for-2026)、[Creative Bloq wilderkind](https://www.creativebloq.com/art/digital-art/what-is-2026s-wilderkind-trend-and-how-can-artists-paint-it)）。
- 色彩轉向安靜、有深度的大地色、溫暖中性色與柔和粉彩，反映人們對平衡的渴望（[Wanna This](https://wannathis.one/blog/color-trends-2026-for-designers-and-brands)、[Carnegie 2026](https://carnegiefabrics.com/resources/carnegie-convo-2026-trend-report)）。
- 淡粉彩（嬰兒藍、奶油黃、薄荷綠）在短影音文字卡流行（[Who What Wear](https://www.whowhatwear.com/fashion/pastel-color-trend)）。
- 搜尋未找到台灣或華語療癒帳號的具體數據，上述屬方向，不是量化結論。

### 3. 三套色票（皆實算 WCAG 對比，AA 要求內文 ≥ 4.5:1、大字 ≥ 3:1）

| | A 暖霧紙本（推薦） | B 晨霧鼠尾草 | C 薰衣暮光 |
|---|---|---|---|
| 氣質 | 奶油米紙、暖陶土，像手帳 | 灰綠、森林早晨，最安定 | 淡紫灰，睡前、夜間情緒 |
| 淺底 | `#FBF4EA` | `#EEF3EC` | `#F3EFF7` |
| 卡片／紙 | `#FFFFFF` | `#FFFFFF` | `#FFFFFF` |
| 主文字 | `#3B2F2A`（11.8:1） | `#26362E`（11.3:1） | `#2F2A3D`（12.2:1） |
| 次文字 | `#6E5A4E`（5.9:1） | `#506357`（5.7:1） | `#5E5775`（6.0:1） |
| 強調（單色，限一處） | `#A34A30` 陶土（5.4:1） | `#3F6B53` 松綠（5.4:1） | `#6A5BA8` 薰衣紫（5.0:1） |
| 柔光暈（只作背景，不載字） | `#F3D9C2` | `#CFE0D2` | `#DDD3F0` |
| 深底 | `#2B2622` | `#1F2B26` | `#241F33` |
| 深底主文字 | `#F6EBDD`（12.7:1） | `#E9F0E8`（12.6:1） | `#EFEAF7`（13.5:1） |
| 深底次文字／強調 | `#C8A58E`（6.6:1） | `#9DBBA8`（7.1:1） | `#B9AEE0`（7.7:1） |

- 推薦 **A**：暖色與紙感最貼「被接住」，與前三頻道（糖果、瑞士極簡白黑、深藍終端）縮圖一眼可分。B 作週日／早安系列的備用，C 作晚安系列。同一則貼文只用一套。
- 一張圖最多一個強調色、最多一處使用（一句話中的一個詞或一條細線）。其餘走底色與文字兩階灰。
- 深底版當「晚安」系列用；Andy 曾要 AI 圖「不要暗沉」，該條只針對 AI 生成圖，純排版深底不適用，但深底每週占比建議 ≤ 1/3。
- 不用 `#6E5A4E` 以下淡的字色載字；柔光暈對比不足，只能墊在字的外圍。
- 與紅漲綠跌衝突：強調色不用大面積純紅、純綠。B 的松綠已壓低飽和度，不用於漲跌語意。

規則：全站最多兩種字體（主句＋內文），手寫楷體算第三種，只能用在每張圖一處落款。**不引入新 CDN；字檔放 repo 內。** 若字檔太大，用 `pyftsubset` 針對用字做子集（OFL 允許，但改名要避開保留名稱）。

### 5. 字級（1080 寬計）

| 用途 | 字級／字重 | 限制 |
|---|---|---|
| 語錄主句 | 64～84px／Noto Serif TC 700，行高 1.6 | ≤ 4 行、每行 ≤ 12 字；斷行在語意處，不斷詞 |
| 封面鉤子 | 96px／700，行高 1.45 | ≤ 3 行、每行 ≤ 9 字 |
| 內頁標題 | 56px／700 | ≤ 2 行 |
| 內文 | 38px／Noto Sans TC 500，行高 1.75 | ≤ 4 行 |
| 落款、系列標、頁碼 | 30～34px | |
| **揭露列／小字下限** | **28px** | 任何元素不得小於 28px（沿用頻道③規則） |

字距：主句 letter-spacing 0.04em；行距比一般資訊圖鬆，療癒感來自呼吸。

### 6. 留白比例
- 內容外框（文字＋裝飾）占畫布面積 **≤ 45%**；文字區四周留白 ≥ 96px。
- 語錄卡文字區置於畫面**視覺中心略偏上**（中心點在 y≈45%），下方 1/3 留給落款與系列標。
- 避免「中間一大片空白、四邊擠滿」：留白要集中在文字四周，而不是散在角落。
- 一張圖一句話、一個情緒。

### 7. 質感
- **紙紋**：背景加 4～6% 不透明度的細紙紋（SVG feTurbulence 或預製 PNG），不得讓文字區出現可見雜點；紙紋圖用 CSS 疊在底色上，文字在其上方。
- **柔光**：單一圓形或橢圓徑向漸層，邊緣羽化 ≥ 200px，不透明度 ≤ 60%，不用 bloom、不用發光字。
- **手寫／手繪**：落款、底線、小圈圈用不規則 SVG 路徑自繪（粗細 3～5px），不做機械直線；每張最多一處。
- **細節**：一條 2px 線、一顆小圓點、一片簡化葉子，足夠；不堆元素。

### 8. 禁用
- 螢光色、純白強光、過飽和（任何色飽和度 > 55%）、彩虹漸層。
- 廉價雞湯元素：滿版晚霞加大字、閃亮星光、愛心滿天飛、金色勵志字。
- **悲傷刻板圖像**：雨中背影、窗邊獨坐低頭、黑白孤獨身影、空蕩長椅、蜷縮的人。
- **自傷暗示意象**：刀具、繩索、藥瓶、高處邊緣、天台、鐵軌、橋欄、手腕特寫、血色、沉水、窒息、黑洞似的深淵。
- 字面也禁：句子本身不得美化「消失、結束一切」。若主題涉及低潮，結尾頁固定附一行求助資訊（見下方七）。
- 真人臉、可辨識真實地標、品牌 logo、比比與任何吉祥物。
- 紅色警示色（與紅漲綠跌混淆，且療癒情境不宜）。

## 三、圖片來源規則（依優先序）

1. **純排版＋自繪向量（SVG）— 預設**。紙紋、柔光、葉子、圓點、手繪線全部由 `visual-designer` 以 HTML／SVG 自繪，零授權風險、可程式檢查重疊。
2. **實景照片** — 次選。只准用：自己拍攝；或 CC0／Unsplash／Pexels 且確認授權頁允許商用、不需標註（逐張存檔來源網址與授權截圖於貼文資料夾 `license.md`）；人物照一律排除（肖像權與「像真人病患」風險）。主題限窗光、植物、茶杯、書頁、天空、步道，不得含前述禁用意象。照片須調為暖或冷柔和色調，與色票協調。
3. **AI 圖** — 末選，只當氣氛背景（柔光、水彩暈染、抽象色塊、植物局部）。**不得**畫人（含背影、手）、不得畫文字。每張必走 `ai_image_review.md` 十條審，另加療癒題材專屬審查（見下）。AI 圖的頁面右下角標「AI 生成」小字（28px）。

### 療癒題材專屬審查（加在十條之後，共 14 條，任一退回即整張退回）
| # | 項目 | 退回標準 |
|---|---|---|
| 11 | 無自傷暗示 | 出現刀具、繩索、藥物、高處邊緣、水面下人形、手腕特寫、血色或暗紅，或構圖像「邊緣、墜落、窒息」 |
| 12 | 無刻板悲傷 | 雨中背影、低頭獨坐、黑白孤獨、空椅、蜷縮人形 |
| 13 | 不像真人病患 | 任何人形、臉、手、近似醫療情境（病床、點滴、診間） |
| 14 | 手指與文字無變形 | 手指數量、融合、類字符號；此條與第 1、3 條合併檢，療癒題材更嚴：**有手就退回** |
另：第 4 條明亮度對本頻道放寬為 ≥ 150（柔和明亮底），深底系列 AI 圖不使用。

## 四、重疊與品質檢查（交件必附）
1. 每個元素標 `data-o`；程式查：交集（0 筆）、元素間距 ≥ 32px、越界（0 筆）、字級下限 28px。
2. 版型 1、4 另查：主句外框高度 / 畫布 ≤ 45%、主句四周留白 ≥ 96px。
3. 對比：用腳本算主文字、次文字、強調色對底色，AA ≥ 4.5:1，載字處柔光暈區域也要算。
4. 深淺兩套各出一張，**1080 全尺寸與縮放 0.36（約 390pt）各看一次**，縮小後主句仍清楚。
5. 人工全解析度看每張，確認沒有類似自傷意象的手繪形狀（例如手繪線不構成繩圈）。
6. 回報格式：「重疊檢查：程式 N 張 0 筆；人工 M 張 0 筆」，沒這行不收件。

## 五、可能被 Andy 否決的地方（一次列出）
- 我選暖米紙色（A）作主色，而不是粉彩藍或薄荷，理由是縮圖與前三頻道距離最遠；若他要更清爽可改 B。
- 禁用所有人形（含背影、手）的 AI 圖，限制偏嚴，但療癒題材一旦畫錯風險遠高於好處。
- 揭露列「圖文含 AI 協助」沿用頻道③；心靈類內容若為完全人工撰寫，措辭可由 `legal` 另定。
- 主句字數上限 40 字，比一般語錄帳號更少。

## 六、沒驗到的部分
- 沒有任何範例圖；字體、紙紋、柔光皆尚未在容器內渲染。
- 容器只有文泉驛，未用 Noto 字型驗證斷行與寬度；`visual-designer` 做樣板時須先安裝字檔再跑檢查。
- jf open 粉圓授權未確認；其他字體授權僅依搜尋摘要，上線前請 `legal` 讀官方授權頁。
- 手機實機可讀性是推算。

## 七、給 `visual-designer` 的實作交辦
產出位置：`docs/marketing/channels/healing/layouts/`，仿頻道③ `gen_a.py` ＋ `render_a.js` 結構。

1. 寫 `gen.py`，輸入 JSON（版型、色票代號 A／B／C、淺／深、文案）產 HTML，色票全用 CSS 變數（`--hl-bg`、`--hl-card`、`--hl-text`、`--hl-sub`、`--hl-accent`、`--hl-glow`），不得在 HTML 內寫死色碼。
2. 實作四個版型（語錄卡、輪播封面、輪播內頁、Reels 封面），尺寸與座標照第二節。
3. 紙紋與柔光用純 CSS／SVG，不引外部資源；字體用本地 `@font-face`，字檔存放 `layouts/fonts/`，先確認授權檔 `OFL.txt` 一併放入。
4. 實作 `render.js`（Playwright）：截 PNG，並依第四節跑重疊、間距、越界、字級、留白占比、對比檢查，輸出 `overlap_report`。
5. 每版型出 A 推薦色票淺色一張；語錄卡與 Reels 封面再各出 A 深色、B 淺色、C 淺色各一張。共 4＋6＝10 張範例（用中文假文案，主句不使用可能被誤讀為自傷暗示的字）。
6. 最後頁範例加求助資訊一行：「1925 安心專線（24 小時）」。**電話與措辭由 `legal` 與 `content` 於上線前核對台灣現行公告（本檔未查證），樣板先放占位並標註「待核」。**
7. 交件附：全解析度與縮放 0.36 各一張並排檢查圖、檢查結果、逐條過／不過清單。
8. 紅線：不碰既有 `site/` 與其他頻道檔案；不引入新 CDN；不使用 AI 圖（樣板階段全用向量）。

## 八、LOGO 方向規範（2026-11-04 追加，Andy 要 3 款方向）

### 1. 通則

| 路線 | **不走吉祥物**，也不放人臉、人形、手；以「字標＋一個極簡符號」或純字標為主 |

### 2. 三款方向（供 visual-designer 對應）
| 款 | 構想 | 辨識點 |
|---|---|---|
| L1 純字標 | 名稱兩到四字，最後一字帶一筆手繪弧線（呼氣的意象） | 最安全，字小仍清楚 |
| L2 圓章 | 圓形內一個葉或月牙，下緣一條細弧 | 天然適合圓形頭像 |
| L3 字＋符號橫排 | 小符號在左、字標在右，符號可獨立當頭像 | 系統最完整，符號必須能單獨成立 |

### 3. 尺寸與驗收（逐條過／不過）
1. **IG 圓形頭像**：輸出 1080×1080 方圖，內容必須落在中央直徑 **864px 圓內**（四周留 108px）；圓形裁切後符號與字標不被切。
2. **110px 可讀**：縮到 **110×110 圓形**（IG 實際顯示約此尺寸）仍能看清符號輪廓；最細線寬縮放後 ≥ 2px；字標在 110px 下單字高度 ≥ 20px，否則頭像版只留符號、不放字。另驗 **44×44**（留言區縮圖）符號仍可辨。
3. **單色版**：每款提供單色（純 `#3B2F2A` 於米底、純米白於 `#2B2622` 底、純黑白）三版，單色下辨識度不得掉，**不得靠漸層或色差區分**。
4. **對比**：符號對底色 ≥ 3:1（圖形）、字標對底色 ≥ 4.5:1，須實算。
5. **深淺底各一**：米紙底、深底（`#2B2622`）都看得見。
6. **不重疊**：符號與字標外框不相交、間距 ≥ 字標高度的 0.25 倍，程式量測。
7. **安全區**：貼文角落使用時（右上或左上小標）寬 ≤ 160px、距邊 ≥ 88px，不壓到主句區。
8. **禁項自查**：逐項確認無吉祥物、人形、自傷暗示形狀、AI 生成部分（LOGO 一律自繪向量，不用 AI 圖）。
9. 交件：每款 1080 方圖、110px 圓形縮圖並排拼圖、單色三版、驗收結果；格式 SVG 原檔＋PNG。
