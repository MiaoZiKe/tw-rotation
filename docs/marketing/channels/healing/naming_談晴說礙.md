# 名稱「談晴說礙」：概念陳述（2026-11-06）

Andy 原話：「談"晴"說"礙" 這個不錯，這LOGO表示 一方面會說正向的 年輕人的希望，另一方面談論到年輕人面臨的困難阻礙。談"晴" 在這裡 表示 希望 正向，一句以上我的內容 簡短話語陳述」

## 名稱的意思
- 諧音「談情說愛」。
- **談晴**：說希望、說正向，說年輕人還在努力、還有好事的那一面。
- **說礙**：說擋在前面的難：買不起房、薪水追不上、被催婚、養不起自己。

## 一句話定位
**談晴，也說礙：說這一代的難，也說還在的光。**

## 簡短陳述（標語候選）
1. 談晴，也說礙。
2. 礙還在，晴也在。
3. 把難說清楚，把晴留下來。
4. 說得出難，才看得見晴。
5. 這一代的難，我們說；這一代的晴，我們找。

## 要注意
- 諧音會被當成感情帳號：好處是好記、有梗；壞處是 #談情說愛 這類標籤會被感情內容淹沒，標籤要自己的（#談晴說礙）。催婚、不敢談戀愛本來就是「礙」的一部分，偶爾寫感情題材剛好接得上。
- 「礙」筆畫多，縮到頭像 44px 看不清，頭像用圖形，不放字。
