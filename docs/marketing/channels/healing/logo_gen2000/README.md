## 可讀性自評（看過總覽與 44px 圖）
符號線寬 9 單位×3.0＝1080 圖上 27px；縮到 110px 約 2.75px（≥2px 達標），44px 約 1.1px。
| 款 | 110px | 44px |
|---|---|---|
| 1A | 可辨（兩條線＋點） | 弱：虛線消失，剩兩條短線，辨識度最低 |
| 1B | 佳 | 可辨月曆輪廓，亮點尚在 |
| 2A | 佳 | 可辨窗格，燈點小 |
| 2B | 佳 | 可辨弧線與燈 |
| 3A | 可辨 | 弱：鑰匙齒糊掉，只剩圓環與斜線 |
| 3B | 佳 | 可辨門形，門牌糊成一點 |
| 4A | 佳 | 佳：九宮格＋亮格最耐縮 |
| 4B | 佳 | 佳：燈罩實心，最耐縮 |
結論：44px 最耐縮為 4B、4A、1B；1A、3A 偏弱，若選用建議頭像版加粗或只留主體。頭像只放符號，字標頭像版不放字（110px 下字高不足 20px）。
