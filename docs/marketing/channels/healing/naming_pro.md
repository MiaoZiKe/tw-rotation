# 頻道④ 專業命名（第四輪，品牌命名顧問版，2026-11-04）

> Andy 11-04 原話：「名稱不要那麼直白 請專業的人來命名」。前三輪被嫌太直白的名單（我們這一代、還是會開燈、再亮一點點、一邊累一邊好、一格亮著、夜間觀測、低照度、十一點的窗）**全部不重用**，連同「同一種直白」的近親也避開。
> 本輪原則：**名稱不說「累／光會來／會變好」，只給一個畫面或一個有出處的詞，讓讀者自己補完感受。**
> 全篇分「事實（有來源）」與「我的判斷」。撞名檢查只用 WebSearch，**抓不到 IG／Threads 小帳號與商標資料庫，所有撞名結論信心＝低**，上線前要 Andy 或我方人員人工查（見第七節）。

## 一、命名策略

### 1.1 品牌個性（3 個形容詞）【我的判斷】
**安靜、近距離、留一盞燈**。說話像隔壁窗的鄰居，不像講師；有觀察的冷靜，但語氣是暖的；不喊口號、不保證結果。

### 1.2 命名不能做的事【我的判斷】
1. 不能直接說出「累／窮／買不起／會變好」（直白，且像保證）。
2. 不能出現財經詞（股、漲、報酬、輪動）——這個帳號要與頻道① 切開。
3. 不能有自傷、尋短、厭世的聯想（「末班」「熄燈」「墜落」類字眼要避）。
4. 不能宣稱療癒、治癒、救贖（醫療／心理宣稱的法律灰區，見 legal_gen2000.md）。
5. 不能用 2000 後根本不用的老派腔（太文縐縐會被當作長輩口吻）；有出處的古詩詞只能用一個「看起來像新詞」的小片段。
6. 英文帳號要能念、能拼，不超過 20 字元。

### 1.3 成功的華語名稱如何「不直白但有感」（5 例）

| # | 名稱 | 事實（來源） | 手法與可借鏡之處【我的判斷】 | 信心 |
|---|---|---|---|---|

**五個案例的共通規律【我的判斷】**：①名稱是名詞或短語，不含情緒形容詞的結論；②都有一個可想像的畫面（一頁、小日子、食堂、動物園、微熱）；③讀者可以把自己的經驗放進去；④不承諾結果。

## 二、命名領域（7 個）

| 領域 | 說明 |
|---|---|
| A 意象隱喻 | 用空間或物件（窗、巷口、玄關）承載「觀察」與「陪伴」 |
| B 時間與光 | 用時辰、光的狀態，不直說「亮」 |
| C 古典詩詞化用 | 只用已進入公共領域的古詩詞片段（唐宋，作者已逾著作權期），標出處 |
| D 自創詞或組合字 | 新詞，讓人第一眼停一下 |
| E 外語借詞或音譯 | 日文、拉丁文、古英文，語感乾淨但有撞名風險 |
| F 數字或座標 | 時間、坪數、緯度，冷靜觀察家的口吻 |
| G 反差句 | 小小的轉折，帶點自嘲，口語 |

## 五、推薦前 6 名

排序依據：總分為基礎，再看「是否能自然長成系列」「2000 後讀到會不會停一下」。**十一點的窗型（23:47、十二坪）因與被否決的「十一點的窗」同屬時間／空間直白，降權。**

### 第 1 名　窗與窗之間（29）
- **副標**：2000 後的城市觀察
- **品牌故事**：房價追不上，薪水停在原地，過年又被問東問西。這座城市有很多扇亮著的窗，每一扇後面都有人和你一樣。我們不替你加油，只在窗與窗之間，記下今天發生了什麼、你不是一個人。（78 字）
- **理由【我的判斷】**：「之間」站的就是觀察家位置；同感與被安撫都在名字裡，卻一個字都沒說「累」。

### 第 2 名　西窗燭（30）
- **副標**：給還醒著的人
- **品牌故事**：李商隱寫「何當共剪西窗燭」，等一個能一起坐在燭下說話的人。一千多年後，我們也在各自的窗前。這裡不談成功，只把今天的事說給你聽，剪一剪燈芯，明天再說。（75 字）
- **理由**：分數最高，窗＋燭＝我們的視覺母題，且有出處、有故事可講。**風險**：2000 後可能覺得太文，需靠首圖與副標拉近。

### 第 3 名　微明（28）
- **副標**：夜與天亮之間，一點點可見
- **品牌故事**：微明，是天還沒亮、燈剛亮起的那一點。不保證會變好，只確定看得見。我們用冷靜的方式整理這一代的處境，讓你知道不是只有你覺得不容易。（70 字）
- **理由**：兩個字、好記、不直白，延伸為「微明筆記」「微明日記」都順。**風險**：詞太短，社群帳號很可能被佔，要用 weiming 加後綴。

### 第 4 名　夜糧（27）
- **副標**：給晚歸的人一點力氣
- **品牌故事**：加班回家、洗完澡、還沒睡的那一段，是這一代最長的一天。夜糧不是雞湯，是一份冷靜、有料的小觀察，配著宵夜讀完就好。（66 字）
- **理由**：有「生存感」又不悲情，與「照顧自己」接得上；系列延伸好（夜糧 01、夜糧盒）。**風險**：像美食帳號，要靠視覺與副標釐清。

### 第 5 名　巷口那盞（28）
- **副標**：回家路上的小事
- **品牌故事**：每個人回家的巷口都有那麼一盞燈，不起眼，卻讓人知道快到了。我們寫給 2000 後的城市生活：薪水、房子、過年，不吵、不勸，只在巷口等你看一眼。（73 字）
- **理由**：最有台灣人情味與圖像感；「那盞」留白，符合要求。**風險**：與「還是會開燈」同是路燈／燈意象，辨識度偏低。

### 第 6 名　燈籽（29）
- **副標**：一點光的種子
- **品牌故事**：燈籽，是一顆很小的光的種子。長不長得大，沒人保證，但今天先放在窗台上。我們把這一代的處境整理給你，不談立刻改變，只談還能做的一件小事。（70 字）
- **理由**：獨特度最高，沒有撞名；「種子」有希望但不承諾。**風險**：陌生字詞，需要首次曝光時解釋，可能被當成錯字。

> 備選：23:47（最酷，搜尋性最差）、巷口那盞可與窗與窗之間做「主名＋系列名」搭配，例如帳號「窗與窗之間」，每週專題名「巷口那盞」。
