## 驗收（visual.md 第八節）
- 安全區：內容在中央直徑 80% 圓（512 底圖半徑 204.8）內。程式量測 L1 172、L2 162 通過；L3 外框圓章半徑 184（含線寬）通過（報告中 255 是圓的方形外接框角，非實際圖形）。
- 重疊：程式以文字外接框量測會把相鄰行與圓章包字誤報為相交（文字框含字體上下空間）；人工看圖，字與符號實際無相交，間距未達「字標高度 0.25 倍」的細項未逐一量。
- **110px 可讀：L1 不過**（字標高約 16px，<20px 規範）；L2、L3 字也偏小，正式版頭像建議只留符號（L1 燈弧、L3 窗）或放大字標。44px 未驗。
- 單色三版、符號對底 3:1 數值：未做，只做淺／深兩版。L3 的「窗」看起來像手機，需再調整。
- 字體：字標設為 Noto Serif TC 900（SIL OFL 1.1），容器只有文泉驛正黑，**實際渲染為文泉驛**（GPL 加字型例外，可商用）；LOGO 若要定案，字標需用授權明確的字型轉外框。
