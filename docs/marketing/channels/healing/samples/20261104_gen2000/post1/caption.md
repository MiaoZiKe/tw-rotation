# post1 文案（取自 範例1_threads.txt）

存了三年的頭期款，追不上房價漲的速度。

內政部統計，2025 年第 2 季全國房價所得比是 9.89 倍：不吃不喝要將近十年，才買得起一戶中位數的房子。台北市是 15.41 倍。

1989 年，台北也有上萬人夜宿忠孝東路抗議房價，那時台北房價所得比約 8.58 倍。現在是 15.41 倍，約 1.8 倍。上一代不是比較輕鬆，只是我們的起跑線又往後退了一大段。

這週可以做的小事：把房租、存款、每月能留下的錢，三個數字寫在同一張紙上。不是為了急著買，是為了看清楚自己站在哪裡。

不是我們不夠努力，是起跑線的價格變了。看清楚，才不會一直怪自己。

出處：內政部不動產資訊平台，2025 年第 2 季房價所得比（全國 9.89 倍、臺北市 15.41 倍）；1989 年臺北約 8.58 倍為巢運整理之歷史估算，與內政部口徑不同，僅供對照。房價所得比＝中位數住宅價格÷家戶可支配所得中位數。以上為公開統計整理，非購屋或投資建議。
