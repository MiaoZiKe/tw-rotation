## 結論
1. **前三名分差很小，沒有統計上的差別**：④霧紫灰、⑤水泥暖灰、①灰藍夜。兩邊意見相反的地方：
   - ④霧紫灰：美術第 1（燈最明顯、縮圖最好認、跟頻道①藍黑與財經鮮豔色區隔最大）；但研調查不到「紫色＝悲傷」的證據，太紫會變夢幻。
   - ⑤水泥暖灰：研調第 1（悲傷感來自「暗＋低彩度」，暖灰最低彩度）；但美術說燈的光暈被底色吃掉。
2. **淘汰**：②太暗且撞頻道①底色 #0b1220（可留作「深夜特別篇」）；⑥⑦淺色底燈光消失，失去「悲傷但不絕望」。
3. **建議**：開張預設用 **④霧紫灰**（名次加總第 1，副標字再調亮一階避免夢幻感）；前 4 週把 ④／⑤／① 輪流用在同類貼文，第 5 週看「收藏率、分享率、觀看中位數」選定一個（測法見 `research_color.md` 第六節）。這是唯一能拿到真正統計的方法。
