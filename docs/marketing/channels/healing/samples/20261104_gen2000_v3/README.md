禁用意象：無高處／欄杆／水邊／雨中背影／躺地／抱頭蜷縮／藥物或尖銳物／哭泣特寫／繩索（捷運只用扶手桿，無吊環）／鐵軌月台。
窗戶規則：有窗的場景一律是室內小窗（窗框、窗簾、窗台），高樓只在窗內遠處；人物不靠窗、不在窗前。
