# 「我們這一代」創意概念 LOGO 10 款（2026-11-04）

頻道定位：冷靜的觀察家。每款都是「一個想法」，不是單一物件。全部自繪向量（SVG＋PNG），不用 AI 圖、不用比比、不走吉祥物。色票④霧紫灰（底 #4A4454、線 #ABA0B5、主字 #F3EFF5、燈 #F2D88E），每款一點暖黃。字型 Noto Sans CJK TC Bold（OFL，~/.fonts）。
重跑：`python3 gen.py && node render.js && python3 compose.py`

## 驗收
- 重疊檢查：程式 111 項 0 筆（安全圓 864 內 30 張頭像、字標符號與字間距≥0.25 倍字高 30 張、暖黃燈存在 10 款、總覽版面與概念句不超格 30、封面示意 10 張不壓「往右滑」／副句且寬≥220、對比 1）；人工逐張看總覽、可讀性、配合示意 3 張 0 筆。明細 `overlap_report.json`。
- 符號內沒有文字，所以無文字相交項。款 8 的人形是抽象幾何（圓頭＋圓頂身），站姿、無五官、無懸吊。
- 安全：無品牌、無高處／陽台／欄杆／月台／軌道／繩索／吊掛／藥／尖銳物／墓碑形。款 9 的窗台線是水平地面線；款 3 沙漏無尖角；款 5 房頂的接頭是電池頭，不是煙囪或掛鉤。
- 對比：線條 ≥3、字標 ≥4.5、燈 ≥3。單色版：燈改為實心面，與線條區分。

## 美術自評與 Andy 可能不同意的地方
1. 推薦：1 窗是眼（最貼「觀察家」）、3 沙漏房子（最有雙關）、9 窗格向上（唯一帶希望）。8 燈裡的人最貼「我們」，但人形在 44px 幾乎看不見。
2. 款 7、10 太細碎，44px 只當氣氛，適合當封面插圖，不適合當頭像。
3. 款 4 橫長，圓形頭像裡偏小。款 5 屋頂接頭可能被讀成瓶子，已加寬為電池頭，仍有風險。
4. 款 7 的「人」字是漢字拼貼，不是人形，不涉及人像姿態。
