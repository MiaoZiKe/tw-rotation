# 談晴說礙｜素材登記（插圖不得跨篇重複）

> 2026-11-10 Andy：「貼文上的素材製作，需要依據文章的內容進行對應製作，有數據就有圖表，另外避免同一個素材使用過，其他文章再次使用同一個」。
> 規則：新篇開工前先查這張表；插圖（場景、物件構圖）與這裡任何一列相同就重畫。LOGO、右下頁碼元件、圖上出處行不在此限。
> 圖表（長條、直條、圓環）是「呈現數據的形式」，可以再用，但每篇的數據與構圖不同；裝飾性場景不准重複。
> 產圖程式：`templates_tqsa_v3/src/gen_short.py`（首篇）、`illus.py`（模板／長輩的期待）、`gen_posts.py`（說明型貼文）。
