# 日日小晴 模板（明亮版）

頻道④「日日小晴」：不求天天大晴，每天有一小段晴就好。調性悠閒、溫和、帶希望。
LOGO 位置目前是純文字字標「日日小晴」（40px 粗體，「晴」用色調深色），LOGO 定案後換掉 `wm` 那一格即可。LOGO 另有人做，本資料夾不碰 `logo_rrxq/`。

## 檔案
- 總覽：`templates_overview.png`（7 種 × 奶油晨光）、`templates_palettes.png`（同一張封面 × 4 色調）
- 成品：`1_cover/` … `7_reels/`，每種 4 色（`_cream` 奶油晨光、`_sky` 晴空淡藍、`_matcha` 抹茶午後、`_peach` 蜜桃傍晚），共 28 張 PNG
- 原始碼：`src/`（`illus.py` 自繪向量插圖、`gen.py` 版面與示範文字、`render.js` 轉圖＋重疊檢查、`contrast.py` 對比檢查、`sheets.py` 總覽圖）。重跑：`cd src && python3 gen.py && node render.js && python3 contrast.py && python3 sheets.py`（要先把 render.js 預設的 playwright 路徑確認存在）

## 共通規格（量得出來）
畫布 1080×1350（Reels 1080×1920）；左右邊界 96px；字體 Noto Sans CJK TC。字標 y96；插圖框 x96–984（888 寬）、圓角 40、線寬 5px，線條加填色，不用 AI 圖、照片、比比、品牌；無自傷暗示意象。主句 64px 粗體（Threads 68、Reels 84）、行距 1.5、一句最多兩行；小字 34px（Reels 40）；其他標籤 32px。全部文字 ≥30px。插圖約佔 2/3（輪播類 168–920 的框 ＋ 數據頁大數字）。

## 檢查結果
- 重疊：程式逐一比對每張的所有文字框、插圖框、膠囊、小圖，28 張 0 筆；超出左右邊界 96px 0 筆；最小字級 32px（≥30）；頁面無捲動溢出。
- 對比：用「無字底圖」實取每個文字框底色，取最亮與最暗兩端算 WCAG，28 張最差 4.58（≥4.5 全過）。
- 人工全解析度看過：奶油晨光 7 種全部、晴空淡藍的 Threads 配圖，以及兩張總覽圖。**其餘 21 張（晴空、抹茶、蜜桃的其他模板）只看過縮圖版總覽，沒逐張全解析度看**。
- 未驗：沒在手機 IG／Threads 實機看過；Reels 的上下安全區是依一般慣例（上 250、下 340），平台實際 UI 要再對。
- 圖例沒有使用。設計取捨：數據頁小圖是示意（不是真實分布），已在底註寫明。
