夜版（主）底 #2B2A2E、線與「礙」#CFC9C0、「晴」#F2B35E、主字 #F3EEE6、次字 #B8B1A7。
晝版（輔）底 #F6F1E8、線與「礙」#6E6A66、「晴」#D9822B、主字 #2F2D2B。另有單色黑（黑 #111 在白）、單色白（白在 #111）。
**微調一（晝版符號）**：#D9822B 對 #F6F1E8 只有 2.6:1，低於圖形對比 3:1，晝版符號的「晴」改用 **#C5782B（3.06:1）**。
**微調二（晝版文字）**：字標裡的「晴」字要 ≥4.5:1，#D9822B 不夠，晝版字標「晴」自動加深為 **#98622B**。模板設計師若在晝版放橘色文字請照這兩個值；夜版完全照原色票，無微調。
字型：Noto Serif／Sans CJK TC Regular（OFL）；副標「礙還在，晴也在。」用 Noto Sans CJK TC。全自繪向量，無 AI 生圖、無吉祥物。

## 推薦前三
1. **08 缺口圓**：最貼「礙還在，晴也在。」，圓沒封口、光從缺口進來，一圈一點，44px 仍清楚，也最像細線插畫模板的語言。
2. **09 三點**：最簡單、最粗，頭像最穩；「說不出口的話，最後一點亮起」是觀察者的口吻。缺點：像聊天輸入中的點點，辨識度稍弱。
3. **10 雙圓對談**：直接對應「談」，空心＝礙、實心＝晴，晝夜版都穩。
備選：02 圓中一點（最穩但較通用）。05、06 不建議做頭像。

## 字標
預設＝襯線（Noto Serif CJK TC）、「晴」橘、「礙」雲灰、談說主字色、字距 30、副標小字。四種變體（襯線／黑體 × 晴礙點色／全單色）在 `字標變體_夜版_*`。我的判斷：襯線貼模板的襯線字；點色版「晴」「礙」各自成色，辨識較強，全單色版較安靜，用在極小尺寸或單色印刷。
