### 2. 色彩心理學（情緒）

## 二、6 種候選色調：有證據的優點與缺點

色票：灰藍夜、末班車暗藍、日光燈灰綠白的色碼取自 `visual.md` 第二版；深夜黑藍、霧紫灰、水泥暖灰在 repo 尚無色碼，下面只就色相／明度方向論證。

| 色調 | 有證據的優點 | 有證據的缺點 | 撞色／其他 |
|---|---|---|---|
| **N 灰藍夜** 底 `#1C2128` 暗、低彩度、偏冷 | 暗＋低彩度是悲傷聯想的穩定核心（2-1、2-3、2-4）；低飽和＝低喚起，貼合「安靜無力」（2-6）；藍調在 Curalate 較多讚（1-1，低信心）；不以藍色本身當賣點，避開 2-1 的陷阱；低飽和在 Gen Z 趨勢上對味（4-2） | 暗圖在 Curalate 的亮度項較少讚（1-1，低信心）；深底小字辨識略輸淺底（3-2），需壓字級與對比 | 與①的深色終端底較近但偏灰，距離中等 |
| **深夜黑藍**（近黑、偏深藍；如 `#0B1220` 一帶） | 同上暗與藍的優點；Reece 的「更藍更暗更灰」與憂鬱發文方向一致（2-5） | 暗度最高，亮度項最吃虧（1-1）；小字辨識風險最高（3-2）；憂鬱聯想最重，需配合 visual.md 的自傷暗示禁用清單與安全規範 | **直接撞①**（`#0b1220` 就是①的底），縮圖幾乎分不出，不建議 |
| **M 末班車暗藍** 底 `#12171F` | 與 N 同類；比 N 更暗更藍，情境感（深夜）強 | 同深夜黑藍：暗度、小字、撞色風險；比 N 更偏①的底色 | 與①距離小 |
| **F 日光燈灰綠白** 底 `#E3E7E1` 淺色 | 淺底深字在小字辨識上有證據優勢（3-2）；亮度項在 Curalate 佔優（1-1，低信心）；低飽和（1-1、2-6）；日光燈偏黃綠與閾限美學對應（4-2）；唯一的淺色選項，與①②深色系縮圖易分 | 「灰綠＝疲憊」沒有實驗（2-8）；淺色高亮度偏向「中性、清醒」，情緒上不如暗色貼近悲傷（2-1）；白天看反而像一般清爽雜貨風，須靠文案與插圖把「無力」撐起來 | 可能與②③的白黑極簡接近，需並排看 |
| **霧紫灰**（低彩度紫灰） | 低飽和＝低喚起（2-6）；紫色在跨文化調查中意義不穩（2-7），也就是沒有可依據的悲傷聯想 | **沒有任何證據支持紫色＝憂鬱或孤獨**（2-7）；紫色語意跨語言差異最大，對台灣讀者的實際聯想未知；色相本身帶來的是「夢幻」多於「無力」的風險（推論） | 與①②③都不撞（獨特度高），這是主要優點，但獨特不等於有效 |
| **水泥暖灰** 暗至中、低彩度、偏暖 | 灰是憂鬱者自選心情色（2-4）、憂鬱發文偏灰（2-5）；暖灰與「厭世動物園」類黑白灰風格同路（4-1）；暖調濾鏡與留言相關最高（1-3，Flickr）；與①的藍系距離最遠 | 證據都是「灰」而不是「暖灰」；暖偏向舒適，可能沖淡悲傷感（推論，無實驗）；中灰在手機上容易顯髒／無生氣（行銷常識，無來源） | 與①②③都不撞，縮圖辨識最好 |

## 四、證據量表（不是實測統計；「統計」只能到這裡）

評分方式：以每個維度的有證據支持程度計分，+2＝有同行審查證據直接支持、+1＝間接證據或低信心證據、0＝查無、-1＝有證據不利、-2＝有直接同行審查證據不利。這是我依第一、二節證據手算的結果，維度權重相同，**僅供排序討論，不是統計檢定**。

| 維度 | N 灰藍夜 | 深夜黑藍 | M 末班車暗藍 | F 灰綠白 | 霧紫灰 | 水泥暖灰 |
|---|---|---|---|---|---|---|
| 悲傷／無力感情緒（暗、低彩度；2-1、2-4、2-5） | +2 | +2 | +2 | 0 | 0 | +1 |
| 低喚起（低飽和；2-6） | +1 | +1 | +1 | +1 | +1 | +1 |
| 互動（亮度、藍；1-1，低信心） | 0 | -1 | -1 | +1 | 0 | 0 |
| 手機小字辨識（3-2） | -1 | -1 | -1 | +1 | 0 | 0 |
| 與頻道①撞色風險（5） | 0 | -2 | -1 | 0 | +1 | +1 |
| 台灣厭世系先例（4-1） | 0 | 0 | 0 | 0 | 0 | +1 |
| **合計** | **+2** | **-1** | **0** | **+3** | **+2** | **+4** |

**觀察**：
1. 沒有任何一種色調同時拿到「悲傷情緒」與「小字辨識」兩項高分：暗色最悲傷但最難讀，淺色最好讀但最不悲傷。這是真正的取捨，不是資料缺漏。
2. 水泥暖灰總分最高，但它的優勢多來自「不撞色」與「灰」的間接證據，沒有「暖灰」的直接實驗；F 灰綠白總分第二，主要靠辨識與亮度項。兩者的分差（+4 對 +3）沒有統計意義。
3. 深夜黑藍的唯一問題是撞①，其餘與 N、M 同類；扣掉撞色後三個深藍系幾乎等價。
4. 霧紫灰沒有負面證據也沒有正面證據，是三項 0 分的「未知」。

## 五、對頻道④出圖的建議（含不確定處）

1. **不要選深夜黑藍**（直接撞①）；末班車暗藍也偏近，除非與①並排縮圖確認可分。
2. **灰藍夜、F 灰綠白、水泥暖灰三案入圍做 A/B 小測**，霧紫灰當對照組（用來檢驗「紫色沒有悲傷聯想」的推論是否成立）。
3. **混合解法（推論，無直接實驗支持）**：封面與首張用暗色灰藍夜負責情緒與停留，內頁含長文字的頁改用淺底（字級大、對比高）。需先確認同一輪播深淺混用是否讓畫面不連貫。
4. 無論哪一案：維持低飽和（IG 2013 數據與 Wilms 2018 同向）；不加濾鏡式暖色補償；避開紅色警示色與金色（與①區隔，也避開自傷聯想）。

## 六、建議的實測方法（因為查無直接研究，答案要自己測）
