### 3-1 法說解析（每場 1 篇，每晚 1-3 篇）
- **張數**：IG 輪播 6 張（1080×1350）；Threads 主文 1 則＋留言 1 則（免責），圖附前 3 張。
- **版型**：專業數據圖卡，**不用比比**，亮色底、單色主色、大數字。封面：公司名＋「這次法說公司說了什麼」＋一個核心數字。
- **每張內容**（每個數字附出處與日期，沒有就整張不放）：①封面 ②公司公布的數字（營收、毛利率、EPS，對比去年同期與上一季，來自財報／簡報）③管理層說法（逐字引述一句，標「公司表示」）④公司公布的展望／資本支出／產能（只轉述，不加形容詞）⑤問答重點（公司回應了哪些問題）⑥資料來源與日期＋免責。

```

・營收 ○○ 億元，年增 ○○%；
```

- **張數**：IG 8 張；Threads 主文＋圖前 3 張。

- **我們的版型（學手法、不抄樣子）**：①封面：問句或數字鉤子（例：「每月領 1 萬，要存多少？」）②這檔 ETF 是什麼（追蹤什麼、規模、費用率）③成分股「屬於哪種類型」圓環（占比，不只列名）④試算：存 X 元 N 年的歷史配息現金流（用 `#etf/inc` 同口徑，標「歷史」）⑤對比：同類 ETF 配息率／費用率並排⑥時間軸：配息月份／除息日⑦要注意的地方（費用、追蹤誤差、折溢價，中性寫）⑧資料日期＋免責。

- **不可**：預測報酬、「適合存」、跨檔勝負結論、含 `etf.cmp` 之類 Plus 才有的內容截圖。
- **落點**：`#etf/inc`（試算）、`#etf/cal`（配息）、`#etf/list`（總覽），`?u=th-etfw-<日期>`。

## 四、法遵：可寫／不可寫（個股法說解析 = 最高風險）

> 這是風險盤點，不是法律意見；與 salary 方案相同，收費後本結論要重審。**每一篇發文前必過 legal-compliance agent**。

| 可寫 | 不可寫 |
|---|---|
| 公司公布的數字（營收、EPS、毛利率、資本支出）與日期，附來源 | 目標價、評等、本益比高低、「便宜／貴」 |
| 管理層說法逐字引述，標「公司表示」 | 「利多／利空／受惠／看好／優於預期」等評價詞 |
| 與去年同期、上一季的數字對比（同一份財報內） | 與「市場預期／分析師共識」比較並下結論（除非來源可靠且只陳述事實，需法遵逐篇同意） |
| 事件日程（誰、何時、哪裡） | 推論股價走向、買賣時點、「可以留意」 |
| 總經：實際值、前值、官方聲明原文 | 對台股或個股的影響推論、利率預測 |
| ETF：成分、費用、歷史配息與日期 | 保證配息、報酬率預測、勝負排名 |
| 公司名稱（事實轉述） | 股票代號、股價、漲跌幅、K 線、技術指標；個股頁 `#stock/<代號>` 當落點 |
- 留言被問「可以買嗎」→ 固定回覆（`growth_plan` 9-2），任何人包含 Andy 都不個別回答。
- 熱度排序是內部選題用，**不對外寫「最熱門」「必看」**。
