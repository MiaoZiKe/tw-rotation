### CEO 10-12 守門規則（剪輯端程式會擋）
1. 同一頁的素材用一段連續錄影、來源時間只往前；相鄰兩鏡用同一素材時，後一鏡起點 ≥ 前一鏡終點；同一素材不可 A→B→A 穿插。
2. 頁序固定：總覽（含今日事件、搜尋）→ 財經日曆 → 資金流向 → 熱力圖 → 產業地圖 → 個股 → 市場明細 → 選股策略 → 週期統計 → ETF → 自選清單 → 導覽 → 願望清單；某頁離開後不可再出現。
3. I03 整支禁用；報酬比較的備案見 10-3。

### 1-2 比比四腳天竺鼠原則（`reference/README.md` 10-12 那節）在本片的寫法
素材名照 `bibi_library` 舊名（四腳重做版沿用同名），但動作一律四腳著地：
- `tap`＝跳上按鈕用前腳踩下（腳落下那一格比錄影點擊早 2 格）；連續點擊時**從上一個按鈕直接彈跳（popcorn）到下一個**，中間不回待機位。
- `talk_*`＝趴著／站四腳抬頭說話，身體輕晃；`wave`＝四腳原地左右搖身體＋弧形動作線（不舉手）；`point_*`／`pointer_*`＝鼻尖湊向重點、指示棒**懸空**在身前（不用前掌拿）。
- 道具一律懸空在身前或放在地上讓比比低頭湊近；推 3D 時用頭／身體「推」著拖曳方向走。
- 每鏡比比欄寫法：【素材｜表情｜道具】位置・動作。
