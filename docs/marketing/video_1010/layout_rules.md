# 影片版面鐵則：任何元素都不可以重疊（必須實際檢查）

> Andy 2026-10-11：看到自我介紹那一格，對話泡泡壓在「比比・問題解答小助手」名牌上、遮住字，說「CEO 幫我寫進 .md 檔案，不可以有重疊，要確實檢查」。
> 適用：所有影片（網頁版、手機版、可愛風、專業風、短版）、所有貼文圖、封面、輪播。違反就退件，不准交給 Andy。

## 規則
1. **畫面上任何兩個「有內容的元素」的外框不可以互相重疊**：大字、段落膠囊、台詞泡泡（含尾巴）、名牌、比比、道具與效果符號（愛心、閃光、問號…）、字幕條、底部備註、角標、發光框的標籤、網站錄影裡的重點內容（圖表、卡片、按鈕、文字）。
2. **例外**（第 4 版另加例外 5，見第 8 條；例外 1 的第 4 版規則見下方 2-1）：① 比比踩下按鈕那一瞬間的點擊漣漪與比比本身（≤0.8 秒，站在被點的按鈕上，其餘時間必須待在空位）；② 發光框的框線本身框住重點（框內不放任何別的元素）；③ 半透明浮層壓在網站的「純空白區」（無文字、無圖形的底色）。
2-1. **例外 1（踩按鈕）第 4 版規則（CEO 10-12 定案）**。審片退件原因：v4 預覽比比點擊時不在被點的按鈕上，漣漪在按鈕、比比卻落在旁邊 100～900px 的網站內容上，壓住股價、數字、股名（例：63.5 秒點「週」蓋住股價 2,550.00）。CEO 的決定：
   - 比比瞬間出現在被點的按鈕上（點下前 0.25 秒到點下後 0.45 秒，共 ≤0.7 秒），腳碰按鈕上緣；上方放不下才站在按鈕左右兩側或頭頂碰按鈕下緣；比比由 150px 最小縮到 48px。不從網站內容上飛過去。
   - 這 ≤0.7 秒內：**主角圖表的資料區（K 線、熱力圖色塊、紅綠漲跌數字等有顏色的資料像素）0%**；按鈕以外的文字（導覽欄、表頭、篩選列；被點按鈕那一列不算資料區）**≤15%**；被點的按鈕本身**露出 ≥80%**。其他時間一律 ≤1%。
   - 找不到合格站位的點擊，由內容剪輯換時段或換點擊對象，不准硬壓。程式：`v3_core.Op._tap_pose`（找站位）、`busy_check`（逐幀驗）。
3. **泡泡的尾巴只能指向比比，不可壓住別的元素**；泡泡、名牌、字卡各自要有自己的空間，必要時換位置、縮小、延後出場、分兩鏡，不能靠疊起來解決。
4. **遮蓋網站內容也算重疊**：浮層、比比、泡泡不可蓋住網站的文字、數字、圖例、按鈕（Andy：所有資訊都要看得到）。
6. **手機版版面（Andy 10-11 指定）**：網站畫面框至少寬 ≈1000px、高 ≈1480px（約佔畫面寬 92%、高 77%），置中；內容比框高時「慢慢往下滑」（垂直平移）讓觀眾看到後面的資訊；標題在框上方、比比＋台詞泡泡＋備註只能在框下方的窄帶（約 280px），不可壓到框內內容。
5. **動畫過程也要檢查**：元素進出場、彈跳、飄動、推近放大的每一幀都不可重疊，不是只看停住那一格。

8. **例外 5：疊在網站框上（第 4 版網頁，CEO 10-12 定案）**。Andy 原話：「網站畫面約佔 92% 寬，比比放大，畫面可以調整，重點是圖表一定要都被看到」。所以網頁版網站框固定約 1766px 寬（92%），比比、泡泡、字卡、小字、道具**可以疊在網站框上**，但只能落在「該鏡的重點框（focus_targets）、點擊後內容框（content_rect）、圖表區、點擊目標」以外的地方（實作上放在左側導覽欄或框下方空帶）。錄影端沒有標重點框的鏡頭，整個內容區都當重點保護。放不下就把比比縮小或換位置，**不准壓到圖表**。
   - 程式檢查 `site_overlay_check`（每一幀）：疊加元素與上述區域相交面積必須是 0，報告 `site_overlay_check.md`，有一筆就不出片。
   - 踩按鈕（例外①）也一樣不准蓋住按鈕文字：比比只讓腳碰到按鈕上緣（與被踩按鈕重疊高度 ≤8px），身體在按鈕上方；上方放不下就站在按鈕正下方（CEO 10-12）。
   - 網站錄影本身內建的客服鈕（右下角小比比，`.supfab`／`.bibiring`）也算疊加元素（CEO 10-12 永久檢查）：素材不是 `_nofab`（錄影時已藏）也不在 `FAB_EXEMPT` 例外清單時，客服鈕位置跟重點框、內容框、點擊目標相交 >0 就擋。例外：V25、V26（客服在那兩段是主角，CEO 決定不重錄），以及目視確認客服鈕落在空白的 V16／V17／V18／V23 桌機、V04 手機 v3c（見 `fab_hits.json`）。
9. **停格（CEO 10-12）**：全片任何停格（來源時間停住、或播過素材尾端停在最後一格）不得超過 0.5 秒；守門程式 `freeze_check` 會擋。內容量不足時改用更長的連續錄影，不准停格補秒數。

7. **台詞泡泡（Andy 10-11 退件）**：泡泡本體＋尾巴必須是「單一封閉路徑」（同一個填色、同一條連續描邊，尾巴根部平滑嵌在邊上，無縫、無雙線；尾巴長約泡泡高的 25%）；尾巴尖端離比比外框 12～14px，只指向比比，不可穿過名牌、字卡或任何元素；泡泡文字離尾巴根部至少 10px（尾巴 bbox 與文字 box 外擴 10px 不得相交）。程式檢查：`draw_bubble()` 每幀登記 bubble／bubble_tail／bubble_text 三個外框並做「泡泡非單一路徑」「尾巴離文字<10px」檢查，尾巴與其他元素走一般兩兩碰撞檢查。

## 怎麼檢查（兩道，缺一不可）
**A. 程式檢查（渲染器內建，交件前必跑）**
- 渲染時每一幀為每個元素記錄外框（x, y, w, h，含尾巴與陰影外擴 6px）。
- 對每一幀兩兩比對，外框相交面積 > 0 就記錄「第幾秒／哪兩個元素」，輸出 `overlap_report.md`；有任何一筆就不得出片（例外三種要在程式裡明確標註白名單）。
- 網站內容的外框取自錄影時記下的重點區（shots.md 的完整入框區與焦點框），浮層與比比只能放在該框以外。
**B. 人工逐格檢查**
- 每 0.5 秒抽一格（不是每 2 秒），全解析度打開看，重點看：自我介紹、泡泡出現的前後各 1 秒、轉場、發光框描出的過程、3D 推轉、片尾與警語卡。
- 用 Read 實際打開圖片看過才算，不能只看縮圖總覽或只相信程式。

## 回報時要寫
「重疊檢查：程式 N 幀 0 筆；人工抽 M 格 0 筆；例外 X 筆（列出）」。沒有這一行，CEO 不收件。
