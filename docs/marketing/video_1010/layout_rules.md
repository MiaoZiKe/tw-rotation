# 影片版面鐵則：任何元素都不可以重疊（必須實際檢查）

> Andy 2026-10-11：看到自我介紹那一格，對話泡泡壓在「比比・問題解答小助手」名牌上、遮住字，說「CEO 幫我寫進 .md 檔案，不可以有重疊，要確實檢查」。
> 適用：所有影片（網頁版、手機版、可愛風、專業風、短版）、所有貼文圖、封面、輪播。違反就退件，不准交給 Andy。

## 規則
1. **畫面上任何兩個「有內容的元素」的外框不可以互相重疊**：大字、段落膠囊、台詞泡泡（含尾巴）、名牌、比比、道具與效果符號（愛心、閃光、問號…）、字幕條、底部備註、角標、發光框的標籤、網站錄影裡的重點內容（圖表、卡片、按鈕、文字）。
2. **例外只有三種**：① 比比踩下按鈕那一瞬間的點擊漣漪，與按鈕重疊（那是要點的位置）；② 發光框的框線本身框住重點（框內不放任何別的元素）；③ 半透明浮層壓在網站的「純空白區」（無文字、無圖形的底色）。
3. **泡泡的尾巴只能指向比比，不可壓住別的元素**；泡泡、名牌、字卡各自要有自己的空間，必要時換位置、縮小、延後出場、分兩鏡，不能靠疊起來解決。
4. **遮蓋網站內容也算重疊**：浮層、比比、泡泡不可蓋住網站的文字、數字、圖例、按鈕（Andy：所有資訊都要看得到）。
5. **動畫過程也要檢查**：元素進出場、彈跳、飄動、推近放大的每一幀都不可重疊，不是只看停住那一格。

## 怎麼檢查（兩道，缺一不可）
**A. 程式檢查（渲染器內建，交件前必跑）**
- 渲染時每一幀為每個元素記錄外框（x, y, w, h，含尾巴與陰影外擴 6px）。
- 對每一幀兩兩比對，外框相交面積 > 0 就記錄「第幾秒／哪兩個元素」，輸出 `overlap_report.md`；有任何一筆就不得出片（例外三種要在程式裡明確標註白名單）。
- 網站內容的外框取自錄影時記下的重點區（shots.md 的完整入框區與焦點框），浮層與比比只能放在該框以外。
**B. 人工逐格檢查**
- 每 0.5 秒抽一格（不是每 2 秒），全解析度打開看，重點看：自我介紹、泡泡出現的前後各 1 秒、轉場、發光框描出的過程、3D 推轉、片尾與警語卡。
- 用 Read 實際打開圖片看過才算，不能只看縮圖總覽或只相信程式。

## 回報時要寫
「重疊檢查：程式 N 幀 0 筆；人工抽 M 格 0 筆；例外 X 筆（列出）」。沒有這一行，CEO 不收件。
