### 2-1 版面（Reels／Threads 安全區已扣）

```
y   0–220     留白（平台帳號列）
y 230–400     段落膠囊＋大字（粉圓 80px，一行 ≤10 字；放不下時 64px 兩行）
y 420–1510    第一拍：手機畫面完整入框（x 50–553，寬 503、高 1090，等比縮放，圓角 28px）
              第三拍：推近時畫面卡放大到 x 40–1000 全寬（只顯示框住的那一塊）
x 580–950     右欄（第一拍與第二拍）：y 600–900 比比台詞泡泡（粉圓 40px，≤16 字×2 行）；y 940–1300 比比（320px）
              推近後比比縮到畫面卡左下角 240px、泡泡改在畫面卡上緣
y 1515–1545   小字一行（思源黑體 24px）：畫面數據為過往歷史資料，僅供功能展示，不具投資參考價值
y 1550–1920   留白（平台說明與按鈕）；x>960 不放字
```
- 同畫面要讀的字最多兩段：大字＋比比泡泡（小字備註不算）。
- 第一拍手機畫面完整但字小（約真手機的 47%），是為了讓觀眾知道「原本長怎樣」；第二拍框住、第三拍推近到看得清楚。

### 2-2 三拍與發光框規格（兩版共用）

| 拍 | 做法 | 時間 |
|---|---|---|
| 1 完整 | 整張圖／整塊卡片完整入框，不推不移（3D 鏡改成完整入框自轉） | 鏡頭開頭 0.6～1.2 秒 |
| 2 發光框 | 圓角矩形 4px 天空藍 `#2AA6F5` 框線，從左上順時針描出 0.5 秒；外光 12px、40% 不透明，**描完就固定，不閃、不呼吸**；框外畫面壓暗 15%；同時配 `draw` 音效（鐵琴三音） | 0.5 秒 |
| 3 推近 | 0.8 秒緩入緩出推到框內（倍數見逐鏡表），推完停到鏡尾；配 `zoom` 音效 | 0.8 秒＋停留 |

比比配合第 2 拍：用指示棒（pointer）指框、聚光燈（spotlight）照框，或在框描出那一刻點頭（nod）。可以做點不同（例如框角冒出 2～3 顆小星星，0.3 秒內消失），但不誇張、不閃。

- [ ] 總長 110.0 秒；30 鏡；每鏡 3.0～6.0 秒（片尾、警語除外），切點表逐條對第 3 節；切點落在 0.6 秒拍點
- [ ] 每段第一拍是**完整畫面**（整張圖或整塊卡片都在框內、沒裁邊）——看③那一格的前一格
- [ ] 每段都有發光框：描出 0.5 秒、描完不閃不呼吸、框住的是逐鏡表寫的那一塊
- [ ] 推近後字清楚、沒有糊（桌機 ≤1.9 倍、手機 ≤2.0 倍）
- [ ] 大字從鏡頭開頭出現、停 ≥2.5 秒；同畫面要讀的字最多兩段
- [ ] 每段下方都有那行小字（開場、片尾、警語除外）
- [ ] **全片沒有馬賽克、沒有「Plus」、沒有使用次數、沒有網址、沒有信箱**
- [ ] 第 3 節逐鏡「可以看哪些數據」講到的東西畫面上都看得到
- [ ] 3D 四個產品都完整入框、各自轉、各有一句說明；點零件那一鏡看得到負責的公司與環節
- [ ] 每次 bibi_tap 腳落下那一格跟錄影點擊同一格（誤差 ≤2 格）、位置誤差 ≤20px，踩完回到原位、按下後的變化有露出來
- [ ] 比比：同時只有一隻、無白邊無陰影、每段至少換一種表情與一個道具（第 4-2 節）、切走時停在待機格
- [ ] 片尾卡所有元素在同一條垂直中線上；警語卡另一張、置中、原文程式逐字比對
- [ ] 音樂 100 BPM、3D 段進副歌、尾奏自然收、警語音量減半
- [ ] 法遵第 8 節的禁用字逐條搜一次（字卡、泡泡、`.srt`）
