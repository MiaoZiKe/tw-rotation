# 比比主持規格：要讓觀眾覺得「是比比在操作、在主持、在為我著想」

> Andy 2026-10-11（看完分段版，附比比素材庫總目錄與 E 批圖）：「第一版輕快版本反而互動、比比主持效果更好，並且依據當前的分頁介紹的感覺更棒，需要你再多點互動感、情境感，需要讓觀眾覺得是比比在操作，他在主持，並且是為觀眾著想，表情、情境、動作需要更豐富點。」
> 素材庫：`docs/anim/bibi_library/`（67 組，`index.md` 與 `catalog.png`）。重疊鐵則仍適用（`layout_rules.md`）。

## 五個原則
1. **比比是操作者**：錄影裡每一次點擊、切換、播放、拖曳、滑動，都由比比做（跳過去踩／小肉掌點／推著拖），觀眾看不到別的游標；操作前後要有反應（點完退開、看向結果）。
2. **比比是主持人**：每個分頁一開頭由比比「說話」帶入（talk_happy／explain／excited 輪替），台詞第一人稱、口語：「我來帶你看」「這裡我幫你整理好了」。結尾用「所以你可以…」收。
3. **為觀眾著想**：每段台詞都要講出「對你有什麼好處」——省時間、少切 App、不用自己拉表格、一眼看懂、不漏掉重要日子；用「你」稱呼觀眾，不用命令句，不寫買賣建議。
4. **每 3 秒至少換一次表情或動作**：同一段不能連續兩鏡用同一個素材；反應要跟內容對得上（大漲→驚喜、重要日子→嚇一跳、複利→得意、不用熬夜看盤→打瞌睡、看到前五名→獎盃）。
5. **道具跟分頁走**：每個分頁用該頁的情境道具（對照表如下），道具大小與位置不可蓋住網站重點內容。

## 尺寸與位置
- 比比在手機版 ≥ 220px、網頁版 ≥ 200px（說話時可更大）；泡泡文字 ≥ 36px（手機）／30px（網頁）。
- 位置：不蓋網站內容、不與其他元素重疊；網頁版滿版放不下時，優先保留比比尺寸，縮小網站框（不低於 92% 寬）並在回報註明。
- 同一鏡最多一個泡泡＋一個道具，避免畫面雜亂。

## 驗收
- 回報附「素材使用表」：每段用了哪些素材、共幾種、有無連續重複。
- 重疊、點擊、裁切、焦點框、泡泡尾巴檢查全部 0 筆。
