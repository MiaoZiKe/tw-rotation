## 2. 點擊特效精準規格（新，錄影端與剪輯端都要照做）

### 2-1 錄影端（capture.py 的 `record_target` 改版要求）
1. 每次點擊前：`el.scrollIntoViewIfNeeded()` → 等版面穩定（連續 2 個 `requestAnimationFrame` 外框不變，而且該元素的 CSS transition 都結束）→ `r = el.getBoundingClientRect()`。
2. 滑鼠／手指一律點在 `(r.left + r.width/2, r.top + r.height/2)`，不准用 `click_xy` 加比例偏移（舊 V27 的 `#sgo34` 偏 129、I01 的 canvas 偏 514 就是這樣來的）。
3. 同一刻寫入 `click_targets.json`：`t`（以影片第 0 格對齊）、`selector`、`css_rect`、`css_point`、`dpr`、`scrollX/scrollY`、`visualViewport.offsetLeft/offsetTop/scale`；點擊後 300ms 再量一次外框，位移 >2 CSS px 就標 `moving:true`（剪輯端用點擊那一刻的外框）。
4. 目標是 canvas 或整張 SVG 時（題材熱力圖方塊、剖析圖環節），**目標＝邏輯子元素**：ECharts 方塊用版面算出的方塊外框（capture.py 的 `tm_center` 同法），SVG 用 `[data-seg]` 群組的 `getBoundingClientRect()`，寫進 `block_css_rect`；漣漪中心＝這個外框中心。
5. 滑過（hover）與拖曳也記：hover 記 `kind:"hover"`＋外框；拖曳記 `kind:"drag"`＋pointerdown 點＋每 16ms 的 pointermove 點，剪輯端照實際軌跡畫，不准補間估。

### 2-2 剪輯端
1. 特效中心（漣漪圓心、手指游標的指尖熱點、比比腳底中心 x）＝ `css_point × dpr`（canvas／SVG 用 `block_css_rect` 中心 × dpr）→ 套用**點擊那一幀**的鏡頭轉換（裁切起點、推近倍率、平移量、網站框位置）→ 成片座標。分鏡表上的數字只是參考，**不准拿來畫**。
2. 手指游標圖要標熱點（指尖）座標，對齊的是熱點，不是圖片中心。
3. 漣漪：直徑 28→64px、0.45 秒擴散淡出；中心 6px 實心點停 0.2 秒；從點擊那一格前 1 格開始。滑過：游標＋淡色外圈（直徑 48px）停到下一個動作。
4. 驗證（交件必附）：程式對每一個點擊／滑過輸出 `click_precision.md`，一行一筆「鏡號｜選擇器｜DOM 中心換算座標｜實際畫的中心｜距離」，**距離 ≤6px（成片像素；網頁 1920×1080 與手機 1080×1920 都以成片像素算）**，超過一筆就不出片；另外人工把每一個點擊那一格放大 2 倍目視，回報寫「點擊精準：程式 N 點 0 筆超過 6px；人工 N 點看過」。
5. 點了要有變化：點擊後 1.5 秒內畫面必須真的換（分頁變亮、清單換、圖表動），不然那一下不放。

## 3. 比比表情動作規則（新）

1. **每鏡兩拍**：說話拍（`talk_happy`／`talk_excited` 或配合道具的動作）→ 反應拍（`face_*`），反應拍在畫面變化（點擊結果出現）後 0.3 秒內切換，表情要跟畫面意思對得上：看到新東西＝`face_curious`、出現大數字或重要日子＝`wow`／`face_shock`、想通了＝`face_thinking_bulb`、喜歡＝`face_love`、完成＝`face_proud`。
2. **臉朝重點**：重點在比比右邊就用原圖、在左邊就左右翻轉素材（翻轉不改造型）；點擊前 0.3 秒先轉頭看按鈕。
3. **換段一定有移動動作**：`hop_l`／`hop_r`／`slide_l`／`slide_r`／`peek_l`／`peek_r` 擇一，不准原地切換。
4. **同一表情不連續超過 2 段**（第 8 節矩陣證明）；同一頁內相鄰兩鏡不用同一個「素材＋表情」組合。
5. **四腳原則禁用素材**（有前掌、舉手、握拳或 v4 C 節已換掉的）：`wave`、`talk_explain`、`face_think`、`face_determined`、`face_clap`、`face_thumbs`、`face_shy`、`magic_frame`、`pointer_l`、`pointer_r`、`point_r`、`point_ur`、`point_dr`、`face_sweat`（抓抓頭）、`intro`（揮掌，改用 `intro_blank`）。要指方向一律用鼻尖朝向＋虛線箭頭（v5 做法）。
6. 第 14 段比比主持人跳進客服鈕、由網站上的比比本人演出（避免畫面同時出現兩隻比比），該段表情由網站素材 `ball_catch`、`eat_q`、`pet_q`、`hop_reach` 負責，不另疊主持人。
