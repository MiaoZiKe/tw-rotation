# 產業鏈頁下半部重構：關聯圖改成 Obsidian 式、拿掉重複的區塊

> Andy 2026-09-23 交辦四件事（原話節錄）：
> 1. 「我看到『環節清單』與『關聯圖』長得很像，先幫我確認是否重複，如果是只保留一個」
> 2. 「圖一紅框處這兩個拿掉，然後以後圖二下方的族群的關聯圖改成圖三那樣的形式，像 Obsidian 關聯圖那樣展開，
>    並且新增幾種風格我要看看（科技、電路、星際、泡泡），且置中，會依據當前螢幕大小調整比例，
>    另外它 Default 只顯示族群名稱，且下面是標籤式列出個股，直到點擊才是個股清單，並且旁邊會附註關聯圖」
> 3. 「圖四族群卡片幫我移除，漲跌幅 & 占比等基本資訊可以放在上方關聯圖顯示」
>    ＋「這點整個確認，**所有介紹資訊需附上連結**」
> 4. 「圖五下方成分股清單可以暫時覆蓋旁邊事件頁面」

## 〇、先回答第 1 題：重複嗎？**是同一份資料的兩種畫法，但不是同時出現**

機器查到的事實（`site/industry.js`）：

| | DOM | 現在怎麼出現 |
|---|---|---|
| 環節清單 | `#chainList`（`.seglist`） | 預設顯示 |
| 關聯圖 | `#chainMap`（`.chainmap`） | `hidden`，按 `#chainView`（「看關聯圖 →」）才切出來 |

- 第 1168 行的註解自己寫著：**「環節卡清單跟關聯圖是同一份資料的兩種畫法，所以高亮規則也要同一套」**。
- 第 537–538 行寫了當初為什麼留兩個：
  「清單＝這條鏈有哪些格、每格有誰（預設，因為高度只有關聯圖的三分之一）；
   關聯圖＝誰連到誰、線多粗（140 條邊本身，只有圖畫得出來）」。

**結論**：資料同一份、兩個畫面互斥（同一顆按鈕切換），所以**畫面上不重複**，但**維護上重複**（同一份資料兩套繪圖、兩套高亮）。
第 2 題的新關聯圖既要顯示族群名稱、又要標籤式列個股 —— **那正是清單在做的事**。
所以：**留關聯圖、移除環節清單**（`#chainList` 與 `#chainView` 切換鈕一起拿掉）。

**改掉的斷言要逐條寫理由，不准直接刪掉整段。** 被它們承載的功能（環節篩選、跨鏈對照、族群篩選）
**要在新關聯圖裡找到新家**，不可以連功能一起消失。

## 二、新的關聯圖（力導向，Obsidian 式）
- **預設只顯示族群名稱**：一個族群＝一個節點，半徑依「占本鏈成交值」，顏色＝族群色。
- **節點上直接顯示基本資訊**：族群名 ＋ 今日漲跌幅（紅漲綠跌）＋ 占比。這是第 3 題要的。
- **下面是標籤式個股**：節點底下用小標籤列出成分股代號（最多 N 個，多的收成 `+12`）。
- **點一下節點才展開成個股清單**（節點展開成子節點，或右側面板出個股清單 —— 兩種都要試，截圖給 Andy 挑）。
- **旁邊附註關聯圖**：選起來的節點旁顯示「它連到誰、為什麼」的小卡（沿用現在 `產業關係面板` 的內容）。
- **置中**、**依螢幕大小調整比例**（`ResizeObserver` 重算佈局與縮放，不是固定 viewBox）。
- 互動：拖曳節點、滾輪縮放、雙擊回到置中、點背景取消選取（跟剖析圖同一套手勢語言）。

### 四種風格（**第一個交付就是這四張截圖，給 Andy 挑**）
| 風格 | 長相 |
|---|---|
| **科技** | 深底、節點是帶邊框的圓角方塊、連線細直線帶發光端點、等寬字 |
| **電路** | 連線走直角折線（像 PCB 走線）、節點是方形焊盤、轉角有圓點、金屬色 |
| **星際** | 深藍黑底、節點是發光星球（大小差距拉大）、連線是淡淡的星塵、有輕微的漂浮感 |
| **泡泡** | 淺底、節點是半透明彩色泡泡、有柔和陰影與高光、連線是細柔曲線 |
四種共用同一份佈局與互動，**只換視覺**（走 `--dg-*` 風格的 token，深淺兩主題都要成立）。

## 三、所有介紹資訊都要附連結（Andy 特別強調）
畫面上每一段「介紹／說明」文字，只要講到**可以連過去的東西**，就要是連結：
- 族群 → 族群頁；個股 → 個股頁；環節 → 該環節的剖析圖；產業鏈 → 該鏈頁。
- 外部資料來源（媒體、公司法說會）→ 附原始網址。
- 查不到、沒有對應的，照舊明講「查不到」，**不要放一個死連結**。

## 四、成分股可以覆蓋事件面板
`#memberTable` 那一區在需要時可以往右延伸、蓋住右側「今日事件」面板（Andy：「可以暫時覆蓋」）。
做法：成分股區加一顆「放寬」鈕或捲到它時自動加寬；事件面板不是被刪掉，是被蓋住，關掉就回來。

## 五、驗收（新段落 `批次25-關聯圖`）
1. 四種風格各切一次，節點／連線／底色真的變（量 computed style，不是只看 class）。
2. 預設只顯示族群名稱與標籤式個股；點節點才出現個股清單。
3. 節點上有漲跌幅與占比，紅漲綠跌方向正確。
4. 置中：容器中心與圖的外接盒中心差 ≤ 容器寬的 2%；改變視窗寬度後仍然成立（1440／1100／800／390）。
5. 拖曳節點真的移動、滾輪真的縮放、點背景真的取消選取。
6. **所有「介紹資訊」裡該有連結的都有**：逐條檢查族群名、個股代號、環節名是不是 `<a>` 且 href 正確。
7. 被拿掉的四塊確實不在 DOM 裡，而它們承載的功能在新圖裡找得到對應操作。
8. 成分股覆蓋事件面板：開啟後成分股寬度變大、事件面板被蓋住；關掉回復。

## 二、切換不要跳回頁首
- **根因（已定位）**：`site/app.js` 第 655 行 `window.scrollTo({ top: 0 })` —— 路由每換一次就捲到頁首。
  切圖別會改 `location.hash`（`#industry/<chain>/dg/<slot>`）→ 觸發路由 → 整頁捲到最上面。
- 修法：路由捲頁首改成**有條件**：
  - **同一頁內的切換**（同一條鏈換圖別、換族群、換關聯圖的中心節點）→ **保留捲動位置**。
  - 換到不同的頁（`#overview`／`#flow`／`#stock/...`／換一條鏈）→ 照舊捲到頁首。
  - 判斷方式：比對前後 hash 的「頁面部分」（第一段 ＋ 鏈 id），一樣就不捲。
- ⚠ `industry.js` 第 522 行「按目前這條鏈自己 → `window.scrollTo({top:0})`」是**刻意**的（按自己＝我要回頁首），保留。
- 相關的既有坑：第 1115 行註解記過「個股頁被 `scrollIntoView` 拉到底」，改的時候不要把那個修法弄壞。

# 第四版（Andy 2026-09-23）：只留星際與泡泡，兩種都要更生動，圓圈大小跟市占走

> 原話：「**保留星際及泡泡**，並且**星際及泡泡效果需要效果加強、更生動豐富點**，
> **圓圈大小會因為市占影響**。麻煩接續做到結束。」

## 一、風格從四種收成兩種
- **留下**：`01 星際`、`03 泡泡`。**移除**：`02 科技`、`04 電子電路`（連同它們的 token、CSS、切換選項一起清掉，
  不要留成註解掉的死碼）。舊 `localStorage` 存到 `科技`／`電子電路` 的值 → **fallback 到星際**。
- 切換鈕從四選一變兩選一（星際 ↔ 泡泡）。
- 兩種都要在深／淺主題成立（泡泡是亮底風格，深色主題下字要跟著換）。

## 二、圓圈大小＝市占（這是硬規則，要寫成斷言）
- 族群大圓點的**半徑對應「占本鏈成交值」**（`turnover_share`）。
- 用**面積**成比例、不是直徑（直徑成比例會讓大的看起來誇張到失真）：`r = rMin + (rMax - rMin) * sqrt(share / shareMax)`。
- `rMin`／`rMax` 依畫布大小算，讓最小的仍然看得到名稱、最大的不壓到鄰居。
- **驗收**：取占比最大與最小的兩個族群，`r_max / r_min` 要落在 `sqrt(share_max/share_min)` 的 ±15% 內；
  而且**所有大圓點的半徑排序＝占比排序**（不准有大小顛倒）。

## 三、星際：加強成什麼樣
- **星球本體**：內核亮、外圈有光暈（多層徑向漸層），占比越大光暈越厚。
- **背景**：多層星空（遠景細星點、近景大星點），**視差** —— 拖曳或縮放時遠近層移動速度不同。
- **連線**：不是直線，是**帶流動粒子的星塵軌跡**（沿線移動的小亮點，方向＝上游→下游）。
- **選中的節點**：外圈加一圈緩慢旋轉的光環。
- **hover 族群**：該族群的個股小點像衛星一樣**繞著大點緩慢公轉**（半徑不變、只轉角度），名稱標籤跟著浮出。
- 動態一律**可停**：`動畫：關` 與 `prefers-reduced-motion` 時全部靜止（跟 3D 的 E4 同一個規矩）。

## 四、泡泡：加強成什麼樣
- **泡泡本體**：半透明彩色球 ＋ **高光點**（左上角小白點）＋ 邊緣一圈薄的折射亮邊，底下有柔和陰影。
- **輕微呼吸**：泡泡上下緩慢浮動（振幅 ≤ 3px、週期各自不同，不要整齊劃一）。
- **hover**：泡泡微微放大並「彈」一下（ease-out-back），個股小泡泡從大泡泡裡**散開**、名稱浮出。
- **連線**：細柔曲線（二次貝茲），顏色取兩端泡泡的混色。
- **背景**：淺藍白漸層 ＋ 幾顆很淡的大泡泡當裝飾（不干擾閱讀）。
- 一樣**可停**。

## 五、效能上限（加強不能把頁面拖垮）
- 粒子／星點總數 ≤ 400；`動畫：關` 時**完全不 rAF**（照 DECISIONS #245 的按需渲染精神）。
- 靜止時不重繪；只有 hover／拖曳／縮放／動畫開著才畫。
- 1440 下每幀 ≤ 8ms（量 `performance.now()` 的中位數，寫進回報）。

## 六、驗收（併進 `批次25-關聯圖`）
22. 只剩兩種風格：切換鈕只有星際／泡泡；DOM／CSS 裡沒有 `科技`／`電子電路` 的殘留 token。
23. 舊 `localStorage` 值（科技／電子電路）→ 進來是星際，而且值被改寫成 `star`。
24. **半徑＝市占**：半徑排序＝占比排序（全部族群）；`r_max/r_min` 在 `sqrt(share_max/share_min)` 的 ±15% 內。
25. 星際：連線上的流動粒子真的在動（兩次取樣座標不同）；`動畫：關` 之後**完全停住**（座標一致）。
26. 泡泡：hover 大泡泡 → 半徑真的變大、個股小泡泡真的散開（座標位移 > 0）；移開回復。
27. 兩種風格 × 深／淺 × 四個寬度：撐滿 ≥ 80%、置中誤差 ≤ 2%、0 節點被切掉、字 ≥ 11px。
