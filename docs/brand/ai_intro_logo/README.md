# 頻道③「AI 介紹頻道」LOGO 第一輪：八個方向（2026-11-03，美編）

Andy 原話：「需要符合科技透明圈那樣有 LOGO 意義」。做法照頻道②：每個圖形都有一句「形狀代表什麼」。
定位：上班族的 AI 實戰，只寫親手做過、附證據、包含翻車（真實測、透明、可驗證）。
全部座標格向量（`src/build.py` 產生），無 AI 生圖、無吉祥物、圖示內無文字，帳號名（候選「小事交給 AI」「AI 上班日記」）可隨時換。
色票取自版型 A：底 #0F1722、綠 #6FD8A0、琥珀 #FFC857；淺底版改深綠 #1E9E6A、深琥珀 #E39A00 以免糊掉。

## 檔案
- `overview.png`：八個方向，深／淺底大圖、IG 圓形 110／40px 實際像素、名稱與意義。
- 各資料夾：`icon_dark/light.svg`＋`_1024.png`、`mark_transparent.svg`（無底）、`circle110_dark.png`、`cover_A.png`（版型 A 封面，LOGO 放左上、系列標右側）。
- 重繪：`cd src && python3 build.py && python3 render.py && node shot.js`。

## 八個方向（形狀意義）
| # | 名稱 | 形狀代表什麼 |
|---|---|---|
| 1 | 終端游標 | 綠色「>」加琥珀游標方塊：每個做法都是親手在終端機跑過的 |
| 2 | 勾與叉並陳 | 綠勾與琥珀叉兩塊同大：成功與翻車同樣大方攤開，就是「透明」 |
| 3 | 實測刻度 | 半圓量表加指針：用數字量過才下結論 |
| 4 | 疊層證據 | 三層視窗疊起：每個結論背後都有一疊截圖可查 |
| 5 | 日誌行 | 綠色行列夾一行琥珀：上班日記，翻車那行也照記 |
| 6 | 前後對照柱 | 矮灰柱對高綠柱同一基準線：用前後對比說話 |
| 7 | 放大驗證 | 放大鏡裡一個綠勾：可驗證，你能自己再做一次 |
| 8 | 實驗矩陣 | 3×3 格，綠成功、空框沒做出來、琥珀翻車：一格一次實測 |

## 推薦
1. **2 勾與叉並陳**（已複製為 `site/channels/logos/ai_intro.svg`）：唯一把「包含翻車」這個差異化賣點直接畫出來；綠與琥珀就是版型 A 的兩個標註色，LOGO 和貼文天然一致；110px 與 40px 都清楚（兩塊大色塊）。弱點：勾叉像「通過／失敗」通用圖示，個性靠配色與並排。
2. **1 終端游標**：「實測終端」版型的直接呼應，形狀最簡、40px 最清楚、和頻道①（暖圓）②（開口圈）最容易分；弱點：像一般程式／終端圖示，「翻車」意涵靠琥珀色暗示，較含蓄。
3. **7 放大驗證**：「可驗證」意象最直白，大眾一看懂；弱點：放大鏡＋勾是常見圖示，40px 勾變細。
- 較不推薦：8（40px 變雜點）、4（40px 糊成一團）、3（細刻度 40px 消失）、5（小尺寸像「選單」圖示）、6（像股票長條圖，容易和財經頻道混淆）。
