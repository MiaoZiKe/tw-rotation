## 受歡迎 LOGO 的 5 條共通點（WebSearch 查證 Airbnb、Spotify、Duolingo 與通則文章）
1. 一個簡單形狀：Spotify 三道弧線、Airbnb 單一符號；簡單才好記。
2. 一個意義：形狀要連到產品在做什麼（Airbnb 的家與地點）。
3. 角色或溫度：Duolingo 的貓頭鷹靠親切與情緒被記住。
4. 小尺寸可辨：通則文章建議測 16px 與黑白版，細節與漸層多會糊掉。
5. 一個主色加完整橫式、直式版本：靠顏色與固定版型累積辨識。
（查到的是文章摘要，LINE、Robinhood 等沒查到可引用內容，未列入。）
