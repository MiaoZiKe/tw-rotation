# 哩股哩股 LOGO 第六輪（F01～F10，2026-11-02，設計總監）

Andy：「再給我更多風格看看，20 個」。另一位同事做另外 10 種，本輪為 F01～F10，每種 1 套主配色。全部 SVG（`svg/`），文字轉字型輪廓（不加粗、不變形），Playwright 輸出 PNG。不用吉祥物、不用 AI 生圖。字型皆 OFL（`fonts/`）。

1. **F05 極光漸層**：最貼「陽光糖果」親和感，40px 仍亮眼，適合 Threads／IG 頭像。

3. **F07 家紋**：最有辨識度與質感，40px 最穩，與前幾輪完全不同。
