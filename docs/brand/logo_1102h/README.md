# 哩股哩股 LIGU 字標 第八輪（2026-11-02，設計總監）

Andy：「設計 LIGU 這四個字的 LOGO 風格，Li 有設計到，但 GU 沒有」。本輪 10 種都是完整 L-I-G-U 四個字母。總覽：`overview.png`（橫式 A淺／A深／B淺／B深＋方形 A／B＋IG 110／40 實際像素）、`overview_wordmarks.png`（橫式大圖）。

配色 A＝陽光糖果（#FFF7E8／#1F2A44／橘 #E8590C／藍 #2B6BF3／紫 #7B4FE0／青 #0A8CA3）；B＝墨夜金紅（深墨藍 #0E1A36＋漲紅 #D7263D＋金 #E39B00＋跌綠 #0E8F7E，財經專業向）。

字型皆 SIL OFL 1.1（`fonts/` 附授權）；字型輪廓只做縮放，不描邊加粗。自繪字母為統一筆寬的圓頭向量筆畫。檔案：`H0X_<A|B>_<light|dark>.png` 橫式、`_icon512／_ig400／_ig110／_ig40.png`、`svg/`；`python3 src/build.py && python3 src/overview.py` 重產。

## 40px 檢視
H01、H05、H10、H02 最清楚；H09 圖示（G＋箭頭）在 40px 變糊、H07 靠色塊辨識。

## 推薦
1. **H01 幾何字標（配色 B 或 A）**：四字統一、有自己的字形，i 點與圖示 G 落點呼應，最像自訂品牌字標，40px 仍清楚。
2. **H02 輪動圓 G**：一個 G 就講完「資金輪動」，圖示最強，字標乾淨。
3. **H05 粗體＋G 換色**：最穩、最專業有力，適合搭配 B 配色做財經調性。
