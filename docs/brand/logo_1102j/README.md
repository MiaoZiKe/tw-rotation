# 哩股哩股 LIGU LOGO 第十輪（2026-11-02，設計美編）

Andy：「其他的風格有些跟我的題材都跑偏了……依據我的主題重新給其他風格」。本輪放掉太空、紙飛機、家紋、花磚等無關風格，12 款**每一款都能對應到產品主題**。總覽：`overview.png`（每款一列：方形、IG 110px、40px、橫式；皆實際像素，左欄寫對應主題）。

配色：陽光糖果單一主配色（底 #FFF7E8、墨藍 #1F2A44、橘 #E8590C、藍 #2B6BF3、紫 #7B4FE0、青 #0A8CA3）；紅 #D62839／綠 #0B8F4D 只用在漲跌（J04、J10、J12 的 K 棒）。深底款使用同色相提亮版。不用吉祥物；字型：Noto Sans TC Black（哩股哩股）、Poppins ExtraBold（LIGU LIGU、J12 的「3」），皆 OFL，附 `fonts/`。

## 40px 檢視（已用實際像素與 3 倍放大看過）
清楚：J02、J04、J05、J08、J10、J11、J12。可辨但偏小：J06、J07。較弱：J01（色塊小）、J03（淺底上的淡色格）、J09（細環與光點，40px 變成一團暗圓）。

## 推薦 3
1. **J02 輪動時鐘**：最直接講「錢現在在哪個族群」，色環＋指針辨識度高，110／40px 都穩，深底與品牌色搭得好。
2. **J05 ETF 堆疊硬幣**：存股、配息、逐年累積一眼懂，輪廓清楚，40px 仍讀得出階梯；暖橘最「親切」。
3. **J04 K 線＋量柱 L**：台股味最濃（紅 K、量柱），同時藏著字母 L；淺底、40px 都清楚。
