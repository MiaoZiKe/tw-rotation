# 科技透明圈 LOGO 第一輪：八個風格（2026-11-02，美編）

Andy 原話：「頻道二名稱就叫科技透明圈，並設計一個 LOGO，LOGO 簡約休閒風格，需要大家都喜歡」「多給幾個風格我看看」。
不用吉祥物；與「哩股哩股」明顯區隔（哩股走暖橘、糖果、粗黑字；這裡走冷色、留白、柔和）。

## 總覽圖
- `overview.png`：八個方向，每個有方形圖示（淺／深）＋IG 圓形 110／40px 實際像素（上淺下深，不放大）。
- `overview_detail.png`：八個方向各自的橫式 LOGO（淺／深）＋Threads 個人頁頂端模擬（淺／深，簡介為「科技業的薪水、面試、製程，用真實經驗講白話」，帳號 `tech.transparent` 只是示意）。
- 每個方向的資料夾：`icon_light/dark.png|svg`（1024，svg 為 512 向量，含文字者的 svg 需要字型）、`circle110_*.png`、`circle40_*.png`（真實像素）、`horizontal_*.png`、`profile_*.png`。

## 八個方向（一句理念）
| # | 名稱 | 理念 | 字標字型 |
|---|---|---|---|
| 1 | 開口圈 | 一條開口圓環＝「圈」，缺口那顆暖色小點是「進來的你」 | Noto Sans TC 700 |
| 2 | 對話圈 | 圓形對話泡泡，中間挖空心圈：同業交流、坦白透明 | 粉圓 Huninn |
| 3 | 透明疊圓 | 三個半透明圓疊出新顏色：「透明」的字面意思，也是圈子重疊 | M PLUS Rounded 1c 700 |
| 4 | 柔光球 | 柔和漸層玻璃珠，像 App 圖示一樣想點 | Zen Maru Gothic 700 |
| 5 | 手寫圈 | 螢光筆隨手畫圈、圈住「透」：像朋友在筆記上畫重點 | 霞鶩文楷 TC 700 |
| 6 | 積木圓 | 圓、四分之一圓、半圓、圓角方塊的積木：知識一塊塊拼起來 | Noto Sans TC 900 |
| 7 | 單字標 | 小寫 tc＋薄荷句點，黑白極簡（Notion 式） | Noto Sans TC 700 |
| 8 | 點陣圈 | 十二顆圓點排成一圈、一顆暖色亮著：晶片接腳的休閒版 | Noto Sans TC 500 |

## 推薦
1. **首選 3「透明疊圓」**：唯一把「透明」直接畫出來的；三個柔和色疊在一起親切、有「圈子」感，淺深底都好看，和哩股（單色塊）一眼分得開。弱點：40px 時三色變成小色塊，辨識靠整體配色而非形狀。
2. **次選 1「開口圈」**：最簡約、40px 最清楚、最像專業品牌；弱點是有點像「重新整理／載入」圖示。
3. 第三 2「對話圈」：同業交流意象最直白，40px 也清楚。
- 較不推薦：8（40px 變成雜點）、4（泛用、像 App 預設圖示）、5（有個性但「透」字單獨看不出品牌名）、7（tc 英文縮寫對中文帳號辨識低）。
