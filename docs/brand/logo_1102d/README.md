# 哩股哩股 LOGO 第四輪（2026-11-02，設計美編）

Andy 評語：「都需要重新設計，有點太簡單，並且配色要再給我多點選擇」。本輪 6 個新概念 × 4 套配色 = 24 組，加入漸層、層次、立體與負空間。字型用正式 Noto Sans TC 900／Inter（未變形）。AI 生圖無額度，全部為 SVG 向量（`svg/`），Playwright 輸出 PNG。

總覽：`overview.png`（矩陣＋110／40px 實際像素）、`overview_detail.png`（橫式字標＋Threads 個人頁）。

## 6 個概念
| 代號 | 名稱 | 理念 |
|---|---|---|
| C1 | 流動 L | L 的腳留出空隙後流成向右上的資金趨勢線，下方帶漸層面積 |
| C2 | 輪動環 L | 兩個 L 旋轉 180° 互相咬合＝LIGU LIGU 重複與輪動，中心一點是 i 點／資金落點 |
| C3 | 缺口圓餅 L | 甜甜圈圓餅被切出 L 形縫隙，抽離的扇區是熱點，縫隙轉角指向中心資金池 |
| C4 | 三層資金流 L | 三道同心圓角 L 逐層縮短，像資金層層輪動／成長年輪 |
| C5 | 哩字口＝圓餅 | 「哩」＝口＋里，口換成缺口圓餅，「里」為 Noto Sans TC Black 原字 |

## 推薦
1. **C2 輪動環 L ＋ P3 紫藍漸層**：最有記憶點、最不像一般財經 App；兩個 L 咬合直接對應 LIGU LIGU，40px 輪廓仍清楚。
2. **C6 摺紙 Li 軌道球 ＋ P3**：延續 Andy 說很棒的 Li 上揚，加立體與軌道球（資金熱點），最有做工。
3. **C3 缺口圓餅 L ＋ P4 深色**：最直接結合輪動圓餅；深底上紅色熱點扇區最醒目。
