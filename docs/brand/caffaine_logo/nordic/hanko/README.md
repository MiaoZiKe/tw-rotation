# 像素印章 10 變體（以「03 像素印章」為核心）

> Andy：「這個幫我修改，多點不同風格」。全部手寫 SVG（`src/hanko_marks.js`），沒有 AI 生圖、沒有角色、沒有藍色。
> 重新產出：`cd ../src && HANKO=1 node build.js && node hoverview.js`

## 避開 Adobe 系圖示的原則

美術總監指出：原版是「圓角方塊＋實心亮紅＋白字」，很像 Illustrator 那類「Ai」圖示。10 個變體裡，這三點**沒有一個同時出現**：
- 外形：直式長印、橢圓、手刻不規則邊、直角雙框、蓋歪的框印、直角粗框、像素階梯角、八角切角、郵票齒孔、一對章。
- 顏色：印泥紅一律降飽和（#A6～#B5），另有焦糖橘、深可可、深抹茶（偏橄欖）、墨黑單色、紅＋可可雙色。
- 質感：印泥暈染（01、08、10）、印泥不均（05）、紙紋（04、06）、手刻抖動＋刻痕（03），另有乾淨扁平的對照組（02）。
- 文字標也不再用「紅膠囊＋白字」：改成落款小印（01）、像素 AI（03、06、07）、小印框嵌在名字裡（05、10），其餘用換色或底線。

## 推薦前 3

1. **05 歪印雙色**：離 Adobe 最遠（只有框線、不是實心、還蓋歪），紅色 AI 加可可色杯子，主次分明；手作小店的溫度最強，文字標裡的 AI 小印框也最醒目。
2. **07 八位元衝框**：最有創意也最有科技感，像素蒸氣衝出印框，有「新知滿出來」的故事；焦糖色加可可色，沒有紅色，跟兩個姊妹頻道都分得開。
3. **01 落款長印**：日系味最正（畫作落款），直式長印一看就跟 App 圖示不同；文字標右上角的落款小印很有巧思，大頭貼 110／40px 都讀得出 AI。

備選：04 抹茶雙框（最沉穩、最「選物店」）、02 橢圓細像素（最乾淨，印刷最省事）。

## 重疊檢查

程式在瀏覽器裡量「圖形／文字標／標語」的外框（文字用字身框量，比實際筆畫保守；圖形多留 6px），兩兩算最短距離，結果在 `overlap_report.json`。
共 40 張（10 變體 × 橫式深淺、外帶杯、IG）：**重疊 0 筆、間距小於 24px 0 筆、超出畫布 0 筆**。最小間距：橫式 30px，情境 40～60px。

## 注意

- 質感是用 SVG 濾鏡做的（feTurbulence），在瀏覽器與 PNG 看起來都一致；正式交給印刷廠前，建議把質感點陣化或轉成外框。
- SVG 裡的文字用的是系統字體名稱，以 PNG 為準。
