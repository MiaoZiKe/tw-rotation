# CaffAIne LOGO：日系、北歐、溫暖線畫 8 方向

> 標語：一杯咖啡的時間，看懂一個 AI 新知
> 全部手寫 SVG（`src/marks.js`），沒有 AI 生圖、沒有角色；字體只用容器內建（Inter／Inter Display、Bitstream Charter、Caladea、JetBrains Mono、文泉驛正黑）。
> 重新產出：`cd src && node build.js && node overview.js`

## 設計理念

1. **形狀本身要講出含義**：8 個方向都讓「咖啡的一個部件」同時是「AI 的一個符號」，例如蒸氣寫成 AI、杯套上的 I 是輸入游標、暖簾是長條圖。
2. **AI 在名稱裡一定最顯眼**：文字標一律是「Caff＋**AI**＋ne」，AI 換主色與更粗字重，有些方向再加膠囊底或底線。
3. **大寫 I 不會被讀成小寫 l**：無襯線字體（Inter 系列）一律補上下橫筆；Charter、Caladea、JetBrains Mono 本身的 I 就有襯線。圖形裡的 I 也都有上下橫筆，或者畫成文字游標（I-beam）。
4. **溫和、休閒**：米色、燕麥色、焦糖色、陶土色、朱色，筆畫一律圓頭圓角。
5. **和姊妹頻道一眼可分**：不用藍色，不用完整圓環（科技透明圈）；不用糖果高彩度（哩股哩股）；也避開綠色圓徽章、美人魚、四角星、「Ai」方塊。

## 推薦前 3

1. **01 蒸氣寫字**：「AI」在圖形和文字裡都是主角，Andy 第一條要求最直接；線畫溫和，節點點出科技感，110px 大頭貼仍讀得到 AI。
2. **04 游標杯套**：用輸入游標來畫 I，一舉解決「I 被讀成 l」的問題，而且是科技人一眼就懂的符號；外帶杯符合「休閒、喝咖啡」，杯身應用最自然。
3. **03 像素印章**：40px 也最清楚（實心方塊＋朱色），日系選物店的味道最濃，像素字帶出科技感；可以直接當貼文角標蓋章。

## 重疊檢查

`src/build.js` 在瀏覽器裡排版後，逐張量測「圖形／文字標／標語」（封面另加標題區）的外框，再兩兩算最短距離。文字用字身框量，比實際筆畫保守；圖形外框另外多留 4～6px。結果在 `overlap_report.json`。
- 共 40 張（8 方向 × 橫式深淺 2 張＋應用情境 3 張）：**重疊 0 筆、間距小於 24px 的 0 筆、超出畫布 0 筆**。
- 最小間距：橫式 30px（文字標與標語之間）；應用情境 34～60px。

## 注意

- 橫式與應用情境的 SVG 用的是系統字體名稱；在沒有這些字體的電腦開 SVG 會換成替代字體，以 PNG 為準。正式定稿時再把文字轉成外框。
- 標語裡的「AI」是文泉驛正黑的無襯線字體，因為只是內文字級，所以沒有另外補 I 的橫筆。
