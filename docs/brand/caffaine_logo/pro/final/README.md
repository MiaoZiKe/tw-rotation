## 重疊檢查

做法：每個元素單獨渲染成一張圖層，量出真實墨水邊界，再兩兩算間距（`src/overlap.py`，結果在 `src/overlap_report.json`）。

- 共 20 張構圖、204 組元素。
- 圖形、文字標、標語三者之間最小 35px；所有元素之間最小 33px。
- **不合格 0 組**（標準 ≥ 24px）。

人工全解析度看過的有：`final_compare.png`（分上下兩半看）、F3 橫式版、F3 的 IG 名稱放大圖（確認點陣 A 讀得出是 A）、三個方向的 40px 大頭貼（放大 3 倍看）。

## 注意

SVG 裡的文字是用字體名稱指定的（Inter、Inter Display、JetBrains Mono、文泉驛正黑）。送印或交給外包之前，要先把文字轉成外框。

重新產出：在 `src` 資料夾執行 `CF_LAYERS=<暫存資料夾> node build.js && python3 overlap.py <暫存資料夾> && node compare.js`
