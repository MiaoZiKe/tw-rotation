# 哩股哩股 LOGO 第四輪：八種風格 × 八組色調（2026-11-04，美編）

Andy 原話：「LOGO 再多給我幾個不同的風格 並且 色調也是」。延續他選的 C1「雙 L 對扣」＋小寫 i，換筆法、換色調。
全部向量，圖示檔不含文字；橫式字用 Noto Sans TC（SIL OFL 1.1）；不用 AI 生圖、不用吉祥物。

## 推薦前三（風格＋色調）
1. **⑤ 字標連字 × C 深藍＋銅紅**：L 的腳長出 i，一眼就是「Li」，40px 仍清楚（粗字母剪影＋一顆點）；跟貼文 B 專業版同色，社群與頭像一套；也最像金融品牌字標。弱點：只剩單一 Li，「雙 L 對扣」的第二個 L 被拿掉。
2. **③ 圓潤軟糖 × B 柔和陶土**：保留雙 L 對扣但筆畫胖、圓角大，40px 比細線穩、不嚇人，柔和（呼應「不要太鮮豔」）；弱點：兩顆圓點讀成冒號多於 i，要靠旁邊的名字補。
3. **⑥ 徽章 × H 酒紅＋米白（或 C）**：圓章最適合頭像圓形裁切，細框線給專業感；弱點：章內符號縮小，40px 只剩方塊回字紋，i 看不出來。
- 其他：①單線與④精品在 110px 很好看，但 40px 線條太細（④更明顯），不建議當頭像；⑦負空間最有特色、40px 仍是塊狀 i，但 i 的切口形狀還要再修；⑧像素格子多、40px 偏雜。
