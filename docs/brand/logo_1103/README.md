# 哩股哩股 LOGO 第三輪：有寓意（2026-11-03，美編）

Andy 原話：「LOGO 需要像科技透明圈那樣會有寓意，圖片能解釋其他意思，我覺得很有深度很棒」。
做法：每款都是「一個圖、兩層意思」。不用吉祥物、不用 AI 生圖，全部向量＋真字型（Noto Sans TC，SIL OFL 1.1；「里」字轉成路徑，圖示檔不含文字）。
色票走頻道一「陽光糖果」暖色：主色橘 #F2762E（深底 #FF8F4A）、墨色 #3B2A20、奶油 #FFF4E2；與科技透明圈（冷色、留白）區隔。

## 八款與兩層寓意
| # | 名稱 | 第一層看到什麼 | 第二層是什麼意思 |
|---|---|---|---|
| C1 | 雙 L 對扣 | 兩個 L 風車式對扣成方框 | 哩（Li）＋哩（Li），你的股、我的股互扣；中間那格＝被選中的那檔股 |
| C2 | 飛走的一角 | 圓餅缺一角，那一角飛向右上 | 資金從這個族群跑去下一個（輪動） |
| C3 | 哩的螢幕 | 一台上揚線的小螢幕＋「里」 | 螢幕＝「哩」的口，也是看盤；合起來是「哩」 |
| C4 | 河道成 L | 一條河彎成字母 L，流進一顆圓 | L＝哩；河＝資金流，終點圓＝它流進的族群 |
| C5 | 岔路的點 | 一個點站在三岔路口，橘色那條最粗 | 錢在選族群；橘色＝資金最大宗流向 |
| C6 | 看懂的放大鏡 | 放大鏡裡有一塊圓餅 | 放大＝看懂；橘色那塊＝錢集中的族群 |
| C7 | K 棒哩字 | 兩根 K 棒 | 空心 K 棒＝口；田字實體＋影線＋底座＝里；合起來是「哩」 |
| C8 | 錢的入口 | 一枚硬幣掉進方框缺口 | 方框＝哩的口，也是資金入口；帶你看錢從哪個口進場 |

## 推薦前三
1. **C5 岔路的點**：最貼品牌核心「錢在選族群」，40px 仍清楚（Y 形剪影＋一顆橘點），橘色粗枝一眼是重點，淺深底都好；弱點是比較像「分支／樹」，要靠說明才讀到第二層。
2. **C2 飛走的一角**：「資金輪動」最直白，簡單、40px 最乾淨，像 IG 圖示；弱點是圓餅圖很常見，要靠飛走的那一角建立辨識。
3. **C4 河道成 L**：L 同時是「哩」的首字母與資金流，一筆就有兩層意思，剪影最獨特；弱點是 40px 時河中小點會糊掉（不影響剪影）。
- 較不推：C7（40px 變成雜點）、C3（40px 只剩「里」字，像里長）、C8（框太大、像背包／收納圖示）、C1（40px 變成方塊回字紋，第二層要解釋才懂；但 11-02 Andy 說 A「先預留」，若要延續 Li 上揚概念可再調）。
