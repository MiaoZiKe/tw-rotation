# 哩股哩股 LOGO 第七輪（G11～G20，2026-11-02，設計美編）

Andy 評語：「再給我更多風格看看，20 個」。另一位同事做 10 種（負空間、摺紙、像素、等角 3D、極光漸層、線稿、家紋、包浩斯、塗鴉、剪紙），本輪是另外 10 種，彼此不重複。每種 1 套主配色，全部 SVG 向量（`svg/`），Playwright 輸出 PNG。不用吉祥物、不使用 AI 生圖。

總覽：`overview.png`（10 種：方形、IG 110、IG 40、橫式縮圖）。

## 檔案
`G##_icon512.png`（圓角方形）、`G##_ig400／ig110／ig40.png`（圓形，實際像素）、`G##_horizontal.png`（1200×400，符號＋「哩股哩股」＋LIGU LIGU）。`src/`：`python3 src/build.py [11 12…]` 產圖、`python3 src/overview.py` 產總覽。字型與授權在 `fonts/`（全部 SIL OFL 1.1，可商用）。

## 備註與限制
- 紫、粉、金、鉻色是為了風格才用的延伸色，品牌主色（橘、藍、紫、青、墨藍、奶油）仍都在各案出現。
- G15、G18 的字用 Noto Sans TC Black 原輪廓；描邊、陰影、擠出都是另外疊的圖層，字型輪廓本身沒有加粗或變形。
- G14 的水彩由 SVG 濾鏡（feTurbulence）產生，輸出 PNG 穩定；若要給印刷廠請用 PNG 或請設計師重繪。
- 縮圖檢視：IG 圓形裁切後，G19 左側衛星、G15 最外圈燈泡接近邊緣但未被切到。

## 推薦
1. **G15 台灣老招牌**：與「哩股哩股」的台灣在地感最貼，辨識度與 40px 可讀性都最好，社群上很吸睛。
2. **G18 3D 立體擠出字**：單字「哩」在 40px 也一眼認得，色彩跟陽光糖果一致，最適合當頭像。
3. **G17 新粗野主義**：三根上升長條直接講「資金」，高彩粗框跟現有社群圖的陽光糖果調性最接近，也最好延伸成貼文版型。
