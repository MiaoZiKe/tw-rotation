## 40px 檢視
最好認：I10、I11（哩）、I05（U＋箭頭）、I01（Li）、I06（G＋曲線）；I03／I04 靠折線／階梯剪影辨識；I07、I08、I12 縮到 40px 偏小，建議頭像用 110 以上。

## 推薦
1. **I05 U 尾巴衝出箭頭**：同時有「連筆」「流入」「衝出上漲」，頭像 U＋箭頭 40px 最清楚。
2. **I01 兩段連筆（精修）**：忠於 Andy 喜歡的原案，新頭像 Li 好認。
3. **I11 粉圓中文＋LIGU 連鎖**：唯一把中文名與連筆線合在一起，橘底「哩」頭像在 40px 最醒目。
