## 推薦
1. K03 瑞士格線：最專業、2×2 在 40px 最清楚，紅 G＋▲ 記憶點強。
2. K10 圓餅四象限：最適合圓形頭像，圖形完整、和「資金輪動」直接對應。
3. K05 圓餅＋K 棒＋量柱：股票元素最豐富、最像專屬於台股站的識別。
