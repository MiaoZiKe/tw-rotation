## 二、結構：三組風格 × 淺深共六組變數，改成同一組色票

站上實際會用到的是 `hud`（科技，預設）與 `pro`（專業）兩種版面風格（`casual` 已從選項拿掉，theme4.css 裡的定義留著但選不到；為求一致也一併換了）。
圓角、字重、角框、格線、毛玻璃這些「風格」照舊，只有顏色換成 ⑤C。`site/theme5c.css` 的選擇器特異度與 `theme4.css` 主題變數段相同（0,3,0），靠載入順序蓋過，所以退版只要拿掉 `index.html` 那一行 `<link>`。

分工原則（「導覽藍、強調銅」）：

- **深藍**＝結構與文字：墨色、連結與焦點環（`--cyan`／`--focus`）、圖表主色。
- **銅紅**＝控制項與品牌：主要按鈕、選中的導覽列／分頁／膠囊（`--accent`、`--t4-accent*`）、HUD 的四角定位框。
- **不用銅紅的地方**：數字、漲跌、圖表資料列、焦點環、表格列 hover／選取（這些用藍系），避免被讀成「漲」。

## 三、台股漲跌色（紅漲綠跌）與銅紅怎麼分

| | 淺色 | 深色 |
|---|---|---|
| 漲 `--rise` | **沒動**（hud `#C4142F`／pro `#C00F2C`） | `#FF4D6D`／`#FF5470`／`#FF4F62` → **統一為 `#FF5E75`**，只拉亮明度（色相 349°→351°） |
| 跌 `--fall` | **沒動** | **沒動** |
| 平 `--flat`、熱力圖 `--hm-n*`／`--hm-p*` | **沒動** | **沒動**（只有無資料格 `--hm-0`／`--hm-na` 改成藍灰，不是漲跌色） |
| 銅紅 | `#A8482A` | `#D0643F`（字用 `#E58A67`） |
| 銅紅與漲色的色差 ΔE2000 | 11.5～13.8 | 15.5～19.4 |

調整的唯一一處：深色漲色微調明度。原因：新深藍底的 panel-3 比舊底亮，舊紅字落到 4.2:1（低於 AA 4.5），新值對 panel-3 為 4.57、對頁底 5.96。

**撞色的處理**：銅紅與紅漲在色相上相近（紅漲約 350°、銅紅約 14°），而且紅綠色盲下兩者幾乎一樣（模擬：紅色盲 ΔE 9.5、綠色盲 2.5）。所以不靠色差，靠「用途分離」：

1. 銅紅只用在控制項與品牌，不用在任何數字、漲跌標示、圖表資料列、表格選取列。
2. 圖表色盤（第四節）完全不含紅與銅紅色相。
3. 漲跌數字一律帶 ＋／－ 號與箭頭（既有規則），不靠顏色單獨傳達。

## 四、圖表多序列色盤（34 色重做）

`site/app.js` 的 `PALETTE_DARK`／`PALETTE_LIGHT` 整組換掉。索引（`color_idx`）沒變，同一個板塊維持同一個索引，只是換成新色；舊的 34 色與「鎖定區 14 色」不再使用（Andy 要求圖表配色重做）。

做法：
- 0–7 手選主色盤（藍、金、褐、紫、天藍、橄欖、粉紫、灰藍；原第 3 色青綠已於 11-10 換成褐色，避開跌綠色相）：明度刻意錯開，彼此都不在紅或銅紅色相上；
- 8–33 依序挑「離前面所有色最遠」的色（CIEDE2000），彩度壓低（主線亮、雜項退後）；
- 排除條件：與漲跌色、銅紅 ΔE < 18 的候選一律不收（手選 0–7 例外，見下）。

量測（`scratchpad/tools/gen.py`，CIEDE2000）：

| 指標 | 淺色（對 `#FBFAF6`） | 深色（對 `#142142`） |
|---|---|---|
| 對底色對比最低 | 4.30 | 4.98 |
| 任兩色最小 ΔE | 6.8 | 8.9 |
| 相鄰索引最小 ΔE | 9.7 | 23.9 |
| 與漲跌色、銅紅最小 ΔE | 以最終 app.js 為準（前 8 色青綠換褐色後，此欄的量測值未重算；粉紫 `#D98CB8` 對漲紅 14.9 不變） | 同左 |

誠實說明：舊色盤的下限是「任兩色 ΔE ≥ 10、相鄰 ≥ 34、與漲跌 ≥ 18」。新色盤改為手選主色盤以符合品牌，前 8 色之外靠數學挑，所以下限略低（上表）。前 8 色的色盲模擬最小色差：紅色盲 2.8／綠色盲 2.2／藍色盲 4.4（淺色），仍有相近對，靠「明度錯開＋圖上直接標示名稱」補，沒辦法完全靠顏色分辨。如果 Andy 要求更嚴，下一步是縮減到 6 色主盤並加線型／標記形狀。

## 五、刻意沒動的（有理由）

1. 紅漲綠跌的所有色（除上面那一處深色漲色明度）、熱力圖 7 格離散色階（`--hm-n3…--hm-p3`）。
2. 題材熱力 5 格（`--hm-v*`：深藍→淺藍→淺紅→深紅，Andy 2026-09-25 拍板）與湖水藍組（`--hm-t*`）。
3. 剖析圖的「材質色」：陶瓷、銅、錫、PCB 綠、鋼灰（`--dg-cer`、`--dg-cu` 等，約 150 處）。那是「這個零件在現實中長什麼顏色」，不是介面色；改了會讓圖不像實物。只換了剖析圖的**強調色／文字三階／底色**（隨上面第四節的批次替換）。
4. `#ffb454` 琥珀（約 58 處）：警示語意色，和 ⑤C 搭得起來（暖金），沒必要動。
5. 手機頁首、同意橫幅、LOGO 圖檔：另一位同事在 `preview/mobile-restart` 處理，這裡不碰。
6. 付費開關相關邏輯（`preview/coldstart`）：不碰。
