## 問題清單（依嚴重度）

### 1. 高：燒焦恢復後，在沙發上（離營火 12 公尺）又再著火一次
- 重現：1920 → 長按離營火最近的人（data-scraper「織網」）→ 拖到營火上放開 → 等約 75 秒。事件記錄：`3.0 burned` → `7.4 extinguished` → **`76.7 recovered` 與 `76.7 burned` 同一刻** → `81 extinguished` → `125 recovered`。第二次著火時他在 (30.0, 27.6)，離營火中心 12.4 公尺。兩次跑都一樣（`fire.stats.ignited = 2`）。
- 原因（讀程式）：`site/office/world/js/fire.js` 約 282～288 行，每一步用「上一次位置 `c._fp` → 這一次位置」的線段判斷有沒有掃過火。但燒焦期間（state 不是 none）在更新 `c._fp` **之前**就 `continue` 了，所以 `_fp` 一直停在被丟進營火時的位置；一恢復，線段變成「營火 → 沙發」，必然穿過火心 → 再點燃一次。
- 修正方向：`continue` 之前也更新 `c._fp`，或恢復時把 `c._fp` 設成目前位置。
- 證據：`js/out4a.txt`（含逐 2 秒位置），截圖 04_d1920_fire_recovering。

### 2. 高：跟隨鏡頭被緊貼角色的路燈擋住時不會繞開
- 重現：1920 → 長按任一人拖到路燈 (23.4, 36.9) 南側約 0.2 公尺放開 → 點他 → 畫面中央是整根路燈與燈罩，角色臉被擋住（06b_d1920_follow_start.png、06_d1920_s0_follow_late.png），15 秒以上不動。
- 原因：`site/office/world/js/camclear.js` 的 `blockedFrom` 把射線長度設成 `L - 0.6`，**離角色頭部 0.6 公尺內的東西一律不算**；路燈離角色只有 0.2～0.3 公尺，正好被排除。最常見的「擋住」就是東西緊貼角色，這個門檻剛好讓功能失效。
- 另外：跟隨鏡頭的 z 被限制在 `layout.size.d + 4`（= 34），遊民區（z 33～38）裡的角色鏡頭幾乎都貼在 z=34，離角色很近、角色常被切到畫面下緣。
- 修正方向：射線改成只扣角色自身半徑（例如 0.15～0.25），並在 `_uitest` 加一段「放到路燈正後方 → 跟隨 → 鏡頭位置要改變且頭部可見」。

### 3. 中～高：新模型角色「跳跳」從 CEO 室走回座位時卡在西牆邊
- 重現：1280 → 長按「跳跳」(bibi-animator) → 拖到 CEO 椅子左側約 0.9 公尺放開 → 按畫面上「4×」等。他的路徑第 6 個點是 (0.63, 13.63)（貼著西牆），他走到 (1.06, 13.63) 就過不去，狀態一直 walk／run，卡住計數 0→0.4→0.8→0 循環，**超過 20 秒沒有放棄、也沒有重新找路**。3/3 重現（2 次用 advance 等、1 次只用 4×）。
- 對照：同樣操作的「格子」（舊模型）15 秒內坐回座位。
- 可能原因：路徑點離牆太近（新模型的身體半徑比較大走不到），而卡住偵測一直被重設、沒有觸發重新規劃或改用瞬移保底。相關檔：`site/office/world/js/newchar.js`（`_stuck`、`_path`）、`nav.js`。
- 證據：03_d1280_stuck_zoom_bibi-animator.png（頭上冒「?」貼在牆邊）、03_d1280_r1_later.png、`js/out3c.txt`。

### 4. 中：甩出速度的記錄被兩個模組共用、單位混在一起
- `phys.js` 第 208～215 行與 `mind.js` 第 123～127 行都包住 `c.dragTo`，**都把記錄推進同一個 `c._dh` 陣列**，但 phys 用「秒」、mind 用「毫秒」。實測記錄：`[[101.29, …], [101288, …], [107.1, …], [107101.8, …]]`。
- 後果：phys 算速度時 `last`（毫秒）減前一筆（秒）永遠 > 0.15，`first = last`、`dt = 0` → **舊模型角色（大多數同事）的甩出速度覆寫從來沒生效**；mind 算出的速度 ≈ 0，永遠走不到「sp > 2.2 立刻送 knocked」，只靠之後的補送。這很可能是上一輪「椅子沒翻倒」的原因之一，真機上也會發生。
- 修正方向：兩邊各用自己的欄位名（例如 `_dhP`、`_dhM`），或統一成同一個記錄與單位。

### 5. 中（需真機確認）：甩人撞翻椅子
