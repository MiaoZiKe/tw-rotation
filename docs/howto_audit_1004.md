## 已知限制

- 本機 `build_payload` 在 60 分 K 階段被系統以記憶體不足砍掉（exit 137，同機有其他 agent 在跑）；
  前 16 個 JSON 是這次重建的，其餘（含 `stock/`、`flow_v3.json` 等）從主工作目錄 05:53 建好的 `site/data/` 複製。
  所以資料是**今天早上的版本**，不是這個 commit 現算的；若有人改了 JSON 格式，個別卡片的實際畫面可能略有不同。
- 只跑 1440 寬；手機版（`mobile3.js` 的 `rot` 那一顆）沒有打開。
- 「說明缺漏」類（第 13～18 項）是判斷題：條列有 5 條上限，不是每個控制項都該寫進去，列出來是讓改的人取捨。
- 指標算法類的句子（例如量比「含今日」）沒有判定對錯，那歸 `smc-technical` 核。
