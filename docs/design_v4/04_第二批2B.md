## 4. 判斷過、但 Andy 可能不同意的地方

1. **圖例「放得下才搬」**：放不下時照改前畫（ECharts 圖例在圖裡），同一張圖在不同寬度長得不一樣。另一個選項是一律搬出來、放不下就自己佔一行 —— 量過，那會讓 1100 寬營收頁高 +31、除權息 +15（多一行圖例把卡片撐高），是退步，所以不上。
2. **K 線主圖少 23px（587 → 564）換副圖標籤不壓資料**：量柱可畫的高度跟改前一樣。不要的話把 `chart.js` 的 `KChart.LBL_STRIP` 改成 0 就回到改前。
3. **「此檔暫無分時資料」短註搬進左欄**：位置從「K 線正上方整行」換到「工具列正下方、只有左欄寬」，文字與行為不變（點了照樣展開，id 不變）。
4. **641～820 現價列小標不再是 36px 高**：它們是資訊標籤不是按鈕；觸控 36px 的規則（index.html 那段）是給篩選晶片的。
5. **除權息年份縮成 'YY 的門檻從「容器 < 420」改成「一格放不下四位數」**：1100 寬半欄卡片也會縮（改前在那裡疊字）。
6. **營收柱不標數字**：改前的自動標籤是原值（元，12 位數），不是設計；要標的話應該標「億」而且只標最新幾根，那是新功能，這一批不做。
