Andy 原話：「這太不美觀了 都影響到整個版面，你需要會變通……並站在使用者角度下去製作」「這邊應該要固定版面 不該隨清單數量而改變」「這邊的清除選項功能呢？」「上面分頁幫我用不同顏色標註」。
接續 `docs/ui_polish_spec.md`；與其衝突處：分頁不再一律同色（改識別色），原因見第 5 節。

## 1. 使用者第一眼要看到什麼
想算「每月領多少、要買幾張」的散戶，順序是：**選了哪幾檔 → 各要幾張、多少錢 → 每月入帳圖**。
所以已選明細（張數・金額）必須貼在圖正上方、跟色點同一顆，不該是另一塊獨立的表。

## 3. 方案比較
| | 方案 A：已選明細＝色塊本身 | 方案 B：右欄上方放已選明細、下方是清單 |
|---|---|---|
| 做法 | 圖例 chips 直接寫「名稱・N 張・金額 ×」；右欄只剩可搜尋清單，與圖同高 | 右欄 = 已選小表（5 列）＋清單 |
| 標題列 | 不撐高 | 不撐高 |
| 圖寬 | 維持 | 右欄變高、清單被壓成約 200px，要捲很多 |
| 空白 | 無 | 無 |
| 手機 | 不影響（手機本來就收成清單） | 手機要再改 |
**選方案 A**：資訊與色點同一顆、少一塊；右欄全留給清單（使用者要挑 ETF 的地方）。

## 4. 規格（現況 → 目標）
| 項目 | 現況 | 目標 |
|---|---|---|
| 單檔標題列 | h3＋小表＋排序，約 205px | h3＋排序，≤ 60px |
| 色塊 | 名稱 ×，12px | 名稱・N 張・金額 ×，12px 等寬數字；滑過 title 補現價、殖利率；最小高度 62px（2 排） |
| 單檔右清單 | max-height 380／460 | 桌機（≥1101）固定 524px，內部捲動；＝色塊區＋說明列＋圖 440 |
| 清單頂端 | 搜尋＋「回前 5」 | 搜尋（× 22px 有底有框）／頻率 chips（選中尾巴 ×）／「已勾 N／5 檔」＋「清除勾選」＋「回前 5」 |
| 勾選列 | 選取時其他列淡到 .6 | 勾選列一律 opacity 1、同一種樣式（選取只加琥珀色底） |
| 自訂組合上半部 | 高度隨列數 | 桌機固定 372px 兩欄同高，表／清單各自在框內捲；選 2 檔或 8 檔結果卡 top 相同 |
| 自訂清單 | 「清空」 | 「清除勾選」＋「已勾 N／10 檔」 |
| 甜甜圈標籤 | 全標 | 占比 < 9% 不標字（改看滑過提示與下方「各檔明細」） |
| 自動配張數 | 只有「總投入最少」 | 新增「各檔金額平均」（預設）；畫面用白話說明差異與多花多少 |
| 字級 | ≥12px | 不變（色塊 12、數字等寬） |
| 間距 | 12／8px | 不變（清單內距 8、chips 間距 6） |
手機（≤640）：版面維持原本的清單式，只補「清除勾選」鈕、分頁識別色（用 `site/m4/20261031-etf-tabcolor.css`，只在 `html.m4`），不影響桌機。

### 預設配法為什麼選「各檔金額平均」
使用者挑 8 檔，目的通常是分散；「總投入最少」會讓 7 檔各買 1 張、一檔買 1,345 張（NT$ 1,208 萬）——數學最省、但等於只買一檔，和「我挑了 8 檔」的意圖相反。
預設改成各檔投入金額大致相同、每月仍 ≥ 目標，多花的錢直接寫在畫面上（「比總投入最少多花約 N 萬」）；要最省的人一鍵切「總投入最少」，畫面會說明為什麼會集中在一檔（例如該檔每月都配息）。

## 5. 分頁識別色（單檔 ETF／組合 A～E／自訂組合）
| 分頁 | 色 | 色相 |
|---|---|---|
| 單檔 | `#5B86B8` 鋼藍 | 215° |
| A | `#17A2B8` 青 | 190° |
| B | `#7C5CE0` 紫 | 255° |
| C | `#C25AA8` 洋紅 | 313° |
| D | `#D9922E` 琥珀 | 36° |
| E | `#8A6D3B` 古銅 | 40°（低飽和） |
| 自訂 | `#7A8794` 灰藍 | 210°（低飽和） |
做法：分頁上緣 3px 色條＋9% 淡底，選中 24% 加深＋粗體；結果卡上緣同色條、標題字用同色（與文字色混 72%）。深淺主題同一組色票（中明度，兩種底都可辨）；不用紅（漲）與綠（跌）色相，避免與漲跌混淆。與 `docs/style_guide.md`「分頁一律照產業地圖」不衝突（仍是 `.nbsw`，只加識別色）。

- 組合 A～E 沒有「勾選清單」（組合是演算法算出來的），所以沒有清除勾選；已選明細＝各檔明細卡。
