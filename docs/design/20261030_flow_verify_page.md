## 一、投資人的三個問題 → 版面順序

| 問題 | 頁面上的回答 | 位置 |
|---|---|---|
| ① 錢往哪跑？ | 輪盤（三選一）＋流入／流出前 5 | 左欄上 |
| ② 那個族群真的有在漲嗎？ | 族群走勢大圖（相對大盤＋成交值占比副圖）＋成分股各一張走勢＋「吻合／背離」標籤 | 右欄 |
| ③ 我看到的訊號事後有沒有用？ | 時間軸上的訊號點、觸發後實際走勢、歷史回測表 | 中下大卡 |

最頂端一句「結論列」先答三題的摘要（自動產生，見 §三），讓人不用看圖就知道今天要看哪幾個族群；圖與表是證據。

## 二、頁面結構

名稱「流向驗證」，路由 `#flowcheck`（站內側欄放在「資金流向」群組下、與資金輪動／資金分流樹並列，獨立頁，不是子分頁）。狀態全放網址：`#flowcheck?g=<族群>&d=<日期>&t=<HHMM|close>&v=<wheel|money|tree>`，可分享、可上一頁。

### 1. 單一焦點狀態（核心互動）
全頁只有一個狀態 `{gid, date, t, view}`：
- 點輪盤的點、樹的節點、熱力方塊、焦點籤、背離榜、成分股表列＝改 `gid`，**所有圖同步換**（走勢、成分股、新聞、法人、訊號）。
- 拖時間軸／按播放＝改 `t`，輪盤的點、熱力方塊、走勢游標、樹的值同時換。
- 日期選擇器＝改 `date`，整頁重載那一天（`t` 重置為該日收盤或最新）。
- 滑過任一圖：全頁只出一個 tooltip（andy_ui_rules 12）。

### 2. 控制列（一列，1440 一行放得下）
標題「流向驗證」｜模式分段 `今天 5 分鐘`／`歷史回放`｜日期 `◀ 2026-10-30 (五) ▶`（◀▶ 跳交易日，點日期開日曆，非交易日灰掉、早於資料起點的灰掉並寫「資料起點 2023-09-19」）｜族群篩選分段（全部／半導體／AI 伺服器／其他，同全站 `.seg`）｜「?」。說明不另放卡片，全進「?」。

### 3. 結論列（一句話＋焦點籤）
範例：「資金流入前 5 名是 A、B、C、D、E；其中 3 個走勢吻合、2 個背離（資金進、相對大盤落後）：D、E。今日吻合度 71%（近 3 年常態 62%）。」右側焦點籤（預設＝流入榜第 1 名；背離榜按鈕列出背離族群）。

### 4. 左欄「錢往哪跑」
- 輪盤分段三選一（同一個位置換內容，andy 規矩 6）：
  - **強弱輪盤**（現有價格 RS-Ratio／動能象限，沿用 `rrg`，名稱照 rrg_audit 建議標「相對強弱」）；
  - **資金輪盤（真）**：x＝占比 5 日均 − 20 日均（pp），y＝當日（或該時點）占比變化（pp）；象限：資金湧入／資金續進／資金轉出／資金退場。這是 rrg_audit 方案 (2)，後端軸要新算（§七）。盤中版 y＝該時點占比 − 同族群同時段過去 20 日平均。零和提示放「?」。預設選這個，因為強弱輪盤是用價格算的，它和走勢吻合是意料中事，拿來驗證沒有資訊量；
  - **資金分流樹**（沿用 `sankey_daily`／`sankey`，點節點＝選族群）。
- 輪盤下方：流入前 5／流出前 5 籤（點＝選族群）。
- 同色語言：紅漲綠跌；背離族群的點加琥珀外環（對比 AA）；焦點族群粗框＋5 日軌跡。
- 下方：全族群熱力圖（同一時點，面積＝成交值，顏色＝相對大盤漲跌，背離加琥珀框，點＝選族群）。尺寸 ≥ 560×150。

### 5. 右欄「真的有在漲嗎」
- 族群走勢大圖：≥ 640×250（1440）。主線＝族群指數相對大盤（預設）或絕對漲跌（分段）；副圖＝族群成交值占比（柱）；垂直游標＝時間軸；琥珀三角＝訊號點；日線模式顯示最近 60 交易日，並以焦點日為中心標色。歷史日的 09:00–10:00 因資料湖無量，該段灰底標「此時段無成交量資料」。
- 標題旁一枚吻合狀態籤：吻合（綠）／背離（琥珀）／中性（灰），文字寫出數字，例如「背離：資金進、相對大盤 −0.4%」。
- 成分股走勢：前 6 大（依占族群成交值）各一張小折線（≥ 200×110，有軸、有游標，不是 sparkline），下方成分股全表（框內捲、固定表頭、數字等寬右對齊）：漲跌、相對大盤、占族群成交、法人買賣超、貢獻（長條）。點股名進 `#stock/<code>`。

### 6. 中下「提前判斷」卡（標「實驗」，預設收起）
- 時間軸（今天為 5 分鐘 54 格；歷史日為 4 格 60 分＋收盤）上畫三種訊號的觸發點：**資金先行**（占比放大但價格尚未動）、**擴散**（上漲家數比率上升）、**開低回升**；規則沿用 `origin/preview/verify-panel` 的盤中訊號（t ≥ 6 格才判斷、每條每族群只記第一次）。
- 表：訊號、族群、觸發時間、觸發後至目前相對大盤、至收盤、隔日。使用者自己看有沒有用。
- 歷史回測（全族群、近 3 年）：樣本數、命中率（相對大盤 > 0 比例，附 95% CI）、平均超額、扣成本（0.47%）後超額。**誠實規則**：n < 30 整列灰字不下結論；CI 含 50% 標「無法區分於隨機」；整卡標題旁固定「實驗，回測未達顯著」，因研究 16 組未通過多重比較（flow_vs_price.md）。若日後某訊號通過，才改標籤，不是先寫「有效」。

### 7. 底部輔助
- 當日相關新聞／事件：只列焦點族群成分股（`news.codes`）當天的，含重大訊息；游標之前實色、之後灰；最多 8 則框內捲，點開外部連結。
- 法人買賣超：焦點族群外資／投信／自營近 20 日堆疊直條，當日數字寫出。
（桌機兩卡並排一列，不留空白。）

### 8. 共用時間軸（貼視窗底部 sticky）
▶ 播放｜×1／×2／×5（沿用 `Tape` 播放設定 `tw.play.speed`）｜可拖拉軸｜時間標籤。今天模式＝09:00–13:30 5 分鐘；歷史回放＝同一條軸換成「交易日軸」（拖 = 換日期，播放 = 逐日回放，輪盤點沿軌跡走）；歷史單日若有 60 分 K，可在日內再切 4 格。游標右端＝最新，繼續跟新（今天）。

## 三、吻合／背離的定義（寫進「?」，公式只一份）

| 名詞 | 定義 |
|---|---|
| 資金方向 f | 日線：占比日變化 dshare（今日占比 − 前一交易日占比）；盤中：該時點占比 − 該族群同時段過去 20 日平均（研究已驗證與網站 `group_daily` 相關 0.97） |
| 走勢方向 r | 族群相對大盤漲跌（族群成交值加權漲跌 − 大盤漲跌，與 `group_daily` 同口徑） |
| 吻合 | f 與 r 同號，且至少一方 \|值\| 過門檻 |
| 資金進但走勢弱（背離 A） | f 在全族群前 30% 且 r < −0.3pp（門檻放設定，預設可調） |
| 走勢強但資金退（背離 B） | r > +0.3pp 且 f 在後 30% |
| 吻合度分數 | 當日（或該時點）全族群「f 與 r 同向」的比率；同畫出當日橫斷面 Spearman IC。旁邊固定印近 3 年常態（研究值：同向 61.9%、IC +0.28），讓人知道 71% 是高還是低 |
| 大盤急跌日 | 當日大盤 < −1.5% 時，吻合度旁加灰字「大盤急跌日，占比被動變動，一致率常態偏低（55%）」 |

## 四、預設狀態與「點一下看到什麼」

| 進頁 | 預設 |
|---|---|
| 日期／時間 | 最新交易日；若有今日 5 分鐘資料且盤中＝最新一格，盤後＝收盤 |
| 輪盤 | 資金輪盤 |
| 焦點族群 | 資金流入榜第 1 名 |
| 收展 | 走勢大圖、輪盤、結論列展開；成分股全表、提前判斷、新聞／法人、熱力圖在桌機因版面夠放而展開，手機全部收起（手機五條第 5：所有收展預設收起，使用者手動展開才記住） |
| 點輪盤一個點 | 焦點換成它；走勢圖、成分股、新聞、法人、訊號 0.3 秒內同步；網址更新 |
| 點熱力方塊／樹節點／背離榜 | 同上 |
| 拖時間軸 | 輪盤點移位、熱力色換、走勢游標移動、樹重算；不改焦點 |
| 換日期 | 整頁換那一天，焦點保留（若那天沒有該族群，退回流入榜第 1 並提示） |

## 七、資料需求（給 finance-quant 對齊）

原則：新 JSON 由 main 的 `pipeline/build_payload.py` 產出（預覽版讀正式站資料）；檔案切小、依日期懶載入；首次載入 ≤ 60KB（gz 前）。欄位名先定，若現有檔已有請沿用同名。

### 7.1 `site/data/flowcheck/index.json`（進頁就載）
| 欄位 | 說明 |
|---|---|
| `schema` | 版本號 |
| `dates` | 可回放的交易日陣列（目前資料湖 60 分 K 起點 2023-09-19；日線若更早也可列，標示哪些日有哪些層） |
| `layers[date]` | 該日有哪些資料：`["daily","m60","m5"]` |
| `latest`、`updated_at` | 最新交易日、資料時間 |
| `groups[]` | `{gid,name,chain,tier,members:[code…],is_bucket}`（`ind_` 補位桶標記） |
| `baseline` | 近 3 年常態：同向率、IC（全部／分盤勢），供「常態 62%」顯示 |
| `market` | 大盤日報酬序列（日期＋漲跌），用於相對大盤與大盤急跌日判斷 |

### 7.2 `site/data/flowcheck/day/<YYYY-MM-DD>.json`（換日期才載，每檔 ≤ 150KB）
| 區塊 | 欄位 |
|---|---|
| `groups[gid]`（約 56 個題材族群） | `share`（占比 %）、`dshare`（占比日變化 pp）、`rot`（5 日均 − 20 日均 pp）、`chg`（族群漲跌 %）、`rel`（相對大盤 pp）、`adv`／`dec`（上漲／下跌家數）、`tv`（成交值）、`rs_x`／`rs_y`／`quadrant`（價格強弱輪盤）、`m_x`／`m_y`／`m_quadrant`（資金輪盤：x＝rot，y＝dshare，含 5 日軌跡）、`inst`：外資／投信／自營淨買超、`div`：`A`／`B`／`null` 與門檻版本 |
| `members[code]` | `name`、`gid[]`、`close`、`chg`、`rel`、`tv`、`share_in_group`、`inst`（外／投／自營）、`contrib`（對族群漲跌貢獻） |
| `sankey` | 與 `sankey_daily` 同格式（當日 leaves），讓樹可回放任一天 |
| `signals` | 當日觸發清單：`{gid,type,t,rel_at_trigger,rel_to_close,rel_next_day}`（type：flow_lead／breadth／open_low_recover） |
| `news` | 當日與焦點族群成分股相關：`{id,t,title,url,source,codes,kind}`（來自 `data/news`、`data/material_news`） |
| `m60` | 若該日有 60 分 K：每族群 4～5 根 `{t,idx_rel,share}` 與前 6 大成分股的 `{t,close}`；`gap_0900:true` 標 09:00–10:00 無量 |

### 7.3 `site/data/flowcheck/m5/<YYYY-MM-DD>.json`（只有有 `tape_5m` 的日子，10-30 起）
每族群與前 6 大成分股的 54 格序列：`idx_rel`（相對大盤）、`share`（累積占比 － 同時段 20 日基準，基準不足時為 null 並標原因）、`chg`、`adv`／`dec`。公式與 `group_daily` 同口徑（成交值加權），前端不重算。每日盤後由 `tape_5m` 產出並**累積保存**（資料湖每天只增不改，之後歷史才會越來越長）。

### 7.4 `site/data/flowcheck/series/<gid>.json`（走勢大圖日線模式用，一次載整個族群）
近 750 交易日：`date`、族群指數（含相對大盤指數）、`share`、`dshare`、`chg`、`rel`；以及前 6 大成分股的日收盤。約 56 檔 × < 80KB。

### 7.5 `site/data/flowcheck/backtest.json`
每種訊號（以及分盤勢、分族群大小）：`n`、`hit_rate`＋95% CI、`avg_excess`、`avg_excess_net`（扣 0.47%）、`ic`、`t_nw`（Newey-West）、`period`、`as_of`、`passed_multiple_test`（bool；目前研究為 false）。另附「訊號事件表」（date、gid、type、t、至收盤超額、隔日超額）給前端畫分布。重現腳本沿用 `scripts/research/flow_vs_price.py`，回測口徑一份、不得和頁面公式分岔。

## 九、我判斷過、Andy 可能不同意的地方

1. **預設選「資金輪盤（真）」而非他現在熟悉的那張。** 理由是現有那張是價格算的，和走勢必然吻合，沒有驗證力；代價是他要先接受新軸（rot、dshare）。已用分段開關讓他一鍵切回強弱輪盤，並把「現有輪盤實為價格強弱」寫進「?」。
2. **三種輪盤做成「三選一分段」而不是三張同時並排。** 1440 同時放三張圖加走勢會壓縮到不可讀（他自己最痛的是圖被壓縮），故用焦點同步＋切換；若他堅持並排，可在 ≥1600 寬加一個「並排兩張」開關，列為第二期。
3. **提前判斷一律標「實驗，回測未達顯著」並預設收起。** 研究 16 組無一通過，若把它做成醒目的買進訊號，等於誤導；他可能希望更醒目，我不建議。
4. **歷史 5 分鐘做不到。** 10-30 以前只能 60 分＋日線，且 09:00–10:00 無量；回放能力要隨資料累積變好，頁面會明講而不是假裝有。
5. **吻合度分數旁固定印「近 3 年常態 62%」。** 這會讓「71%」看起來沒那麼亮眼，但沒有基準的百分比會被誤讀。
6. **背離門檻（前 30%／−0.3pp）是我先定的預設值**，尚未用資料校準；規格要求門檻放設定並在回測表裡統計「背離 A 事後表現」，由數據決定要不要調。
7. **手機把輪盤放在走勢圖下面**（先看「有沒有漲」再看「錢往哪」），與桌機左欄在前相反；理由是手機第一屏要先給可驗證的走勢。
