# 網站預設風格規範（Default Style Guide）

> 2026-10-05 設立。**新頁面、改版、新元件一律照這份**；跟這份衝突的舊寫法，下次碰到就改成這份。
> 值都落在 CSS 變數（`site/theme4.css` 的 `:root[data-theme4]`、`site/index.html` 的 `:root`），**不准在 JS／頁面 CSS 寫死 px 或色碼**。
> 自動檢查：`python scripts/_uitest.py --sections 風格規範`（違反就紅燈）。決策紀錄：DECISIONS #322（分頁細則 #321）。

## 二、字體

- 內文：`"Noto Sans TC","PingFang TC","Microsoft JhengHei",system-ui`；數字一律 `var(--mono)`＋`font-variant-numeric:tabular-nums`。
- 字級（`--fs-*`，只有這 6 階＋分頁 13.5）：

| 用途 | token | px | 字重 | 行高 |
|---|---|---|---|---|
| 頁標／區段標題 | `--fs-h2` | 20 | 700（HUD 600） | 1.3 |
| 卡片標題 | `--fs-h3` | 16 | **600**（量自總覽「資金熱力圖」、市場明細頁標；2026-10-05 由 700 改 600） | 1.3 |
| 內文、圖例 | `--fs-body` | 14 | 400 | 1.55 |
| 副標、表格、長條標籤 | `--fs-sm` | 13 | 400 | 20px |

| 下限（軸字、小註） | `--fs-min` | **12（全站下限，低於即紅燈）** | 400 | — |

## 三、顏色

- 全部引用主題變數：底 `--bg`／卡 `--panel`／淺一階 `--panel-3`／線 `--line`、`--line-2`／字 `--ink`、`--ink-2`（次要）、`--ink-3`（最淡）／主色 `--accent`。深淺主題只換值不換名字。
- **紅漲綠跌**：`--rise`／`--fall`／`--flat`，**只表示漲跌**，不准拿來當類別色。
- **類別色盤**（甜甜圈、多系列）：`--cat-1`…`--cat-6`，「其他」用 `--cat-other`。甜甜圈 ≤ 5 類＋其他。
- **同一系列一種顏色**：排行長條、每日直條都用 `--cat-1`；不要每根不同色。
- **文字不用系列色**：圖例文字、數值用 `--ink`／`--ink-2`，顏色只上在色塊。
- 對比：內文 ≥ 4.5:1、大字與圖形 ≥ 3:1（主題值已在 #124／theme4 驗過，新增色要自己量）。

## 四、間距與格線

- 間距只有 5 階：`--sp-1..5` ＝ 4／8／12／16／24。卡片間距 `--gap-card` 12；卡片內距 12～16；頁邊 16。
- 卡片兩欄 `grid-template-columns:repeat(2,minmax(0,1fr))`（三欄同理）：**欄寬由格線決定，不由內容決定**。同一排卡片 `align-items:stretch` 同高，卡內內容**從上往下排**（不要 `margin:auto` 讓圖浮在中間）。
- 空白處理順序：①配對時把內容量相近的卡放同一排 ②圖高設上下限（`min/max-height`）③才考慮跨欄。不准補小圖填空。
- 斷點：≤ 820 卡片單欄；≤ 640 手機版（`mobile-ui` 規範）。

## 五、元件

- **分頁**：`.nbsw`（一層）、`.nbsw.lv2`（二層）；CSS 只在 `site/index.html` 一份。頁面 CSS 只准補邊框，不准改字級（#321）。
- **表格**：表頭與欄位置中；數字欄窄、mono；文字欄一行省略（`white-space:nowrap;overflow:hidden;text-overflow:ellipsis`）＋`title`；列高 `--t4-row-h` 32（手機 40）；分隔線 `--line`。
- **按鈕／選單**：高 32、圓角 `--r-sm`、字 13～13.5。**Switch 三態**：on／off／mixed（`aria-checked="mixed"`，圓鈕停中間）。
- **狀態**：改過未存＝控制項外框換 `--amber`；不寫文字。
- **圖示**：一律帶色（`currentColor` 或 `--accent`），卡片標題左側 4×14 主色豎條。

## 六、圖表

| 圖 | 用在 | 規格 |
|---|---|---|
| 甜甜圈 | 佔比、≤ 5 類、加總＝100% | 外徑 **160～260 隨卡片可用高度放大**（`--chart-donut` 160 為下限）、環寬比例 22/160、12 點鐘起順時針、中心＝第一類 % ＋名稱（置中）、**圖例放圖下方一排**（色塊 12×12＋名稱＋數字＋%，卡片較窄時比放右邊更不留白） |
| 橫向長條 | 類別比大小 | **由大到小排序**、條粗 `--chart-bar-h` **14**、列距 `--chart-row-h` **32 起，資料少時列距平均拉開以填滿卡片**（不再固定 28、不留底部空白）、條填色＝類別色 1 的漸層、全圓角、底槽 `--panel-3`、三欄格線（名稱 10em／長條／數字 6.5em）每欄 x 對齊、數字 mono |

| 散佈 | 兩個量的關係 | **依容器實際大小重畫（ResizeObserver）吃滿卡片**（取代舊的「高 ≤ 200」）、軸刻度＝真值、只標前 6 點且標籤互相避開、軸字 12 |
| 表格卡 | 排行＋明細 | 表格包在 `.tbw` 吃滿卡片，列高隨資料量放大；超過 340px 在卡內捲動、表頭黏住；佔比欄用小長條＋數字，功能欄用晶片（≤ 3 個） |

共通：格線淡（`--grid`）、軸字 12、圖例不佔繪圖區、tooltip 用 `--tip-bg`；空資料一行字交代（不畫空框）。

**圖表填滿的量法**（`_uitest` 流量觀測1005 自動檢查，資料少／資料多各一次）：每張卡 `.cb`（圖區）高 ÷ 卡內容高（扣內距）**≥ 0.8**，圖區內的圖吃滿圖區 ≥ 0.9；同一排卡等高、頂端對齊。

**管理區版型（2026-10-05 重設計）**：流量觀測＝三欄格線（第一列趨勢 2＋佔比 1、第二列三張長條榜、第三列表格 2＋散佈 1、第四列在線 1＋會員 2）；會員權限的「開放功能表」分類卡改成欄流排版（CSS columns），每欄由上往下接著排，不再因同列拉齊而在短卡下留大片空白。

**流量觀測的分頁統計（2026-10-05）**：上方一排＝每天直條＋登入甜甜圈（期間：即時／近 N 天／指定日期到現在，只影響統計資料，整頁同一份）；下方 `.nbsw` 頂層分頁＝全部＋側欄各頁＋個股，頁內小分頁（`.nbsw.lv2`）＝子頁；每個分頁都是「左長條＋右大甜甜圈」。「全部」的長條依子頁堆疊上色、甜甜圈同色系子扇區，滑過有占比，點長條／扇區進入該頁。頁面色＝固定色相（`PG_H`）＋明度 `--pgL`（深 60%／淺 40%）；這是「各頁／各子頁」的類別色，不受「甜甜圈 ≤ 5 類」限制（Andy 指定）。

**圖表風格補充（2026-10-05，Andy：圓餅以母族群分界、長條太粗、要淡淡的 Y 軸）**：甜甜圈照產業地圖「成交值占比」——環 R45／寬 14（約 58%～78%）、扇區端點**直角（不做圓頭，Andy：不要這麼嚴重的圓弧化）**、內側極細軌道（`--ink-3` 22%）、中心小標題＋大數字、滑過扇區中心換成該扇區名稱與占比；**非同組扇區之間一律同樣的間隙 2°（小扇區也照，太小的畫成 0.8° 細片，不准有的有縫有的沒縫）；只有同一母頁的子分頁扇區相連（間隙 0）、同色系深淺**。長條一律細：橫向長條 10px（`--chart-bar-h`，原 14）、每天直條最寬 12px（原約 22）；產業地圖長條上限 17。每天直條 X 軸每 7 天（週一）一個刻度（> 98 天改每 4 週、即時每 4 小時）、Y 軸 5 個刻度＋很淡的水平格線（透明度 ≤ 0.5）；不加週末底色。

**圖表互動（管理區所有圖一致，2026-10-05 Andy）**：滑過高亮該柱／扇區／點、其餘變淡（透明度 .3～.4，120ms）；浮動提示 `#trTip`（名稱粗體、次數、占比）；甜甜圈滑過扇區或圖例，中心字換成該段名稱與占比、圖例與扇區連動；「全部」頁的長條與扇區可點進該頁；其餘圖沒有下一層，只提示。`prefers-reduced-motion` 關掉過渡。**開站身分甜甜圈**＝訪客｜註冊會員｜各付費方案（每個付費範本一段、顏色依範本 id 雜湊固定、新增方案多一色）；登入的幾段相連、與訪客留 2° 間隙；中心「登入 xx%」。

## 七、禁止事項

1. 寫死色碼／px（`#3ee0ff`、`font-size:11px`）—— 用 token。
2. 小於 12px 的字。
3. 文字換行把卡片撐高、切換／輸入讓版面晃動。
4. 自寫分頁（`.ptabs`、非 `.nbsw` 的膠囊）。
5. 卡片上放長段說明（副標 ≤ 20 字，說明進 `title`）。
6. 用文字表示狀態（「改過 未存」）。
7. 用紅綠當類別色；文字上系列色。
8. 圖浮在卡片中間、上下大空白；補小圖填空。

## 八、新頁面開發流程（每一頁都要走）

1. 開工：讀本檔；只用上面的 token 與 `.nbsw`／表格／圖表規格。
2. 開發中：1440 與 **800** 兩個寬度都看（`python scripts/_show.py --view <路由> --width 1440,800`），深淺主題各一次。
3. 自檢清單（逐條打勾）：□ 字級 ≥ 12 □ 分頁是 `.nbsw` □ 欄位置中 □ 文字一行 □ 同排同高、欄寬一致 □ 無大空白 □ 圖示有色 □ 類別色用 `--cat-*` □ 無寫死色碼。
4. 把新路由加進 `scripts/_uitest.py` 的 `STYLE_ROUTES`，跑 `--sections 風格規範` 必須綠燈。
5. 審核（`reviewer`／`art-director`）照本檔逐條給「過／不過」；不過就退。
