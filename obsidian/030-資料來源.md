# 資料來源

原則：**只用免費且合規的來源**。抓下來會重複用到的東西一律存進資料湖（`data/` 的 Parquet），
不每次重抓；只增不改，不覆寫。

## 來源一覽

| **櫃買中心** | 上櫃日收盤價量 | 每日盤後 | |

| **集保中心（TDCC）** | 股權分散表（大戶持股增減） | 每週 | 用它替代「主力家數差」——**券商分點沒有免費合規來源，所以不爬** |

| **FRED** | 美國總經指標 | 每日 | ⛔ 目前回 400，`data/macro/` 還不存在 |
| **期交所行情看板** | 台指期夜盤報價 | 每分鐘 | **只有當下一筆快照，沒有分時序列** —— 所以夜盤走勢圖是網頁自己一筆一筆收的真實報價點，不是內插 |

### 刻意不用的

- **`www.twse.com.tw/rwd/...`**（證交所官網端點）—— 使用條款禁止爬取
- **券商分點**—— 主力家數差沒有免費合規來源，改用集保大戶增減＋法人動向替代

## 資料湖有哪些表

`price_daily`（日價量）、`inst_daily`（三大法人）、`valuation_daily`（本益比等）、
`revenue_monthly`（月營收）、`financial_q` / `balance_q`（財報）、
`dividend` / `dividend_events` / `dividend_results`（股利）、`margin_daily`（融資券）、
`shareholding_weekly`（股權分散）、`index_daily` / `index_ohlc`（指數）、
`intraday_60m`（分 K）、`market_daily`（大盤）、`company_info`（公司基本資料）、
`news` / `material_news`（新聞／重大訊息）、`intl_daily`（國際）、`macro`（總經）、
`broker_views`（券商觀點）

## 人工維護的三個檔（只有這三個是人訂的，其餘都是抓的）

| 檔案 | 內容 | 誰校訂 |
|---|---|---|
| `groups.yaml` | 族群成分（產業鏈位置） | Andy |
| `themes.yaml` | 題材成分（市場敘事） | Andy |
| `supply_chain.yaml` | 供應鏈環節、公司節點、**140 條上下游關係** | Andy |

每一條供應鏈關係都標了 `confidence`：
- **verified** — 官方文件／重訊等級（公司官網、優良供應商名單、採購金額揭露）
- **reported** — 兩個以上獨立媒體在摘要層級講同一件事
- **estimated** — 產業邏輯推論，**一定附來源**並寫明「推論依據是什麼、缺的是什麼」

**查不到出處的一律不畫**，讓節點維持孤立並在圖上標「?」。

## 已知的資料限制（會直接影響畫面）

| 問題 | 影響 | 狀態 |
|---|---|---|
| 🔴 **FinMind token 失效** | 法人籌碼、財報、股利、融資券、股權分散、歷史回補、指數歷史全部停止更新 | **要 Andy 去換 token** |
| **指數歷史只有 32 個交易日** | 大盤 K 線的週／月／季只有幾根 | 卡在上面那個 token。換好之後 3 次請求就補完 |
| **FRED 回 400** | 總經那一塊沒有資料 | 下一輪回補會印出 400 的原因 |
| **當天盤中的量是暫定值** | 15:30 那一輪的成交量與成交值偏低 | 正式資料進來後自動覆蓋，畫面上有提示 |
