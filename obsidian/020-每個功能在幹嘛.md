# 每個功能在幹嘛

網址後面的 `#xxx` 就是頁面。下面照選單順序。

## `#overview` 總覽 — 今天發生了什麼

| 區塊 | 回答什麼 | 怎麼看 |
|---|---|---|
| **上方三張大盤圖** | 加權 / 櫃買 / 台指期現在多少、今天怎麼走 | 可切「走勢圖 / K 線」與日週月季。台指期可切日盤／夜盤 |
| **資金熱力圖** | 錢集中在哪幾個族群 | 方塊大小＝成交值佔比，顏色＝資金流入流出 |
| **輪動階段** | 四段循環（落後 → 改善 → 領先 → 轉弱）各有哪些族群 | 這是「現在在循環的哪一段」，不是預測 |
| **熱門題材** | 市場在炒什麼故事 | 熱度＝資金佔比變化＋法人＋新聞。點題材進題材頁 |
| **今日候選** | 今天有哪些股票值得看 | A＝回檔承接、B＝突破追進。綜合分＝技術 40%＋籌碼 30%＋基本面 30% |
| **市場寬度** | 今天是真的漲，還是只有指數漲 | 儀表＝站上 20 日均線的比例；圓環＝漲／平／跌家數 |
| **法人連續買超** | 誰在持續收貨 | 橫軸＝連續買超天數、縱軸＝累計張數、泡泡大小＝張數。**右上角那幾顆才是真的在收貨** |
| **族群估值** | 哪些族群貴、哪些便宜 | **同族群才比本益比**（IC 設計本來就比航運貴）。橫軸＝本益比、縱軸＝資金流入 |

## `#flow` 資金流向 — 錢從哪裡流到哪裡

| 區塊 | 回答什麼 |
|---|---|
| **期間切換** | 本週／上週／上上週／本月／上月／近三月 —— 底下所有圖都跟著這個期間 |
| **資金流向排行** | 這段期間誰把錢吸走了（佔比變化，單位是百分點） |
| **輪動時鐘（RRG）** | 每個族群相對大盤跑到強弱循環的哪一段。**圈圈越大＝成交值佔比越高；離圓心越遠＝和大盤差越多** |
| **資金去向（桑基圖）** | 大盤成交值 → 各族群 → 各族群的代表股，一條線看到底 |
| **族群 × 法人** | 三大法人在各族群的淨買賣超 |

## `#industry` 產業與個股

- **產業地圖**：所有產業鏈與法定產業別的方塊，點進去看單一產業鏈
- **單一產業鏈**（`#industry/<鏈>`）：
  - **產品剖析圖**：原創等角示意圖，每個零件對應一個供應鏈環節，點零件看供應商
  - **供應鏈關聯圖**：上游 → 下游。線越粗依存度越高；虛線＝委外、點虛線＝終端指定料號、
    灰線＝設備／材料、虛線框＝外商、「?」＝還沒建立上下游關聯
  - **環節色標**：點任一個，同色的一起亮，下方成分股同步篩選
  - 點關聯圖上的公司 → 右側展開它的產業關係（不跳頁）
- **個股頁**（`#stock/<代號>`）：K 線 → 多週期判讀 → 總覽／營收／獲利／除權息／籌碼／基本資料／公告·新聞 → 產業鏈位置

## `#themes` 題材熱度

市場炒作的敘事單位。**跟族群不同**：
- 族群是**產業鏈位置**，一檔股票的量能會依所屬族群數平均拆分（避免灌水）
- 題材是**故事**，一檔可以同時是 AI、CoWoS、矽光子；量能**不拆分**，
  因為題材熱度就是要看「多少錢在追這個故事」，重複計算是刻意的

## `#season` 季節性

某個月份歷史上漲的機率與幅度。**這是統計不是預測**，樣本不足會留白。

## `#market` 市場明細

總覽上方那排數字的完整名單（漲跌家數、站上均線、今日候選…）。

## 判斷模組

| 模組 | 在哪些頁面出現 | 算什麼 |
|---|---|---|
| **M1 資金面** | 總覽、資金流向 | 族群成交值佔比變化、輪動時鐘、桑基圖 |
| **M2 基本面** | 總覽、個股頁 | 月營收動能、同族群估值分位。**營收 YoY 超過 100% 會標示可能是併購或一次性** |
| **M3 技術面** | 個股頁、今日候選 | MA / MACD / RSI / KD / ATR / SMC。**指標自己算，不用 TA-Lib** |
| **M4 事件面** | 今日事件、公告·新聞 | 重大訊息（公司自己公告的）、新聞、除權息、季節性 |

**新聞和重大訊息刻意分開**：新聞是媒體寫的，重大訊息是公司自己公告的。
要否決一筆進場靠的是後者（減資、解散、訴訟、重大處分、財報更正都在那裡）。
